# 9주차 – 함수

## 객관식

### 9-1
함수 선언(프로토타입)의 역할로 **옳은** 것은?

① 함수 본문을 실행한다  
② 컴파일 전에 함수의 존재·형식을 알려 준다  
③ main보다 반드시 뒤에 써야 한다  
④ 반환값이 없으면 선언할 수 없다  

### 9-2
값 전달(Call by Value)에 대한 설명으로 **옳은** 것은?

① 원본 변수가 함수 안에서 바뀐다  
② 매개변수는 원본의 복사본이다  
③ 반드시 포인터를 사용해야 한다  
④ 배열에는 사용할 수 없다  

### 9-3
아래 코드 실행 후 `num`의 값은?

```c
void change(int x) {
    x = 100;
}
int main() {
    int num = 10;
    change(num);
    // num = ?
}
```

### 9-4
지역변수와 전역변수에 대한 설명으로 **틀린** 것은?

① 지역변수는 함수가 끝나면 소멸한다  
② 전역변수는 모든 함수에서 접근할 수 있다  
③ 전역변수는 프로그램 시작 시 0으로 초기화된다  
④ 지역변수는 main 밖에서 선언한다  

### 9-5
아래 코드의 출력 결과는?

```c
#include <stdio.h>
int global = 100;
void func() { global = 200; }
int main() {
    printf("%d\n", global);
    func();
    printf("%d\n", global);
}
```

## 프로그래밍

### 9-6
정수 **2개**를 입력받아 **최댓값**을 반환하는 함수 `max(int a, int b)` 를 작성하고, `main`에서 결과를 출력하세요.

```
입력: 15 28
출력: 최댓값: 28
```

### 9-7
정수 **5개**를 입력받아 배열에 저장하고, **평균**(소수점 2자리)을 계산하는 함수 `double average(int arr[], int size)` 를 작성하세요.

```
입력: 10 20 30 40 50
출력: 평균: 30.00
```

### 9-8
정수 **n**(1~10)을 입력받아 **n! (팩토리얼)** 을 계산하는 함수 `int factorial(int n)` 을 작성하세요.

```
입력: 5
출력: 120
```

### 9-9
정수 **5개**를 입력받아 **합계**를 구하는 함수 `int sumArray(int arr[], int size)` 를 작성하세요.

```
입력: 10 20 30 40 50
출력: 합계: 150
```

### 9-10
두 정수 **x, y**를 입력받아 **값을 교환**하는 함수 `void swap(int *a, int *b)` 를 작성하세요. (포인터 사용)

```
입력: 10 20
출력:
교환 전: x=10, y=20
교환 후: x=20, y=10
```

### 9-11
정수 **n**을 입력받아 **1부터 n까지의 합**을 구하는 함수 `int sumToN(int n)` 을 작성하세요.

```
입력: 10
출력: 55
```

# 10주차 – 포인터

## 객관식

### 10-1
포인터에 대한 설명으로 **옳은** 것은?

① 변수의 값을 저장한다  
② 변수의 주소를 저장한다  
③ 배열과는 관계없다  
④ `*`는 주소 연산자이다  

### 10-2
`int a = 10; int *p = &a;` 일 때, **같은 값**을 가리키는 조합은?

① `a` 와 `p`  
② `&a` 와 `*p`  
③ `a` 와 `*p`  
④ `&a` 와 `p`  

### 10-3
아래 코드 실행 후 `a`의 값은?

```c
int a = 10;
int *p = &a;
*p = 20;
```

### 10-4
`int arr[5] = {1, 2, 3, 4, 5}; int *p = arr;` 일 때, `*(p + 2)` 의 값은?

### 10-5
아래 코드의 출력 결과는?

```c
#include <stdio.h>
int main() {
    int a = 5, b = 10;
    int *p = &a;
    *p = *p + b;
    printf("%d %d\n", a, b);
}
```
