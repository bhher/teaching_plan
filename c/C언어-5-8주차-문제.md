# 5주차 – 조건문 (if / switch)

## 객관식

### 5-1
`switch` 문에서 `break`를 빼면 어떻게 되나?

① 컴파일 오류  ② 다음 case도 실행됨  ③ default만 실행  ④ 무한 루프  

### 5-2
점수 85일 때 아래 코드 출력은?

```c
if (score >= 90) printf("A");
else if (score >= 80) printf("B");
else printf("F");
```

### 5-3
`switch`에 넣을 수 **없는** 타입은?

① int  ② char  ③ float  ④ int 상수

|------|------|
