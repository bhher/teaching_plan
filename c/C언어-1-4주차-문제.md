# 1주차 – C 개요 & Hello World

③ Java처럼 가비지 컬렉션이 기본 제공된다

② 전처리 → 컴파일 → 어셈블 → 링크

```

# 3주차 – 입력 & 출력 (scanf)

## 객관식

### 3-1
정수 입력에 옳은 `scanf`는?

① `scanf("%d", num);`  
② `scanf("%d", &num);`  
③ `scanf("%f", &num);`  
④ `scanf("%d");`  

### 3-2
`scanf("%s", name);` 에서 `name` 앞에 `&`를 **안 쓰는** 이유는?

### 3-3
정수 입력 직후 문자 `%c` 입력 시 값이 이상하게 나올 때, 원인으로 적절한 것은?

① printf 오류  
② 입력 버퍼에 남은 `\n`  
③ return 0 누락  
④ main이 void  

---

## 프로그래밍

### 3-8
두 정수를 입력받아 **합**을 출력하세요.

```
입력 예: 15 27
출력 예: 합: 42
```

### 3-9
**나이(int)** 와 **키(float)** 를 한 줄에 입력받아 출력하세요.

```
입력 예: 20 175.5
출력 예: 나이: 20, 키: 175.5
```

### 3-10
**이름(문자열, 공백 없음)**, **나이**, **키**를 입력받아 한 줄로 출력하세요.

```

20
170.5
