# 9주차 정답

| 번호 | 정답 |
|------|------|
| 9-1 | ② 컴파일 전에 함수의 존재·형식을 알려 준다 |
| 9-2 | ② 매개변수는 원본의 복사본이다 |
| 9-3 | 10 (값 전달이므로 원본 변경 안 됨) |
| 9-4 | ④ 지역변수는 main 밖에서 선언한다 (함수 **안**에서 선언) |
| 9-5 | `100` 다음 줄 `200` |

### 9-6

```c
#include <stdio.h>

int max(int a, int b) {
    return (a > b) ? a : b;
}

int main() {
    int a, b;
    scanf("%d %d", &a, &b);
    printf("최댓값: %d\n", max(a, b));
    return 0;
}
```

### 9-7

```c
#include <stdio.h>

double average(int arr[], int size) {
    int i, sum = 0;
    for (i = 0; i < size; i++)
        sum += arr[i];
    return (double)sum / size;
}

int main() {
    int arr[5], i;
    for (i = 0; i < 5; i++)
        scanf("%d", &arr[i]);
    printf("평균: %.2f\n", average(arr, 5));
    return 0;
}
```

### 9-8

```c
#include <stdio.h>

int factorial(int n) {
    int i, result = 1;
    for (i = 1; i <= n; i++)
        result *= i;
    return result;
}

int main() {
    int n;
    scanf("%d", &n);
    printf("%d\n", factorial(n));
    return 0;
}
```

### 9-10

```c
#include <stdio.h>

void swap(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

int main() {
    int x, y;
    scanf("%d %d", &x, &y);
    printf("교환 전: x=%d, y=%d\n", x, y);
    swap(&x, &y);
    printf("교환 후: x=%d, y=%d\n", x, y);
    return 0;
}
```

# 10주차 정답

| 번호 | 정답 |
|------|------|
| 10-1 | ② 변수의 주소를 저장한다 |
| 10-2 | ③ `a` 와 `*p` (둘 다 10) |
| 10-3 | 20 |
| 10-4 | 3 (`arr[2]` 와 같음) |
| 10-5 | `15 10` (`*p = 5 + 10` → a=15, b는 그대로) |

### 10-6

```c
#include <stdio.h>

void swap(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

int main() {
    int x, y;
    scanf("%d %d", &x, &y);
    printf("교환 전: %d %d\n", x, y);
    swap(&x, &y);
    printf("교환 후: %d %d\n", x, y);
    return 0;
}
```

### 10-7

```c
#include <stdio.h>

int findMax(int *arr, int size) {
    int i, max = arr[0];
    for (i = 1; i < size; i++) {
        if (arr[i] > max)
            max = arr[i];
    }
    return max;
}

int main() {
    int arr[5], i;
    for (i = 0; i < 5; i++)
        scanf("%d", &arr[i]);
    printf("최댓값: %d\n", findMax(arr, 5));
    return 0;
}
```

### 10-8

```c
#include <stdio.h>

void printReverse(int *arr, int size) {
    int i;
    for (i = size - 1; i >= 0; i--)
        printf("%d ", arr[i]);
    printf("\n");
}

int main() {
    int arr[5], i;
    for (i = 0; i < 5; i++)
        scanf("%d", &arr[i]);
    printReverse(arr, 5);
    return 0;
}
```

### 10-10

```c
#include <stdio.h>

int main() {
    int arr[5], i;
    int *p = arr;

    for (i = 0; i < 5; i++)
        scanf("%d", &arr[i]);

    for (i = 0; i < 5; i++)
        printf("%d ", *(p + i));
    printf("\n");

    return 0;
}
```

### 10-11

```c
#include <stdio.h>

int main() {
    int n, arr[5], i, count = 0;
    int *p = arr;

    scanf("%d", &n);
    for (i = 0; i < 5; i++)
        scanf("%d", &arr[i]);

    for (i = 0; i < 5; i++) {
        if (*(p + i) == n)
            count++;
    }
    printf("%d\n", count);

    return 0;
}
```

## 핵심 정리

| 주차 | 핵심 |
|------|------|
| 9주차 | 값 전달 = 복사본 / 참조 전달(포인터) = 원본 변경 가능 / 배열은 참조로 전달 |
| 10주차 | `&` 주소 / `*` 역참조 / `arr[i]` == `*(arr + i)` / 포인터로 함수 매개변수 전달 |
