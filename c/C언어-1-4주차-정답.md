# 1주차 정답

| 번호 | 정답 |
|------|------|
| 1-1 | ③ (C는 수동 메모리 관리, GC 없음) |
| 1-2 | ② 전처리 → 컴파일 → 어셈블 → 링크 |
| 1-3 | ③ (`A` 한 줄, `B` 한 줄, `C` 한 줄 → 3줄) |
| 1-4 | `#include <stdio.h>` |

### 1-5

```c
#include <stdio.h>

int main() {
    printf("홍길동\n");
    return 0;
}
```

### 1-6

```c
#include <stdio.h>

int main() {
    printf("안녕하세요\n");
    printf("C 언어를 배워봅시다!\n");
    return 0;
}
```

### 1-7
`hello.exe` (Windows) / `-o` 뒤에 지정한 실행 파일 이름

# 2주차 정답

| 번호 | 정답 |
|------|------|
| 2-1 | `int` |
| 2-2 | ② 3.14 |
| 2-3 | ③ |
| 2-4 | 1문자 (문자 상수) |

### 2-5

```c
#include <stdio.h>

int main() {
    int age = 20;
    float height = 170.5f;
    char grade = 'A';

    printf("나이: %d\n", age);
    printf("키: %.1f\n", height);
    printf("등급: %c\n", grade);
    return 0;
}
```

### 2-6

```c
#include <stdio.h>

int main() {
    int num1 = 10, num2 = 20;
    printf("합: %d\n", num1 + num2);
    printf("차: %d\n", num1 - num2);
    printf("곱: %d\n", num1 * num2);
    printf("몫: %d\n", num1 / num2);
    return 0;
}
```

### 2-7

```c
#include <stdio.h>

int main() {
    float pi = 3.14159f;
    printf("소수점 2자리: %.2f\n", pi);
    printf("소수점 4자리: %.4f\n", pi);
    return 0;
}
```

# 3주차 정답

| 번호 | 정답 |
|------|------|
| 3-1 | ② |
| 3-2 | `%s`는 **문자 배열(주소)** 를 받으며, 배열 이름 자체가 주소이므로 `&` 불필요 |
| 3-3 | ② 입력 버퍼에 남은 `\n` |

### 3-8

```c
#include <stdio.h>

int main() {
    int a, b;
    scanf("%d %d", &a, &b);
    printf("합: %d\n", a + b);
    return 0;
}
```

### 3-9

```c
#include <stdio.h>

int main() {
    int age;
    float height;
    scanf("%d %f", &age, &height);
    printf("나이: %d, 키: %.1f\n", age, height);
    return 0;
}
```

### 3-10

```c
#include <stdio.h>

int main() {
    char name[20];
    int age;
    float height;

    scanf("%s", name);
    scanf("%d", &age);
    scanf("%f", &height);

    printf("%s (%d세, %.1fcm)\n", name, age, height);
    return 0;
}
```

# 4주차 정답

| 번호 | 정답 |
|------|------|
| 4-1 | `3` |
| 4-2 | `1` |
| 4-3 | `0` (거짓) |
| 4-4 | ② a=11, b=10 (후위: b에 10 대입 후 a 증가) |
| 4-5 | age≥18 **그리고** score≥60 동시 만족 |

### 4-11

```c
#include <stdio.h>

int main() {
    int a = 10, b = 3;
    printf("a + b = %d\n", a + b);
    printf("a - b = %d\n", a - b);
    printf("a * b = %d\n", a * b);
    printf("a / b = %d\n", a / b);
    printf("a %% b = %d\n", a % b);
    return 0;
}
```

### 4-12

```c
#include <stdio.h>

int main() {
    int a, b;
    scanf("%d %d", &a, &b);
    printf("%d + %d = %d\n", a, b, a + b);
    printf("%d - %d = %d\n", a, b, a - b);
    printf("%d * %d = %d\n", a, b, a * b);
    printf("%d / %d = %d\n", a, b, a / b);
    printf("%d %% %d = %d\n", a, b, a % b);
    return 0;
}
```

### 4-13

```c
#include <stdio.h>

int main() {
    int age;
    scanf("%d", &age);
    if (age >= 18)
        printf("성인\n");
    else
        printf("미성년\n");
    return 0;
}
```

### 4-14

```c
#include <stdio.h>

int main() {
    int score;
    scanf("%d", &score);
    if (score >= 60)
        printf("합격\n");
    else
        printf("불합격\n");
    return 0;
}
```

### 4-15

```c
#include <stdio.h>

int main() {
    float r;
    scanf("%f", &r);
    printf("넓이: %.2f\n", 3.14159f * r * r);
    return 0;
}
```

입력 `5` → 넓이: 78.54
