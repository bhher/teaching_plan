## 해설

### 1번 ②
`viewport` 메타 태그가 있어야 모바일에서 화면 너비에 맞게 표시됩니다.

### 2번 ②
모바일 우선은 **작은 화면 CSS를 기본**으로 두고, `min-width`로 큰 화면 스타일을 추가합니다.

### 3번 ②
`min-width: 768px` → 768px **이상**일 때 적용됩니다.  
(`max-width`가 이하일 때입니다.)

### 4번 ②
`border-box`는 padding/border를 width 안에 포함해, `%` 너비 계산이 쉬워집니다.

### 5번 ②
`grid-template-columns: repeat(3, 1fr);` → 같은 비율의 3열입니다.

### 6번 ③
`content-box`(기본값)에서는 padding이 너비 밖으로 더해져 50%+50%가 100%를 넘어 **줄바꿈**됩니다.

### 7번 ①
버튼 클릭 → `active` 클래스 토글 → CSS로 메뉴 표시가 일반적인 패턴입니다.

### 8번 ②
사이드바 `flex: 0 0 250px`(고정), 본문 `flex: 1`(나머지)입니다.

### 9번 ④
④가 틀립니다. `min-width`는 **이상**에서 적용되고, **미만만** 적용되는 것은 `max-width`입니다.

### 10번 ②
모바일 우선이므로 **1열 → 2열 → 3열**로 확장하는 흐름이 자연스럽습니다.
