# ex01 정답

| 문제 | 정답 | 해설 |
|------|------|------|
| 1 | ② | HTML5는 `<!DOCTYPE html>` |
| 2 | ② | head=설정/메타, body=화면 본문 |
| 3 | ③ | `div`는 의미 없는 상자. 시맨틱은 header, nav, main, article, footer 등 |
| 4 | ② | `h1`이 가장 상위(중요) 제목 |
| 5 | ② | `target="_blank"` |
| 6 | ② | `alt`는 대체 텍스트 (접근성) |
| 7 | `<title>` | `<head>` 안에 작성 |
| 8 | `<strong>`, `<em>` | strong=중요, em=강조 |

# ex02 정답

| 문제 | 정답 | 해설 |
|------|------|------|
| 9 | ② | 순서 없음 = `ul` + `li` |
| 10 | ② | 정의 목록 = `dl` > `dt`(용어) + `dd`(설명) |
| 11 | ② | 헤더 셀은 `th`, 데이터 셀은 `td` |
| 12 | ② | 가로는 `colspan`, 세로는 `rowspan` |

| 14 | ② | radio=하나만, checkbox=여러 개 |
| 15 | ② | 외부 영상은 주로 `iframe` |
| 16 | `required` | 필수 입력 |

# ex03 정답

| 문제 | 정답 | 해설 |
|------|------|------|
| 17 | ② | `<link rel="stylesheet" href="...">` |
| 18 | ③ | 인라인 > 내부 ≈ 외부 (구체성에 따라 다름). 보통 인라인이 가장 강함 |
| 19 | ② | 클래스는 `.이름`, ID는 `#이름` |
| 20 | ② | 공백(후손) = 안쪽 모든 해당 태그 |
| 21 | ② | `text-align: center;` |
| 22 | ② | `contain`=전체 보임, `cover`=꽉 채움(잘릴 수 있음) |
| 23 | `border-radius` | 둥근 모서리 |
| 24 | `700` 또는 `bold` | 둘 다 굵게 |

# ex04 정답

| 문제 | 정답 | 해설 |
|------|------|------|
| 25 | ② | padding=안쪽, margin=바깥 |
| 26 | ② | border-box는 padding+border를 width에 포함 (권장) |
| 27 | ③ | inline은 같은 줄, 크기 지정 어려움 |
| 28 | ① | inline-block = 같은 줄 + 크기 지정 가능 |
| 29 | ② | none=공간 제거, hidden=투명하지만 자리 유지 |
| 30 | ② | clearfix / overflow로 부모 높이 복구 |
| 31 | `margin`, `padding` | 바깥 / 안쪽 |
| 32 | `F12` | 개발자 도구 |

# ex05 정답

| 문제 | 정답 | 해설 |
|------|------|------|
| 33 | ② | `display: flex;` |
| 34 | ② | 주축 = `justify-content` |
| 35 | ② | 교차축 = `align-items` |
| 36 | ② | `flex-direction: column;` |
| 37 | ② | `flex-wrap: wrap;` |
| 38 | ② | grow 1, shrink 1, basis 300px |

## 코드 예시 (자주 쓰는 정답 패턴)

### ex01 — 기본 구조

```html
<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <title>문서 제목</title>
</head>
<body>
  <header>...</header>
  <nav>...</nav>
  <main>...</main>
  <footer>...</footer>
</body>
</html>
```

### ex02 — 폼 label 연결

```html
<label for="email">이메일</label>
<input type="email" id="email" required>
```

### ex03 — 외부 CSS + 클래스

```html
<link rel="stylesheet" href="style.css">
```

```css
.box {
  color: #333;
  background-color: #fff;
  border-radius: 8px;
}
```

### ex04 — border-box

```css
* {
  box-sizing: border-box;
}
```

### ex05 — Flex 헤더 / 카드

```css
.header {
  display: flex;
  justify-content: space-between;
  align-items: center;
}

.card-list {
  display: flex;
  flex-wrap: wrap;
  gap: 20px;
}

.card {
  flex: 1 1 300px;
}
```
