## 1. 전체 구조

```text
header   → 로고 + 햄버거 메뉴 + 내비게이션
main
  ├─ hero          → 큰 타이틀 영역
  ├─ card-grid     → 카드 3개 (반응형 열 수 변경)
  └─ content-layout → 사이드바 + 본문
footer   → 회사정보 / 링크 / SNS
```

**핵심 개념:** 작은 화면용 CSS를 먼저 쓰고, `@media (min-width: …)`로 큰 화면에 스타일을 추가합니다.

---

## 2. 기본 설정

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```

- 모바일에서 화면 너비에 맞게 보이게 하는 **필수 설정**입니다.

```css
* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}
```

- `box-sizing: border-box` → padding/border를 너비 안에 포함
- 반응형에서 `width: 50%` 계산이 꼬이지 않게 도와줍니다.

## 3. 헤더 / 햄버거 메뉴

### 모바일 (기본)

```css
.header-container {
  display: flex;
  flex-direction: column; /* 세로 배치 */
}

nav {
  display: none; /* 메뉴 숨김 */
}

nav.active {
  display: flex; /* 버튼 클릭 시 표시 */
}
```

- 작은 화면에서는 메뉴를 숨기고 **햄버거 버튼(☰)**으로 엽니다.

### 태블릿 이상 (768px~)

```css
@media (min-width: 768px) {
  .header-container {
    flex-direction: row;
    justify-content: space-between;
    align-items: center;
  }

  .menu-toggle {
    display: none; /* 햄버거 숨김 */
  }

  nav {
    display: flex;
    flex-direction: row; /* 가로 메뉴 */
  }
}
```

| 화면 | 메뉴 표시 |
|------|-----------|
| 모바일 | 햄버거 버튼 → 클릭 시 세로 메뉴 |
| 태블릿 이상 | 가로 메뉴 항상 표시 |

## 4. 히어로 섹션

```css
.hero {
  background: linear-gradient(...);
  padding: 40px 20px;
  text-align: center;
}

@media (min-width: 768px) {
  .hero {
    padding: 60px 40px; /* 여백 확대 */
  }
  .hero h1 {
    font-size: 3em; /* 제목 확대 */
  }
}
```

- 모바일: 적당한 패딩, 작은 제목
- 태블릿 이상: 여백·글자 크기를 키워 임팩트를 줍니다.

## 5. 카드 그리드

### 기본 (모바일)

```css
.card-grid {
  display: grid;
  grid-template-columns: 1fr; /* 1열 */
  gap: 20px;
}
```

### 화면별 열 수

```css
/* 480px 이상 → 2열 */
@media (min-width: 480px) {
  .card-grid {
    grid-template-columns: repeat(2, 1fr);
  }
}

/* 768px 이상 → 2열 (중복, 생략 가능) */
@media (min-width: 768px) {
  .card-grid {
    grid-template-columns: repeat(2, 1fr);
  }
}

/* 1024px 이상 → 3열 */
@media (min-width: 1024px) {
  .card-grid {
    grid-template-columns: repeat(3, 1fr);
  }
}
```

| 너비 | 열 수 |
|------|------|
| ~479px | 1열 |
| 480px ~ 1023px | 2열 |
| 1024px~ | 3열 |

### 왜 768에도 2열을 또 썼나?

`min-width: 480px`만 있어도 768에서는 이미 2열이 적용됩니다.  
768 미디어쿼리의 `repeat(2, 1fr)`는 **같은 값을 다시 적은 중복**입니다.  
실무에서는 빼도 됩니다.

```css
/* 권장 (간결한 버전) */
.card-grid { grid-template-columns: 1fr; }

@media (min-width: 480px) {
  .card-grid { grid-template-columns: repeat(2, 1fr); }
}

@media (min-width: 1024px) {
  .card-grid { grid-template-columns: repeat(3, 1fr); }
}
```

### Grid vs Flex (카드 배치)

| 방식 | 특징 |
|------|------|
| **Grid** (`repeat(3, 1fr)`) | 열 수를 한 줄로 명확히 지정, gap 계산이 쉬움 |
| **Flex** (`flex: 0 0 calc(...)`) | gap을 직접 빼서 `calc` 해야 함 |

이 예제는 Grid를 써서 열 전환이 단순합니다.

## 6. 사이드바 레이아웃

### 모바일 (기본)

```css
.content-layout {
  display: flex;
  flex-direction: column; /* 위→아래 */
}
```

순서: 사이드바 → 메인 콘텐츠 (세로 쌓임)

### 태블릿 이상 (768px~)

```css
@media (min-width: 768px) {
  .content-layout {
    flex-direction: row; /* 가로 배치 */
  }

  .sidebar {
    flex: 0 0 250px; /* 고정 너비 250px */
  }

  .main-content {
    flex: 1; /* 나머지 공간 차지 */
  }
}
```

| 속성 | 의미 |
|------|------|
| `flex: 0 0 250px` | 안 늘어나고, 안 줄어들고, 기본 너비 250px |
| `flex: 1` | 남은 공간을 모두 사용 |

## 7. 푸터

```css
.footer-content {
  display: flex;
  flex-direction: column; /* 모바일: 세로 */
  gap: 30px;
}

@media (min-width: 768px) {
  .footer-content {
    flex-direction: row; /* 태블릿: 가로 */
    justify-content: space-around;
  }
}
```

회사 정보 / 빠른 링크 / SNS 3블록이  
모바일에서는 세로, 넓은 화면에서는 가로로 나란히 배치됩니다.

## 8. JavaScript 메뉴 토글

```html
<button class="menu-toggle" onclick="toggleMenu()">☰</button>
<nav id="nav">...</nav>
```

```js
function toggleMenu() {
  const nav = document.getElementById('nav');
  nav.classList.toggle('active');
}
```

1. 버튼 클릭
2. `nav`에 `active` 클래스 추가/제거
3. CSS `nav.active { display: flex; }`로 메뉴 표시

태블릿 이상에서는 햄버거 버튼이 `display: none`이라 이 JS는 사실상 쓰이지 않습니다.

## 9. 브레이크포인트 정리

| 구간 | 주요 변화 |
|------|-----------|
| **기본 (~479px)** | 1열 카드, 세로 헤더, 햄버거 메뉴, 세로 사이드바/푸터 |
| **480px~** | 카드 2열 |
| **768px~** | 가로 헤더 메뉴, 히어로 확대, 사이드바 옆 배치, 푸터 가로 |
| **1024px~** | 카드 3열 |

### 모바일 우선 흐름

```text
작은 화면 CSS (기본)
    ↓
@media (min-width: 480px)  추가/변경
    ↓
@media (min-width: 768px)  추가/변경
    ↓
@media (min-width: 1024px) 추가/변경
```

큰 화면용 규칙을 **덮어쓰는** 방식이므로,  
기본 스타일을 모바일 기준으로 잡는 것이 중요합니다.

## 10. 학습 체크리스트

- [ ] `viewport` 메타 태그의 역할을 안다
- [ ] `box-sizing: border-box`가 왜 필요한지 안다
- [ ] 모바일에서 햄버거 메뉴가 어떻게 열리는지 안다 (`active` 클래스)
- [ ] `min-width` 미디어쿼리의 누적 적용을 이해한다
- [ ] Grid로 1열 → 2열 → 3열 전환을 할 수 있다
- [ ] Flex로 사이드바(`0 0 250px`) + 본문(`flex: 1`) 레이아웃을 만들 수 있다
- [ ] 768px 카드 2열 선언이 중복임을 안다
