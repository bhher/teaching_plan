# 반응형 웹 객관식 문제 10문항

모바일 우선, 미디어쿼리, Flex/Grid, viewport 관련 문제입니다.  
정답은 [반응형-웹-객관식-정답.md](./반응형-웹-객관식-정답.md)를 참고하세요.

## 1번

반응형 웹에서 모바일 기기 화면에 맞게 표시하려면 HTML에 어떤 태그가 필요한가?

① `<meta charset="UTF-8">`  
② `<meta name="viewport" content="width=device-width, initial-scale=1.0">`  
③ `<link rel="stylesheet">`  
④ `<meta name="description">`

---

## 2번

모바일 우선(Mobile First) 설계의 올바른 설명은?

① 큰 화면 CSS를 먼저 작성하고, 작은 화면용으로 줄여 나간다.  
② 작은 화면 CSS를 먼저 작성하고, `min-width`로 큰 화면에 스타일을 추가한다.  
③ 모든 화면에서 같은 CSS만 사용한다.  
④ 모바일에서는 JavaScript만으로 레이아웃을 바꾼다.

## 3번

다음 미디어쿼리의 의미로 옳은 것은?

```css
@media (min-width: 768px) {
  .box { width: 50%; }
}
```

① 화면 너비가 768px **이하**일 때만 적용  
② 화면 너비가 768px **이상**일 때 적용  
③ 화면 높이가 768px일 때만 적용  
④ 모든 화면에서 항상 적용

## 4번

`box-sizing: border-box`를 사용하는 이유로 가장 적절한 것은?

① 글자 색을 바꾼다.  
② padding과 border를 너비(width) 안에 포함시켜 크기 계산을 쉽게 한다.  
③ 요소를 화면 가운데 정렬한다.  
④ Flex 레이아웃을 자동으로 만든다.

## 5번

CSS Grid에서 카드 3열을 만드는 올바른 코드는?

① `grid-template-columns: 3;`  
② `grid-template-columns: repeat(3, 1fr);`  
③ `display: flex-3;`  
④ `columns: 3fr;`

## 6번

다음 상황에서 카드가 2열로 안 나란히 배치되는 가장 원인은?

```css
.card-list { display: flex; flex-wrap: wrap; gap: 16px; }
.card { flex: 1 1 calc(50% - 8px); padding: 16px; }
/* * { box-sizing 설정 없음 } */
```

① `gap`을 써서  
② `flex-wrap`을 써서  
③ `box-sizing: border-box`가 없어 padding 때문에 너비가 넘쳐서  
④ 카드 색깔 때문에

## 7번

햄버거 메뉴(모바일)에서 메뉴를 보이게 하는 일반적인 방법은?

① `nav`에 `active` 클래스를 토글하고, CSS에서 `nav.active { display: flex; }`  
② `header`의 배경색만 바꾼다.  
③ `viewport`를 삭제한다.  
④ `float: left`만 사용한다.

## 8번

Flex에서 사이드바를 고정 너비 250px, 본문은 나머지 공간을 차지하게 하려면?

①  
```css
.sidebar { flex: 1; }
.main { flex: 0 0 250px; }
```

②  
```css
.sidebar { flex: 0 0 250px; }
.main { flex: 1; }
```

③  
```css
.sidebar { width: 100%; }
.main { width: 100%; }
```

④  
```css
.sidebar { float: right; }
.main { float: left; }
```

## 9번

`min-width` 미디어쿼리에 대한 설명으로 **틀린** 것은?

① 지정한 너비 **이상**에서 적용된다.  
② 모바일 우선 방식과 잘 맞는다.  
③ 480px 규칙이 있으면 768px에서도 그 규칙이 계속 적용될 수 있다.  
④ 지정한 너비 **미만**에서만 적용된다.

## 10번

다음 중 반응형 레이아웃 전환 순서로 가장 자연스러운 것은? (모바일 우선)

① 3열 → 2열 → 1열  
② 1열 → 2열 → 3열  
③ 항상 3열 고정  
④ Grid만 사용하고 Flex는 사용 금지
