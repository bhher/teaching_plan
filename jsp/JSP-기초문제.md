## 실습 문제

> Dynamic Web Project를 만들고 `WebContent` 아래에 JSP를 작성한 뒤 Tomcat으로 실행하세요.

### 실습 ① Hello JSP ⭐

**파일:** `hello.jsp`

**요구사항**

1. `page` 지시자로 UTF-8 설정  
2. 제목: `안녕하세요, JSP!`  
3. 표현식으로 현재 날짜/시간 출력 (`new java.util.Date()`)  
4. 스크립틀릿으로 변수 `name = "본인이름"` 선언 후 화면에 출력  

**완성 모습 예시**

```text
안녕하세요, JSP!
접속 시각: Thu Oct 01 ...
이름: 홍길동
```

---

### 실습 ② 구구단 출력 ⭐

**파일:** `gugudan.jsp`

**요구사항**

1. 스크립틀릿 `for` 문으로 **2단**만 출력  
2. 각 줄: `2 x 1 = 2` 형식  
3. HTML `<br>` 또는 `<ul><li>` 사용  

**보너스:** 2단~9단을 표(`<table>`)로 출력

---

### 실습 ③ 짝수 / 홀수 판별 ⭐

**파일:** `oddEven.jsp`

**요구사항**

1. 스크립틀릿에서 `int num = 17;` (원하는 숫자로 변경 가능)  
2. `if` / `else`로 짝수면 `짝수입니다`, 홀수면 `홀수입니다` 출력  
3. 결과는 **표현식**으로 화면에 표시  

---

### 실습 ④ 합계 구하기 ⭐⭐

**파일:** `sum.jsp`

**요구사항**

1. 1부터 100까지 합을 스크립틀릿으로 계산  
2. 결과: `1부터 100까지의 합 = 5050`  
3. (선택) 선언부(`<%! %>`)에 `sum(int n)` 메서드를 만들고 호출  

---

### 실습 ⑤ 점수 → 학점 ⭐⭐

**파일:** `grade.jsp`

**요구사항**

1. `int score = 85;`  
2. 아래 기준으로 학점 출력  

| 점수 | 학점 |
|------|------|
| 90 이상 | A |
| 80 이상 | B |
| 70 이상 | C |
| 60 이상 | D |
| 그 외 | F |

3. 출력 예: `점수: 85 / 학점: B`

---

### 실습 ⑥ 자기소개 카드 ⭐⭐

**파일:** `profile.jsp`

**요구사항**

1. 이름, 나이, 취미를 스크립틀릿 변수로 저장  
2. HTML로 카드처럼 보이게 출력 (간단한 CSS 가능)  
3. 나이가 20 이상이면 `성인`, 미만이면 `미성년`을 조건문으로 표시  

---

### 실습 ⑦ 간단 입력 폼 ⭐⭐

**파일:** `form.jsp` , `formResult.jsp`

**요구사항**

1. `form.jsp`  
   - 이름(`name`), 나이(`age`) 입력  
   - `method="get"` , `action="formResult.jsp"`  
2. `formResult.jsp`  
   - `request.getParameter("name")`, `request.getParameter("age")` 로 받기  
   - `OOO님, 나이는 N세입니다.` 출력  
3. 한글이 깨지면 결과 페이지 상단에  
   `request.setCharacterEncoding("UTF-8");`  
   (POST일 때) 또는 GET이면 Tomcat/이클립스 UTF-8 설정을 확인  

---

### 실습 ⑧ include로 공통 헤더 ⭐⭐

**파일:** `header.jsp` , `main.jsp`

**요구사항**

1. `header.jsp` — 사이트 제목 / 메뉴 문구만 작성  
2. `main.jsp`에서  
   `<%@ include file="header.jsp" %>`  
   로 포함  
3. 본문에 `메인 페이지입니다` 출력  

---

## 제출 · 확인 체크리스트

- [ ] 모든 JSP에 `page` 지시자(UTF-8)가 있다  
- [ ] 표현식 `<%= %>` 안에 세미콜론(`;`)을 쓰지 않았다  
- [ ] 반복/조건은 스크립틀릿에서 처리했다  
- [ ] Tomcat에서 브라우저로 실행해 결과를 확인했다  
- [ ] (폼) 파라미터가 null이 아닌지 확인해 보았다
