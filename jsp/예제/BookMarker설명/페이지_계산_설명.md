# 게시판 페이지 계산 설명

BoardController와 BoardDAO에서 사용하는 **페이징(Pagination)** 로직을 설명합니다.

---

## 1. 사용 변수

| 변수 | 의미 | 예시 |
|------|------|------|
| `pageNum` | 현재 페이지 번호 | 1, 2, 3, ... |
| `limit` | 페이지당 글 개수 | 5 (LISTCOUNT) |
| `total_record` | 전체 글 개수 | DB에서 조회 |
| `total_page` | 전체 페이지 수 | 계산값 |

---

## 2. BoardController의 total_page 계산

```java
int pageNum = 1;
int limit = 5;  // LISTCOUNT

int total_record = dao.getListCount(items, text);  // 예: 13건
boardlist = dao.getBoardList(pageNum, limit, items, text);

int total_page;

if (total_record % limit == 0) {     
    total_page = total_record / limit;
} else {
    total_page = total_record / limit;
    total_page = total_page + 1; 
}
```

### 계산 예시

| total_record | limit | total_record % limit | total_page |
|--------------|-------|----------------------|------------|
| 13 | 5 | 3 ≠ 0 | 13/5 + 1 = **3** |
| 15 | 5 | 0 | 15/5 = **3** |
| 5 | 5 | 0 | 5/5 = **1** |
| 1 | 5 | 1 ≠ 0 | 1/5 + 1 = **1** |

### 공식

```
total_page = (total_record + limit - 1) / limit
```

또는

```
total_page = total_record % limit == 0 
    ? total_record / limit 
    : total_record / limit + 1
```

- **나누어떨어지면**: `total_record / limit`
- **나머지가 있으면**: `total_record / limit + 1`

---

## 3. BoardDAO의 start, index 계산

```java
int start = (page - 1) * limit;   // 시작 행 위치 (0-based)
int index = start + 1;             // ResultSet.absolute()는 1-based
```

### 예시 (limit = 5)

| pageNum | start | index | 가져오는 글 |
|---------|-------|-------|-------------|
| 1 | (1-1)*5 = 0 | 1 | 1~5번째 글 |
| 2 | (2-1)*5 = 5 | 6 | 6~10번째 글 |
| 3 | (3-1)*5 = 10 | 11 | 11~15번째 글 |

### 그림

```
전체 13건, limit=5

[1페이지]  start=0, index=1  →  글 1, 2, 3, 4, 5
[2페이지]  start=5, index=6  →  글 6, 7, 8, 9, 10
[3페이지]  start=10, index=11 → 글 11, 12, 13
```

## 4. BoardDAO.getBoardList() 동작

```java
rs = pstmt.executeQuery();  // ORDER BY num DESC (최신순)

while (rs.absolute(index)) {   // index번째 행으로 이동
    // BoardDTO에 담아 list에 추가
    list.add(board);
    
    if (index < (start + limit) && index <= total_record)
        index++;
    else
        break;
}
```

- `ResultSet.absolute(index)`: `index`번째 행으로 이동 (1부터 시작)
- `start + limit`: 해당 페이지의 마지막 행 번호
- `index`를 1씩 증가시키며 `limit`개만큼 읽음

## 5. list.jsp에서 페이지 링크

```jsp
<c:forEach var="i" begin="1" end="<%=total_page%>">
    <a href="./BoardListAction.do?pageNum=${i}"> [${i}] </a>
</c:forEach>
```

- 1 ~ total_page까지 링크 생성
- `pageNum=${i}`로 클릭한 페이지 번호 전달

---

## 6. 전체 흐름 요약

```
1. 사용자: BoardListAction.do?pageNum=2 클릭

2. BoardController
   - pageNum = 2
   - total_record = 13 (DB)
   - total_page = 3 (13/5 + 1)

3. BoardDAO.getBoardList(2, 5, ...)
   - start = (2-1)*5 = 5
   - index = 6
   - 6~10번째 글 조회

4. list.jsp
   - [1] [2] [3] 링크 표시
   - 2페이지가 굵게 표시
```

## 7. 참고: Math.floor() 부분

```java
Math.floor(total_page);  // 사용되지 않음
```

- `total_page`는 `int`라서 소수점이 없음
- `Math.floor()` 결과를 변수에 넣지 않아 실제로는 아무 효과 없음
- 삭제해도 동작에는 영향 없음
