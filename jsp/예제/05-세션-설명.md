# 📝 05-세션 예제 해설

## 📋 파일 개요

이 예제는 JSP에서 세션을 활용한 로그인/로그아웃 기능을 구현합니다. 세션의 생성, 관리, 무효화를 학습할 수 있습니다.

**파일 구성:**
- `login.jsp`: 로그인 페이지
- `login_process.jsp`: 로그인 처리
- `main.jsp`: 메인 페이지 (로그인 후)
- `logout.jsp`: 로그아웃 처리
- `session_test.jsp`: 세션 테스트 페이지

---

## 🎯 학습 목표

- 세션의 개념 이해
- 로그인/로그아웃 구현
- 세션 정보 확인
- 세션 속성 관리
- 세션 보안

## 📖 login.jsp 상세 설명

### 1. 로그인 폼

```jsp
<form action="login_process.jsp" method="post">
    <div class="form-group">
        <label for="id">아이디:</label>
        <input type="text" id="id" name="id" required>
    </div>
    <div class="form-group">
        <label for="pw">비밀번호:</label>
        <input type="password" id="pw" name="pw" required>
    </div>
    <button type="submit">로그인</button>
</form>
```

**설명:**
- `method="post"`: 비밀번호를 URL에 표시하지 않음
- `required`: 필수 입력 속성
- `action="login_process.jsp"`: 로그인 처리 페이지로 전송

---

### 2. 에러 메시지 표시

```jsp
<%
    String error = request.getParameter("error");
    if ("1".equals(error)) {
%>
    <div class="error">아이디 또는 비밀번호가 틀렸습니다.</div>
<%
    }
%>
```

**설명:**
- URL 파라미터로 에러 전달: `login.jsp?error=1`
- 로그인 실패 시 에러 메시지 표시

**다른 방법:**
```jsp
<c:if test="${param.error == '1'}">
    <div class="error">로그인 실패</div>
</c:if>
```

## 📖 login_process.jsp 상세 설명

### 1. 파라미터 받기

```jsp
<%
    String id = request.getParameter("id");
    String pw = request.getParameter("pw");
%>
```

**설명:**
- 폼에서 전송된 아이디와 비밀번호 받기

---

### 2. 인증 처리

```jsp
if ("admin".equals(id) && "1234".equals(pw)) {
    // 로그인 성공
    session.setAttribute("loginId", id);
    session.setAttribute("loginTime", new java.util.Date());
    session.setAttribute("loginCount", 1);
    
    response.sendRedirect("main.jsp");
} else {
    // 로그인 실패
    response.sendRedirect("login.jsp?error=1");
}
```

**설명:**
- 간단한 인증 (실제로는 DB에서 확인)
- 로그인 성공 시 세션에 정보 저장
- `response.sendRedirect()`: 페이지 이동

**보안 주의사항:**
```jsp
// 잘못된 예 (NullPointerException 가능)
if (id.equals("admin")) { ... }

// 올바른 예 (null 안전)
if ("admin".equals(id)) { ... }
```

---

### 3. 세션에 정보 저장

```jsp
session.setAttribute("loginId", id);
session.setAttribute("loginTime", new java.util.Date());
session.setAttribute("loginCount", 1);
```

**설명:**
- `setAttribute(name, value)`: 세션에 값 저장
- 다른 페이지에서 `getAttribute()`로 가져올 수 있음
- Object 타입으로 저장되므로 캐스팅 필요

## 📖 main.jsp 상세 설명

### 1. 로그인 체크

```jsp
<%
    String loginId = (String) session.getAttribute("loginId");
    if (loginId == null) {
        response.sendRedirect("login.jsp");
        return;
    }
%>
```

**설명:**
- 세션에 로그인 정보가 없으면 로그인 페이지로 리다이렉트
- **중요**: 보호된 페이지의 필수 코드

**패턴:**
```jsp
<%
    // 로그인 체크
    if (session.getAttribute("loginId") == null) {
        response.sendRedirect("login.jsp");
        return;  // 이후 코드 실행 방지
    }
    
    // 보호된 내용
%>
```

---

### 2. 세션 정보 표시

```jsp
<%
    java.util.Date loginTime = (java.util.Date) session.getAttribute("loginTime");
    Integer loginCount = (Integer) session.getAttribute("loginCount");
    if (loginCount == null) {
        loginCount = 1;
    }
%>
```

**설명:**
- 세션에서 저장된 정보 가져오기
- 타입 캐스팅 필요
- null 체크 필요

---

### 3. 세션 정보 출력

```jsp
<p>세션 ID: <%= session.getId() %></p>
<p>세션 생성 시간: <%= new java.util.Date(session.getCreationTime()) %></p>
<p>마지막 접근 시간: <%= new java.util.Date(session.getLastAccessedTime()) %></p>
<p>세션 유지 시간: <%= session.getMaxInactiveInterval() %>초</p>
```

**주요 메서드:**

| 메서드 | 반환 타입 | 설명 |
|--------|----------|------|
| `getId()` | String | 세션 고유 ID |
| `getCreationTime()` | long | 생성 시간 (밀리초) |
| `getLastAccessedTime()` | long | 마지막 접근 시간 |
| `getMaxInactiveInterval()` | int | 유지 시간 (초) |

## 📖 logout.jsp 상세 설명

### 세션 무효화

```jsp
<%
    session.invalidate();
    response.sendRedirect("login.jsp");
%>
```

**설명:**
- `invalidate()`: 세션 완전히 삭제
- 모든 세션 속성 제거
- 로그아웃 시 필수

**다른 방법:**
```jsp
<%
    // 특정 속성만 제거
    session.removeAttribute("loginId");
    
    // 또는 모든 속성 제거 후 무효화
    session.invalidate();
%>
```

## 📖 session_test.jsp 상세 설명

### 1. 세션에 값 추가

```jsp
<form action="session_test.jsp" method="post">
    <h3>세션에 값 추가</h3>
    <p>
        키: <input type="text" name="key" placeholder="키 입력">
        값: <input type="text" name="value" placeholder="값 입력">
        <button type="submit" name="action" value="add">추가</button>
    </p>
</form>
```

**처리:**
```jsp
<%
    String action = request.getParameter("action");
    if ("add".equals(action)) {
        String key = request.getParameter("key");
        String value = request.getParameter("value");
        if (key != null && value != null && !key.isEmpty() && !value.isEmpty()) {
            session.setAttribute(key, value);
        }
    }
%>
```

---

### 2. 세션에서 값 제거

```jsp
<form action="session_test.jsp" method="post">
    <h3>세션에서 값 제거</h3>
    <p>
        키: <input type="text" name="removeKey" placeholder="제거할 키 입력">
        <button type="submit" name="action" value="remove">제거</button>
    </p>
</form>
```

**처리:**
```jsp
<%
    if ("remove".equals(action)) {
        String removeKey = request.getParameter("removeKey");
        if (removeKey != null && !removeKey.isEmpty()) {
            session.removeAttribute(removeKey);
        }
    }
%>
```

### 3. 모든 세션 속성 표시

```jsp
<%
    java.util.Enumeration<String> sessionNames = session.getAttributeNames();
    boolean hasAttributes = false;
    while (sessionNames.hasMoreElements()) {
        hasAttributes = true;
        String attrName = sessionNames.nextElement();
        Object attrValue = session.getAttribute(attrName);
%>
    <div class="info-item">
        <span class="info-label"><%= attrName %>:</span>
        <span class="info-value"><%= attrValue %></span>
    </div>
<%
    }
    if (!hasAttributes) {
%>
    <p>세션에 저장된 값이 없습니다.</p>
<%
    }
%>
```

**설명:**
- `getAttributeNames()`: 모든 속성 이름 가져오기
- Enumeration으로 순회
- 디버깅에 유용

## 🔍 세션 개념 정리

### 1. 세션이란?

**정의:**
- 서버에 저장되는 사용자별 정보
- 브라우저가 닫히거나 타임아웃될 때까지 유지
- 쿠키와 함께 사용 (세션 ID는 쿠키에 저장)

**생명주기:**
```
사용자 접속
    ↓
세션 생성 (서버에서)
    ↓
세션 ID를 쿠키로 전송
    ↓
이후 요청마다 세션 ID 전송
    ↓
세션 타임아웃 또는 브라우저 종료
    ↓
세션 삭제
```

---

### 2. 세션 vs 쿠키

| 구분 | 세션 | 쿠키 |
|------|------|------|
| 저장 위치 | 서버 | 클라이언트 |
| 보안 | 높음 | 낮음 |
| 용량 | 제한 없음 | 제한 있음 (4KB) |
| 생명주기 | 서버 설정 | 설정 가능 |
| 사용 예시 | 로그인 정보 | 장바구니, 설정 |

---

### 3. 세션 Scope

**범위:**
- 같은 브라우저에서 여러 페이지 간 공유
- 다른 브라우저나 다른 컴퓨터에서는 접근 불가

**예시:**
```
사용자 A (Chrome)
  - login.jsp → 세션 생성
  - main.jsp → 같은 세션 사용
  - logout.jsp → 세션 삭제

사용자 B (Firefox)
  - 별도의 세션 사용
```

## 💡 실전 활용 팁

### 팁 1: 세션 타임아웃 설정

**web.xml 설정:**
```xml
<session-config>
    <session-timeout>30</session-timeout>  <!-- 30분 -->
</session-config>
```

**JSP에서 설정:**
```jsp
<%
    session.setMaxInactiveInterval(1800);  // 30분 (초 단위)
%>
```

---

### 팁 2: 로그인 체크 함수화

```jsp
<%!
    public boolean isLoggedIn(HttpSession session) {
        return session.getAttribute("loginId") != null;
    }
%>

<%
    if (!isLoggedIn(session)) {
        response.sendRedirect("login.jsp");
        return;
    }
%>
```

---

### 팁 3: 세션 보안 강화

```jsp
<%
    // 로그인 성공 시
    session.setAttribute("loginId", id);
    session.setAttribute("loginIp", request.getRemoteAddr());
    session.setAttribute("loginTime", new java.util.Date());
    
    // IP 변경 체크
    String savedIp = (String) session.getAttribute("loginIp");
    String currentIp = request.getRemoteAddr();
    if (!savedIp.equals(currentIp)) {
        session.invalidate();
        response.sendRedirect("login.jsp?error=ip_changed");
        return;
    }
%>
```

---

### 팁 4: 세션 만료 메시지

```jsp
<%
    long lastAccess = session.getLastAccessedTime();
    long currentTime = System.currentTimeMillis();
    long inactiveTime = (currentTime - lastAccess) / 1000;  // 초
    
    if (inactiveTime > session.getMaxInactiveInterval() - 60) {
        out.println("<p style='color: orange;'>세션이 곧 만료됩니다.</p>");
    }
%>
```

## 🐛 자주 발생하는 오류

### 오류 1: 세션이 유지되지 않음

**원인:**
- 브라우저 쿠키 비활성화
- 세션 타임아웃

**해결:**
- 브라우저 쿠키 활성화 확인
- 세션 타임아웃 시간 확인

---

### 오류 2: IllegalStateException

**원인:**
- 이미 무효화된 세션에 접근

**해결:**
```jsp
<%
    try {
        String id = (String) session.getAttribute("loginId");
    } catch (IllegalStateException e) {
        // 세션이 이미 무효화됨
        response.sendRedirect("login.jsp");
    }
%>
```

---

### 오류 3: 타입 캐스팅 오류

**원인:**
- 잘못된 타입으로 캐스팅

**해결:**
```jsp
<%
    Object obj = session.getAttribute("loginId");
    if (obj instanceof String) {
        String loginId = (String) obj;
    }
%>
```
