# 파일 선택 시 미리보기 동작 설명

## ❓ 질문: 파일을 바로 불러오면 미리보기가 보이나요?

### 답변: **네, 파일을 선택하면 즉시 미리보기가 표시됩니다!**

---

## 🔄 작동 흐름

### 1. 사용자가 파일 선택

```
사용자가 파일 입력 필드 클릭
   ↓
파일 선택 다이얼로그 열림
   ↓
이미지 파일 선택 (예: photo.jpg)
   ↓
파일 선택 완료
```

### 2. onchange 이벤트 발생

```html
<input type="file" name="image" id="image" 
       accept="image/*" 
       onchange="previewImage(this)">
       <!-- ↑ 파일 선택 시 자동으로 이 함수 호출 -->
```

**설명:**
- 파일이 선택되면 `onchange` 이벤트가 자동 발생
- `previewImage(this)` 함수가 즉시 호출됨
- `this`는 파일 입력 요소 자체를 의미

### 3. 미리보기 표시

```javascript
function previewImage(input){
    // input.files[0]: 선택된 파일
    if (input.files && input.files[0]) {
        var reader = new FileReader();
        
        reader.onload = function(e) {
            // 파일 읽기 완료 → 이미지 표시
            previewImage.src = e.target.result;
            previewContainer.style.display = 'block';  // 보이기
        };
        
        reader.readAsDataURL(input.files[0]);  // 파일 읽기 시작
    }
}
```

**결과:**
- 파일 선택 후 **즉시** 미리보기 표시
- 서버 업로드 없이 브라우저에서만 처리
- 매우 빠른 응답 속도

## 🎯 코드 동작 분석

### HTML 부분

```html
<div class="form-group">
    <label>이미지파일</label>
    <input type="file" name="image" id="image" 
           accept="image/*" 
           onchange="previewImage(this)">
    <!--                                    ↑
          파일 선택 시 자동으로 이 함수 호출
    -->
    
    <div class="preview-container" id="previewContainer" style="display: none;">
        <!-- 초기 상태: 숨김 -->
        <img id="previewImage" class="preview-image" alt="미리보기">
    </div>
</div>
```

### JavaScript 부분

```javascript
function previewImage(input){
    var previewContainer = document.getElementById('previewContainer');
    var previewImage = document.getElementById('previewImage');
    
    // 1. 파일이 선택되었는지 확인
    if (input.files && input.files[0]) {
        var reader = new FileReader();
        
        // 2. 파일 읽기 완료 시 실행될 함수
        reader.onload = function(e) {
            // e.target.result: Base64 데이터 URL
            // 예: "data:image/jpeg;base64,/9j/4AAQ..."
            
            previewImage.src = e.target.result;  // 이미지 소스 설정
            previewContainer.style.display = 'block';  // 컨테이너 표시
        };
        
        // 3. 파일 읽기 시작 (비동기)
        reader.readAsDataURL(input.files[0]);
        // 파일을 Base64 데이터 URL로 변환
    } else {
        // 파일 선택 취소 시
        previewContainer.style.display = 'none';
    }
}
```

## 🔍 상세 동작 설명

### 1. 파일 선택 전

```html
<!-- 초기 상태 -->
<div class="preview-container" id="previewContainer" style="display: none;">
    <!-- 숨김 상태 -->
    <img id="previewImage" class="preview-image" alt="미리보기">
</div>
```

**화면:**
- 미리보기 영역이 보이지 않음
- 파일 입력 필드만 표시

### 2. 파일 선택 중

```
사용자가 파일 선택 다이얼로그에서 파일 선택
→ 파일 입력 필드에 파일명 표시
→ onchange 이벤트 발생
```

### 3. 파일 선택 후 (즉시)

```javascript
// previewImage() 함수 실행
reader.readAsDataURL(input.files[0]);
// 파일을 읽어서 Base64로 변환
```

**화면:**
- 파일 읽기 중... (사용자는 거의 느끼지 못함)

### 4. 미리보기 표시 완료

```html
<!-- 변경된 상태 -->
<div class="preview-container" id="previewContainer" style="display: block;">
    <!-- 표시됨 -->
    <img id="previewImage" src="data:image/jpeg;base64,/9j/4AAQ..." 
         class="preview-image" alt="미리보기">
</div>
```

**화면:**
- 미리보기 이미지가 즉시 표시됨 ✅
- 사용자가 선택한 이미지가 보임

## ⚠️ 주의사항

### 1. 파일 크기에 따른 지연

**작은 파일 (< 1MB):**
- 즉시 표시 (0.1초 이내)

**큰 파일 (> 5MB):**
- 약간의 지연 가능 (0.5~1초)
- Base64 변환 시간 필요

**해결 방법:**
```javascript
// 로딩 표시 추가
reader.onloadstart = function() {
    previewContainer.innerHTML = '<p>이미지 로딩 중...</p>';
};

reader.onload = function(e) {
    previewImage.src = e.target.result;
    previewContainer.style.display = 'block';
};
```

### 2. 브라우저 호환성

**FileReader API 지원:**
- Chrome 7+ ✅
- Firefox 3.6+ ✅
- Safari 6+ ✅
- Edge 모든 버전 ✅
- IE 10+ ✅

**IE 9 이하:**
- 미리보기 기능 작동하지 않음
- 대체 방법 필요

## 🎨 추가 기능 제안

### 1. 로딩 표시 추가

```javascript
function previewImage(input){
    var previewContainer = document.getElementById('previewContainer');
    var previewImage = document.getElementById('previewImage');
    
    if (input.files && input.files[0]) {
        // 로딩 표시
        previewContainer.innerHTML = '<p>이미지 로딩 중...</p>';
        previewContainer.style.display = 'block';
        
        var reader = new FileReader();
        
        reader.onload = function(e) {
            previewContainer.innerHTML = '<img id="previewImage" class="preview-image" alt="미리보기">';
            document.getElementById('previewImage').src = e.target.result;
        };
        
        reader.readAsDataURL(input.files[0]);
    } else {
        previewContainer.style.display = 'none';
    }
}
```

### 2. 파일 정보 표시

```javascript
function previewImage(input){
    var previewContainer = document.getElementById('previewContainer');
    var previewImage = document.getElementById('previewImage');
    
    if (input.files && input.files[0]) {
        var file = input.files[0];
        
        // 파일 정보 표시
        var fileInfo = document.createElement('div');
        fileInfo.innerHTML = `
            <p>파일명: ${file.name}</p>
            <p>크기: ${(file.size / 1024).toFixed(2)} KB</p>
            <p>타입: ${file.type}</p>
        `;
        
        var reader = new FileReader();
        
        reader.onload = function(e) {
            previewImage.src = e.target.result;
            previewContainer.appendChild(fileInfo);
            previewContainer.style.display = 'block';
        };
        
        reader.readAsDataURL(file);
    } else {
        previewContainer.style.display = 'none';
    }
}
```

### 질문: 파일을 바로 불러오면 미리보기가 보이나요?

**답변: 네, 파일을 선택하면 즉시 미리보기가 표시됩니다!**

### 작동 원리:

1. **파일 선택** → `onchange` 이벤트 발생
2. **`previewImage()` 함수 호출** → FileReader로 파일 읽기
3. **Base64 변환** → 데이터 URL 생성
4. **이미지 표시** → 미리보기 컨테이너 표시

### 특징:

- ⚡ **즉시 표시**: 파일 선택 후 0.1~0.5초 이내
- 🌐 **서버 불필요**: 브라우저에서만 처리
- 🚀 **빠른 응답**: 네트워크 요청 없음
