# 부트스트랩 적용 가이드

## ❓ 문제: 부트스트랩이 적용되지 않는 이유

### 원인 분석

1. **부트스트랩 CDN 링크가 없음**
   - 현재 코드에는 부트스트랩이 임포트되어 있지 않음

2. **인라인 CSS와 충돌**
   - 기존 인라인 스타일이 부트스트랩 스타일을 덮어씀
   - CSS 우선순위 문제

3. **부트스트랩 클래스 미사용**
   - HTML에 부트스트랩 클래스가 없음
   - 부트스트랩 스타일을 적용하려면 클래스 필요

---

## ✅ 해결 방법

### 1. 부트스트랩 CDN 추가

**HTML `<head>`에 추가:**

```html
<!-- Bootstrap 5 CSS -->
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css" rel="stylesheet">

<!-- Bootstrap Icons (선택사항) -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bootstrap-icons@1.11.1/font/bootstrap-icons.css">
```

**HTML `</body>` 전에 추가:**

```html
<!-- Bootstrap 5 JS Bundle -->
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/js/bootstrap.bundle.min.js"></script>
```

### 2. 부트스트랩 클래스 사용

**기존 코드:**
```html
<div class="form-group">
    <label>제목</label>
    <input type="text" name="title">
</div>
```

**부트스트랩 적용:**
```html
<div class="mb-3">
    <label for="title" class="form-label">제목</label>
    <input type="text" class="form-control" id="title" name="title">
</div>
```

### 3. 인라인 CSS 제거 또는 조정

**문제:**
- 인라인 CSS가 부트스트랩 스타일을 덮어씀

**해결:**
- 부트스트랩 클래스 사용
- 필요한 경우에만 커스텀 CSS 추가

## 📋 부트스트랩 주요 클래스

### 레이아웃

```html
<!-- 컨테이너 -->
<div class="container">  <!-- 고정 너비 -->
<div class="container-fluid">  <!-- 전체 너비 -->

<!-- 카드 -->
<div class="card">
    <div class="card-header">제목</div>
    <div class="card-body">내용</div>
</div>
```

### 폼 요소

```html
<!-- 입력 필드 -->
<input type="text" class="form-control" id="title" name="title">

<!-- 레이블 -->
<label for="title" class="form-label">제목</label>

<!-- 텍스트 영역 -->
<textarea class="form-control" id="content" name="content" rows="8"></textarea>

<!-- 파일 입력 -->
<input type="file" class="form-control" id="image" name="image">

<!-- 간격 -->
<div class="mb-3">  <!-- margin-bottom -->
<div class="mt-3">  <!-- margin-top -->
```

### 버튼

```html
<!-- 기본 버튼 -->
<button type="submit" class="btn btn-primary">등록</button>
<button type="button" class="btn btn-secondary">취소</button>

<!-- 버튼 그룹 -->
<div class="d-grid gap-2 d-md-flex justify-content-md-end">
    <button class="btn btn-secondary">목록</button>
    <button class="btn btn-primary">등록</button>
</div>
```

### 아이콘 (Bootstrap Icons)

```html
<i class="bi bi-camera"></i>  <!-- 카메라 아이콘 -->
<i class="bi bi-list"></i>    <!-- 목록 아이콘 -->
<i class="bi bi-check-circle"></i>  <!-- 체크 아이콘 -->
```

## 🔄 기존 코드 vs 부트스트랩 코드

### 기존 코드 (인라인 CSS)

```html
<div class="form-group">
    <label>제목</label>
    <input type="text" name="title" style="width: 100%; padding: 10px;">
</div>
```

### 부트스트랩 코드

```html
<div class="mb-3">
    <label for="title" class="form-label">제목</label>
    <input type="text" class="form-control" id="title" name="title">
</div>
```

**차이점:**
- 인라인 스타일 제거
- 부트스트랩 클래스 사용 (`form-control`, `mb-3`)
- 더 깔끔하고 유지보수 용이

## 🎨 부트스트랩 버전 선택

### Bootstrap 5 (권장)

```html
<!-- CSS -->
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css" rel="stylesheet">

<!-- JS -->
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/js/bootstrap.bundle.min.js"></script>
```

**특징:**
- 최신 버전
- jQuery 불필요
- 모던 브라우저 지원

### Bootstrap 4 (레거시)

```html
<!-- CSS -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bootstrap@4.6.2/dist/css/bootstrap.min.css">

<!-- JS (jQuery 필요) -->
<script src="https://code.jquery.com/jquery-3.6.0.min.js"></script>
<script src="https://cdn.jsdelivr.net/npm/bootstrap@4.6.2/dist/js/bootstrap.bundle.min.js"></script>
```

## 🐛 자주 발생하는 문제

### 문제 1: 부트스트랩 스타일이 적용되지 않음

**원인:**
- CDN 링크 누락
- 네트워크 문제

**해결:**
```html
<!-- CDN 링크 확인 -->
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css" rel="stylesheet">
```

### 문제 2: 인라인 CSS가 부트스트랩을 덮어씀

**원인:**
- 인라인 스타일의 우선순위가 높음

**해결:**
- 인라인 스타일 제거
- 부트스트랩 클래스 사용
- 필요한 경우 `!important` 사용 (비권장)

### 문제 3: 반응형이 작동하지 않음

**원인:**
- viewport 메타 태그 누락

**해결:**
```html
<meta name="viewport" content="width=device-width, initial-scale=1">
```

## 📝 완전한 예제

### 부트스트랩 적용된 board_write.jsp

```jsp
<%@ page language="java" contentType="text/html; charset=UTF-8" pageEncoding="UTF-8" %>
<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>이미지 게시글 작성</title>
    
    <!-- Bootstrap 5 CSS -->
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <div class="container mt-5">
        <div class="card">
            <div class="card-header bg-primary text-white">
                <h2>이미지 게시글 작성</h2>
            </div>
            <div class="card-body">
                <form action="board_write_process.jsp" method="post" enctype="multipart/form-data">
                    <div class="mb-3">
                        <label for="title" class="form-label">제목</label>
                        <input type="text" class="form-control" id="title" name="title" required>
                    </div>
                    
                    <div class="mb-3">
                        <label for="image" class="form-label">이미지</label>
                        <input type="file" class="form-control" id="image" name="image" accept="image/*">
                    </div>
                    
                    <div class="d-grid gap-2 d-md-flex justify-content-md-end">
                        <button type="submit" class="btn btn-primary">등록</button>
                    </div>
                </form>
            </div>
        </div>
    </div>
    
    <!-- Bootstrap 5 JS -->
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

### 부트스트랩이 적용되지 않는 이유

1. ❌ CDN 링크 없음
2. ❌ 부트스트랩 클래스 미사용
3. ❌ 인라인 CSS와 충돌

### 해결 방법

1. ✅ Bootstrap CDN 추가
2. ✅ 부트스트랩 클래스 사용
3. ✅ 인라인 CSS 제거 또는 조정

**부트스트랩을 사용하려면 CDN 링크를 추가하고 부트스트랩 클래스를 사용해야 합니다!** 🎨
