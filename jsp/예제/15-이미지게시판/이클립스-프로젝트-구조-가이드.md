## 🔧 이클립스 프로젝트 설정

### 1. 프로젝트 생성

**Dynamic Web Project 생성:**
1. File → New → Dynamic Web Project
2. Project name: `imgBoard`
3. Target runtime: Apache Tomcat 선택
4. Finish

### 2. Java 패키지 생성

**패키지 생성:**
1. `src` 폴더 우클릭
2. New → Package
3. Name: `jsp.imageboard`
4. Finish

### 3. Java 클래스 생성

**클래스 생성:**
1. `src/jsp/imageboard` 패키지 우클릭
2. New → Class
3. Name: `FileUploadUtil` (또는 다른 클래스명)
4. Finish

### 4. JSP 파일 생성

**JSP 파일 생성:**
1. `WebContent` 폴더 우클릭
2. New → JSP File
3. File name: `board_write.jsp`
4. Finish

## 🚀 프로젝트 실행

### 1. 서버 설정

**Tomcat 서버 추가:**
1. Window → Show View → Servers
2. "No servers are available" 링크 클릭
3. Apache → Tomcat vX.X 선택

### 2. 프로젝트 배포

**서버에 프로젝트 추가:**
1. Servers 뷰에서 서버 우클릭
2. Add and Remove...
3. `imgBoard` 프로젝트 선택
4. Add → Finish

**서버 시작:**
1. Servers 뷰에서 서버 우클릭
2. Start
3. 브라우저에서 `http://localhost:8080/imgBoard/board_write.jsp` 접속

## 🐛 자주 발생하는 문제

### 문제 1: 클래스를 찾을 수 없음

**원인:**
- Java 파일이 `src` 폴더에 없음
- 패키지 이름이 일치하지 않음

**해결:**
- Java 파일을 `src/jsp/imageboard/` 폴더에 배치
- 패키지 선언 확인: `package jsp.imageboard;`

### 문제 2: JSP에서 클래스를 찾을 수 없음

**원인:**
- 클래스가 컴파일되지 않음
- import 문이 잘못됨

**해결:**
- 프로젝트 빌드 (Project → Clean → Build)
- import 문 확인: `<%@ page import="jsp.imageboard.*" %>`

### 문제 3: 업로드 파일 경로 오류

**원인:**
- `uploads/images/` 폴더가 없음
- 경로 설정이 잘못됨

**해결:**
- `WebContent/uploads/images/` 폴더 생성
- `FileUploadUtil.java`의 `UPLOAD_DIR` 확인
