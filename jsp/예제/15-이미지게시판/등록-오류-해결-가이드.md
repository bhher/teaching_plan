# 등록 오류 해결 가이드

## 🐛 문제: "등록 중 오류가 발생했습니다" 메시지

### 가능한 원인들

1. **import 문 오류** - 패키지 이름 불일치
2. **클래스 이름 오류** - 클래스를 찾을 수 없음
3. **DB 연결 오류** - 데이터베이스 연결 실패
4. **파일 업로드 경로 오류** - 업로드 디렉토리 없음
5. **SQL 오류** - 데이터베이스 쿼리 오류

---

## 🔍 1단계: 오류 메시지 확인

### 디버깅 코드 추가

**현재 코드:**
```jsp
} catch (Exception e) {
    e.printStackTrace();
    out.println("<script>alert('게시글 등록 중 오류가 발생했습니다.'); history.back();</script>");
}
```

**디버깅 코드:**
```jsp
} catch (Exception e) {
    e.printStackTrace();
    // ✅ 상세 오류 메시지 출력
    out.println("<h2>오류 발생!</h2>");
    out.println("<p>오류 메시지: " + e.getMessage() + "</p>");
    out.println("<pre>");
    e.printStackTrace(new java.io.PrintWriter(out));
    out.println("</pre>");
    out.println("<script>alert('게시글 등록 중 오류가 발생했습니다.\\n오류: " + e.getMessage() + "'); history.back();</script>");
}
```

**확인 방법:**
1. 페이지에서 오류 메시지 확인
2. 브라우저 콘솔(F12) 확인
3. 서버 콘솔(이클립스) 확인

## 🔧 2단계: import 문 확인

### 현재 import 문

```jsp
<%@ page import="dto.*" %>    
<%@ page import="dao.*" %>   
<%@ page import="util.*" %>
```

### 확인 사항

**1. 패키지 이름 확인**

**이클립스에서 확인:**
- `src/dto/` 폴더가 있는지 확인
- `src/dao/` 폴더가 있는지 확인
- `src/util/` 폴더가 있는지 확인

**또는:**
- `src/jsp/imgBoard/` 같은 구조일 수 있음

**2. 실제 패키지 이름 확인**

**Java 파일 확인:**
```java
// FileUploadUtil.java 첫 줄 확인
package dto;  // 또는 package util; 또는 package jsp.imgBoard;
```

**3. import 문 수정**

**만약 패키지가 `jsp.imgBoard`라면:**
```jsp
<%@ page import="jsp.imgBoard.*" %>
```

**만약 패키지가 `dto`, `dao`, `util`로 분리되어 있다면:**
```jsp
<%@ page import="dto.*" %>    
<%@ page import="dao.*" %>   
<%@ page import="util.*" %>
```

## 🔍 3단계: 클래스 이름 확인

### 사용하는 클래스들

1. **FileUploadUtil** - 파일 업로드 유틸리티
2. **DBConnection** - 데이터베이스 연결
3. **ImageBoardDAO** - 데이터베이스 접근 객체
4. **ImageBoardDTO** - 데이터 전송 객체

### 확인 방법

**이클립스에서:**
1. `Ctrl + Shift + T` (Type 검색)
2. 클래스 이름 입력
3. 클래스가 있는지 확인

**또는 파일 탐색기에서:**
- `src/dto/ImageBoardDTO.java` 확인
- `src/dao/ImageBoardDAO.java` 확인
- `src/util/FileUploadUtil.java` 확인
- `src/util/DBConnection.java` 확인

## 🐛 4단계: 일반적인 오류 해결

### 오류 1: 클래스를 찾을 수 없음

**오류 메시지:**
```
DBConnection cannot be resolved
```

**해결:**
```jsp
<!-- 올바른 패키지 이름으로 import -->
<%@ page import="jsp.imgBoard.*" %>
<!-- 또는 -->
<%@ page import="dto.*" %>
<%@ page import="dao.*" %>
<%@ page import="util.*" %>
```

### 오류 2: DB 연결 실패

**오류 메시지:**
```
Communications link failure
```

**해결:**
- `DBConnection.java`의 연결 정보 확인
- MySQL 서버 실행 확인
- 데이터베이스 이름 확인

### 오류 3: 파일 업로드 경로 오류

**오류 메시지:**
```
java.io.FileNotFoundException
```

**해결:**
- `WebContent/uploads/images/` 폴더 생성
- 폴더 권한 확인

### 오류 4: SQL 오류

**오류 메시지:**
```
SQLSyntaxErrorException
```

**해결:**
- 데이터베이스 테이블 구조 확인
- `ImageBoardDAO.java`의 SQL 문 확인

## 🔧 5단계: 단계별 디버깅

### 디버깅 코드 추가

```jsp
<%
    try {
        // 1. 파라미터 확인
        out.println("제목: " + title + "<br>");
        out.println("작성자: " + writer + "<br>");
        
        // 2. 파일 업로드 확인
        Part imagePart = request.getPart("image");
        out.println("파일 크기: " + (imagePart != null ? imagePart.getSize() : 0) + "<br>");

        Connection conn = DBConnection.getConnection();
        out.println("DB 연결 성공<br>");
        
        // 4. DAO 확인
        ImageBoardDAO boardDAO = new ImageBoardDAO(conn);
        out.println("DAO 생성 성공<br>");
        
        // 5. DTO 확인
        ImageBoardDTO board = new ImageBoardDTO(title, content, writer, password, imageFile, imageOriginal);
        out.println("DTO 생성 성공<br>");
        
        // 6. 저장 시도
        int boardId = boardDAO.insertBoard(board);
        out.println("저장된 ID: " + boardId + "<br>");
        
    } catch (Exception e) {
        e.printStackTrace();
        out.println("<h2>오류 발생!</h2>");

        e.printStackTrace(new java.io.PrintWriter(out));
        out.println("</pre>");
    }
%>
```

**사용 방법:**
1. 위 코드로 임시 교체
2. 페이지 실행
3. 어느 단계에서 오류가 나는지 확인
4. 오류가 나는 부분 수정

## 🎯 빠른 해결 방법

### 방법 1: import 문 확인 및 수정

**가장 흔한 원인:**
- 패키지 이름 불일치

**확인:**
1. Java 파일의 `package` 선언 확인
2. JSP 파일의 `import` 문과 일치하는지 확인

**예시:**
```java
// FileUploadUtil.java
package jsp.imgBoard;  // 패키지 이름
```

```jsp
<!-- board_write_process.jsp -->
<%@ page import="jsp.imgBoard.*" %>  <!-- 일치해야 함 -->
```

### 방법 2: 디버깅 코드로 오류 확인

**디버깅 버전 사용:**
- `board_write_process_디버깅.jsp` 파일 사용
- 실제 오류 메시지 확인
- 오류 메시지에 따라 수정
