# 브라우저 캐시 문제 해결 가이드

## 🐛 문제: 파일은 수정했는데 여전히 오류 발생

**오류 메시지:**
```
Uncaught TypeError: previewImage is not a function
    at HTMLInputElement.onchange (board_write.jsp:132:107)
```

**원인:**
- 브라우저가 이전 버전의 파일을 캐시에서 로드하고 있음
- 서버가 변경된 파일을 아직 반영하지 않음

---

## ✅ 해결 방법

### 방법 1: 강제 새로고침 (가장 빠름)

**Windows/Linux:**
- `Ctrl + F5` (강제 새로고침)
- 또는 `Ctrl + Shift + R`

**Mac:**
- `Cmd + Shift + R`

**설명:**
- 브라우저 캐시를 무시하고 서버에서 최신 파일을 다시 로드

### 방법 2: 개발자 도구에서 새로고침

1. **F12** 키를 눌러 개발자 도구 열기
2. **Network(네트워크)** 탭 클릭
3. **Disable cache(캐시 비활성화)** 체크
4. 페이지 새로고침 (`F5`)

### 방법 3: 하드 리프레시

**Chrome/Edge:**
1. 개발자 도구 열기 (`F12`)
2. 새로고침 버튼을 **우클릭**
3. **"캐시 비우기 및 강력 새로고침"** 선택

**Firefox:**
1. 개발자 도구 열기 (`F12`)
2. 새로고침 버튼을 **우클릭**
3. **"캐시 비우기 및 새로고침"** 선택

### 방법 4: 서버 재시작

**Tomcat 재시작:**
1. Tomcat 서버 중지
2. Tomcat 서버 시작
3. 브라우저에서 페이지 새로고침

**이유:**
- JSP 파일이 컴파일되어 서버 메모리에 저장됨
- 서버 재시작 시 최신 파일로 다시 컴파일됨

### 방법 5: 브라우저 캐시 완전 삭제

**Chrome:**
1. 설정 → 개인정보 및 보안
2. 인터넷 사용 기록 삭제
3. "캐시된 이미지 및 파일" 선택
4. 삭제

**Firefox:**
1. 설정 → 개인정보 및 보안
2. 쿠키 및 사이트 데이터
3. 데이터 삭제

## 🔍 확인 방법

### 1. 브라우저 콘솔에서 함수 확인

**F12 키를 눌러 개발자 도구 열기**

```javascript
// 함수가 정의되어 있는지 확인
console.log(typeof previewImage);  
// "function" 출력되어야 함
// "undefined" 출력되면 함수가 로드되지 않은 것

// 함수 내용 확인
console.log(previewImage.toString());
// 함수 코드가 출력되어야 함
```

### 2. 소스 코드 확인

1. **F12** 키로 개발자 도구 열기
2. **Sources(소스)** 탭 클릭
3. `board_write.jsp` 파일 열기
4. 152번 줄 확인:
   ```javascript
   function previewImage(input) {
       var previewImg = document.getElementById('previewImage');
       // ...
   }
   ```

**확인 사항:**
- 함수가 `previewImg` 변수를 사용하는지 확인
- `var previewImage`가 없는지 확인

### 3. 네트워크 탭에서 파일 확인

1. **F12** 키로 개발자 도구 열기
2. **Network(네트워크)** 탭 클릭
3. 페이지 새로고침 (`F5`)
4. `board_write.jsp` 파일 찾기
5. **Response(응답)** 탭에서 실제 서버 응답 확인

## 🛠️ 추가 해결 방법

### 방법 6: 파일에 버전 추가 (임시)

**HTML에 버전 파라미터 추가:**
```html
<!-- 기존 -->
<script src="board_write.jsp"></script>

<!-- 수정 -->
<script src="board_write.jsp?v=2"></script>
```

**또는 JSP 파일에 캐시 방지 헤더 추가:**
```jsp
<%
    response.setHeader("Cache-Control", "no-cache, no-store, must-revalidate");
    response.setHeader("Pragma", "no-cache");
    response.setDateHeader("Expires", 0);
%>
```

### 방법 7: 시크릿 모드에서 테스트

**Chrome:**
- `Ctrl + Shift + N` (시크릿 창 열기)
- URL 입력하여 테스트

**Firefox:**
- `Ctrl + Shift + P` (시크릿 창 열기)
- URL 입력하여 테스트

**이유:**
- 시크릿 모드는 캐시를 사용하지 않음
- 최신 파일을 항상 로드함
