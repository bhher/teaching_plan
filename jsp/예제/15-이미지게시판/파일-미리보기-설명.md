# 파일 미리보기 기능 설명

## ❓ 질문: 파일을 미리 images에 넣어놔야 하나요?

### 답변: **아니요! 필요 없습니다!**

현재 코드는 **클라이언트 사이드 미리보기**를 사용하므로, 서버에 파일을 업로드하지 않고도 브라우저에서 이미지를 미리볼 수 있습니다.

---

## 🔍 현재 코드 분석

### previewImage() 함수

```javascript
function previewImage(input) {
    var previewContainer = document.getElementById('previewContainer');
    var previewImage = document.getElementById('previewImage');
    
    if (input.files && input.files[0]) {
        var reader = new FileReader();  // FileReader API 사용
        
        reader.onload = function(e) {
            previewImage.src = e.target.result;  // Base64 데이터 URL
            previewContainer.style.display = 'block';
        };
        
        reader.readAsDataURL(input.files[0]);  // 파일을 Base64로 읽기
    } else {
        previewContainer.style.display = 'none';
    }
}
```

### 작동 원리

1. **사용자가 파일 선택**
   ```html
   <input type="file" onchange="previewImage(this)">
   ```

2. **FileReader API로 파일 읽기**
   - 파일을 Base64 데이터 URL로 변환
   - 서버 업로드 없이 브라우저 메모리에서 처리

3. **이미지 태그에 표시**
   ```javascript
   previewImage.src = e.target.result;  // data:image/jpeg;base64,/9j/4AAQ...
   ```

## 📊 서버 업로드 vs 클라이언트 미리보기

### 클라이언트 사이드 미리보기 (현재 방식) ✅

**특징:**
- 서버 업로드 불필요
- 즉시 미리보기 가능
- 네트워크 트래픽 없음
- 브라우저에서만 처리

**장점:**
- 빠른 응답 속도
- 서버 부하 없음
- 사용자 경험 향상

**단점:**
- 브라우저 메모리 사용
- 큰 파일의 경우 메모리 부족 가능

### 서버 사이드 미리보기 (대안)

**특징:**
- 파일을 서버에 먼저 업로드
- 서버에서 이미지 URL 반환
- 이미지 태그에 URL 표시

**장점:**
- 서버에서 이미지 처리 가능
- 썸네일 생성 등 추가 기능 가능

**단점:**
- 네트워크 트래픽 발생
- 서버 부하 증가
- 업로드 취소 시 서버 파일 정리 필요

## 🎯 현재 코드의 작동 흐름

```
1. 사용자가 파일 선택
   <input type="file" onchange="previewImage(this)">
   ↓
2. previewImage() 함수 호출
   ↓
3. FileReader API로 파일 읽기
   reader.readAsDataURL(input.files[0])
   ↓
4. 파일을 Base64 데이터 URL로 변환
   data:image/jpeg;base64,/9j/4AAQ...
   ↓
5. 이미지 태그에 표시
   <img src="data:image/jpeg;base64,...">
   ↓
6. 사용자가 "등록" 버튼 클릭
   ↓
7. 폼 제출 → 서버로 업로드
   board_write_process.jsp
```

**중요:**
- 미리보기는 **브라우저에서만** 작동
- 실제 업로드는 **"등록" 버튼 클릭 시** 발생

## 💻 FileReader API 설명

### FileReader란?

- 브라우저에서 파일을 읽는 JavaScript API
- 서버 업로드 없이 파일 내용 읽기 가능
- 비동기 처리

### 주요 메서드

```javascript
// 1. FileReader 객체 생성
var reader = new FileReader();

// 2. 파일 읽기 완료 이벤트
reader.onload = function(e) {
    // e.target.result에 파일 내용 (Base64)
    console.log(e.target.result);
};

// 3. 파일 읽기 시작
reader.readAsDataURL(file);  // Base64 데이터 URL로 읽기
reader.readAsText(file);     // 텍스트로 읽기
reader.readAsArrayBuffer(file);  // ArrayBuffer로 읽기
```

### Base64 데이터 URL 형식

```
data:image/jpeg;base64,/9j/4AAQSkZJRgABAQEAYABgAAD...
```

**구성:**
- `data:` - 데이터 URL 프로토콜
- `image/jpeg` - MIME 타입
- `base64` - 인코딩 방식
- `/9j/4AAQ...` - Base64 인코딩된 데이터

### 개선된 코드 (에러 처리 추가)

```javascript
function previewImage(input) {
    var previewContainer = document.getElementById('previewContainer');
    var previewImage = document.getElementById('previewImage');
    
    // 파일이 선택되지 않은 경우
    if (!input.files || !input.files[0]) {
        previewContainer.style.display = 'none';
        return;
    }
    
    var file = input.files[0];
    
    // 이미지 파일인지 확인
    if (!file.type.match('image.*')) {
        alert('이미지 파일만 선택할 수 있습니다.');
        input.value = '';  // 선택 취소
        previewContainer.style.display = 'none';
        return;
    }
    
    // 파일 크기 확인 (10MB)
    if (file.size > 10 * 1024 * 1024) {
        alert('파일 크기는 10MB를 초과할 수 없습니다.');
        input.value = '';
        previewContainer.style.display = 'none';
        return;
    }
    
    var reader = new FileReader();
    
    // 파일 읽기 성공
    reader.onload = function(e) {
        previewImage.src = e.target.result;
        previewContainer.style.display = 'block';
    };
    
    // 파일 읽기 실패
    reader.onerror = function() {
        alert('파일을 읽는 중 오류가 발생했습니다.');
        previewContainer.style.display = 'none';
    };
    
    // 파일 읽기 시작
    reader.readAsDataURL(file);
}
```

## 🐛 자주 발생하는 문제

### 문제 1: 미리보기가 표시되지 않음

**원인:**
- FileReader API 미지원 브라우저
- 파일이 선택되지 않음

**해결:**
```javascript
// 브라우저 호환성 확인
if (typeof FileReader === 'undefined') {
    alert('이 브라우저는 파일 미리보기를 지원하지 않습니다.');
    return;
}
```

### 문제 2: 큰 파일에서 메모리 부족

**원인:**
- Base64 인코딩으로 메모리 사용량 증가
- 10MB 파일 → 약 13MB 메모리 사용

**해결:**
- 파일 크기 제한 (현재 10MB)
- 또는 서버 사이드 미리보기 사용

### 문제 3: 여러 파일 선택 시

**현재 코드:**
- 단일 파일만 지원

**개선:**
```javascript
// 여러 파일 미리보기
function previewImages(input) {
    var previewContainer = document.getElementById('previewContainer');
    previewContainer.innerHTML = '';  // 초기화
    
    if (input.files && input.files.length > 0) {
        for (var i = 0; i < input.files.length; i++) {
            var reader = new FileReader();
            var img = document.createElement('img');
            img.className = 'preview-image';
            
            reader.onload = (function(image) {
                return function(e) {
                    image.src = e.target.result;
                };
            })(img);
            
            reader.readAsDataURL(input.files[i]);
            previewContainer.appendChild(img);
        }
        previewContainer.style.display = 'block';
    }
}
```

## ✅ 요약

### 질문: 파일을 미리 images에 넣어놔야 하나요?

**답변: 아니요!**

### 이유:

1. **클라이언트 사이드 미리보기**
   - FileReader API 사용
   - 서버 업로드 불필요

2. **작동 방식**
   - 파일 선택 → Base64 변환 → 이미지 표시
   - 실제 업로드는 "등록" 버튼 클릭 시

3. **장점**
   - 빠른 응답
   - 서버 부하 없음
   - 네트워크 트래픽 없음

### 결론:

**파일을 미리 서버에 업로드할 필요가 없습니다!**

현재 코드는 브라우저에서 파일을 읽어서 미리보기만 보여주고, 실제 업로드는 사용자가 "등록" 버튼을 클릭할 때 발생합니다. 🎉
