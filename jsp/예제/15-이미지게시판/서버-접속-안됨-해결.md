# 서버 접속 안 됨 해결 가이드

## 🐛 문제: 서버 접속이 안 됨

### 가능한 원인들

1. **프로젝트가 서버에 배포되지 않음**
2. **URL 경로 오류**
3. **서버가 시작되지 않음**
4. **포트 충돌**

---

## ✅ 해결 방법

### 1단계: 프로젝트를 서버에 추가

**이클립스에서:**

1. **Servers 뷰 열기**
   - Window → Show View → Servers
   - 또는 하단의 Servers 탭

2. **프로젝트 추가**
   - 서버 우클릭
   - **Add and Remove...** 선택
   - 왼쪽 목록에서 프로젝트 선택 (예: `imgBoard`)
   - **Add >** 클릭
   - **Finish**

3. **서버 시작**
   - 서버 우클릭 → **Start**

---

### 2단계: URL 확인

**올바른 URL 형식:**
```
http://localhost:8080/프로젝트명/파일명.jsp
```

**예시:**
```
http://localhost:8080/imgBoard/board_write.jsp
```

**확인 방법:**
- Servers 뷰에서 배포된 프로젝트 확인
- 컨텍스트 경로 확인

---

### 3단계: web.xml 파일 위치 확인

**중요:**
- 제공하신 web.xml은 Tomcat의 기본 설정 파일입니다
- 프로젝트의 web.xml은 별도로 필요합니다

**파일 위치:**
```
WebContent/WEB-INF/web.xml
```

**확인:**
- 이클립스에서 `WebContent/WEB-INF/web.xml` 파일이 있는지 확인
- 없으면 생성 필요

---

### 4단계: 프로젝트 web.xml 생성

**파일 생성:**
1. `WebContent/WEB-INF/` 폴더 확인
2. `web.xml` 파일 생성
3. multipart 설정 추가

**내용:**
```xml
<?xml version="1.0" encoding="UTF-8"?>
<web-app xmlns="https://jakarta.ee/xml/ns/jakartaee"
         xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
         xsi:schemaLocation="https://jakarta.ee/xml/ns/jakartaee
         https://jakarta.ee/xml/ns/jakartaee/web-app_6_0.xsd"
         version="6.0">

    <!-- 파일 업로드 처리 JSP에 multipart 설정 -->
    <servlet>
        <servlet-name>BoardWriteProcess</servlet-name>
        <jsp-file>/board_write_process.jsp</jsp-file>
        <multipart-config>
            <max-file-size>10485760</max-file-size>
            <max-request-size>10485760</max-request-size>
            <file-size-threshold>0</file-size-threshold>
        </multipart-config>
    </servlet>
    
    <servlet-mapping>
        <servlet-name>BoardWriteProcess</servlet-name>
        <url-pattern>/board_write_process.jsp</url-pattern>
    </servlet-mapping>
    
</web-app>
```

---

## 🔍 단계별 확인

### 1. 서버 상태 확인

**Servers 뷰에서:**
```
Servers
  └── Tomcat v10.1 Server at localhost [Started]
      └── imgBoard [Started]  ← 프로젝트가 보여야 함
```

**없다면:**
- Add and Remove로 프로젝트 추가

---

### 2. 배포 경로 확인

**실제 경로:**
```
C:\Users\TJ\eclipse-workspace2\.metadata\.plugins\org.eclipse.wst.server.core\tmp1\wtpwebapps\imgBoard\
```

**확인 사항:**
- 위 경로에 프로젝트 파일들이 있는지 확인
- `board_write.jsp` 파일이 있는지 확인
- `WEB-INF/web.xml` 파일이 있는지 확인

---

### 3. URL 테스트

**테스트 URL:**
```
http://localhost:8080/imgBoard/board_write.jsp
```

**404 오류가 나면:**
- 프로젝트명 확인
- 파일 경로 확인
- 서버 재시작

---

## 🛠️ 빠른 해결 순서

1. **프로젝트를 서버에 추가**
   - Servers 뷰 → Add and Remove

2. **web.xml 파일 확인/생성**
   - `WebContent/WEB-INF/web.xml` 확인
   - 없으면 생성하고 multipart 설정 추가

3. **서버 재시작**
   - 서버 중지 → 시작

4. **URL 접속 테스트**
   - `http://localhost:8080/프로젝트명/board_write.jsp`

---

## 📋 체크리스트

서버 접속 확인:

- [ ] 서버가 시작되었는지 확인
- [ ] 프로젝트가 서버에 배포되었는지 확인
- [ ] `WebContent/WEB-INF/web.xml` 파일 존재 확인
- [ ] multipart 설정이 web.xml에 있는지 확인
- [ ] 올바른 URL 사용 (컨텍스트 경로 포함)
- [ ] 서버 재시작
