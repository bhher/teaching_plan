# 톰캣 서버 변경 후 404 오류 해결 가이드

## 🐛 문제: 서버 변경 후 404 오류

### 가능한 원인들

1. **프로젝트가 새 서버에 배포되지 않음**
2. **컨텍스트 경로 변경**
3. **프로젝트가 서버에 추가되지 않음**
4. **배포 경로 문제**

---

## ✅ 해결 방법

### 방법 1: 프로젝트를 새 서버에 추가

**이클립스에서:**

1. **Servers 뷰 열기**
   - Window → Show View → Servers
   - 또는 하단의 Servers 탭

2. **새 서버 확인**
   - Servers 뷰에 새 톰캣 서버가 보이는지 확인

3. **프로젝트 추가**
   - 새 서버 우클릭
   - **Add and Remove...** 선택
   - 왼쪽 목록에서 프로젝트 선택
   - **Add >** 클릭
   - **Finish**

4. **서버 시작**
   - 서버 우클릭 → **Start**

---

### 방법 2: 서버 설정 확인

**서버 설정 확인:**

1. **서버 우클릭**
   - **Open** 선택

2. **Server Locations 확인**
   - **Use Tomcat installation** 선택
   - 또는 **Use workspace metadata** 선택

3. **Deploy path 확인**
   - **Deploy path**: `wtpwebapps` 확인

---

### 방법 3: 컨텍스트 경로 확인

**URL 확인:**

**기존 URL:**
```
http://localhost:8080/imgBoard/board_write.jsp
```

**변경된 URL:**
```
http://localhost:8080/프로젝트명/board_write.jsp
```

**확인 방법:**
1. Servers 뷰에서 서버 확장
2. 배포된 프로젝트 확인
3. 컨텍스트 경로 확인

---

### 방법 4: 프로젝트 재배포

**재배포 방법:**

1. **서버 중지**
   - 서버 우클릭 → **Stop**

2. **프로젝트 제거**
   - 서버 우클릭 → **Add and Remove...**
   - 오른쪽 목록에서 프로젝트 선택
   - **Remove <** 클릭
   - **Finish**

3. **프로젝트 다시 추가**
   - 서버 우클릭 → **Add and Remove...**
   - 왼쪽 목록에서 프로젝트 선택
   - **Add >** 클릭
   - **Finish**

4. **서버 시작**
   - 서버 우클릭 → **Start**

---

## 🔍 단계별 확인

### 1단계: 서버 상태 확인

**Servers 뷰에서:**
- 서버가 시작되었는지 확인
- 프로젝트가 배포되었는지 확인

**확인 사항:**
```
Servers
  └── Tomcat v10.1 Server at localhost [Started]
      └── imgBoard [Started]  ← 프로젝트가 보여야 함
```

---

### 2단계: 배포 경로 확인

**실제 배포 경로:**
```
C:\Users\TJ\eclipse-workspace2\.metadata\.plugins\org.eclipse.wst.server.core\tmp1\wtpwebapps\imgBoard\
```

**확인:**
- 위 경로에 프로젝트 파일들이 있는지 확인
- JSP 파일들이 있는지 확인

---

### 3단계: URL 확인

**올바른 URL 형식:**
```
http://localhost:8080/프로젝트명/파일명.jsp
```

**예시:**
```
http://localhost:8080/imgBoard/board_write.jsp
http://localhost:8080/imgBoard/board_list.jsp
```

**확인 방법:**
1. Servers 뷰에서 프로젝트 확장
2. 컨텍스트 경로 확인
3. URL에 정확한 경로 사용

---

## 🛠️ 빠른 해결 방법

### 방법 1: Clean and Publish

1. **서버 중지**
2. **프로젝트 우클릭**
   - **Clean...** 선택
   - 프로젝트 선택
   - **Clean**
3. **서버 우클릭**
   - **Clean...** 선택
   - 서버 선택
   - **Clean**
4. **서버 시작**

### 방법 2: 서버 삭제 후 재생성

1. **기존 서버 삭제**
   - Servers 뷰에서 서버 우클릭
   - **Delete** 선택
   - **Delete** 확인

2. **새 서버 생성**
   - Servers 뷰 빈 공간 우클릭
   - **New → Server**
   - Apache → Tomcat v10.1 선택
   - **Next → Finish**

3. **프로젝트 추가**
   - 서버 우클릭 → **Add and Remove...**
   - 프로젝트 추가

---

## 🔍 컨텍스트 경로 변경

### 컨텍스트 경로 확인 및 변경

**확인 방법:**
1. Servers 뷰에서 프로젝트 확장
2. 컨텍스트 경로 확인

**변경 방법:**
1. **프로젝트 우클릭**
   - **Properties** 선택
2. **Web Project Settings**
   - **Context root** 확인/변경
   - 예: `/imgBoard` 또는 `/`

## 📋 체크리스트

404 오류 해결 확인:

- [ ] 서버가 시작되었는지 확인
- [ ] 프로젝트가 서버에 배포되었는지 확인
- [ ] 올바른 URL 사용 (컨텍스트 경로 포함)
- [ ] 배포 경로에 파일들이 있는지 확인
- [ ] 서버 재시작
- [ ] 프로젝트 재배포

---

## 🎯 일반적인 해결 순서

1. **Servers 뷰 확인**
   - 서버 상태 확인
   - 프로젝트 배포 상태 확인

2. **프로젝트 추가 확인**
   - 서버에 프로젝트가 추가되어 있는지 확인
   - 없으면 Add and Remove로 추가

3. **URL 확인**
   - 컨텍스트 경로 포함한 올바른 URL 사용

4. **서버 재시작**
   - 서버 중지 → 시작

5. **프로젝트 재배포**
   - 필요시 Clean and Publish
