# 이미지 업로드 구현 가이드

## 📋 JSTL 버전 관련 답변

### ❌ JSTL은 필요 없습니다!

**파일 업로드 자체에는 JSTL이 필요하지 않습니다.**

- `FileUploadUtil.java`는 순수 Java 코드
- Servlet 3.0+의 `Part` API 사용
- JSTL과는 무관

**JSTL이 필요한 경우:**
- JSP에서 반복문, 조건문 등을 태그로 사용할 때
- 파일 업로드와는 별개의 기능

---

## ✅ 필요한 것들

### 1. Servlet 3.0+ 환경
- Tomcat 7.0 이상
- Java 7 이상

### 2. 필수 설정

#### A. JSP 폼 설정 (`enctype` 필수!)

```jsp
<form action="board_write_process.jsp" method="post" 
      enctype="multipart/form-data">
    <!-- 파일 입력 -->
    <input type="file" name="image" accept="image/*">
    <!-- 다른 입력 필드들 -->
</form>
```

**중요:**
- `enctype="multipart/form-data"` **반드시 필요!**
- 없으면 파일이 전송되지 않음

#### B. JSP 처리 페이지 설정

```jsp
<%@ page language="java" contentType="text/html; charset=UTF-8" pageEncoding="UTF-8" %>
<%@ page import="javax.servlet.http.Part" %>
<%@ page import="java.io.File" %>
<%@ page import="jsp.imageboard.FileUploadUtil" %>
```

#### C. web.xml 설정 (선택사항)

**방법 1: web.xml에서 설정 (권장)**

```xml
<?xml version="1.0" encoding="UTF-8"?>
<web-app xmlns="http://xmlns.jcp.org/xml/ns/javaee"
         xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
         xsi:schemaLocation="http://xmlns.jcp.org/xml/ns/javaee
         http://xmlns.jcp.org/xml/ns/javaee/web-app_3_1.xsd"
         version="3.1">

    <!-- 파일 업로드 설정 -->
    <servlet>
        <servlet-name>FileUploadServlet</servlet-name>
        <jsp-file>/board_write_process.jsp</jsp-file>
        <multipart-config>
            <!-- 최대 파일 크기: 10MB -->
            <max-file-size>10485760</max-file-size>
            <!-- 최대 요청 크기: 10MB -->
            <max-request-size>10485760</max-request-size>
            <!-- 임시 파일 저장 위치 -->
            <file-size-threshold>0</file-size-threshold>
        </multipart-config>
    </servlet>
    
    <servlet-mapping>
        <servlet-name>FileUploadServlet</servlet-name>
        <url-pattern>/board_write_process.jsp</url-pattern>
    </servlet-mapping>
    
    <!-- 인코딩 필터 -->
    <filter>
        <filter-name>encodingFilter</filter-name>
        <filter-class>org.apache.catalina.filters.SetCharacterEncodingFilter</filter-class>
        <init-param>
            <param-name>encoding</param-name>
            <param-value>UTF-8</param-value>
        </init-param>
    </filter>
    
    <filter-mapping>
        <filter-name>encodingFilter</filter-name>
        <url-pattern>/*</url-pattern>
    </filter-mapping>
</web-app>
```

**방법 2: JSP에서 직접 사용 (간단한 경우)**

- Servlet 3.0+ 환경에서는 `web.xml` 설정 없이도 가능
- `request.getPart()` 직접 사용 가능

### 2. 처리 페이지 (board_write_process.jsp)

```jsp
<%@ page language="java" contentType="text/html; charset=UTF-8" pageEncoding="UTF-8" %>
<%@ page import="javax.servlet.http.Part" %>
<%@ page import="java.io.File" %>
<%@ page import="java.sql.Connection" %>
<%@ page import="jsp.imageboard.*" %>

<%
    request.setCharacterEncoding("UTF-8");
    
    // 일반 파라미터 받기
    String title = request.getParameter("title");
    String content = request.getParameter("content");
    String writer = request.getParameter("writer");
    String password = request.getParameter("password");
    
    // 파일 업로드 처리
    String imageFile = null;
    String imageOriginal = null;
    
    try {
        // Part 객체 가져오기
        Part imagePart = request.getPart("image");
        
        // 파일이 업로드되었는지 확인
        if (imagePart != null && imagePart.getSize() > 0) {
            // 실제 업로드 경로 계산
            String uploadDir = FileUploadUtil.getUploadDir();
            String realPath = application.getRealPath("/") + uploadDir;
            
            // 파일 업로드
            imageFile = FileUploadUtil.uploadFile(imagePart, realPath);
            
            if (imageFile != null) {
                // 원본 파일명 추출
                String contentDisposition = imagePart.getHeader("content-disposition");
                if (contentDisposition != null) {
                    String[] tokens = contentDisposition.split(";");
                    for (String token : tokens) {
                        if (token.trim().startsWith("filename")) {
                            String fileName = token.substring(
                                token.indexOf("=") + 2, 
                                token.length() - 1
                            );
                            imageOriginal = fileName.substring(
                                fileName.lastIndexOf("\\") + 1
                            );
                            break;
                        }
                    }
                }
            }
        }
        
        // 데이터베이스에 저장
        Connection conn = null;
        try {
            conn = DBConnection.getConnection();
            ImageBoardDAO boardDAO = new ImageBoardDAO(conn);
            
            ImageBoardDTO board = new ImageBoardDTO(
                title, content, writer, password, 
                imageFile, imageOriginal
            );
            
            int boardId = boardDAO.insertBoard(board);
            
            if (boardId > 0) {
                response.sendRedirect("board_view.jsp?id=" + boardId);
            } else {
                // 실패 시 업로드된 파일 삭제
                if (imageFile != null) {
                    String uploadDir = FileUploadUtil.getUploadDir();
                    String realPath = application.getRealPath("/") + uploadDir;
                    FileUploadUtil.deleteFile(realPath, imageFile);
                }
                out.println("<script>alert('게시글 등록에 실패했습니다.'); history.back();</script>");
            }
        } catch (Exception e) {
            e.printStackTrace();
            // 실패 시 업로드된 파일 삭제
            if (imageFile != null) {
                String uploadDir = FileUploadUtil.getUploadDir();
                String realPath = application.getRealPath("/") + uploadDir;
                FileUploadUtil.deleteFile(realPath, imageFile);
            }
            out.println("<script>alert('오류가 발생했습니다.'); history.back();</script>");
        } finally {
            DBConnection.close(conn);
        }
        
    } catch (Exception e) {
        e.printStackTrace();
        out.println("<script>alert('파일 업로드 중 오류가 발생했습니다.'); history.back();</script>");
    }
%>
```

## 🔍 핵심 포인트

### 1. enctype 설정 (가장 중요!)

```html
<!-- ❌ 잘못된 예 -->
<form action="upload.jsp" method="post">
    <input type="file" name="image">
</form>

<!-- ✅ 올바른 예 -->
<form action="upload.jsp" method="post" enctype="multipart/form-data">
    <input type="file" name="image">
</form>
```

**차이점:**
- `enctype` 없음: 파일이 전송되지 않음
- `enctype="multipart/form-data"`: 파일이 정상적으로 전송됨

### 2. Part API 사용

```jsp
// Part 객체 가져오기
Part imagePart = request.getPart("image");

// 파일 크기 확인
if (imagePart != null && imagePart.getSize() > 0) {
    // 파일 처리
}
```

### 3. 파일 경로 처리

```jsp
// 상대 경로 가져오기
String uploadDir = FileUploadUtil.getUploadDir(); // "uploads/images"

// 실제 물리적 경로로 변환
String realPath = application.getRealPath("/") + uploadDir;
// 예: "C:\tomcat\webapps\myapp\uploads\images"
```

## 🐛 자주 발생하는 오류

### 오류 1: 파일이 업로드되지 않음

**원인:**
- `enctype="multipart/form-data"` 누락

**해결:**
```html
<form enctype="multipart/form-data">
```

### 오류 2: request.getPart()가 null 반환

**원인:**
- Servlet 3.0 미만 환경
- web.xml 설정 누락 (일부 경우)

**해결:**
- Tomcat 7.0 이상 사용
- web.xml에 `multipart-config` 추가

### 오류 3: 파일 크기 제한 오류

**원인:**
- 파일이 너무 큼 (기본 제한 초과)

**해결:**
```xml
<multipart-config>
    <max-file-size>10485760</max-file-size> <!-- 10MB -->
    <max-request-size>10485760</max-request-size>
</multipart-config>
```

### 오류 4: 한글 파일명 깨짐

**원인:**
- 인코딩 설정 누락

**해결:**
```jsp
<%@ page pageEncoding="UTF-8" %>
<%
    request.setCharacterEncoding("UTF-8");
%>
```

## 📦 필요한 라이브러리

### 필수 라이브러리

**없음!** Servlet 3.0+에 내장되어 있음

- `javax.servlet.http.Part` - Servlet API에 포함
- `FileUploadUtil.java` - 직접 작성한 유틸리티 클래스

### 선택적 라이브러리

**JSTL (파일 업로드와 무관)**
- JSP에서 태그 사용 시에만 필요
- 파일 업로드 자체에는 불필요

**Maven 의존성 (참고):**
```xml
<!-- JSTL (선택사항) -->
<dependency>
    <groupId>javax.servlet</groupId>
    <artifactId>jstl</artifactId>
    <version>1.2</version>
</dependency>

<!-- Servlet API는 Tomcat에 포함되어 있음 -->
```
