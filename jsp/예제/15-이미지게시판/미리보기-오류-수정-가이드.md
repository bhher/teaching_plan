# 미리보기 오류 수정 가이드

## 🐛 발견된 오류

### ❌ 오류: `accept="images/*"`

**원인:**
```html
<!-- 잘못된 코드 -->
<input type="file" accept="images/*">
```

**문제점:**
- `images`는 올바른 MIME 타입이 아님
- 브라우저가 인식하지 못함
- 파일 선택 다이얼로그에서 이미지 필터가 작동하지 않음

### ✅ 수정: `accept="image/*"`

```html
<!-- 올바른 코드 -->
<input type="file" accept="image/*">
```

**설명:**
- `image/*`는 모든 이미지 타입을 의미하는 올바른 MIME 타입
- 브라우저가 정상적으로 인식
- 파일 선택 시 이미지 파일만 필터링됨

## 📋 수정 사항

### 1. accept 속성 수정

**변경 전:**
```html
<input type="file" name="image" id="image" accept="images/*" onchange="previewImage(this)">
```

**변경 후:**
```html
<input type="file" name="image" id="image" accept="image/*" onchange="previewImage(this)">
```

## 🔍 MIME 타입 설명

### 올바른 MIME 타입

| MIME 타입 | 설명 | 예시 |
|-----------|------|------|
| `image/*` | 모든 이미지 타입 | `image/jpeg`, `image/png`, `image/gif` |
| `image/jpeg` | JPEG 이미지 | `.jpg`, `.jpeg` |
| `image/png` | PNG 이미지 | `.png` |
| `image/gif` | GIF 이미지 | `.gif` |
| `image/webp` | WebP 이미지 | `.webp` |

### 잘못된 MIME 타입

| 잘못된 예 | 올바른 예 |
|-----------|----------|
| `images/*` ❌ | `image/*` ✅ |
| `image` ❌ | `image/*` ✅ |
| `img/*` ❌ | `image/*` ✅ |

## ✅ 수정된 완전한 코드

### HTML 부분

```html
<div class="form-group">
    <label>이미지파일</label>
    <!-- ✅ 수정됨: accept="image/*" -->
    <input type="file" name="image" id="image" accept="image/*" onchange="previewImage(this)">
    <div class="file-info">지원 형식: JPG, PNG, GIF, BMP, WEBP (최대 10MB)</div>
    <div class="preview-container" id="previewContainer">
        <img id="previewImage" class="preview-image" alt="미리보기">
    </div>
</div>
```

### JavaScript 부분

```javascript
function previewImage(input){
    var previewContainer = document.getElementById('previewContainer');
    var previewImage = document.getElementById('previewImage');
    
    // 파일 선택 확인
    if (input.files && input.files[0]) {
        var reader = new FileReader();
        
        // 파일 읽기 완료 시
        reader.onload = function(e) {
            previewImage.src = e.target.result;
            previewContainer.style.display = 'block';
        };
        
        // 파일 읽기 시작
        reader.readAsDataURL(input.files[0]);
    } else {
        // 파일 선택 취소 시
        previewContainer.style.display = 'none';
    }
}
```

## 🔧 추가 개선 제안

### 1. 이미지 타입 검증 추가

```javascript
function previewImage(input){
    var previewContainer = document.getElementById('previewContainer');
    var previewImage = document.getElementById('previewImage');
    
    if (input.files && input.files[0]) {
        var file = input.files[0];
        
        // 이미지 파일인지 확인
        if (!file.type.match('image.*')) {
            alert('이미지 파일만 선택할 수 있습니다.');
            input.value = '';  // 선택 취소
            previewContainer.style.display = 'none';
            return;
        }
        
        var reader = new FileReader();
        
        reader.onload = function(e) {
            previewImage.src = e.target.result;
            previewContainer.style.display = 'block';
        };
        
        reader.readAsDataURL(file);
    } else {
        previewContainer.style.display = 'none';
    }
}
```
