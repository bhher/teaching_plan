## 🏗️ 전체 구조

### 데이터 흐름

```
사용자
  ↓
board_list.jsp (게시글 목록)
  ├── board_write.jsp (글쓰기)
  │   └── board_write_process.jsp → DB 저장
  ├── board_view.jsp (상세보기)
  │   ├── board_modify.jsp (수정)
  │   │   └── board_modify_process.jsp → DB 업데이트
  │   └── board_delete.jsp (삭제)
  │       └── board_delete_process.jsp → DB 삭제
  └── 검색 기능
```

## 💾 데이터베이스 설계

### board 테이블 구조

| 컬럼명 | 타입 | 제약조건 | 설명 |
|--------|------|----------|------|
| id | INT | PK, AUTO_INCREMENT | 게시글 고유 번호 |
| title | VARCHAR(200) | NOT NULL | 제목 |
| content | TEXT | NULL | 내용 |
| writer | VARCHAR(50) | NOT NULL | 작성자 |
| password | VARCHAR(255) | NULL | 비밀번호 (수정/삭제용) |
| hit | INT | DEFAULT 0 | 조회수 |
| reg_date | DATETIME | DEFAULT CURRENT_TIMESTAMP | 등록일시 |
| mod_date | DATETIME | DEFAULT CURRENT_TIMESTAMP | 수정일시 |

**인덱스:**
- `idx_writer`: 작성자 검색 최적화
- `idx_reg_date`: 날짜순 정렬 최적화
- `idx_title`: 제목 검색 최적화

## 🎨 주요 기능 상세

### 1. 게시글 목록 (board_list.jsp)

#### 페이징 처리

```jsp
<%
    int currentPage = (pageParam != null) ? Integer.parseInt(pageParam) : 1;
    int pageSize = 10;
    int start = (currentPage - 1) * pageSize;
    
    List<BoardDTO> boardList = boardDAO.selectAllBoards(start, pageSize);
    int totalCount = boardDAO.getTotalCount();
    int totalPages = (int) Math.ceil((double) totalCount / pageSize);
%>
```

**계산 예시:**
- 현재 페이지: 3
- 페이지 크기: 10
- 시작 인덱스: (3 - 1) × 10 = 20
- SQL: `LIMIT 20, 10` (20번째부터 10개)

---

#### 페이징 링크 생성

```jsp
<% for (int i = 1; i <= totalPages; i++) { %>
    <% if (i == currentPage) { %>
        <span class="current"><%= i %></span>
    <% } else { %>
        <a href="board_list.jsp?page=<%= i %>"><%= i %></a>
    <% } %>
<% } %>
```

### 2. 게시글 작성 (board_write.jsp)

#### 폼 구조

```html
<form action="board_write_process.jsp" method="post">
    <input type="text" name="title" required>
```

**처리 과정:**

2. 필수 항목 검증

5. 상세보기 페이지로 리다이렉트

### 3. 게시글 상세보기 (board_view.jsp)

#### 조회수 증가

```jsp
<%
    // 조회수 증가 (먼저 실행)
    boardDAO.increaseHit(id);
    
    // 게시글 조회
    board = boardDAO.selectBoardById(id);
%>
```

**주의사항:**
- 조회수 증가를 먼저 실행해야 정확한 조회수 표시

---

#### 줄바꿈 처리

```jsp
<div class="board-content">
    <%= board.getContentWithBr() %>
</div>
```

**변환:**
```
원본: "안녕하세요\n반갑습니다"
변환: "안녕하세요<br>반갑습니다"
```

## 📄 페이징 처리 상세

### 페이징 계산

```java
// 전체 게시글: 25개
// 페이지 크기: 10개
// 총 페이지: 3페이지

// 1페이지: LIMIT 0, 10  (1~10번)
// 2페이지: LIMIT 10, 10 (11~20번)
// 3페이지: LIMIT 20, 10 (21~25번)
```

**공식:**
```
start = (currentPage - 1) × pageSize
totalPages = ceil(totalCount / pageSize)
```

---

### 페이징 UI

```jsp
<div class="pagination">
    <% if (currentPage > 1) { %>
        <a href="?page=<%= currentPage - 1 %>">이전</a>
    <% } %>
    
    <% for (int i = 1; i <= totalPages; i++) { %>
        <a href="?page=<%= i %>"><%= i %></a>
    <% } %>
    
    <% if (currentPage < totalPages) { %>
        <a href="?page=<%= currentPage + 1 %>">다음</a>
    <% } %>
</div>
```

## 🔍 검색 기능 상세

### 검색 타입

```jsp
<select name="searchType">
    <option value="title">제목</option>
    <option value="writer">작성자</option>
    <option value="content">내용</option>
</select>
```

---

### 검색 SQL

```java
String sql = "SELECT * FROM board WHERE " + searchType + " LIKE ?";
pstmt.setString(1, "%" + searchKeyword + "%");
```

**예시:**
- 검색어: "게시판"
- SQL: `WHERE title LIKE '%게시판%'`

---

### 검색과 페이징 함께 사용

```jsp
<%
    if (searchKeyword != null && !searchKeyword.trim().isEmpty()) {
        totalCount = boardDAO.getSearchCount(searchType, searchKeyword);
        boardList = boardDAO.searchBoards(searchType, searchKeyword, start, pageSize);
    } else {
        totalCount = boardDAO.getTotalCount();
        boardList = boardDAO.selectAllBoards(start, pageSize);
    }
%>
```

**URL 예시:**
```
board_list.jsp?page=2&searchType=title&searchKeyword=게시판
```

## 🔒 보안 고려사항

### 1. SQL Injection 방지

✅ **PreparedStatement 사용** (이미 구현됨)

```java
String sql = "SELECT * FROM board WHERE id = ?";
pstmt.setInt(1, id);
```

---

### 2. XSS 방지

**현재 코드:**
```jsp
<%= board.getContent() %>
```

**개선 방법:**
```jsp
<c:out value="${board.content}" />
```

또는:
```jsp
<%
    String content = board.getContent();
    content = content.replace("<", "&lt;").replace(">", "&gt;");
%>
<%= content %>
```

---

### 3. 비밀번호 암호화

**현재 코드:**
```java
board.setPassword(password);  // 평문 저장
```

**개선 방법:**
```java
// SHA-256 또는 BCrypt 사용
String hashedPassword = BCrypt.hashpw(password, BCrypt.gensalt());
board.setPassword(hashedPassword);
```
