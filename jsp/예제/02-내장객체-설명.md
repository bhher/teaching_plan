# 📝 02-내장객체.jsp 해설

## 📋 파일 개요

이 파일은 JSP의 9개 내장 객체를 학습하기 위한 예제입니다. 각 내장 객체의 주요 메서드와 사용법을 실습할 수 있습니다.

## 🎯 학습 목표

- application 객체 사용법
- 쿠키 사용법

## 📖 코드 상세 설명

### 1. request 객체

**request 객체란?**
- 클라이언트의 요청 정보를 담고 있는 객체
- `HttpServletRequest` 타입

#### 요청 정보 가져오기

```jsp
<p>요청 메서드: <%= request.getMethod() %></p>
<p>요청 URI: <%= request.getRequestURI() %></p>
<p>요청 URL: <%= request.getRequestURL() %></p>
<p>클라이언트 IP: <%= request.getRemoteAddr() %></p>
<p>서버 이름: <%= request.getServerName() %></p>
<p>서버 포트: <%= request.getServerPort() %></p>
<p>프로토콜: <%= request.getProtocol() %></p>
```

**주요 메서드:**

| 메서드 | 반환 타입 | 설명 |
|--------|----------|------|
| `getMethod()` | String | 요청 메서드 (GET, POST) |
| `getRequestURI()` | String | 요청 URI (/test.jsp) |
| `getRequestURL()` | StringBuffer | 전체 요청 URL |
| `getRemoteAddr()` | String | 클라이언트 IP 주소 |
| `getServerName()` | String | 서버 이름 |
| `getServerPort()` | int | 서버 포트 번호 |
| `getProtocol()` | String | 프로토콜 (HTTP/1.1) |

#### 파라미터 처리

```jsp
<%
    Enumeration<String> paramNames = request.getParameterNames();
    while (paramNames.hasMoreElements()) {
        String paramName = paramNames.nextElement();
        String paramValue = request.getParameter(paramName);
%>
    <p><%= paramName %>: <%= paramValue %></p>
<%
    }
%>
```

**설명:**
- `getParameterNames()`: 모든 파라미터 이름을 Enumeration으로 반환
- `getParameter(name)`: 특정 파라미터 값 가져오기
- `getParameterValues(name)`: 같은 이름의 여러 값 가져오기 (체크박스 등)

**예시:**
```
URL: test.jsp?name=홍길동&age=25

request.getParameter("name")  → "홍길동"
request.getParameter("age")   → "25"
```

### 2. response 객체

**response 객체란?**
- 클라이언트에게 응답을 보내기 위한 객체
- `HttpServletResponse` 타입

```jsp
<p>컨텐츠 타입: <%= response.getContentType() %></p>
<p>인코딩: <%= response.getCharacterEncoding() %></p>
```

**주요 메서드:**

| 메서드 | 설명 |
|--------|------|
| `setContentType(type)` | 컨텐츠 타입 설정 |
| `setCharacterEncoding(encoding)` | 인코딩 설정 |
| `sendRedirect(url)` | 리다이렉트 |
| `addCookie(cookie)` | 쿠키 추가 |
| `setHeader(name, value)` | 헤더 설정 |

**리다이렉트 예시:**
```jsp
<%
    response.sendRedirect("main.jsp");
%>
```

**쿠키 추가 예시:**
```jsp
<%
    Cookie cookie = new Cookie("name", "value");
    response.addCookie(cookie);
%>
```

### 3. session 객체

**session 객체란?**
- 사용자 세션 정보를 관리하는 객체
- `HttpSession` 타입
- 같은 브라우저에서 여러 요청 간에 데이터 공유

#### 세션 정보 가져오기

```jsp
<%
    String sessionId = session.getId();
    long createTime = session.getCreationTime();
    long lastAccess = session.getLastAccessedTime();
    int maxInactive = session.getMaxInactiveInterval();
%>
<p>세션 ID: <%= sessionId %></p>
<p>세션 생성 시간: <%= new java.util.Date(createTime) %></p>
<p>마지막 접근 시간: <%= new java.util.Date(lastAccess) %></p>
<p>세션 유지 시간: <%= maxInactive %>초</p>
```

**주요 메서드:**

| 메서드 | 반환 타입 | 설명 |
|--------|----------|------|
| `getId()` | String | 세션 고유 ID |
| `getCreationTime()` | long | 세션 생성 시간 (밀리초) |
| `getLastAccessedTime()` | long | 마지막 접근 시간 |
| `getMaxInactiveInterval()` | int | 세션 유지 시간 (초) |
| `setMaxInactiveInterval(seconds)` | void | 세션 유지 시간 설정 |

#### 세션에 값 저장/가져오기

```jsp
<%
    session.setAttribute("username", "홍길동");
    session.setAttribute("loginTime", new java.util.Date());
%>
<p>세션에 저장된 사용자명: <%= session.getAttribute("username") %></p>
```

**주요 메서드:**

| 메서드 | 설명 |
|--------|------|
| `setAttribute(name, value)` | 세션에 값 저장 |
| `getAttribute(name)` | 세션에서 값 가져오기 |
| `removeAttribute(name)` | 세션에서 값 제거 |
| `invalidate()` | 세션 무효화 |

**사용 예시:**
```jsp
<%
    // 로그인 시
    session.setAttribute("loginId", "admin");
    
    // 다른 페이지에서
    String loginId = (String) session.getAttribute("loginId");
    
    // 로그아웃 시
    session.invalidate();
%>
```

### 4. application 객체

**application 객체란?**
- 애플리케이션 전체에서 공유되는 객체
- `ServletContext` 타입
- 서버가 재시작될 때까지 유지

```jsp
<%
    String serverInfo = application.getServerInfo();
    String realPath = application.getRealPath("/");
    
    // 방문자 카운터
    Integer visitCount = (Integer) application.getAttribute("visitCount");
    if (visitCount == null) {
        visitCount = 0;
    }
    visitCount++;
    application.setAttribute("visitCount", visitCount);
%>
<p>서버 정보: <%= serverInfo %></p>
<p>실제 경로: <%= realPath %></p>
<p>총 방문자 수: <%= visitCount %></p>
```

**주요 메서드:**

| 메서드 | 설명 |
|--------|------|
| `getServerInfo()` | 서버 정보 |
| `getRealPath(path)` | 실제 파일 경로 |
| `setAttribute(name, value)` | 애플리케이션 속성 설정 |
| `getAttribute(name)` | 애플리케이션 속성 가져오기 |

**방문자 카운터 원리:**
1. `application.getAttribute("visitCount")`로 기존 값 가져오기
2. 값이 없으면 0으로 초기화
3. 1 증가
4. `application.setAttribute()`로 저장
5. 모든 사용자가 공유하는 값

### 5. out 객체

**out 객체란?**
- 출력 스트림 객체
- `JspWriter` 타입

```jsp
<%
    out.print("out.print()로 출력한 내용<br>");
    out.println("out.println()로 출력한 내용");
    out.flush();
%>
```

**주요 메서드:**

| 메서드 | 설명 |
|--------|------|
| `print(value)` | 값 출력 |
| `println(value)` | 값 출력 + 줄바꿈 |
| `write(value)` | 문자 출력 |
| `flush()` | 버퍼 비우기 |
| `clear()` | 버퍼 지우기 |

**표현식과의 관계:**
```jsp
<!-- 표현식 -->
<%= name %>

<!-- out 객체 사용 (동일한 결과) -->
<% out.print(name); %>
```

### 6. pageContext 객체

**pageContext 객체란?**
- 페이지 컨텍스트 정보를 제공하는 객체
- 다른 내장 객체에 접근 가능

```jsp
<%
    HttpServletRequest req = (HttpServletRequest) pageContext.getRequest();
    HttpSession sess = pageContext.getSession();
%>
<p>pageContext를 통해 가져온 요청 메서드: <%= req.getMethod() %></p>
<p>pageContext를 통해 가져온 세션 ID: <%= sess.getId() %></p>
```

**주요 메서드:**

| 메서드 | 설명 |
|--------|------|
| `getRequest()` | request 객체 가져오기 |
| `getResponse()` | response 객체 가져오기 |
| `getSession()` | session 객체 가져오기 |
| `getServletContext()` | application 객체 가져오기 |
| `setAttribute(name, value, scope)` | 특정 scope에 속성 설정 |

**Scope 지정:**
```jsp
<%
    // REQUEST_SCOPE
    pageContext.setAttribute("name", "value", PageContext.REQUEST_SCOPE);
    
    // SESSION_SCOPE
    pageContext.setAttribute("name", "value", PageContext.SESSION_SCOPE);
    
    // APPLICATION_SCOPE
    pageContext.setAttribute("name", "value", PageContext.APPLICATION_SCOPE);
%>
```

### 7. page 객체

**page 객체란?**
- 현재 JSP 페이지의 서블릿 인스턴스
- `Object` 타입 (실제로는 서블릿 클래스)

```jsp
<p>현재 페이지 클래스: <%= page.getClass().getName() %></p>
```

**사용 빈도:**
- 거의 사용하지 않음
- 디버깅 목적으로 사용

### 8. config 객체

**config 객체란?**
- 서블릿 설정 정보를 제공하는 객체
- `ServletConfig` 타입

```jsp
<p>서블릿 이름: <%= config.getServletName() %></p>
```

**주요 메서드:**

| 메서드 | 설명 |
|--------|------|
| `getServletName()` | 서블릿 이름 |
| `getInitParameter(name)` | 초기화 파라미터 가져오기 |

**web.xml 설정 예시:**
```xml
<servlet>
    <servlet-name>MyServlet</servlet-name>
    <jsp-file>/test.jsp</jsp-file>
    <init-param>
        <param-name>encoding</param-name>
        <param-value>UTF-8</param-value>
    </init-param>
</servlet>
```

### 9. 쿠키 사용

**쿠키란?**
- 클라이언트에 저장되는 작은 데이터
- 브라우저에 저장되어 요청 시 자동 전송

#### 쿠키 읽기

```jsp
<%
    Cookie[] cookies = request.getCookies();
    if (cookies != null) {
        for (Cookie cookie : cookies) {
%>
    <p>쿠키 이름: <%= cookie.getName() %>, 값: <%= cookie.getValue() %></p>
<%
        }
    }
%>
```

**설명:**
- `request.getCookies()`: 모든 쿠키 배열 가져오기
- `cookie.getName()`: 쿠키 이름
- `cookie.getValue()`: 쿠키 값

#### 쿠키 생성 및 전송

```jsp
<%
    // 새 쿠키 생성
    Cookie newCookie = new Cookie("lastVisit", new java.util.Date().toString());
    newCookie.setMaxAge(3600); // 1시간
    response.addCookie(newCookie);
%>
<p>쿠키가 설정되었습니다.</p>
```

**쿠키 설정:**

| 메서드 | 설명 |
|--------|------|
| `Cookie(name, value)` | 쿠키 생성 |
| `setMaxAge(seconds)` | 유효 시간 설정 (초) |
| `setPath(path)` | 쿠키 경로 설정 |
| `setDomain(domain)` | 도메인 설정 |
| `setHttpOnly(true)` | JavaScript 접근 차단 |
| `setSecure(true)` | HTTPS에서만 전송 |

**예시:**
```jsp
<%
    Cookie cookie = new Cookie("username", "홍길동");
    cookie.setMaxAge(3600);        // 1시간
    cookie.setPath("/");           // 전체 경로
    cookie.setHttpOnly(true);      // 보안 강화
    response.addCookie(cookie);
%>
```

## 🔍 내장 객체 비교

### Scope (범위) 비교

| 객체 | Scope | 생명주기 | 용도 |
|------|-------|---------|------|
| page | page | 현재 페이지 | 거의 사용 안함 |
| request | request | 요청 범위 | 요청 파라미터, 속성 전달 |
| session | session | 세션 범위 | 로그인 정보, 사용자 상태 |
| application | application | 애플리케이션 전체 | 공유 데이터, 설정 |

### 속성 저장/가져오기 비교

```jsp
<%
    // request
    request.setAttribute("name", "value");
    String name1 = (String) request.getAttribute("name");
    
    // session
    session.setAttribute("name", "value");
    String name2 = (String) session.getAttribute("name");
    
    // application
    application.setAttribute("name", "value");
    String name3 = (String) application.getAttribute("name");
%>
```

## 💡 실전 활용 예시

### 예시 1: 로그인 처리

```jsp
<%
    String id = request.getParameter("id");
    String pw = request.getParameter("pw");
    
    if ("admin".equals(id) && "1234".equals(pw)) {
        session.setAttribute("loginId", id);
        response.sendRedirect("main.jsp");
    } else {
        out.println("<script>alert('로그인 실패');</script>");
    }
%>
```

### 예시 2: 방문자 카운터

```jsp
<%
    Integer count = (Integer) application.getAttribute("visitCount");
    if (count == null) {
        count = 0;
    }
    count++;
    application.setAttribute("visitCount", count);
%>
<p>총 방문자: <%= count %>명</p>
```

### 예시 3: 마지막 방문 시간 저장

```jsp
<%
    Cookie[] cookies = request.getCookies();
    String lastVisit = null;
    
    if (cookies != null) {
        for (Cookie cookie : cookies) {
            if ("lastVisit".equals(cookie.getName())) {
                lastVisit = cookie.getValue();
                break;
            }
        }
    }
    
    if (lastVisit != null) {
        out.println("<p>마지막 방문: " + lastVisit + "</p>");
    }
    
    // 현재 시간을 쿠키에 저장
    Cookie cookie = new Cookie("lastVisit", new java.util.Date().toString());
    cookie.setMaxAge(86400); // 24시간
    response.addCookie(cookie);
%>
```

## 🐛 자주 발생하는 오류

### 오류 1: NullPointerException

```jsp
<!-- 잘못된 예 -->
<%
    String name = request.getParameter("name");
    out.println(name.length());  // name이 null이면 에러
%>

<!-- 올바른 예 -->
<%
    String name = request.getParameter("name");
    if (name != null) {
        out.println(name.length());
    }
%>
```

### 오류 2: 타입 캐스팅

```jsp
<!-- 잘못된 예 -->
<%
    String count = (String) application.getAttribute("visitCount");
%>

<!-- 올바른 예 -->
<%
    Integer count = (Integer) application.getAttribute("visitCount");
    if (count == null) {
        count = 0;
    }
%>
```

### 오류 3: 쿠키가 null

```jsp
<!-- 잘못된 예 -->
<%
    Cookie[] cookies = request.getCookies();
    for (Cookie cookie : cookies) {  // cookies가 null이면 에러
        // ...
    }
%>

<!-- 올바른 예 -->
<%
    Cookie[] cookies = request.getCookies();
    if (cookies != null) {
        for (Cookie cookie : cookies) {
            // ...
        }
    }
%>
```
