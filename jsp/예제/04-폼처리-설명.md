# 📝 04-폼처리 예제 해설

## 📋 파일 개요

이 예제는 HTML 폼을 작성하고 JSP에서 폼 데이터를 처리하는 방법을 학습합니다. 회원가입 폼을 통해 다양한 입력 요소의 데이터를 받아 처리합니다.

**파일 구성:**
- `form.jsp`: 회원가입 폼 페이지
- `form_process.jsp`: 폼 데이터 처리 페이지

---

## 🎯 학습 목표

- HTML 폼 작성 방법
- 다양한 입력 요소 사용법
- JSP에서 폼 데이터 받기
- 파라미터 처리 방법
- 세션에 데이터 저장

---

## 📖 form.jsp 상세 설명

### 1. 폼 기본 구조

```jsp
<form action="form_process.jsp" method="post">
    <!-- 폼 요소들 -->
</form>
```

**주요 속성:**
- `action`: 폼 제출 시 이동할 페이지
- `method`: 전송 방식 (GET 또는 POST)
  - **GET**: URL에 파라미터 표시 (검색 등)
  - **POST**: URL에 파라미터 숨김 (회원가입, 로그인 등)

---

### 2. 텍스트 입력 (text)

```html
<div class="form-group">
    <label for="id">아이디:</label>
    <input type="text" id="id" name="id" required>
</div>
```

**설명:**
- `type="text"`: 한 줄 텍스트 입력
- `name`: 서버로 전송될 파라미터 이름
- `required`: 필수 입력 속성

**JSP에서 받기:**
```jsp
String id = request.getParameter("id");
```

---

### 3. 비밀번호 입력 (password)

```html
<input type="password" id="pw" name="pw" required>
```

**설명:**
- `type="password"`: 입력 내용이 마스킹됨
- 보안을 위해 사용

**JSP에서 받기:**
```jsp
String pw = request.getParameter("pw");
```

---

### 4. 이메일 입력 (email)

```html
<input type="email" id="email" name="email">
```

**설명:**
- `type="email"`: 이메일 형식 검증
- 브라우저에서 자동으로 형식 확인

**JSP에서 받기:**
```jsp
String email = request.getParameter("email");
if (email != null && !email.isEmpty()) {
    // 이메일 처리
}
```

---

### 5. 라디오 버튼 (radio)

```html
<div class="radio-group">
    <input type="radio" id="male" name="gender" value="남" checked>
    <label for="male">남</label>
    <input type="radio" id="female" name="gender" value="여">
    <label for="female">여</label>
</div>
```

**설명:**
- `type="radio"`: 단일 선택 (같은 name 그룹에서 하나만 선택)
- `name`: 같은 그룹은 같은 name 사용
- `value`: 선택 시 전송될 값
- `checked`: 기본 선택

**JSP에서 받기:**
```jsp
String gender = request.getParameter("gender");
// "남" 또는 "여" 또는 null
```

---

### 6. 체크박스 (checkbox)

```html
<div class="checkbox-group">
    <input type="checkbox" id="hobby1" name="hobby" value="독서">
    <label for="hobby1">독서</label>
    <input type="checkbox" id="hobby2" name="hobby" value="운동">
    <label for="hobby2">운동</label>
    <!-- ... -->
</div>
```

**설명:**
- `type="checkbox"`: 다중 선택 가능
- 같은 `name`을 사용하면 배열로 전송됨
- 여러 개 선택 가능

**JSP에서 받기:**
```jsp
String[] hobbies = request.getParameterValues("hobby");
// 여러 개 선택 시 배열로 반환
// 선택 안함: null 반환
```

**처리 예시:**
```jsp
<%
    String[] hobbies = request.getParameterValues("hobby");
    if (hobbies != null) {
        for (String hobby : hobbies) {
            out.println(hobby + " ");
        }
    } else {
        out.println("없음");
    }
%>
```

### 7. 셀렉트 박스 (select)

```html
    <option value="">선택하세요</option>
```

**JSP에서 받기:**

```jsp
String city = request.getParameter("city");
```

### 8. 텍스트 영역 (textarea)

```html
<textarea id="bio" name="bio" rows="4" style="..."></textarea>
```

**설명:**
- 여러 줄 텍스트 입력
- `rows`: 행 수
- `cols`: 열 수 (CSS로 너비 지정 가능)

**JSP에서 받기:**
```jsp
String bio = request.getParameter("bio");
// 줄바꿈 문자(\n) 포함
```

**줄바꿈 처리:**
```jsp
<%= bio != null ? bio.replace("\n", "<br>") : "" %>
```

## 📖 form_process.jsp 상세 설명

### 1. 파라미터 받기

```jsp
<%
    String id = request.getParameter("id");
    String pw = request.getParameter("pw");
    String name = request.getParameter("name");
    String email = request.getParameter("email");
    String gender = request.getParameter("gender");
    String[] hobbies = request.getParameterValues("hobby");
    String city = request.getParameter("city");
    String bio = request.getParameter("bio");
%>
```

**주요 메서드:**

| 메서드 | 반환 타입 | 설명 |
|--------|----------|------|
| `getParameter(name)` | String | 단일 값 가져오기 |
| `getParameterValues(name)` | String[] | 여러 값 가져오기 (체크박스 등) |
| `getParameterNames()` | Enumeration | 모든 파라미터 이름 |

**주의사항:**
- 파라미터가 없으면 `null` 반환
- 항상 null 체크 필요

---

### 2. null 체크 및 기본값 처리

```jsp
<%= email != null && !email.isEmpty() ? email : "없음" %>
```

**안전한 처리 방법:**

```jsp
<%
    String email = request.getParameter("email");
    if (email == null || email.trim().isEmpty()) {
        email = "없음";
    }
%>
```

**또는:**

```jsp
<%
    String email = request.getParameter("email");
    email = (email != null && !email.isEmpty()) ? email : "없음";
%>
```

---

### 3. 배열 파라미터 처리

```jsp
<%
    String[] hobbies = request.getParameterValues("hobby");
%>
<c:choose>
    <c:when test="${paramValues.hobby != null && paramValues.hobby.length > 0}">
        <c:forEach var="hobby" items="${paramValues.hobby}">
            <span class="hobby-item">${hobby}</span>
        </c:forEach>
    </c:when>
    <c:otherwise>
        없음
    </c:otherwise>
</c:choose>
```

**스크립틀릿 방식:**
```jsp
<%
    String[] hobbies = request.getParameterValues("hobby");
    if (hobbies != null && hobbies.length > 0) {
        for (String hobby : hobbies) {
            out.print("<span>" + hobby + "</span> ");
        }
    } else {
        out.print("없음");
    }
%>
```

### 4. 세션에 데이터 저장

```jsp
<%
    session.setAttribute("userId", id);
    session.setAttribute("userName", name);
%>
```

**설명:**
- 폼 데이터를 세션에 저장하여 다른 페이지에서 사용 가능
- 로그인 정보, 사용자 정보 등 저장

**다른 페이지에서 사용:**
```jsp
<%
    String userId = (String) session.getAttribute("userId");
    String userName = (String) session.getAttribute("userName");
%>
```

### 5. 모든 파라미터 출력 (디버깅용)

```jsp
<c:forEach var="paramName" items="${param}">
    <div class="info-item">
        <span class="info-label">${paramName.key}:</span>
        <span class="info-value">
            <c:forEach var="value" items="${paramValues[paramName.key]}">
                ${value}
            </c:forEach>
        </span>
    </div>
</c:forEach>
```

**설명:**
- `${param}`: 모든 파라미터 Map
- `${paramValues}`: 모든 파라미터 배열 Map
- 디버깅 시 유용

## 🔍 주요 개념

### 1. GET vs POST

| 구분 | GET | POST |
|------|-----|------|
| URL 표시 | 파라미터 표시 | 파라미터 숨김 |
| 데이터 크기 | 제한 있음 | 제한 없음 |
| 보안 | 낮음 | 높음 |
| 사용 예시 | 검색, 조회 | 회원가입, 로그인 |

**GET 예시:**
```
URL: search.jsp?keyword=JSP&page=1
```

**POST 예시:**
```
URL: register.jsp
데이터: HTTP Body에 포함 (보이지 않음)
```

---

### 2. 파라미터 이름 규칙

- 영문, 숫자, 언더스코어(`_`) 사용
- 한글 사용 가능하지만 권장하지 않음
- 대소문자 구분

**좋은 예:**
```html
name="user_id"
name="userName"
name="email_address"
```

**나쁜 예:**
```html
name="사용자 아이디"  <!-- 한글 사용 -->
name="user id"        <!-- 공백 사용 -->
```

---

### 3. 필수 입력 검증

**HTML5 속성:**
```html
<input type="text" name="id" required>
<input type="email" name="email" required>
```

**JavaScript 검증:**
```javascript
function validateForm() {
    var id = document.getElementById("id").value;
    if (id == "") {
        alert("아이디를 입력하세요.");
        return false;
    }
    return true;
}
```

**서버 측 검증:**
```jsp
<%
    String id = request.getParameter("id");
    if (id == null || id.trim().isEmpty()) {
        out.println("<script>alert('아이디를 입력하세요.'); history.back();</script>");
        return;
    }
%>
```

## 💡 실전 활용 팁

### 팁 1: 데이터 유효성 검증

```jsp
<%
    String id = request.getParameter("id");
    String pw = request.getParameter("pw");
    
    // 빈 값 체크
    if (id == null || id.trim().isEmpty()) {
        response.sendRedirect("form.jsp?error=id_empty");
        return;
    }
    
    // 길이 체크
    if (id.length() < 4 || id.length() > 20) {
        response.sendRedirect("form.jsp?error=id_length");
        return;
    }
    
    // 형식 체크 (정규식)
    if (!id.matches("^[a-zA-Z0-9_]+$")) {
        response.sendRedirect("form.jsp?error=id_format");
        return;
    }
%>
```

### 팁 2: 에러 메시지 표시

```jsp
<!-- form.jsp -->
<%
    String error = request.getParameter("error");
    if ("id_empty".equals(error)) {
        out.println("<p style='color: red;'>아이디를 입력하세요.</p>");
    }
%>
```

### 팁 3: 입력 값 유지 (에러 시)

```jsp
<!-- form.jsp -->
<input type="text" name="id" value="<%= request.getParameter("id") != null ? request.getParameter("id") : "" %>">
```

## 🐛 자주 발생하는 오류

### 오류 1: 한글 깨짐

**원인:** 인코딩 설정 누락

**해결:**
```jsp
<%@ page contentType="text/html; charset=UTF-8" pageEncoding="UTF-8" %>
```

**web.xml 설정:**
```xml
<filter>
    <filter-name>encodingFilter</filter-name>
    <filter-class>org.apache.catalina.filters.SetCharacterEncodingFilter</filter-class>
    <init-param>
        <param-name>encoding</param-name>
        <param-value>UTF-8</param-value>
    </init-param>
</filter>
```

### 오류 2: null 값 처리

**원인:** 파라미터가 없을 때 null 반환

**해결:**
```jsp
<%
    String name = request.getParameter("name");
    if (name == null) {
        name = "";
    }
%>
```

### 오류 3: 배열 파라미터 null 체크

**원인:** 체크박스 미선택 시 null 반환

**해결:**
```jsp
<%
    String[] hobbies = request.getParameterValues("hobby");
    if (hobbies != null && hobbies.length > 0) {
        // 처리
    }
%>
```
