# 📝 JSP 회원관리 시스템 숙제 (간단 버전)

## 🎯 숙제 목표

JSP와 JDBC를 활용한 기본적인 회원관리 시스템을 구현합니다.

---

## 📋 숙제 내용

### ✅ 필수 구현 사항

#### 1. 데이터베이스 설정 (10점)

```sql
CREATE DATABASE jsp_exem_db;
USE jsp_exem_db;

CREATE TABLE member (
    id INT AUTO_INCREMENT PRIMARY KEY,
    userid VARCHAR(50) UNIQUE,
    password VARCHAR(50),
    username VARCHAR(50)
);
```

#### 2. Java 클래스 구현 (30점)

**MemberDTO.java** (10점)
- id, userid, password, username 필드
- Getter/Setter 메서드

**DBUtil.java** (10점)
- `getConnection()` 메서드 구현

**MemberDAO.java** (10점)
- `insert()`: 회원가입
- `login()`: 로그인
- `selectAll()`: 전체 조회

#### 3. JSP 페이지 구현 (60점)

**회원가입** (15점)
- `join.jsp`: 회원가입 폼
- `joinProcess.jsp`: 가입 처리

**로그인** (15점)
- `login.jsp`: 로그인 폼
- `loginProcess.jsp`: 로그인 처리

**회원 목록** (15점)
- `memberList.jsp`: 전체 회원 목록 표시

**로그아웃** (15점)
- `logout.jsp`: 세션 무효화
