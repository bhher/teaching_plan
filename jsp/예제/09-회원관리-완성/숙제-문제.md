# 📝 JSP 회원관리 시스템 숙제

## 🎯 숙제 목표

JSP와 JDBC를 활용한 회원관리 시스템을 구현하고, 기본 기능을 확장합니다.

---

## 📋 숙제 내용

### ✅ 필수 과제 (기본 점수: 70점)

#### 1. 기본 회원관리 시스템 구현 (30점)

다음 기능을 모두 구현하세요:

- [ ] **회원가입** (`join.jsp`, `joinProcess.jsp`)
  - 아이디, 비밀번호, 이름 입력
  - 중복 아이디 체크 기능 추가
  
- [ ] **로그인** (`login.jsp`, `loginProcess.jsp`)
  - 아이디와 비밀번호로 로그인
  - 로그인 실패 시 에러 메시지 표시
  
- [ ] **회원 목록** (`memberList.jsp`)
  - 전체 회원 목록을 테이블로 표시
  - 로그인하지 않은 사용자는 접근 불가 (세션 체크)
  
- [ ] **회원 정보 수정** (`memberEdit.jsp`, `memberUpdate.jsp`)
  - 이름만 수정 가능
  - 수정 후 목록으로 이동
  
- [ ] **회원 삭제** (`memberDelete.jsp`)
  - 삭제 확인 없이 바로 삭제
  - 삭제 후 목록으로 이동
  
- [ ] **로그아웃** (`logout.jsp`)
  - 세션 무효화 후 로그인 페이지로 이동

#### 2. 데이터베이스 및 클래스 구현 (20점)

- [ ] **데이터베이스 테이블 생성**
  ```sql
  CREATE DATABASE jsp_exem_db;
  CREATE TABLE member (
      id INT AUTO_INCREMENT PRIMARY KEY,
      userid VARCHAR(50) UNIQUE,
      password VARCHAR(50),
      username VARCHAR(50)
  );
  ```

- [ ] **MemberDTO.java** 구현
  - id, userid, password, username 필드
  - 기본 생성자, 파라미터 생성자
  - 모든 Getter/Setter 메서드

- [ ] **DBUtil.java** 구현
  - `getConnection()` 메서드
  - 데이터베이스 연결 정보 설정

- [ ] **MemberDAO.java** 구현
  - `insert()`: 회원가입
  - `login()`: 로그인
  - `selectAll()`: 전체 조회
  - `selectOne()`: 1명 조회
  - `update()`: 수정
  - `delete()`: 삭제

#### 3. 코드 품질 (20점)

- [ ] **코드 주석**: 각 메서드에 간단한 설명 주석 추가
- [ ] **코드 정리**: 들여쓰기, 줄바꿈 등 코드 포맷팅
- [ ] **에러 처리**: try-catch 블록 사용 (선택사항, 가산점)
- [ ] **한글 인코딩**: 모든 JSP 파일에 UTF-8 인코딩 설정

## 📝 제출 방법

### 1. 제출 파일

다음 파일들을 압축하여 제출하세요:

```
학번_이름_회원관리.zip
├─ src/
│  ├─ dto/
│  │  └─ MemberDTO.java
│  ├─ dao/
│  │  └─ MemberDAO.java
│  └─ util/
│     └─ DBUtil.java
├─ webapp/
│  ├─ join.jsp
│  ├─ joinProcess.jsp
│  ├─ login.jsp
│  ├─ loginProcess.jsp
│  ├─ logout.jsp
│  ├─ memberList.jsp
│  ├─ memberEdit.jsp
│  ├─ memberUpdate.jsp
│  └─ memberDelete.jsp
└─ db_setup.sql (데이터베이스 생성 SQL)
```

### 2. 제출 형식

- **파일명**: `학번_이름_회원관리.zip`
- **제출 기한**: [교수님이 지정한 날짜]
- **제출 방법**: [이메일 또는 LMS]

### 3. 실행 방법 문서

프로젝트 루트에 `실행방법.txt` 파일을 포함하세요:

```
1. 데이터베이스 설정
   - MySQL 실행
   - db_setup.sql 파일 실행

2. 프로젝트 설정
   - DBUtil.java의 데이터베이스 연결 정보 수정
   - MySQL JDBC 드라이버 추가

3. 실행 순서
   - join.jsp → 회원가입
   - login.jsp → 로그인
   - memberList.jsp → 회원 목록 확인
```
