## 🏗️ 전체 구조

### 데이터 흐름

```
사용자
  ↓
register.jsp (회원가입 폼)
  ↓
register_process.jsp (데이터 처리)
  ↓
MySQL 데이터베이스
  ├── members 테이블 (회원 정보)
  └── member_hobbies 테이블 (취미 정보)
  ↓
성공/실패 메시지
  ↓
register.jsp 또는 member_list.jsp
```

## 💾 데이터베이스 설계

### 1. ERD (Entity Relationship Diagram)

```
members (회원)
├── id (PK)
├── user_id (UK)
├── password
├── name
├── email
├── gender
├── city
└── reg_date

member_hobbies (회원 취미)
├── id (PK)
├── member_id (FK → members.id)
└── hobby
```

### 2. 테이블 구조

#### members 테이블

| 컬럼명 | 타입 | 제약조건 | 설명 |
|--------|------|----------|------|
| id | INT | PK, AUTO_INCREMENT | 회원 고유 번호 |
| user_id | VARCHAR(50) | UNIQUE, NOT NULL | 아이디 |
| password | VARCHAR(255) | NOT NULL | 비밀번호 |
| name | VARCHAR(50) | NOT NULL | 이름 |
| email | VARCHAR(100) | NULL | 이메일 |
| gender | VARCHAR(10) | NULL | 성별 |
| city | VARCHAR(50) | NULL | 거주지 |
| reg_date | DATETIME | DEFAULT CURRENT_TIMESTAMP | 가입일시 |

#### member_hobbies 테이블

| 컬럼명 | 타입 | 제약조건 | 설명 |
|--------|------|----------|------|
| id | INT | PK, AUTO_INCREMENT | 취미 고유 번호 |
| member_id | INT | FK, NOT NULL | 회원 ID |
| hobby | VARCHAR(50) | NOT NULL | 취미명 |

### 3. 관계

- **1:N 관계**: 한 회원은 여러 취미를 가질 수 있음
- **외래키**: `member_hobbies.member_id` → `members.id`
- **CASCADE DELETE**: 회원 삭제 시 취미도 자동 삭제

## 📝 회원가입 폼 상세

### 1. HTML 폼 구조

```html
<form action="register_process.jsp" method="post">
    <!-- 입력 필드들 -->
</form>
```

**주요 속성:**
- `action`: 폼 제출 시 처리할 페이지
- `method="post"`: 데이터를 HTTP Body로 전송 (보안)

---

### 2. 입력 필드별 설명

#### 아이디 입력

```html
<input type="text" id="user_id" name="user_id" required>
```

**검증:**
- **클라이언트**: `required` 속성, JavaScript 정규식
- **서버**: 길이 체크, 형식 체크, 중복 체크

**JavaScript 검증:**
```javascript
if (!/^[a-zA-Z0-9_]{4,20}$/.test(userId)) {
    alert('아이디는 4-20자의 영문/숫자/언더스코어만 사용 가능합니다.');
    return false;
}
```

---

#### 비밀번호 입력

```html
<input type="password" id="password" name="password" required>
<input type="password" id="password_confirm" name="password_confirm" required>
```

**검증:**
- 두 비밀번호 일치 확인
- 최소 길이 확인 (8자 이상 권장)

**JavaScript 검증:**
```javascript
if (password !== passwordConfirm) {
    alert('비밀번호가 일치하지 않습니다.');
    return false;
}
```

---

#### 체크박스 (취미)

```html
<input type="checkbox" id="hobby1" name="hobby" value="독서">
<input type="checkbox" id="hobby2" name="hobby" value="운동">
```

**특징:**
- 같은 `name` 사용 → 배열로 전송
- `getParameterValues("hobby")`로 받기

## 🔌 데이터베이스 연동 상세

### 1. JDBC 드라이버 로드

```jsp
<%
    String driver = "com.mysql.cj.jdbc.Driver";
    Class.forName(driver);
%>
```

**설명:**
- `Class.forName()`: JDBC 드라이버 클래스 로드
- MySQL 8.0 이상: `com.mysql.cj.jdbc.Driver`
- MySQL 5.x: `com.mysql.jdbc.Driver`

---

### 2. 데이터베이스 연결

```jsp
String url = "jdbc:mysql://localhost:3306/jsp_member?" +
             "useSSL=false&" +
             "serverTimezone=Asia/Seoul&" +
             "characterEncoding=UTF-8";
String dbUser = "root";
String dbPassword = "1234";

Connection conn = DriverManager.getConnection(url, dbUser, dbPassword);
```

**URL 파라미터 설명:**

| 파라미터 | 값 | 설명 |
|----------|-----|------|
| `useSSL` | false | SSL 비활성화 (개발 환경) |
| `serverTimezone` | Asia/Seoul | 서버 시간대 설정 |
| `characterEncoding` | UTF-8 | 문자 인코딩 |

**연결 문자열 형식:**
```
jdbc:mysql://[호스트]:[포트]/[데이터베이스명]?[파라미터들]
```

### 3. PreparedStatement 사용

#### 기본 사용법

```jsp
String sql = "INSERT INTO members (user_id, password, name) VALUES (?, ?, ?)";
PreparedStatement pstmt = conn.prepareStatement(sql);
pstmt.setString(1, userId);      // 첫 번째 ?에 값 설정
pstmt.setString(2, password);    // 두 번째 ?에 값 설정
pstmt.setString(3, name);         // 세 번째 ?에 값 설정
pstmt.executeUpdate();            // 실행
```

**장점:**
1. **SQL Injection 방지**: 사용자 입력이 SQL 코드로 실행되지 않음
2. **성능 향상**: SQL이 미리 컴파일되어 재사용
3. **타입 안전성**: 타입 체크 가능

**set 메서드:**

| 메서드 | Java 타입 | SQL 타입 |
|--------|----------|----------|
| `setString()` | String | VARCHAR, CHAR |
| `setInt()` | int | INT |
| `setLong()` | long | BIGINT |
| `setDouble()` | double | DOUBLE |
| `setDate()` | java.sql.Date | DATE |
| `setTimestamp()` | java.sql.Timestamp | DATETIME |

---

### 4. SELECT 쿼리 실행

```jsp
String sql = "SELECT COUNT(*) FROM members WHERE user_id = ?";
PreparedStatement pstmt = conn.prepareStatement(sql);
pstmt.setString(1, userId);
ResultSet rs = pstmt.executeQuery();

if (rs.next()) {
    int count = rs.getInt(1);
    // 처리
}
```

**ResultSet 메서드:**

| 메서드 | 설명 |
|--------|------|
| `next()` | 다음 행으로 이동 (있으면 true) |
| `getInt(column)` | INT 값 가져오기 |
| `getString(column)` | String 값 가져오기 |
| `getTimestamp(column)` | Timestamp 값 가져오기 |

**컬럼 접근 방법:**
```jsp
rs.getInt(1);              // 인덱스로 접근 (1부터 시작)
rs.getInt("id");           // 컬럼명으로 접근
rs.getString("user_id");
```

---

### 5. INSERT 쿼리 실행

```jsp
String sql = "INSERT INTO members (user_id, password, name) VALUES (?, ?, ?)";
PreparedStatement pstmt = conn.prepareStatement(sql, Statement.RETURN_GENERATED_KEYS);
pstmt.setString(1, userId);
pstmt.setString(2, password);
pstmt.setString(3, name);

int result = pstmt.executeUpdate();  // 영향받은 행 수 반환

if (result > 0) {
    // 생성된 키 가져오기
    ResultSet rs = pstmt.getGeneratedKeys();
    if (rs.next()) {
        int memberId = rs.getInt(1);
    }
}
```

**설명:**
- `executeUpdate()`: INSERT, UPDATE, DELETE 실행
- 반환값: 영향받은 행 수
- `RETURN_GENERATED_KEYS`: AUTO_INCREMENT 값 가져오기

---

### 6. Batch 처리 (취미 INSERT)

```jsp
String hobbySql = "INSERT INTO member_hobbies (member_id, hobby) VALUES (?, ?)";
PreparedStatement pstmt = conn.prepareStatement(hobbySql);

for (String hobby : hobbies) {
    pstmt.setInt(1, memberId);
    pstmt.setString(2, hobby);
    pstmt.addBatch();  // 배치에 추가
}

pstmt.executeBatch();  // 한 번에 실행
```

**장점:**
- 여러 INSERT를 한 번에 실행
- 성능 향상
- 네트워크 트래픽 감소

## 🔄 트랜잭션 처리

### 1. 트랜잭션이란?

**정의:**
- 여러 작업을 하나의 단위로 묶어서 처리
- 모두 성공하거나 모두 실패 (All or Nothing)

**예시:**
```
회원 정보 INSERT
  ↓
취미 정보 INSERT (여러 개)
  ↓
모두 성공 → COMMIT
하나라도 실패 → ROLLBACK
```

---

### 2. 트랜잭션 구현

```jsp
<%
    conn.setAutoCommit(false);  // 자동 커밋 비활성화 (트랜잭션 시작)
    
    try {
        // 회원 정보 INSERT
        pstmt.executeUpdate();
        
        // 생성된 ID 가져오기
        ResultSet rs = pstmt.getGeneratedKeys();
        int memberId = rs.getInt(1);
        
        // 취미 정보 INSERT
        pstmt.executeBatch();
        
        conn.commit();  // 모든 작업 성공 시 커밋
        conn.setAutoCommit(true);  // 자동 커밋 다시 활성화
        
    } catch (SQLException e) {
        conn.rollback();  // 오류 발생 시 롤백
        conn.setAutoCommit(true);
        throw e;
    }
%>
```

**단계:**
1. `setAutoCommit(false)`: 트랜잭션 시작
2. 여러 작업 수행
3. `commit()`: 성공 시 커밋
4. `rollback()`: 실패 시 롤백
5. `setAutoCommit(true)`: 원래 상태로 복구

---

### 3. 트랜잭션의 필요성

**문제 상황:**
```
회원 정보 INSERT 성공
  ↓
취미 정보 INSERT 실패
  ↓
결과: 회원 정보만 저장됨 (데이터 불일치!)
```

**해결:**
```
트랜잭션 시작
  ↓
회원 정보 INSERT
  ↓
취미 정보 INSERT 실패
  ↓
ROLLBACK → 모든 작업 취소
```

## ⚠️ 에러 처리

### 1. 예외 처리 구조

```jsp
<%
    Connection conn = null;
    PreparedStatement pstmt = null;
    ResultSet rs = null;
    
    try {
        // 데이터베이스 작업
    } catch (ClassNotFoundException e) {
        // 드라이버 없음
        e.printStackTrace();
        response.sendRedirect("register.jsp?error=db_error");
    } catch (SQLException e) {
        // SQL 오류
        e.printStackTrace();
        try {
            if (conn != null && !conn.getAutoCommit()) {
                conn.rollback();
            }
        } catch (SQLException ex) {
            ex.printStackTrace();
        }
        response.sendRedirect("register.jsp?error=db_error");
    } finally {
        // 리소스 해제 (항상 실행)
        try {
            if (rs != null) rs.close();
            if (pstmt != null) pstmt.close();
            if (conn != null) conn.close();
        } catch (SQLException e) {
            e.printStackTrace();
        }
    }
%>
```

---

### 2. 주요 예외 타입

#### ClassNotFoundException
**원인:** JDBC 드라이버가 없음

**해결:**
- `mysql-connector-java-8.0.x.jar`를 `WEB-INF/lib/`에 추가

---

#### SQLException
**원인:** SQL 오류

**주요 원인:**
- SQL 문법 오류
- 테이블/컬럼 없음
- 제약조건 위반 (중복 등)
- 연결 오류

**디버깅:**
```jsp
catch (SQLException e) {
    out.println("SQL 오류: " + e.getMessage());
    out.println("SQL 상태: " + e.getSQLState());
    out.println("에러 코드: " + e.getErrorCode());
    e.printStackTrace();
}
```

---

### 3. 리소스 해제 (finally 블록)

**중요:**
- `Connection`, `PreparedStatement`, `ResultSet`은 반드시 해제
- `finally` 블록에서 해제 (예외 발생해도 실행됨)

**순서:**
```jsp
finally {
    // 역순으로 해제
    if (rs != null) rs.close();
    if (pstmt != null) pstmt.close();
    if (conn != null) conn.close();
}
```

## 🔒 보안 고려사항

### 1. SQL Injection 방지

✅ **PreparedStatement 사용** (이미 구현됨)

```jsp
// 안전한 방법
String sql = "SELECT * FROM members WHERE user_id = ?";
pstmt.setString(1, userId);
```

❌ **절대 하지 말 것:**
```jsp
// 위험한 방법
String sql = "SELECT * FROM members WHERE user_id = '" + userId + "'";
```

**공격 예시:**
```
입력: admin' OR '1'='1
결과: 모든 회원 정보 노출!
```

---

### 2. 비밀번호 암호화

**현재 코드 (위험):**
```jsp
pstmt.setString(2, password);  // 평문 저장
```

**개선 방법 1: SHA-256**
```jsp
import java.security.MessageDigest;

MessageDigest md = MessageDigest.getInstance("SHA-256");
byte[] hash = md.digest(password.getBytes("UTF-8"));
StringBuilder sb = new StringBuilder();
for (byte b : hash) {
    sb.append(String.format("%02x", b));
}
String encryptedPassword = sb.toString();
pstmt.setString(2, encryptedPassword);
```

**개선 방법 2: BCrypt (권장)**
```jsp
import org.mindrot.jbcrypt.BCrypt;

String hashedPassword = BCrypt.hashpw(password, BCrypt.gensalt());
pstmt.setString(2, hashedPassword);
```

---

### 3. XSS 방지

**위험한 방법:**
```jsp
<%= request.getParameter("name") %>
```

**안전한 방법:**
```jsp
<c:out value="${param.name}" />
```

또는:
```jsp
<%
    String name = request.getParameter("name");
    name = name.replace("<", "&lt;").replace(">", "&gt;");
%>
<%= name %>
```

---

### 4. 입력 검증

**서버 측 검증 (필수):**
```jsp
<%
    String userId = request.getParameter("user_id");
    
    // 빈 값 체크
    if (userId == null || userId.trim().isEmpty()) {
        response.sendRedirect("register.jsp?error=empty");
        return;
    }
    
    // 길이 체크
    if (userId.length() < 4 || userId.length() > 20) {
        response.sendRedirect("register.jsp?error=length");
        return;
    }
    
    // 형식 체크
    if (!userId.matches("^[a-zA-Z0-9_]+$")) {
        response.sendRedirect("register.jsp?error=format");
        return;
    }
%>
```
