# JSP 폼 처리 — 문제 · 답

**참고 패턴:** 회원가입 `form` → `form_process.jsp`  
**핵심:** `request.getParameter` · `getParameterValues` · `setCharacterEncoding`

---

## 예제에서 배우는 것

| 구분 | 파일 | 역할 |
|------|------|------|
| 입력 | `form05.jsp` 등 | `method="post"`, `name` 속성 |
| 처리 | `form05_process.jsp` | 파라미터 읽기 · 화면 출력 |

```jsp
request.setCharacterEncoding("UTF-8");
String id = request.getParameter("id");
String[] hobby = request.getParameterValues("hobby");  // 체크박스(복수)
```

### 예제 코드의 실수 (고치기 연습)

처리 페이지에 아래처럼 **이름과 비밀번호가 뒤바뀐** 경우가 있습니다.

```jsp
<%-- 잘못됨 --%>
<p>비밀번호 : <%=name%>
<p>이름 : <%=passwd%>

<%-- 올바른 예 --%>
<p>비밀번호 : <%=passwd%>
<p>이름 : <%=name%>
```

# A. 문제

## 문제 1. 회원가입 폼 작성 ⭐

**파일:** `joinForm.jsp`

다음 항목이 있는 **회원가입 폼**을 작성하세요.  
`action="joinProcess.jsp"` · `method="post"`

| 항목 | 입력 종류 | name |
|------|-----------|------|
| 아이디 | text + (중복검사 버튼은 동작 없어도 됨) | `id` |
| 비밀번호 | password | `passwd` |
| 이름 | text | `name` |
| 연락처 | select(010~019) + text 2칸 | `phone`, `phone2`, `phone3` |
| 성별 | radio (남성 기본 선택) | `sex` |
| 취미 | checkbox 3개 이상 (복수 선택) | `hobby` (동일 name) |
| 가입인사 | textarea | `comment` |
| | submit / reset | |

**조건**

- `page` 지시자 UTF-8  
- checkbox `value`는 화면 글자와 같게 (예: 독서, 운동, 영화)

## 답 4 — 설문 (핵심만)

**survey.jsp** — `name="studentName"`, `score`, `subject`, `opinion`  
**surveyProcess.jsp**

```jsp
String studentName = request.getParameter("studentName");
String score = request.getParameter("score");
String[] subject = request.getParameterValues("subject");
String opinion = request.getParameter("opinion");
```

체크박스는 `subject != null`일 때 for로 출력.

---

## 답 5 — 서술

1. **getParameter** — 값이 하나(문자열). **getParameterValues** — 같은 name이 여러 개일 때 배열.  
2. 같은 name이어야 복수 선택이 **하나의 배열**로 넘어온다.  
3. `request.setCharacterEncoding("UTF-8");` (파라미터 읽기 **전**)  
4. radio는 같은 name 중 **하나만** 선택되므로 값이 하나다.

## 답 6 — 고치기

```jsp
<p>비밀번호 : <%= passwd %></p>
<p>이름 : <%= name %></p>
<p>취미 :
<%
  if (hobby != null) {
    for (int i = 0; i < hobby.length; i++) {
      out.print(" " + hobby[i]);
    }
  }
%>
</p>
```

- `name` / `passwd` 출력 바로잡기  
- `hobby`는 배열이라 `<%= hobby %>`로 출력하면 안 되고 **반복 출력**
