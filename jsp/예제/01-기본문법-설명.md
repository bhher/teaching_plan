# 📝 01-기본문법.jsp 해설

## 📋 파일 개요

이 파일은 JSP의 기본 문법을 학습하기 위한 예제입니다. JSP의 핵심 요소인 스크립틀릿, 표현식, 선언문을 실습할 수 있습니다.

## 🎯 학습 목표

- JSP 지시자 이해

- 조건문과 반복문 활용
- HTML과 Java 코드 혼합

## 📖 코드 상세 설명

### 1. JSP 지시자 (Directive)

```jsp
<%@ page language="java" contentType="text/html; charset=UTF-8" pageEncoding="UTF-8" %>
<%@ page import="java.util.Date" %>
```

**설명:**
- **`page` 지시자**: JSP 페이지의 속성을 설정
  - `language="java"`: 사용 언어 지정
  - `contentType`: 응답 컨텐츠 타입과 인코딩
  - `pageEncoding`: 페이지 파일 자체의 인코딩
  - `import`: Java 클래스 import

**중요 포인트:**
- `contentType`과 `pageEncoding`은 모두 UTF-8로 설정해야 한글이 깨지지 않음
- `import`는 여러 개 사용 가능

---

### 2. 스크립틀릿 (Scriptlet)

```jsp
<%
    String name = "홍길동";
    int age = 25;
    double height = 175.5;
%>
```

**설명:**
- **스크립틀릿**: `<% %>` 안에 Java 코드 작성
- 변수 선언, 연산, 제어문 등 모든 Java 코드 사용 가능
- 이 변수들은 `_jspService()` 메서드 내부의 지역 변수로 변환됨

**특징:**
- HTML과 섞어서 사용 가능
- 여러 개의 스크립틀릿을 나눠서 사용 가능

**예시:**
```jsp
<%
    String name = "홍길동";
%>
<p>안녕하세요</p>
<%
    int age = 25;
%>
```

---

### 3. 표현식 (Expression)

```jsp
<p>이름: <%= name %></p>
<p>나이: <%= age %></p>
<p>키: <%= height %>cm</p>
```

**설명:**
- **표현식**: `<%= %>` 안에 출력할 값 작성
- 자동으로 `out.print()`로 변환됨
- 세미콜론(`;`) 사용 불가

**변환 과정:**
```jsp
<!-- 원본 -->
<%= name %>

<!-- 변환 후 -->
<% out.print(name); %>
```

**주의사항:**
- 표현식은 값을 출력하는 용도로만 사용
- 복잡한 로직은 스크립틀릿 사용

---

### 4. 표현식 활용 예시

```jsp
<p>현재 시간: <%= new Date() %></p>
<p>계산 결과: <%= 10 + 20 %></p>
```

**설명:**
- 객체 생성 가능: `new Date()`
- 연산 가능: `10 + 20`
- 메서드 호출 가능: `name.length()`

**예시:**
```jsp
<%= "안녕하세요" %>
<%= 10 + 20 %>
<%= name.toUpperCase() %>
<%= new java.util.Date() %>
```

### 5. 선언문 (Declaration)

```jsp
<%!
    int count = 0;
    
    public int add(int a, int b) {
        return a + b;
    }
%>
```

**설명:**
- **선언문**: `<%! %>` 안에 클래스 레벨의 변수/메서드 선언
- 서블릿 클래스의 멤버 변수/메서드로 변환됨
- 여러 요청 간에 공유되는 변수

**스크립틀릿 vs 선언문:**

| 구분 | 스크립틀릿 | 선언문 |
|------|-----------|--------|
| 문법 | `<% %>` | `<%! %>` |
| 변환 위치 | `_jspService()` 메서드 내부 | 서블릿 클래스 멤버 |
| 변수 범위 | 지역 변수 | 인스턴스 변수 |
| 공유 | 요청마다 새로 생성 | 여러 요청 간 공유 |

**주의사항:**
- 선언문의 변수는 여러 요청 간에 공유되므로 동시성 문제 발생 가능
- 일반적으로는 스크립틀릿 사용 권장

---

### 6. 조건문

```jsp
<%
    int score = 85;
    String grade;
    
    if (score >= 90) {
        grade = "A";
    } else if (score >= 80) {
        grade = "B";
    } else if (score >= 70) {
        grade = "C";
    } else {
        grade = "F";
    }
%>
<p>점수: <%= score %>점</p>
<p>등급: <%= grade %></p>
```

**설명:**
- Java의 조건문을 그대로 사용
- if-else, switch-case 모두 사용 가능

**HTML과 혼합 예시:**
```jsp
<%
    int score = 85;
%>
<% if (score >= 90) { %>
    <p style="color: gold;">우수합니다!</p>
<% } else if (score >= 80) { %>
    <p style="color: silver;">양호합니다!</p>
<% } else { %>
    <p style="color: red;">노력이 필요합니다!</p>
<% } %>
```

### 7. 반복문 - for 문

```jsp
<ul>
<%
    for (int i = 1; i <= 5; i++) {
        out.println("<li>항목 " + i + "</li>");
    }
%>
</ul>
```

**설명:**
- `out.println()`을 사용하여 HTML 출력
- 반복문 안에서 HTML 태그 생성

**출력 결과:**
```html
<ul>
    <li>항목 1</li>
    <li>항목 2</li>
    <li>항목 3</li>
    <li>항목 4</li>
    <li>항목 5</li>
</ul>
```

---

### 8. 반복문 - 향상된 for 문 (배열)

```jsp
<%
    String[] fruits = {"사과", "바나나", "오렌지", "포도"};
%>
<ul>
<%
    for (String fruit : fruits) {
%>
    <li><%= fruit %></li>
<%
    }
%>
</ul>
```

**설명:**
- 배열을 순회하는 향상된 for 문 사용
- HTML과 Java 코드를 섞어서 사용하는 좋은 예시

**작동 과정:**
1. 스크립틀릿에서 배열 선언
2. HTML 태그 시작 (`<ul>`)
3. 반복문 시작
4. 표현식으로 값 출력 (`<%= fruit %>`)
5. 반복문 종료
6. HTML 태그 종료 (`</ul>`)

**장점:**
- HTML 구조를 명확하게 유지
- 코드 가독성 향상

### 9. HTML과 Java 코드 혼합 (테이블)

```jsp
<table border="1">
    <tr>
        <th>번호</th>
        <th>이름</th>
        <th>나이</th>
    </tr>
<%
    String[] names = {"홍길동", "김철수", "이영희"};
    int[] ages = {25, 30, 28};
    
    for (int i = 0; i < names.length; i++) {
%>
    <tr>
        <td><%= i + 1 %></td>
        <td><%= names[i] %></td>
        <td><%= ages[i] %></td>
    </tr>
<%
    }
%>
</table>
```

**설명:**
- 테이블 구조를 유지하면서 동적으로 행 생성
- 여러 배열을 동시에 순회

**출력 결과:**
```html
<table border="1">
    <tr>
        <th>번호</th>
        <th>이름</th>
        <th>나이</th>
    </tr>
    <tr>
        <td>1</td>
        <td>홍길동</td>
        <td>25</td>
    </tr>
    <tr>
        <td>2</td>
        <td>김철수</td>
        <td>30</td>
    </tr>
    <tr>
        <td>3</td>
        <td>이영희</td>
        <td>28</td>
    </tr>
</table>
```

## 🔍 핵심 개념 정리

### 1. JSP 요소 비교

| 요소 | 문법 | 용도 | 변환 위치 |
|------|------|------|----------|
| 지시자 | `<%@ %>` | 페이지 설정 | 서블릿 클래스 상단 |
| 스크립틀릿 | `<% %>` | Java 코드 | `_jspService()` 메서드 |
| 표현식 | `<%= %>` | 값 출력 | `out.print()` |
| 선언문 | `<%! %>` | 멤버 변수/메서드 | 서블릿 클래스 멤버 |
| 주석 | `<%-- --%>` | 주석 | 제거됨 |

---

### 2. 변수 범위

**스크립틀릿 변수:**
```jsp
<%
    String name = "홍길동";  // 지역 변수
%>
```
- 요청마다 새로 생성
- 다른 스크립틀릿에서 접근 가능 (같은 페이지 내)

**선언문 변수:**
```jsp
<%!
    int count = 0;  // 인스턴스 변수
%>
```
- 서블릿 인스턴스가 살아있는 동안 유지
- 여러 요청 간에 공유

---

### 3. 출력 방법 비교

**방법 1: 표현식 사용 (권장)**
```jsp
<p><%= name %></p>
```

**방법 2: out 객체 사용**
```jsp
<%
    out.print("<p>" + name + "</p>");
%>
```

**방법 3: HTML과 혼합**
```jsp
<p><%= name %></p>
```

**권장사항:**
- 표현식 사용이 가장 깔끔하고 읽기 쉬움
- HTML 구조를 명확하게 유지

## 🐛 자주 발생하는 오류

### 오류 1: 세미콜론 사용
```jsp
<!-- 잘못된 예 -->
<%= name; %>

<!-- 올바른 예 -->
<%= name %>
```

### 오류 2: 변수 선언 위치
```jsp
<!-- 잘못된 예 -->
<%= name %>
<%
    String name = "홍길동";  // 사용 후 선언
%>

<!-- 올바른 예 -->
<%
    String name = "홍길동";  // 선언 후 사용
%>
<%= name %>
```

### 오류 3: 인코딩 문제
```jsp
<!-- 한글이 깨질 때 -->
<%@ page contentType="text/html; charset=UTF-8" pageEncoding="UTF-8" %>
```
- 파일 저장 시 UTF-8 인코딩 확인
- IDE 설정에서 UTF-8로 저장 확인
