## 1. 클릭하면 핀 꽂기

**파일:** `kakao-map-click-pin.html`

### 무엇을 하나?
지도를 클릭할 때마다 그 자리에 마커를 만들고, 위도·경도를 화면에 표시합니다.

### 핵심 코드
```javascript
kakao.maps.event.addListener(map, 'click', function (mouseEvent) {
  var latlng = mouseEvent.latLng; // 클릭한 좌표
  new kakao.maps.Marker({ position: latlng, map: map });
});
```

### 수업에서 말할 포인트
- `mouseEvent.latLng` → `getLat()`, `getLng()`
- 마커를 배열에 담아 두면 “모두 지우기”가 쉬움 (`setMap(null)`)
- 구글맵에서 좌표 복사하는 연습과 자연스럽게 연결 가능

### 응용 과제
- 마커는 **하나만** 두고, 클릭할 때마다 위치만 옮기기 (`setPosition`)
- 클릭 시 인포윈도우에 “여기에 핀!” 표시

## 2. 학원 찾아오기

**파일:** `kakao-map-find-academy.html`

### 무엇을 하나?
학원(예시) 좌표에 마커·인포윈도우를 띄우고,  
**카카오맵 길찾기 / 크게 보기** 링크로 연결합니다.

### 핵심 코드
```javascript
// 지도 위 마커
new kakao.maps.Marker({
  map: map,
  position: new kakao.maps.LatLng(37.5665, 126.9780)
});

// 길찾기 URL (지도 SDK 밖)
'https://map.kakao.com/link/to/' + 이름 + ',' + 위도 + ',' + 경도
```

### 수업에서 말할 포인트
- **지도 API**(페이지 안 지도)와 **지도 URL**(카카오맵으로 점프)을 같이 쓰는 패턴
- 학원 정보 객체만 바꾸면 홈페이지 “오시는 길” 페이지가 됨
```javascript
var academy = { name: '...', lat: ..., lng: ..., address: '...' };
```

### 응용 과제
- 본인 학원/카페 실제 좌표로 교체
- “로드뷰 보기” 링크 추가: `https://map.kakao.com/link/roadview/위도,경도`

## 3. 내 위치 찾기

**파일:** `kakao-map-my-location.html`

### 무엇을 하나?
브라우저 **Geolocation API**로 GPS 좌표를 받아 카카오맵 중심에 마커를 표시합니다.

### 핵심 코드
```javascript
navigator.geolocation.getCurrentPosition(function (pos) {
  var coords = new kakao.maps.LatLng(
    pos.coords.latitude,
    pos.coords.longitude
  );
  map.setCenter(coords);
  new kakao.maps.Marker({ map: map, position: coords });
});
```

### 수업에서 말할 포인트
- 카카오맵 API가 “내 위치”를 주는 게 아니라, **브라우저 GPS** → 좌표 → 지도에 표시
- **HTTPS** 또는 **localhost** 에서만 잘 됨 (`file://` 주의)
- 사용자가 “위치 허용”을 눌러야 함

### 응용 과제
- 내 위치 기준으로 “주변 편의점” Places 검색
- 정확도(`coords.accuracy`)도 화면에 표시

## 4. 오늘 뭐 먹지? (랜덤 맛집)

**파일:** `kakao-map-random-food.html`

### 무엇을 하나?
키워드로 장소를 검색해 마커를 찍고, **랜덤으로 한 곳**을 추천합니다.  
추천 장소는 카카오맵 링크도 제공합니다.

### 핵심 코드
```javascript
places.keywordSearch(keyword, function (data, status) {
  // data = 검색된 장소 배열
});

var place = results[Math.floor(Math.random() * results.length)];
```

### 수업에서 말할 포인트
- `libraries=services` + `kakao.maps.services.Places`
- `addressSearch`(주소) vs `keywordSearch`(장소명·키워드) 차이
- 배열 + `Math.random` = 간단한 “추천 앱”
- `map.setBounds` 로 검색 결과가 한눈에 보이게

### 응용 과제
- “다시 추천” 버튼만으로 다른 곳 뽑기 (이미 있음)
- 카테고리(한식/중식) 칩 추가
- 전화번호·카테고리 필드로 카드 UI 꾸미기

## 5. 두 점 사이 거리 재기

**파일:** `kakao-map-distance.html`

### 무엇을 하나?
지도를 **두 번** 클릭하면 출발·도착 마커와 선을 그리고, **직선 거리(m/km)** 를 계산합니다.

### 핵심 코드
```javascript
// 선 그리기
new kakao.maps.Polyline({
  path: [점1, 점2],
  strokeWeight: 4,
  strokeColor: '#6366f1',
  map: map
});

// 거리: 하버사인 공식 (지구 곡률 반영한 직선거리)
```

### 수업에서 말할 포인트
- `Polyline` = 지도 위 선 오버레이
- 이 거리는 **새처럼 나는 직선**이지, 자동차 길찾기 거리가 아님
- 클릭 2회 상태 관리(`points` 배열)는 실무 UI 로직 연습에 좋음

### 응용 과제
- 3개 이상 찍고 총 경로 길이 합산
- 카카오맵 `link/by/walk/...` 로 “실제 길찾기” 버튼 연결

## 수업 추천 순서 (40~60분)

1. **클릭 핀** (이벤트 감각)

3. **맛집 랜덤** (services + 재미)  
4. **내 위치** (브라우저 API 연동)  
5. **거리 재기** (Polyline + 계산)

## 공통 주의사항

| 문제 | 해결 |
|------|------|
| 지도 안 보임 | `#map`에 height, 키·도메인 확인 |
| 검색 안 됨 | `libraries=services` 있는지 |
| 내 위치 실패 | localhost/https, 권한 허용 |
| 키 오류 | JavaScript 키인지 확인 |
