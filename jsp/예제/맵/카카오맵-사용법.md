## 1. 카카오 지도 API 한눈에 보기

[Kakao 지도 API](https://apis.map.kakao.com/) 는 웹·모바일 앱에서 지도를 쓰는 데 필요한 기능을 제공합니다.

| 구분 | 설명 | 수업에서 |
|------|------|----------|
| **Maps API – Web** | 브라우저에 지도·마커·로드뷰 등을 그리는 **JavaScript SDK** | 메인으로 사용 |
| **Maps API – Android / iOS** | 네이티브 앱용 SDK | 참고만 |
| **로컬(Local) API** | 주소·키워드·좌표 변환 등 **데이터 REST API** | JS `fetch` 또는 지도 `services` 와 함께 |
| **우편번호 서비스** | Daum 우편번호 검색·주소 입력 UI | 회원가입 폼 등과 연동 |

### 키 종류 (헷갈리기 쉬움)

| 키 | 어디에 쓰나 |
|----|-------------|
| **JavaScript 키** | Web Maps SDK (`sdk.js?appkey=...`) |
| **REST API 키** | 로컬 REST API (`Authorization: KakaoAK ...`) |
| Native 앱 키 | Android / iOS SDK |

지도만 띄울 때 → **JavaScript 키**  
서버/브라우저에서 REST로 주소 검색할 때 → **REST API 키**

키 발급: [APP KEY 발급](https://apis.map.kakao.com/) → [카카오 개발자 센터](https://developers.kakao.com/)

## 2. 준비: 앱·키·도메인

[공식 Web 가이드 – 준비하기](https://apis.map.kakao.com/web/guide/) 요약입니다.

1. [developers.kakao.com](https://developers.kakao.com) 접속·로그인  
2. **내 애플리케이션** → 앱 생성  
3. **앱 키**에서 **JavaScript 키** 확인·복사  
4. **플랫폼 → Web** 추가 후 **사이트 도메인** 등록  
   - 예: `http://localhost`, `http://localhost:8080`, `http://127.0.0.1:5500`  
5. 등록한 도메인에서만 지도 API 사용 가능  

### 로컬 테스트용 서버 예

```bash
# 해당 폴더에서 (Python)
python -m http.server 8080
```

브라우저에서 `http://localhost:8080` 으로 열고, 개발자 센터에도 `http://localhost:8080` 을 등록합니다.

`file://` 로 HTML만 열면 인증·일부 기능이 막힐 수 있습니다.

## 3. 스크립트 불러오기

### 기본 (지도만)

```html
<script
  type="text/javascript"
  src="//dapi.kakao.com/v2/maps/sdk.js?appkey=YOUR_JAVASCRIPT_KEY">
</script>
```

- `YOUR_JAVASCRIPT_KEY` → 본인 **JavaScript 키**  
- `//` 는 http/https에 맞춰 프로토콜을 자동 선택합니다. (`https://` 도 가능)  
- **실행 코드보다 먼저** 선언해야 합니다. ([가이드](https://apis.map.kakao.com/web/guide/))

### 라이브러리

| 라이브러리 | 용도 |
|-----------|------|
| `services` | 장소 검색, 주소↔좌표 |
| `clusterer` | 마커 클러스터 |
| `drawing` | 지도 위 도형 그리기 |

```html
<script
  type="text/javascript"
  src="//dapi.kakao.com/v2/maps/sdk.js?appkey=YOUR_JAVASCRIPT_KEY&libraries=services,clusterer,drawing">
</script>
```

### 비동기 로드

```html
<script
  src="//dapi.kakao.com/v2/maps/sdk.js?appkey=YOUR_JAVASCRIPT_KEY&autoload=false">
</script>
<script>
  kakao.maps.load(function () {
    // 여기서 지도 생성
  });
</script>
```

## 4. 지도 기본 표시

공식 시작하기 흐름과 동일합니다. ([Web 가이드](https://apis.map.kakao.com/web/guide/))

### 1) 지도를 담을 영역

크기가 없으면 지도가 안 보입니다.

```html
<div id="map" style="width:500px;height:400px;"></div>
```

### 2) SDK 로드 후 Map 생성

`center` 는 **필수**. `LatLng(위도, 경도)` 순서 (WGS84).

```javascript
var container = document.getElementById('map');
var options = {
  center: new kakao.maps.LatLng(33.450701, 126.570667),
  level: 3 // 확대 레벨 (작을수록 확대)
};
var map = new kakao.maps.Map(container, options);
```

### 최소 완성 예제

```html
<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8" />
  <title>Kakao 지도 시작하기</title>
</head>
<body>
  <div id="map" style="width:500px;height:400px;"></div>
  <script
    type="text/javascript"
    src="//dapi.kakao.com/v2/maps/sdk.js?appkey=YOUR_JAVASCRIPT_KEY">
  </script>
  <script>
    var map = new kakao.maps.Map(document.getElementById('map'), {
      center: new kakao.maps.LatLng(33.450701, 126.570667),
      level: 3
    });
  </script>
</body>
</html>
```

### 자주 쓰는 조작

```javascript
map.setCenter(new kakao.maps.LatLng(37.5665, 126.9780));
map.panTo(new kakao.maps.LatLng(37.5665, 126.9780)); // 부드럽게
map.setLevel(5);
var level = map.getLevel();
var center = map.getCenter();
console.log(center.getLat(), center.getLng());
```

더 많은 예: [Web 샘플 – 지도](https://apis.map.kakao.com/web/sample/)

## 6. 마커

```javascript
var marker = new kakao.maps.Marker({
  position: new kakao.maps.LatLng(37.5665, 126.9780),
  title: '서울시청'
});
marker.setMap(map);

// 제거
// marker.setMap(null);
```

### 여러 개 + 전체 보기

```javascript
var positions = [
  { title: '서울시청', lat: 37.5665, lng: 126.9780 },
  { title: '명동', lat: 37.5636, lng: 126.9826 }
];
var markers = [];

positions.forEach(function (p) {
  var marker = new kakao.maps.Marker({
    position: new kakao.maps.LatLng(p.lat, p.lng),
    title: p.title
  });
  marker.setMap(map);
  markers.push(marker);
});

var bounds = new kakao.maps.LatLngBounds();
markers.forEach(function (m) {
  bounds.extend(m.getPosition());
});
map.setBounds(bounds);
```

### 커스텀 이미지

```javascript
var markerImage = new kakao.maps.MarkerImage(
  'marker.png',
  new kakao.maps.Size(40, 40),
  { offset: new kakao.maps.Point(20, 40) }
);

var marker = new kakao.maps.Marker({
  position: new kakao.maps.LatLng(37.5665, 126.9780),
  image: markerImage
});
marker.setMap(map);
```

## 9. 주소 검색 (Geocoder)

지도 SDK의 `services` 라이브러리 사용. (`libraries=services`)

```javascript
var geocoder = new kakao.maps.services.Geocoder();

geocoder.addressSearch('제주특별자치도 제주시 첨단로 242', function (result, status) {
  if (status === kakao.maps.services.Status.OK) {
    var coords = new kakao.maps.LatLng(result[0].y, result[0].x); // y=위도, x=경도
    new kakao.maps.Marker({ map: map, position: coords });
    map.setCenter(coords);
  }
});
```

### 좌표 → 주소

```javascript
geocoder.coord2Address(lng, lat, function (result, status) {
  if (status === kakao.maps.services.Status.OK) {
    console.log(result[0].address.address_name);
  }
});
```

서버에서만 호출하거나 SDK 없이 쓸 때는 [13. 로컬 REST API](#13-로컬-rest-api-fetch) 를 사용합니다.

## 10. 키워드 장소 검색

```javascript
var ps = new kakao.maps.services.Places();

ps.keywordSearch('이태원 맛집', function (data, status) {
  if (status !== kakao.maps.services.Status.OK) return;

  var bounds = new kakao.maps.LatLngBounds();
  data.forEach(function (place) {
    var position = new kakao.maps.LatLng(place.y, place.x);
    new kakao.maps.Marker({
      map: map,
      position: position,
      title: place.place_name
    });
    bounds.extend(position);
  });
  map.setBounds(bounds);
});
```

## 12. 지도 URL (바로가기 링크)

지도를 임베드하지 않고, **카카오맵 앱/웹으로 연결**할 때 사용합니다. ([가이드 – 지도 URL](https://apis.map.kakao.com/web/guide/))

| 용도 | URL 예 |
|------|--------|
| 좌표로 지도 | `https://map.kakao.com/link/map/37.5665,126.9780` |
| 이름+좌표 | `https://map.kakao.com/link/map/서울시청,37.5665,126.9780` |
| 길찾기(목적지) | `https://map.kakao.com/link/to/서울시청,37.5665,126.9780` |
| 출발→도착 | `https://map.kakao.com/link/from/이름,위도,경도/to/이름,위도,경도` |
| 이동수단 | `https://map.kakao.com/link/by/car/출발이름,위도,경도/도착이름,위도,경도` |
| 로드뷰 | `https://map.kakao.com/link/roadview/37.5665,126.9780` |
| 검색 | `https://map.kakao.com/link/search/카카오` |

이동수단: `car` · `traffic` · `walk` · `bicycle`

```html
<a href="https://map.kakao.com/link/to/우리학원,37.5665,126.9780" target="_blank">
  카카오맵으로 길찾기
</a>
```

## 13. 로컬 REST API (fetch)

지도 SDK와 별도로, **로컬 API**로 주소·장소를 조회할 수 있습니다.  
문서: [카카오맵 REST API](https://developers.kakao.com/docs/latest/ko/local/dev-guide)  
포털 소개: [apis.map.kakao.com](https://apis.map.kakao.com/) 의 **로컬 API**

### 인증

- 키: **REST API 키** (JavaScript 키 아님)  
- 헤더: `Authorization: KakaoAK {REST_API_KEY}` (`KakaoAK` 와 키 사이 **공백 1칸**)

### 주소 검색 → 좌표

```javascript
async function searchAddress(query) {
  var url =
    'https://dapi.kakao.com/v2/local/search/address.json?query=' +
    encodeURIComponent(query);

  var res = await fetch(url, {
    headers: {
      Authorization: 'KakaoAK YOUR_REST_API_KEY'
    }
  });

  if (!res.ok) throw new Error('주소 검색 실패');
  var data = await res.json();

  if (!data.documents || data.documents.length === 0) {
    alert('결과 없음');
    return;
  }

  var doc = data.documents[0];
  // x=경도, y=위도
  var coords = new kakao.maps.LatLng(doc.y, doc.x);
  map.setCenter(coords);
  new kakao.maps.Marker({ map: map, position: coords });
}

searchAddress('서울특별시 중구 세종대로 110');
```

### 키워드 장소 검색 (REST)

```javascript
async function searchKeyword(query) {
  var url =
    'https://dapi.kakao.com/v2/local/search/keyword.json?query=' +
    encodeURIComponent(query);

  var res = await fetch(url, {
    headers: { Authorization: 'KakaoAK YOUR_REST_API_KEY' }
  });
  var data = await res.json();
  console.log(data.documents); // place_name, x, y 등
}
```

### Web SDK `services` vs REST

| | Web `services` | 로컬 REST |
|--|----------------|-----------|
| 키 | JavaScript 키 (SDK) | REST API 키 |
| 호출 | 브라우저 SDK 콜백 | `fetch` / 서버 |
| 용도 | 지도와 함께 빠르게 | 서버 저장, SPA, 지도 없이 좌표만 |

브라우저에서 REST 키를 그대로 넣으면 **키가 노출**됩니다. 수업·실습은 가능하지만, 실서비스는 **서버 경유**를 권장합니다.

## 14. 우편번호(주소 검색) 서비스

[apis.map.kakao.com](https://apis.map.kakao.com/) 의 **우편번호 서비스**(Daum 우편번호)로 주소를 고른 뒤, 지도에 마커를 찍는 패턴이 자주 쓰입니다.

```html
<script src="//t1.daumcdn.net/mapjsapi/bundle/postcode/prod/postcode.v2.js"></script>
<button type="button" id="btnAddr">주소 검색</button>
<input type="text" id="address" readonly />

<script>
  document.getElementById('btnAddr').onclick = function () {
    new daum.Postcode({
      oncomplete: function (data) {
        var addr = data.roadAddress || data.jibunAddress;
        document.getElementById('address').value = addr;

        // 지도 SDK Geocoder 또는 로컬 REST로 좌표 변환 후 마커
        var geocoder = new kakao.maps.services.Geocoder();
        geocoder.addressSearch(addr, function (result, status) {
          if (status === kakao.maps.services.Status.OK) {
            var coords = new kakao.maps.LatLng(result[0].y, result[0].x);
            map.setCenter(coords);
            new kakao.maps.Marker({ map: map, position: coords });
          }
        });
      }
    }).open();
  };
</script>
```

우편번호 스크립트 + 지도 SDK(`libraries=services`) 둘 다 필요합니다.

## 15. 자주 하는 실수 / 팁

| 증상 | 확인 |
|------|------|
| 지도가 안 보임 | `#map` **height**, JS 키, **도메인 등록** |
| `kakao is not defined` | SDK가 코드보다 **먼저** 로드됐는지 |
| `Geocoder is not a constructor` | `&libraries=services` |
| `MarkerClusterer` 없음 | `&libraries=clusterer` |
| REST 401 / Authorization | **REST 키**인지, `KakaoAK ` 공백 |
| 탭/숨김 후 깨짐 | `map.relayout()` |
| `file://` | 로컬 HTTP 서버 사용 |

좌표: `LatLng(위도, 경도)` · 검색 결과 `x`=경도, `y`=위도.

## 수업용 체크리스트

1. [apis.map.kakao.com](https://apis.map.kakao.com/) / 개발자 센터에서 앱 생성  
2. **JavaScript 키** + Web 도메인 등록  
3. `#map` 크기 지정 → `sdk.js` 로드 → `new kakao.maps.Map`  
4. 필요 시 `libraries=services,clusterer`  
5. (선택) 길찾기 링크는 [지도 URL](#12-지도-url-바로가기-링크)  
6. (선택) REST 주소 검색은 **REST API 키** + `fetch`  
7. 로컬 서버로 실행·확인
