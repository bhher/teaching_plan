# 📖 JSP 예제 사용 가이드

## 📁 예제 파일 구조

```
jsp/
├── README.md                    # 메인 학습 자료
├── 예제/
│   ├── 01-기본문법.jsp          # JSP 기본 문법 예제
│   ├── 02-내장객체.jsp          # JSP 내장 객체 예제
│   ├── 03-JSTL-EL.jsp           # JSTL과 EL 예제
│   ├── 04-폼처리/
│   │   ├── form.jsp             # 회원가입 폼
│   │   └── form_process.jsp     # 폼 처리 페이지
│   ├── 05-세션/
│   │   ├── login.jsp             # 로그인 페이지
│   │   ├── login_process.jsp     # 로그인 처리
│   │   ├── main.jsp              # 메인 페이지
│   │   ├── logout.jsp            # 로그아웃
│   │   └── session_test.jsp      # 세션 테스트
│   └── 예제-사용-가이드.md      # 이 파일
```

---

## 🚀 실행 방법

### 1. 환경 설정

#### 필요한 것들:
- **Java JDK** (1.8 이상)
- **Apache Tomcat** (9.0 이상 권장)
- **IDE** (Eclipse, IntelliJ IDEA 등)

#### Tomcat 설치 및 설정:
1. Apache Tomcat 다운로드: https://tomcat.apache.org/
2. 압축 해제
3. 환경 변수 설정 (선택사항)

---

### 2. 프로젝트 생성

#### Eclipse에서:
1. File → New → Dynamic Web Project
2. Project name: `jsp-examples`
3. Target runtime: Apache Tomcat 선택
4. Finish

#### IntelliJ IDEA에서:
1. File → New → Project
2. Java Enterprise 선택
3. Application Server: Tomcat 선택
4. Finish

---

### 3. 파일 배치

예제 파일들을 프로젝트의 `WebContent` 또는 `webapp` 폴더에 복사:

```
프로젝트/
└── WebContent/ (또는 webapp/)
    ├── index.jsp
    ├── 01-기본문법.jsp
    ├── 02-내장객체.jsp
    ├── 03-JSTL-EL.jsp
    ├── 04-폼처리/
    │   ├── form.jsp
    │   └── form_process.jsp
    └── 05-세션/
        ├── login.jsp
        ├── login_process.jsp
        ├── main.jsp
        ├── logout.jsp
        └── session_test.jsp
```

---

### 4. JSTL 라이브러리 추가

JSTL을 사용하는 예제(`03-JSTL-EL.jsp`)를 실행하려면:

1. **JSTL 라이브러리 다운로드:**
   - https://mvnrepository.com/artifact/javax.servlet/jstl
   - `jstl-1.2.jar` 다운로드

2. **프로젝트에 추가:**
   - `WebContent/WEB-INF/lib/` 폴더에 복사
   - 또는 프로젝트 Build Path에 추가

## 🐛 문제 해결

### 1. 404 에러 (페이지를 찾을 수 없음)

**원인:**
- 파일 경로가 잘못됨
- 파일이 올바른 위치에 없음

**해결:**
- 파일이 `WebContent` 또는 `webapp` 폴더에 있는지 확인
- URL 경로 확인

---

### 2. 500 에러 (서버 내부 오류)

**원인:**
- JSP 문법 오류
- 라이브러리 누락
- 인코딩 문제

**해결:**
- 콘솔에서 에러 메시지 확인
- JSP 파일 인코딩을 UTF-8로 설정
- 필요한 라이브러리 추가

---

### 3. JSTL 태그가 인식되지 않음

**원인:**
- JSTL 라이브러리가 없음
- taglib 선언이 잘못됨

**해결:**
1. `jstl-1.2.jar` 다운로드
2. `WEB-INF/lib/` 폴더에 복사
3. 프로젝트 재시작

---

### 4. 한글이 깨짐

**원인:**
- 인코딩 설정이 잘못됨

**해결:**
1. JSP 파일 상단에 다음 추가:
   ```jsp
   <%@ page contentType="text/html; charset=UTF-8" pageEncoding="UTF-8" %>
   ```

2. `web.xml`에 필터 추가:
   ```xml
   <filter>
       <filter-name>encodingFilter</filter-name>
       <filter-class>org.apache.catalina.filters.SetCharacterEncodingFilter</filter-class>
       <init-param>
           <param-name>encoding</param-name>
           <param-value>UTF-8</param-value>
       </init-param>
   </filter>
   <filter-mapping>
       <filter-name>encodingFilter</filter-name>
       <url-pattern>/*</url-pattern>
   </filter-mapping>
   ```

---

### 5. 세션이 유지되지 않음

**원인:**
- 브라우저 쿠키 비활성화
- 세션 타임아웃

**해결:**
- 브라우저 쿠키 활성화
- 세션 유지 시간 확인:
  ```jsp
  session.setMaxInactiveInterval(3600); // 1시간
  ```
