## 정규식 패턴 목록

### 회원가입 폼에서 사용하는 정규식 패턴

```javascript
var patterns = {
	// 아이디: 영문으로 시작, 영문/숫자 조합, 4-12자
	id: /^[a-zA-Z][a-zA-Z0-9]{3,11}$/,
	
	// 비밀번호: 영문/숫자/특수문자 각각 1개 이상, 8자 이상
	passwd: /^(?=.*[a-zA-Z])(?=.*[0-9])(?=.*[!@#$%^&*])[a-zA-Z0-9!@#$%^&*]{8,}$/,
	
	// 이름: 한글만, 2-10자
	name: /^[가-힣]{2,10}$/,
	
	// 이메일: 표준 이메일 형식
	email: /^[0-9a-zA-Z]([-_\.]?[0-9a-zA-Z])*@[0-9a-zA-Z]([-_\.]?[0-9a-zA-Z])*\.[a-zA-Z]{2,3}$/,
	
	// 전화번호: 010-1234-5678 형식
	phone: /^010-\d{4}-\d{4}$/,
	
	// 생년월일: YYYY-MM-DD 형식
	birthdate: /^\d{4}-\d{2}-\d{2}$/
};
```

## 각 패턴 상세 설명

### 1. 아이디 패턴: `/^[a-zA-Z][a-zA-Z0-9]{3,11}$/`

**의미:**
- `^`: 문자열 시작
- `[a-zA-Z]`: 첫 글자는 영문 (대소문자)
- `[a-zA-Z0-9]{3,11}`: 나머지 3-11자는 영문 또는 숫자
- `$`: 문자열 끝

**전체 길이:** 4-12자 (첫 글자 1자 + 나머지 3-11자)

**검증 예시:**
```javascript
patterns.id.test("user123")     // ✅ true
patterns.id.test("User123")     // ✅ true
patterns.id.test("user")        // ✅ true (4자)
patterns.id.test("user123456")  // ✅ true (9자)
patterns.id.test("123user")     // ❌ false (숫자로 시작)
patterns.id.test("us")          // ❌ false (3자 미만)
patterns.id.test("user12345678") // ❌ false (13자 초과)
patterns.id.test("user_123")    // ❌ false (특수문자 포함)
```

**사용 예시:**
```javascript
if(!patterns.id.test(id)){
    alert("아이디는 영문으로 시작하고, 영문과 숫자만 사용할 수 있습니다.");
    return false;
}
```

---

### 2. 비밀번호 패턴: `/^(?=.*[a-zA-Z])(?=.*[0-9])(?=.*[!@#$%^&*])[a-zA-Z0-9!@#$%^&*]{8,}$/`

**의미:**
- `^`: 문자열 시작
- `(?=.*[a-zA-Z])`: **전방 탐색** - 영문이 최소 1개 포함되어야 함
- `(?=.*[0-9])`: **전방 탐색** - 숫자가 최소 1개 포함되어야 함
- `(?=.*[!@#$%^&*])`: **전방 탐색** - 특수문자가 최소 1개 포함되어야 함
- `[a-zA-Z0-9!@#$%^&*]{8,}`: 영문/숫자/특수문자 조합으로 8자 이상
- `$`: 문자열 끝

**전방 탐색 (Lookahead) 설명:**
- `(?=...)`: 긍정적 전방 탐색
- `.*`: 임의의 문자 0개 이상
- `[a-zA-Z]`: 영문

**검증 예시:**
```javascript
patterns.passwd.test("Pass123!")      // ✅ true (영문+숫자+특수문자, 8자)
patterns.passwd.test("Password123!")  // ✅ true
patterns.passwd.test("pass123!")      // ✅ true
patterns.passwd.test("Pass123")       // ❌ false (특수문자 없음)
patterns.passwd.test("Password!")     // ❌ false (숫자 없음)
patterns.passwd.test("12345678!")     // ❌ false (영문 없음)
patterns.passwd.test("Pass12!")       // ❌ false (7자)
patterns.passwd.test("Pass123@")      // ❌ false (@는 허용된 특수문자 아님)
```

**사용 예시:**
```javascript
if(!patterns.passwd.test(passwd)){
    alert("비밀번호는 영문, 숫자, 특수문자를 각각 1개 이상 포함해야 합니다.");
    return false;
}
```

### 3. 이름 패턴: `/^[가-힣]{2,10}$/`

**의미:**
- `^`: 문자열 시작
- `[가-힣]`: 완성형 한글 (가-힣)
- `{2,10}`: 2개 이상 10개 이하
- `$`: 문자열 끝

**검증 예시:**
```javascript
patterns.name.test("홍길동")      // ✅ true
patterns.name.test("김철수")      // ✅ true
patterns.name.test("이영희")      // ✅ true
patterns.name.test("홍")          // ❌ false (1자)
patterns.name.test("홍길동홍길동홍길동홍길동") // ❌ false (11자)
patterns.name.test("Hong")        // ❌ false (영문)
patterns.name.test("홍123")       // ❌ false (숫자 포함)
patterns.name.test("")            // ❌ false (빈 값)
```

**사용 예시:**
```javascript
if(!patterns.name.test(name)){
    alert("이름은 한글만 입력할 수 있으며, 2자 이상 10자 이하입니다.");
    return false;
}
```

### 4. 이메일 패턴: `/^[0-9a-zA-Z]([-_\.]?[0-9a-zA-Z])*@[0-9a-zA-Z]([-_\.]?[0-9a-zA-Z])*\.[a-zA-Z]{2,3}$/`

**의미:**
- `^`: 문자열 시작
- `[0-9a-zA-Z]`: 첫 글자는 영문/숫자
- `([-_\.]?[0-9a-zA-Z])*`: 하이픈/언더스코어/점 + 영문/숫자 조합 0개 이상
- `@`: @ 기호
- `[0-9a-zA-Z]`: @ 뒤 첫 글자는 영문/숫자
- `([-_\.]?[0-9a-zA-Z])*`: 하이픈/언더스코어/점 + 영문/숫자 조합 0개 이상
- `\.`: 점 (이스케이프)
- `[a-zA-Z]{2,3}`: 최상위 도메인 (2-3자)
- `$`: 문자열 끝

**검증 예시:**
```javascript
patterns.email.test("user@email.com")        // ✅ true
patterns.email.test("user.name@email.com")   // ✅ true
patterns.email.test("user_name@email.co.kr") // ❌ false (도메인 부분이 복잡)
patterns.email.test("@email.com")            // ❌ false (@ 앞에 문자 없음)
patterns.email.test("user@")                 // ❌ false (도메인 없음)
patterns.email.test("user@email")           // ❌ false (점 없음)
patterns.email.test("user@email.c")         // ❌ false (도메인 1자)
```

**사용 예시:**
```javascript
if(!patterns.email.test(email)){
    alert("올바른 이메일 형식을 입력해 주세요. 예: example@email.com");
    return false;
}
```

### 5. 전화번호 패턴: `/^010-\d{4}-\d{4}$/`

**의미:**
- `^`: 문자열 시작
- `010-`: 리터럴 "010-"
- `\d{4}`: 숫자 4개
- `-`: 하이픈
- `\d{4}`: 숫자 4개
- `$`: 문자열 끝

**검증 예시:**
```javascript
patterns.phone.test("010-1234-5678")  // ✅ true
patterns.phone.test("010-123-4567")   // ❌ false (중간 번호가 3자)
patterns.phone.test("01012345678")    // ❌ false (하이픈 없음)
patterns.phone.test("011-1234-5678")  // ❌ false (010만 허용)
```

**사용 예시:**
```javascript
var phone = phone1 + "-" + phone2 + "-" + phone3;
if(!patterns.phone.test(phone)){
    alert("올바른 전화번호 형식을 입력해 주세요. 예: 010-1234-5678");
    return false;
}
```

### 6. 생년월일 패턴: `/^\d{4}-\d{2}-\d{2}$/`

**의미:**
- `^`: 문자열 시작
- `\d{4}`: 숫자 4개 (년도)
- `-`: 하이픈
- `\d{2}`: 숫자 2개 (월)
- `-`: 하이픈
- `\d{2}`: 숫자 2개 (일)
- `$`: 문자열 끝

**검증 예시:**
```javascript
patterns.birthdate.test("1990-01-01")  // ✅ true
patterns.birthdate.test("2000-12-31")  // ✅ true
patterns.birthdate.test("1990-1-1")    // ❌ false (한 자리 숫자)
patterns.birthdate.test("90-01-01")    // ❌ false (년도 2자)
patterns.birthdate.test("1990/01/01")  // ❌ false (슬래시 사용)
```

**사용 예시:**
```javascript
if(birthdate !== "" && !patterns.birthdate.test(birthdate)){
    alert("올바른 날짜 형식을 입력해 주세요.");
    return false;
}
```

## 패턴 테스트 예제

### JavaScript에서 테스트하기

```javascript
// 패턴 정의
var idPattern = /^[a-zA-Z][a-zA-Z0-9]{3,11}$/;

// 테스트
console.log(idPattern.test("user123"));  // true
console.log(idPattern.test("123user"));  // false

// match 사용
var result = "user123".match(idPattern);
console.log(result);  // ["user123"]
```

### Java에서 테스트하기

```java
import java.util.regex.Pattern;
import java.util.regex.Matcher;

// 패턴 정의
Pattern idPattern = Pattern.compile("^[a-zA-Z][a-zA-Z0-9]{3,11}$");

// 테스트
Matcher matcher = idPattern.matcher("user123");
boolean matches = matcher.matches();  // true
```

## 실전 활용 예제

### 예제 1: 간단한 아이디 검증

```javascript
function validateId(id){
    var pattern = /^[a-zA-Z][a-zA-Z0-9]{3,11}$/;
    
    if(id === ""){
        return {valid: false, message: "아이디를 입력해 주세요."};
    }
    
    if(!pattern.test(id)){
        return {valid: false, message: "아이디는 영문으로 시작하며, 4-12자입니다."};
    }
    
    return {valid: true, message: "사용 가능한 아이디입니다."};
}
```

### 예제 2: 강력한 비밀번호 검증

```javascript
function validatePassword(passwd){
    // 영문 대문자, 소문자, 숫자, 특수문자 각각 1개 이상, 8자 이상
    var pattern = /^(?=.*[a-z])(?=.*[A-Z])(?=.*[0-9])(?=.*[!@#$%^&*])[a-zA-Z0-9!@#$%^&*]{8,}$/;
    
    if(passwd.length < 8){
        return {valid: false, message: "비밀번호는 8자 이상이어야 합니다."};
    }
    
    if(!pattern.test(passwd)){
        return {
            valid: false, 
            message: "비밀번호는 대문자, 소문자, 숫자, 특수문자를 각각 1개 이상 포함해야 합니다."
        };
    }
    
    return {valid: true, message: "사용 가능한 비밀번호입니다."};
}
```

### 예제 3: 다양한 전화번호 형식 지원

```javascript
// 010-1234-5678, 010-123-4567, 02-123-4567 등 지원
var phonePatterns = [
    /^010-\d{4}-\d{4}$/,      // 010-1234-5678
    /^010-\d{3}-\d{4}$/,      // 010-123-4567
    /^02-\d{3,4}-\d{4}$/,     // 02-123-4567 또는 02-1234-5678
    /^0\d{1,2}-\d{3,4}-\d{4}$/ // 기타 지역번호
];

function validatePhone(phone){
    for(var i = 0; i < phonePatterns.length; i++){
        if(phonePatterns[i].test(phone)){
            return {valid: true};
        }
    }
    return {valid: false, message: "올바른 전화번호 형식을 입력해 주세요."};
}
```

## 정규식 메타 문자 요약

| 문자 | 의미 | 예시 |
|------|------|------|
| `^` | 문자열 시작 | `^abc` → "abc"로 시작 |
| `$` | 문자열 끝 | `abc$` → "abc"로 끝 |
| `.` | 임의의 문자 1개 | `a.c` → "abc", "a1c" 등 |
| `*` | 앞 문자 0개 이상 | `a*` → "", "a", "aa", ... |
| `+` | 앞 문자 1개 이상 | `a+` → "a", "aa", ... |
| `?` | 앞 문자 0개 또는 1개 | `a?` → "", "a" |
| `{n}` | 정확히 n개 | `\d{3}` → 숫자 3개 |
| `{n,m}` | n개 이상 m개 이하 | `\d{3,5}` → 숫자 3-5개 |
| `{n,}` | n개 이상 | `\d{3,}` → 숫자 3개 이상 |
| `[]` | 문자 클래스 | `[abc]` → a, b, c 중 하나 |
| `[^]` | 부정 문자 클래스 | `[^abc]` → a, b, c 제외 |
| `\d` | 숫자 | `[0-9]`와 동일 |
| `\w` | 단어 문자 | `[a-zA-Z0-9_]` |
| `\s` | 공백 문자 | 스페이스, 탭 등 |
| `\|` | 또는 (OR) | `a\|b` → a 또는 b |
| `()` | 그룹 | `(abc)+` → "abc" 반복 |
| `(?=...)` | 긍정적 전방 탐색 | 앞에 ...가 있어야 함 |
| `(?!...)` | 부정적 전방 탐색 | 앞에 ...가 없어야 함 |

## 자주 사용하는 정규식 패턴 모음

### 1. 숫자만
```javascript
/^[0-9]+$/           // 양의 정수
/^-?[0-9]+$/         // 정수 (음수 포함)
/^-?[0-9]+\.?[0-9]*$/ // 실수
```

### 2. 영문만
```javascript
/^[a-zA-Z]+$/        // 영문만
/^[a-z]+$/           // 소문자만
/^[A-Z]+$/           // 대문자만
```

### 3. 한글만
```javascript
/^[가-힣]+$/         // 완성형 한글만
/^[ㄱ-ㅎㅏ-ㅣ가-힣]+$/ // 자음, 모음, 완성형 한글
```

### 4. URL 검증
```javascript
/^https?:\/\/.+/     // http:// 또는 https://
```

### 5. 우편번호 (한국)
```javascript
/^\d{5}$/            // 5자리 숫자
```

### 6. 주민등록번호
```javascript
/^\d{6}-\d{7}$/      // 123456-1234567 형식
```

3. **이름**: `/^[가-힣]{2,10}$/`
4. **이메일**: `/^[0-9a-zA-Z]([-_\.]?[0-9a-zA-Z])*@[0-9a-zA-Z]([-_\.]?[0-9a-zA-Z])*\.[a-zA-Z]{2,3}$/`

6. **생년월일**: `/^\d{4}-\d{2}-\d{2}$/`

### 학습 포인트

- 정규식은 문자열 패턴을 표현하는 강력한 도구
- 전방 탐색(`(?=...)`)을 사용하면 복잡한 조건 검증 가능
- 클라이언트와 서버 양쪽에서 검증 필요
- 정규식 테스트 도구를 활용하여 디버깅
