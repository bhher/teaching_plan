## 정규식 패턴 설명

### 1. 아이디 검증: `regExpId`

```javascript
var regExpId = /^[a-z|A-Z|ㄱ-ㅎ|ㅏ-ㅣ|가-힣]/;
```

**의미:**
- `^`: 문자열의 시작
- `[a-z|A-Z|ㄱ-ㅎ|ㅏ-ㅣ|가-힣]`: 첫 글자가 다음 중 하나여야 함
  - `a-z`: 소문자 영문
  - `A-Z`: 대문자 영문
  - `ㄱ-ㅎ`: 자음
  - `ㅏ-ㅣ`: 모음
  - `가-힣`: 완성형 한글

**문제점:**
- `|` (파이프)는 문자 클래스 `[]` 안에서 **리터럴 문자**로 취급됨
- 의도한 대로 작동하지 않을 수 있음
- 올바른 표현: `/^[a-zA-Zㄱ-ㅎㅏ-ㅣ가-힣]/`

**검증 예시:**
```javascript
regExpId.test("user123")    // true (영문으로 시작)
regExpId.test("123user")    // false (숫자로 시작)
regExpId.test("홍길동")      // true (한글로 시작)
regExpId.test("|user")      // true (파이프로 시작 - 의도하지 않은 결과)
```

---

### 2. 이름 검증: `regExpName`

```javascript
var regExpName = /^[가-힣]*$/;
```

**의미:**
- `^`: 문자열의 시작
- `[가-힣]*`: 완성형 한글 0개 이상
- `$`: 문자열의 끝

**검증 예시:**
```javascript
regExpName.test("홍길동")    // true
regExpName.test("김철수")    // true
regExpName.test("")          // true (빈 값도 통과 - 문제!)
regExpName.test("홍길동123")  // false
regExpName.test("Hong")      // false
```

**문제점:**
- `*`는 0개 이상이므로 빈 값도 통과함
- `+` (1개 이상)를 사용하거나 빈 값 검증을 별도로 해야 함

---

### 3. 비밀번호 검증: `regExpPasswd`

```javascript
var regExpPasswd = /^[0-9]*$/;
```

**의미:**
- `^`: 문자열의 시작
- `[0-9]*`: 숫자 0개 이상
- `$`: 문자열의 끝

**검증 예시:**
```javascript
regExpPasswd.test("1234")    // true
regExpPasswd.test("")        // true (빈 값도 통과 - 문제!)
regExpPasswd.test("1234a")   // false
regExpPasswd.test("abcd")    // false
```

**문제점:**
- `*`는 0개 이상이므로 빈 값도 통과함
- 보안상 숫자만 허용하는 것은 좋지 않음
- 최소 길이 제한이 없음

---

### 4. 전화번호 검증: `regExpPhone`

```javascript
var regExpPhone = /^\d{3}-\d{3,4}-\d{4}$/;
```

**의미:**
- `^`: 문자열의 시작
- `\d{3}`: 숫자 3개 (010, 011 등)
- `-`: 하이픈
- `\d{3,4}`: 숫자 3개 또는 4개 (중간 번호)
- `-`: 하이픈
- `\d{4}`: 숫자 4개 (마지막 번호)
- `$`: 문자열의 끝

**검증 예시:**
```javascript
regExpPhone.test("010-1234-5678")   // true
regExpPhone.test("010-123-4567")    // true
regExpPhone.test("01012345678")     // false (하이픈 없음)
regExpPhone.test("010-12345-678")   // false (형식 불일치)
```

**주의사항:**
- 코드에서 `phone1 + "-" + phone2 + "-" + phone3`로 조합
- 각 필드가 비어있으면 `"--"` 같은 형식이 될 수 있음

---

### 5. 이메일 검증: `regExpEmail`

```javascript
var regExpEmail = /^[0-9a-zA-Z]([-_\.]?[0-9a-zA-Z])*@[0-9a-zA-Z]([-_\.]?[0-9a-zA-Z])*\.[a-zA-Z]{2,3}$/i;
```

**의미:**
- `^`: 문자열의 시작
- `[0-9a-zA-Z]`: 첫 글자는 영문/숫자
- `([-_\.]?[0-9a-zA-Z])*`: 하이픈, 언더스코어, 점 + 영문/숫자 조합 0개 이상
- `@`: @ 기호
- `[0-9a-zA-Z]`: @ 뒤 첫 글자는 영문/숫자
- `([-_\.]?[0-9a-zA-Z])*`: 하이픈, 언더스코어, 점 + 영문/숫자 조합 0개 이상
- `\.`: 점 (이스케이프)
- `[a-zA-Z]{2,3}`: 최상위 도메인 (2-3자)
- `$`: 문자열의 끝
- `i`: 대소문자 구분 안 함

**검증 예시:**
```javascript
regExpEmail.test("user@email.com")        // true
regExpEmail.test("user.name@email.co.kr") // false (도메인 부분이 복잡)
regExpEmail.test("@email.com")            // false (@ 앞에 문자 없음)
regExpEmail.test("user@")                 // false (도메인 없음)
```

## 검증 로직 분석

### 단계별 실행 흐름

```javascript
function checkMember() {
    // 1단계: 정규식 패턴 정의
    var regExpId = /^[a-z|A-Z|ㄱ-ㅎ|ㅏ-ㅣ|가-힣]/;
    // ... (다른 정규식들)
    
    // 2단계: 폼 객체 가져오기
    var form = document.Member;
    
    // 3단계: 각 필드 값 가져오기
    var id = form.id.value;
    var name = form.name.value;
    var passwd = form.passwd.value;
    var phone = form.phone1.value + "-" + form.phone2.value + "-" + form.phone3.value;
    var email = form.email.value;
    
    // 4단계: 각 필드별 검증
    if (!regExpId.test(id)) {
        alert("아이디는 문자로 시작해 주세요!");
        form.id.select();
        return;  // 함수 종료 (폼 제출 안 됨)
    }
    // ... (다른 검증들)
    
    // 5단계: 모든 검증 통과 시
    form.submit();  // 폼 제출
}
```

### 각 검증 단계 설명

#### 1. 아이디 검증
```javascript
if (!regExpId.test(id)) {
    alert("아이디는 문자로 시작해 주세요!");
    form.id.select();
    return;
}
```

**동작:**
- 정규식과 일치하지 않으면 (`!regExpId.test(id)`)
- 경고 메시지 표시
- 아이디 입력 필드의 텍스트 선택
- 함수 종료 (`return`)

**문제점:**
- 빈 값 검증이 없음
- `return`만 있고 `return false`가 아님 (의도는 같지만 명시적이지 않음)

#### 2. 이름 검증
```javascript
if (!regExpName.test(name)) {
    alert("이름은 한글만으로 입력해 주세요!");
    return;
}
```

**동작:**
- 한글이 아닌 문자가 포함되어 있으면 경고
- 함수 종료

**문제점:**
- 빈 값도 통과함 (`*`는 0개 이상)
- `focus()`가 없어 사용자가 어느 필드인지 알기 어려움

#### 3. 비밀번호 검증
```javascript
if (!regExpPasswd.test(passwd)) {
    alert("비밀번호는 숫자만으로 입력해 주세요!");
    return;
}
```

**동작:**
- 숫자가 아닌 문자가 포함되어 있으면 경고
- 함수 종료

**문제점:**
- 빈 값도 통과함
- 보안상 숫자만 허용하는 것은 약함
- 최소 길이 제한 없음

#### 4. 전화번호 검증
```javascript
var phone = form.phone1.value + "-" + form.phone2.value + "-" + form.phone3.value;
if (!regExpPhone.test(phone)) {
    alert("연락처 입력을 확인해 주세요!");
    return;
}
```

**동작:**
- 세 개의 입력 필드를 조합하여 검증
- 형식이 맞지 않으면 경고

**문제점:**
- 각 필드가 비어있어도 `"--"` 같은 형식이 될 수 있음
- 각 필드의 빈 값 검증이 없음

#### 5. 이메일 검증
```javascript
if (!regExpEmail.test(email)) {
    alert("이메일 입력을 확인해 주세요!");
    return;
}
```

**동작:**
- 이메일 형식이 맞지 않으면 경고
- 함수 종료

**문제점:**
- 빈 값 검증이 없음 (선택 필드라면 괜찮지만)

## 문제점 및 개선사항

### 1. `onclick` 사용 문제

**현재 코드:**
```html
<input type="button" value="가입하기" onclick="checkMember()">
```

**문제점:**
- `onclick`에서 `return`이 없음
- Enter 키로 제출할 때 검증이 실행되지 않을 수 있음
- `form.submit()`을 직접 호출하는 방식

**개선 방법:**
```html
<!-- 방법 1: onsubmit 사용 (권장) -->
<form ... onsubmit="return checkMember()">
    <input type="submit" value="가입하기">
</form>

<!-- 방법 2: onclick에서 return 사용 -->
<input type="button" value="가입하기" onclick="return checkMember()">
```

### 2. 빈 값 검증 누락

**문제:**
- 모든 필드에서 빈 값 검증이 없음
- 정규식의 `*` (0개 이상) 때문에 빈 값도 통과함

**개선:**
```javascript
// 빈 값 검증 추가
if(id === "" || id.trim() === ""){
    alert("아이디를 입력해 주세요.");
    form.id.focus();
    return false;
}
```

### 3. 정규식 패턴 오류

**문제:**
```javascript
var regExpId = /^[a-z|A-Z|ㄱ-ㅎ|ㅏ-ㅣ|가-힣]/;
```

**개선:**
```javascript
var regExpId = /^[a-zA-Zㄱ-ㅎㅏ-ㅣ가-힣]/;
// 또는
var regExpId = /^[a-zA-Z가-힣]/;  // 완성형 한글만
```

### 4. `return` vs `return false`

**현재:**
```javascript
return;  // 암묵적으로 undefined 반환
```

**개선:**
```javascript
return false;  // 명시적으로 false 반환
```

### 5. 사용자 경험 개선

**현재:**
- 일부 필드에만 `select()` 사용
- `focus()`가 없는 필드도 있음

**개선:**
- 모든 검증 실패 시 해당 필드로 `focus()` 이동
- 명확한 에러 메시지

## 개선된 코드

```jsp
<%@ page contentType="text/html; charset=utf-8"%>
<html>
<head>
<title>Validation</title>
<script type="text/javascript">
	function checkMember() {
		// 정규식 패턴 정의 (수정됨)
		var regExpId = /^[a-zA-Z가-힣]/;  // 파이프 제거
		var regExpName = /^[가-힣]+$/;     // + 사용 (1개 이상)
		var regExpPasswd = /^[0-9]+$/;     // + 사용 (1개 이상)
		var regExpPhone = /^\d{3}-\d{3,4}-\d{4}$/;
		var regExpEmail = /^[0-9a-zA-Z]([-_\.]?[0-9a-zA-Z])*@[0-9a-zA-Z]([-_\.]?[0-9a-zA-Z])*\.[a-zA-Z]{2,3}$/i;

		var form = document.Member;

		// 값 가져오기 (trim 추가)
		var id = form.id.value.trim();
		var name = form.name.value.trim();
		var passwd = form.passwd.value;
		var phone1 = form.phone1.value;
		var phone2 = form.phone2.value.trim();
		var phone3 = form.phone3.value.trim();
		var phone = phone1 + "-" + phone2 + "-" + phone3;
		var email = form.email.value.trim();

		// 아이디 검증 (빈 값 검증 추가)
		if(id === ""){
			alert("아이디를 입력해 주세요!");
			form.id.focus();
			return false;
		}
		if (!regExpId.test(id)) {
			alert("아이디는 문자로 시작해 주세요!");
			form.id.select();
			return false;
		}
		
		// 이름 검증 (빈 값 검증 추가)
		if(name === ""){
			alert("이름을 입력해 주세요!");
			form.name.focus();
			return false;
		}
		if (!regExpName.test(name)) {
			alert("이름은 한글만으로 입력해 주세요!");
			form.name.select();
			return false;
		}
		
		// 비밀번호 검증 (빈 값 검증 추가)
		if(passwd === ""){
			alert("비밀번호를 입력해 주세요!");
			form.passwd.focus();
			return false;
		}
		if(passwd.length < 4){
			alert("비밀번호는 4자 이상 입력해 주세요!");
			form.passwd.select();
			return false;
		}
		if (!regExpPasswd.test(passwd)) {
			alert("비밀번호는 숫자만으로 입력해 주세요!");
			form.passwd.select();
			return false;
		}
		
		// 전화번호 검증 (각 필드 빈 값 검증 추가)
		if(phone1 === "" || phone2 === "" || phone3 === ""){
			alert("연락처를 모두 입력해 주세요!");
			if(phone1 === "") form.phone1.focus();
			else if(phone2 === "") form.phone2.focus();
			else form.phone3.focus();
			return false;
		}
		if (!regExpPhone.test(phone)) {
			alert("연락처 입력을 확인해 주세요!\n예: 010-1234-5678");
			form.phone2.focus();
			return false;
		}
		
		// 이메일 검증 (빈 값 검증 추가 - 선택 필드라면 제거 가능)
		if(email === ""){
			alert("이메일을 입력해 주세요!");
			form.email.focus();
			return false;
		}
		if (!regExpEmail.test(email)) {
			alert("이메일 입력을 확인해 주세요!\n예: example@email.com");
			form.email.select();
			return false;
		}
		
		// 모든 검증 통과
		return true;
	}
</script>
</head>
<body>
	<h3>회원 가입</h3>
	<!-- onsubmit 사용으로 변경 -->
	<form action="validation05_process.jsp" name="Member" method="post" 
	      onsubmit="return checkMember()">
		<p>아이디 : <input type="text" name="id">
		<p>비밀번호 : <input type="password" name="passwd">
		<p>이름 : <input type="text" name="name">
		<p>연락처 : 
			<select name="phone1">
				<option value="010">010</option>
				<option value="011">011</option>
				<option value="016">016</option>
				<option value="017">017</option>
				<option value="019">019</option>
			</select> - 
			<input type="text" maxlength="4" size="4" name="phone2"> - 
			<input type="text" maxlength="4" size="4" name="phone3">
		<p>이메일 : <input type="text" name="email">		
		<p><input type="submit" value="가입하기">
	</form>
</body>
</html>
```

## 정규식 패턴 상세 설명

### 정규식 기본 문법

| 기호 | 의미 | 예시 |
|------|------|------|
| `^` | 문자열 시작 | `^abc` → "abc"로 시작 |
| `$` | 문자열 끝 | `abc$` → "abc"로 끝 |
| `*` | 0개 이상 | `a*` → "", "a", "aa", ... |
| `+` | 1개 이상 | `a+` → "a", "aa", ... |
| `?` | 0개 또는 1개 | `a?` → "", "a" |
| `{n}` | 정확히 n개 | `\d{3}` → 숫자 3개 |
| `{n,m}` | n개 이상 m개 이하 | `\d{3,4}` → 숫자 3-4개 |
| `[]` | 문자 클래스 | `[abc]` → a, b, c 중 하나 |
| `\d` | 숫자 | `[0-9]`와 동일 |
| `\w` | 단어 문자 | `[a-zA-Z0-9_]` |
| `.` | 모든 문자 (점은 `\.`) | |

### 문자 클래스 안의 특수 문자

**주의:** `[]` 안에서는 대부분의 특수 문자가 리터럴로 취급됩니다.

```javascript
/[a-z|A-Z]/     // a-z 또는 | 또는 A-Z (의도와 다름!)
/[a-zA-Z]/      // a-z 또는 A-Z (올바름)
```

## 실습 예제

### 예제 1: 아이디 검증 개선

```javascript
// 현재 (문제 있음)
var regExpId = /^[a-z|A-Z|ㄱ-ㅎ|ㅏ-ㅣ|가-힣]/;

// 개선 1: 파이프 제거
var regExpId = /^[a-zA-Zㄱ-ㅎㅏ-ㅣ가-힣]/;

// 개선 2: 완성형 한글만
var regExpId = /^[a-zA-Z가-힣]/;

// 개선 3: 영문/숫자만 (일반적)
var regExpId = /^[a-zA-Z][a-zA-Z0-9]*$/;  // 첫 글자는 영문, 나머지는 영문/숫자
```

### 예제 2: 이름 검증 개선

```javascript
// 현재 (빈 값 통과)
var regExpName = /^[가-힣]*$/;

// 개선 1: 1개 이상
var regExpName = /^[가-힣]+$/;

// 개선 2: 2-10자 제한
var regExpName = /^[가-힣]{2,10}$/;
```

### 예제 3: 비밀번호 검증 개선

```javascript
// 현재 (숫자만, 빈 값 통과)
var regExpPasswd = /^[0-9]*$/;

// 개선 1: 숫자만, 4자 이상
var regExpPasswd = /^[0-9]{4,}$/;

// 개선 2: 영문/숫자 조합, 8자 이상
var regExpPasswd = /^(?=.*[a-zA-Z])(?=.*[0-9])[a-zA-Z0-9]{8,}$/;
// (?=.*[a-zA-Z]): 영문 포함 확인
// (?=.*[0-9]): 숫자 포함 확인
// [a-zA-Z0-9]{8,}: 영문/숫자 8자 이상
```

## 요약

### 핵심 포인트

1. **정규식 패턴**
   - 문자 클래스 `[]` 안에서 `|`는 리터럴 문자
   - `*`는 0개 이상, `+`는 1개 이상
   - 빈 값 검증을 위해 `+` 사용 또는 별도 검증 필요

2. **검증 순서**
   - 빈 값 검증 → 형식 검증 → 길이 검증

3. **사용자 경험**
   - 모든 검증 실패 시 `focus()` 사용
   - 명확한 에러 메시지 제공

4. **이벤트 처리**
   - `onsubmit` 사용 권장
   - `return false` / `return true` 명시적 사용
