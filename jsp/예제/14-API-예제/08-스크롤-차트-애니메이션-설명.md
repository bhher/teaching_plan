# 스크롤 차트 애니메이션 설명서

## 📋 개요

이 예제는 사용자가 페이지를 스크롤할 때 차트가 화면에 나타나면서 애니메이션 효과를 보여주는 HTML 파일입니다. Chart.js 라이브러리를 사용하여 막대 그래프, 원형 그래프, 선 그래프를 구현했습니다.

---

## 🎯 주요 기능

1. **스크롤 감지**: Intersection Observer API를 사용하여 차트가 화면에 나타날 때 감지
2. **페이드인 애니메이션**: 차트 섹션이 나타날 때 부드러운 페이드인 효과
3. **차트 애니메이션**: Chart.js의 내장 애니메이션 기능 활용
4. **반응형 디자인**: 다양한 화면 크기에 대응

---

## 🔧 기술 스택

### 1. Chart.js
- **용도**: 차트 생성 및 렌더링
- **CDN**: `https://cdn.jsdelivr.net/npm/chart.js`
- **장점**: 
  - 사용하기 쉬운 API
  - 다양한 차트 타입 지원
  - 내장 애니메이션 기능
  - 반응형 디자인 자동 지원

### 2. Intersection Observer API
- **용도**: 요소가 뷰포트에 나타나는지 감지
- **장점**:
  - 성능 최적화 (스크롤 이벤트보다 효율적)
  - 브라우저 네이티브 API
  - 비동기 처리

## 📝 코드 상세 설명

### 1. HTML 구조

```html
<div class="chart-section" id="barChartSection">
    <h2>📊 막대 그래프 (Bar Chart)</h2>
    <div class="chart-container">
        <canvas id="barChart"></canvas>
    </div>
    <div class="chart-description">...</div>
</div>
```

- `chart-section`: 각 차트를 감싸는 컨테이너
- `chart-container`: 차트가 그려질 영역
- `<canvas>`: Chart.js가 차트를 그릴 HTML5 캔버스 요소

### 2. CSS 스타일

#### 초기 상태 (보이지 않음)
```css
.chart-section {
    opacity: 0;
    transform: translateY(50px);
    transition: opacity 0.8s ease, transform 0.8s ease;
}
```

- `opacity: 0`: 투명하게 시작
- `transform: translateY(50px)`: 아래로 50px 이동한 상태
- `transition`: 부드러운 전환 효과

#### 보이는 상태
```css
.chart-section.visible {
    opacity: 1;
    transform: translateY(0);
}
```

- `.visible` 클래스가 추가되면 페이드인과 함께 위로 이동

### 3. JavaScript 로직

#### Intersection Observer 설정

```javascript
var observerOptions = {
    root: null,              // 뷰포트를 기준으로 감지
    rootMargin: '0px',       // 여백 없음
    threshold: 0.3           // 요소가 30% 보이면 트리거
};

var observer = new IntersectionObserver(function(entries) {
    entries.forEach(function(entry) {
        if (entry.isIntersecting) {
            // 요소가 화면에 나타났을 때 실행
            entry.target.classList.add('visible');
            
            // 차트 생성 (한 번만 실행)
            if (entry.target.id === 'barChartSection' && !barChart) {
                createBarChart();
            }
        }
    });
}, observerOptions);
```

**설명:**
- `threshold: 0.3`: 차트가 30% 보이면 감지
- `entry.isIntersecting`: 요소가 뷰포트에 있는지 확인
- `entry.target`: 관찰 중인 요소 (차트 섹션)
- 차트는 한 번만 생성되도록 `!barChart` 조건 추가

#### 차트 생성 함수

```javascript
function createBarChart() {
    var ctx = document.getElementById('barChart').getContext('2d');
    
    barChart = new Chart(ctx, {
        type: 'bar',  // 차트 타입
        data: {
            labels: ['1월', '2월', '3월', ...],  // X축 레이블
            datasets: [{
                label: '매출액 (만원)',
                data: [120, 190, 300, ...],      // 데이터 값
                backgroundColor: [...],          // 막대 배경색
                borderColor: [...],               // 막대 테두리 색
                borderWidth: 2
            }]
        },
        options: {
            animation: {
                duration: 2000,              // 애니메이션 지속 시간 (2초)
                easing: 'easeOutQuart'        // 애니메이션 이징
            },
            responsive: true,                // 반응형
            maintainAspectRatio: false       // 비율 유지 안 함 (높이 자유롭게)
        }
    });
}
```

**주요 옵션 설명:**
- `type`: 차트 타입 (`bar`, `pie`, `line` 등)
- `data.labels`: X축 또는 범례에 표시될 레이블
- `data.datasets`: 실제 데이터와 스타일 정보
- `options.animation.duration`: 애니메이션 지속 시간 (밀리초)
- `options.responsive`: 화면 크기에 맞게 자동 조정

## 📊 차트 타입별 특징

### 1. 막대 그래프 (Bar Chart)

**사용 예시:**
- 월별 매출 비교
- 카테고리별 수량 비교
- 시간대별 통계

**특징:**
- 수평 또는 수직 막대로 값 표현
- 여러 데이터셋 비교 가능
- 범주형 데이터에 적합

### 2. 원형 그래프 (Pie Chart)

**사용 예시:**
- 전체 대비 비율 표시
- 구성 요소 분포 시각화
- 카테고리별 점유율

**특징:**
- 전체에 대한 각 부분의 비율 표현
- 색상으로 구분하여 직관적
- 항목이 많으면 복잡해질 수 있음

**애니메이션 옵션:**
```javascript
animation: {
    animateRotate: true,   // 회전 애니메이션
    animateScale: true     // 크기 애니메이션
}
```

### 3. 선 그래프 (Line Chart)

**사용 예시:**
- 시간에 따른 추이 분석
- 여러 시리즈 비교
- 트렌드 파악

**특징:**
- 연속적인 데이터 표현
- 추세 파악에 유리
- 곡선 또는 직선 선택 가능

**옵션:**
```javascript
tension: 0.4,  // 곡선 정도 (0~1)
fill: true     // 선 아래 영역 채우기
```

## 🎨 커스터마이징 가이드

### 1. 색상 변경

```javascript
backgroundColor: [
    'rgba(102, 126, 234, 0.8)',  // RGBA 형식
    'rgba(118, 75, 162, 0.8)',
    // ...

```

- `rgba(Red, Green, Blue, Alpha)`
- Alpha 값: 0 (투명) ~ 1 (불투명)

### 2. 애니메이션 속도 조절

```javascript
animation: {
    duration: 2000,  // 밀리초 단위 (2000 = 2초)
    easing: 'easeOutQuart'  // 이징 함수
}
```

**이징 옵션:**
- `linear`: 일정한 속도
- `easeIn`: 느리게 시작
- `easeOut`: 느리게 끝
- `easeInOut`: 느리게 시작하고 끝

### 3. 차트 크기 조절

```css
.chart-container {
    height: 400px;  /* 원하는 높이로 변경 */
}
```

### 4. 스크롤 감지 시점 변경

```javascript
threshold: 0.3  // 0.0 (바로 보이면) ~ 1.0 (완전히 보여야)
```

## 🐛 문제 해결

### 1. 차트가 나타나지 않을 때

**원인:**
- Chart.js 라이브러리가 로드되지 않음
- Canvas 요소가 없음
- JavaScript 오류

**해결:**
- 브라우저 개발자 도구(F12)에서 콘솔 확인
- Chart.js CDN이 정상적으로 로드되었는지 확인
- Canvas 요소의 ID가 정확한지 확인

### 2. 애니메이션이 부드럽지 않을 때

**원인:**
- `transition` CSS 속성이 없음
- 브라우저 성능 문제

**해결:**
- CSS에 `transition` 속성 확인
- `will-change` 속성 추가 (성능 최적화)

### 3. 모바일에서 차트가 작게 보일 때

**원인:**
- 반응형 설정 문제
- 캔버스 크기 고정

**해결:**
- `responsive: true` 확인
- `maintainAspectRatio: false` 설정
- CSS에서 `chart-container` 높이 조정

## 💡 학습 포인트

### 1. Intersection Observer API

**기존 방법 (비효율적):**
```javascript
window.addEventListener('scroll', function() {
    // 매번 스크롤할 때마다 실행
    // 성능 저하 가능
});
```

**현재 방법 (효율적):**
```javascript
var observer = new IntersectionObserver(callback, options);
observer.observe(element);
// 요소가 뷰포트에 나타날 때만 실행
```

### 2. Chart.js 사용법

1. Canvas 요소 준비
2. Context 가져오기
3. Chart 객체 생성
4. 데이터와 옵션 설정

### 3. CSS 애니메이션

- `opacity`: 투명도 조절
- `transform`: 위치 이동, 크기 조절
- `transition`: 부드러운 전환

1. **성능**: 많은 차트가 있으면 초기 로딩 시간이 길어질 수 있음

3. **접근성**: 스크린 리더 사용자를 위한 대체 텍스트 추가 권장
