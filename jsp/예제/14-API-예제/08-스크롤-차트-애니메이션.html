📊 막대 그래프 (Bar Chart)

막대 그래프란?
막대 그래프는 범주형 데이터를 수평 또는 수직 막대로 표현하는 차트입니다. 각 막대의 길이는 해당 값의 크기를 나타냅니다. 여러 항목의 값을 비교하거나 시간에 따른 변화를 보여줄 때 유용합니다.

🥧 원형 그래프 (Pie Chart)

원형 그래프란?
원형 그래프는 전체에 대한 각 부분의 비율을 원의 조각으로 표현하는 차트입니다. 전체 대비 각 항목의 비율을 한눈에 파악하기 쉽습니다. 구성 비율을 보여주거나 분포를 시각화할 때 주로 사용됩니다.

📈 선 그래프 (Line Chart)

선 그래프란?
선 그래프는 시간에 따른 데이터의 변화 추이를 선으로 연결하여 표현하는 차트입니다. 추세를 파악하거나 여러 데이터 시리즈를 비교할 때 유용합니다.
