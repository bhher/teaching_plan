## 📝 시험 문제

---

### 문제 1. 회원가입 폼 만들기 (25점)

다음 조건에 맞는 회원가입 페이지를 JSP로 작성하시오.

#### 요구사항

**입력 항목**

| 항목 | name 속성값 |
|------|-------------|
| 아이디 | userid |
| 비밀번호 | userpw |
| 이름 | username |
| 이메일 | email |

**조건**

- `form`의 `method` = `post`
- `form`의 `action` = `joinProcess.jsp`
- 모든 항목 **필수 입력** (`required` 또는 유효성 검사)
- submit 버튼 텍스트 = **회원가입**

**출력 예시**

```
아이디 : [________]
비밀번호 : [________]
이름 : [________]
이메일 : [________]

[회원가입]
```

**작성 파일명:** `join.jsp`

---

### 문제 2. 회원정보 출력 페이지 (25점)

다음 조건에 맞는 `joinProcess.jsp`를 작성하시오.

#### 요구사항

- 회원가입 페이지(`join.jsp`)에서 전달된 값을 받아 출력한다.

**출력 형식**

```
회원가입 정보
아이디 : test
비밀번호 : 1234
이름 : 홍길동
이메일 : test@test.com
```

**조건**

- `request.getParameter()` 사용
- **테이블**로 출력

**작성 파일명:** `joinProcess.jsp`

### 문제 3. 게시글 등록 페이지 (25점)

다음 조건에 맞는 게시글 작성 페이지를 JSP로 작성하시오.

#### 요구사항

**입력 항목**

| 항목 | name 속성값 |
|------|-------------|
| 작성자 | writer |
| 제목 | title |
| 내용 | content |

**조건**

- `form`의 `method` = `post`
- `form`의 `action` = `writeProcess.jsp`
- 내용 입력은 **textarea** 사용
- submit 버튼 텍스트 = **글쓰기**

**출력 예시**

```
작성자 : [________]
제목 : [________]
내용 :
[                 ]

[글쓰기]
```

**작성 파일명:** `write.jsp`

### 문제 4. 게시글 리스트 출력 (25점)

다음 배열 데이터를 JSP에서 출력하시오.

**데이터**

- 작성자: 홍길동, 김철수, 이영희
- 제목: JSP 공부, 서블릿 공부, JDBC 공부

**출력 형식**

| 번호 | 작성자 | 제목 |
|------|--------|------|
| 1 | 홍길동 | JSP 공부 |
| 2 | 김철수 | 서블릿 공부 |
| 3 | 이영희 | JDBC 공부 |

**조건**

- **배열** 사용
- **for문** 사용
- **table**로 출력

**작성 파일명:** `list.jsp`

## 📊 채점 기준

### 문제 1. 회원가입 폼 (25점)

| 채점 항목 | 배점 | 세부 기준 |
|----------|------|----------|
| form 태그 | 5점 | method="post", action="joinProcess.jsp" 정확히 작성 |
| input 요소 | 12점 | userid, userpw, username, email 각 3점 (name 속성 정확) |
| 필수 입력 | 3점 | required 속성 또는 유효성 검사 적용 |
| submit 버튼 | 2점 | "회원가입" 텍스트, type="submit" |
| 레이아웃 | 3점 | 항목별 레이블, 가독성 |

**감점 사항**

- name 속성 오류: 해당 항목 점수 감점
- method/action 오류: 5점 감점
