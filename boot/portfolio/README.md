# HAEUN Portfolio (Bootstrap)

Bootstrap 5.3.8 기반 개인 포트폴리오 예제입니다.

## 실행

`index.html`을 브라우저에서 엽니다. (CDN · Google Fonts)

## 구성

```
portfolio/
├── index.html
├── css/style.css
├── js/main.js
└── README.md
```

## 섹션

| 영역 | 내용 |
|------|------|
| Hero | 브랜드 HAEUN · 헤드라인 · CTA · 풀블리드 이미지 |
| Work | 프로젝트 3개 (Grid + 링크) |
| About | 소개 · 스킬 |
| Contact | Bootstrap Form |
| Footer | 브랜드 · 저작권 |

## Bootstrap 사용처

- `navbar` / `collapse` (반응형 메뉴)
- `container` · `row` · `col-*` (Grid)
- `btn` · `form-control` · `form-label`
