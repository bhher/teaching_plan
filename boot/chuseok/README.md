# 추석 인사 카드 (카톡용)

모바일 세로 한 장 · 보름달 애니메이션 추석 인사입니다.

## 카톡으로 보내는 법 (추천 순)

### 1) 파일 하나 보내기 ★
`추석인사-카톡용.html` 은 CSS가 **파일 안에 포함**되어 있습니다.

1. `추석인사-카톡용.html` 을 메모장/에디터로 열어  
   `— 드림` 을 `— 홍길동 드림` 처럼 이름만 수정
2. 카톡 **파일 전송** 또는 에어드롭으로 보냄
3. 상대방이 파일을 받아 **Chrome / Safari** 로 열면 애니메이션이 재생됩니다  
   (카톡 안에서 HTML이 바로 안 열릴 수 있어, “다른 앱으로 열기”가 필요할 수 있음)

### 2) 링크로 보내기 (가장 편함)
서버나 [Netlify Drop](https://app.netlify.com/drop) 등에 올린 뒤 **URL만** 카톡에 붙여 넣기.  
미리보기(og 태그)도 잡혀 있습니다.

### 3) 화면 캡처 / 화면녹화
폰에서 HTML을 연 뒤 **영상으로 녹화**해 카톡에 보내도 됩니다.

## 파일

| 파일 | 용도 |
|------|------|
| **추석인사-카톡용.html** | 카톡 전송용 (단일 파일) |
| index.html + css/ | 수업·수정용 분리 버전 |

## 미리보기

브라우저에서 `추석인사-카톡용.html` 또는 `index.html` 을 열면 됩니다.
