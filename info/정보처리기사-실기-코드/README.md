# 정보처리기사 실기 문제 코드

이 폴더에는 정보처리기사 실기 문제의 실행 가능한 Java 코드가 포함되어 있습니다.

## 파일 구조

- `Problem1_Array.java` - 배열 처리 알고리즘 문제
- `Problem2_String.java` - 문자열 처리 알고리즘 문제
- `Problem3_Loop.java` - 반복문과 조건문 활용 문제
- `Problem6_StudentManagement.java` - 종합 알고리즘 문제 (학생 점수 관리)

## 실행 방법

각 파일은 독립적으로 실행 가능합니다.

```bash
# 컴파일
javac Problem1_Array.java

# 실행
java Problem1_Array
```
