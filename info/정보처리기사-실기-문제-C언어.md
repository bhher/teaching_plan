## 문제 1: 배열 처리 알고리즘 (20점)

다음과 같은 정수 배열이 주어졌을 때, 주어진 요구사항을 만족하는 코드를 작성하세요.

### 초기 데이터
```c
int arr[] = {3, 7, 2, 9, 1, 5, 8, 4, 6};
int n = sizeof(arr) / sizeof(arr[0]);  // 배열 크기: 9
```

### 요구사항
1. 배열의 최댓값과 최솟값을 찾아 출력하세요.
2. 배열의 평균값을 계산하여 출력하세요. (소수점 둘째 자리까지)
3. 배열에서 짝수만 필터링하여 새로운 배열에 저장하고 출력하세요.
4. 배열을 오름차순으로 정렬하여 출력하세요.

### 출력 형식
```
최댓값: 9
최솟값: 1
평균값: 5.00
짝수 배열: [2, 8, 4, 6]
정렬된 배열: [1, 2, 3, 4, 5, 6, 7, 8, 9]
```

## 문제 2: 문자열 처리 알고리즘 (20점)

다음 문자열을 처리하는 프로그램을 작성하세요.

### 초기 데이터
```c
char text[] = "Hello World Java Programming";
```

### 요구사항
1. 문자열을 공백을 기준으로 분리하여 단어 배열을 만드세요.
2. 각 단어의 길이를 계산하여 출력하세요.
3. 대문자로 시작하는 단어만 필터링하여 출력하세요.
4. 모든 단어를 역순으로 출력하세요. (예: "Hello" → "olleH")

### 출력 형식
```
단어 배열: [Hello, World, Java, Programming]
각 단어의 길이: [5, 5, 4, 11]
대문자로 시작하는 단어: [Hello, World, Java, Programming]
역순 문자열: olleH dlroW avaJ gnimmargorP
```

## 문제 6: 종합 알고리즘 문제 (20점) - 선택 문제

다음 요구사항을 만족하는 프로그램을 작성하세요.

### 문제 설명
학생들의 점수를 관리하는 시스템입니다. 다음 기능을 구현하세요.

### 초기 데이터
```c
char names[][20] = {"김철수", "이영희", "박민수", "최지영", "정수진"};
int scores[] = {85, 92, 78, 88, 95};
int count = 5;
```

### 요구사항
1. 학생들의 평균 점수를 계산하세요.
2. 평균 점수 이상인 학생의 이름과 점수를 출력하세요.
3. 점수에 따라 등급을 부여하세요.
   - 90점 이상: A등급
   - 80점 이상 90점 미만: B등급
   - 70점 이상 80점 미만: C등급
   - 70점 미만: D등급
4. 각 등급별 학생 수를 집계하세요.

### 출력 형식
```
평균 점수: 87.6
평균 이상 학생:
  김철수: 85점
  이영희: 92점
  최지영: 88점
  정수진: 95점

등급별 학생 수:
  A등급: 2명
  B등급: 2명
  C등급: 1명
  D등급: 0명
```
