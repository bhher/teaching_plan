## 문제 1-20

### 문제 1

**문제:** 컴퓨터 소유자도 모르게 해커가 간헐적으로 서비스 거부 공격을 가하여 컴퓨터 보안을 손상시키는 것

**정답:** 펄스형 좀비 (pulsing zombie)

**해설:**
- 좀비 컴퓨터는 해커에 의해 감염되어 제어되는 컴퓨터를 의미합니다.
- 펄스형 좀비는 간헐적으로 서비스 거부(DoS) 공격을 수행하는 좀비 컴퓨터입니다.
- 소유자가 모르는 사이에 공격에 가담하게 되어 보안을 위협합니다.

---

### 문제 2

**문제:** 인터넷에서 의도적으로 웹 사이트나 네트워크에 패킷을 쇄도하게 하여 서비스 거부 상태가 되게 만드는 사람

**정답:** 패킷 멍키 (packet monkey)

**해설:**
- 패킷 멍키는 DoS 공격을 수행하는 해커를 지칭하는 용어입니다.
- 대량의 패킷을 보내서 서버를 마비시키는 공격을 수행합니다.
- "멍키"는 원숭이를 의미하며, 단순 반복적인 공격을 하는 사람을 비유한 표현입니다.

---

### 문제 3

**문제:** 스팸 메일에 포함되어 사회 공학적 기법을 통해 유포되는 변종 웜. 연말연시 새해 축하 카드, 밸런타인데이 카드, 허위 테러 공격 뉴스, SMS Spy 등을 이용하는 등 사회적으로 쟁점화되고 있거나 관심 있는 내용을 통해서 유포되는 웜이다.

**정답:** 웨일댁 봇넷 (Waledac)

**해설:**
- Waledac은 사회 공학적 기법을 사용하는 악성 봇넷입니다.
- 사람들의 관심사를 이용하여 메일을 열도록 유도합니다.
- 봇넷에 감염된 컴퓨터들을 원격에서 제어할 수 있습니다.

---

### 문제 4

**문제:** 웹 서핑을 하던 사람들이 브라우저를 닫거나 이전 페이지로 돌아가지 못하도록 만들어진 기능

**정답:** 마우스트래핑 (mousetrapping)

**해설:**
- 마우스트래핑은 사용자를 특정 웹사이트에 가두는 기법입니다.
- JavaScript를 이용하여 브라우저 창을 닫지 못하게 하거나 무한 팝업을 띄웁니다.
- 사용자 경험을 해치는 악의적인 기법입니다.

---

### 문제 5

**문제:** 사용 중인 다른 사람의 윈도즈 운영 체계(OS)의 충돌 또는 중단 원인이 되게 하는 수법

**정답:** 청색 폭탄 (blue bomb)

**해설:**
- 청색 폭탄은 Windows 시스템을 다운시키는 공격 기법입니다.
- NetBIOS 프로토콜의 취약점을 이용합니다.
- "청색 폭탄"이라는 이름은 Windows의 블루스크린(BSOD)에서 유래했습니다.

---

### 문제 6

**문제:** 키보드 입력을 통한 패스워드 유출을 막기 위해 그래픽과 마우스 따위로 패스워드를 입력하는 방식.

**정답:** 시큐어패스 (SecurePass)

**해설:**
- 키로거(keylogger) 공격을 방어하기 위한 보안 기법입니다.
- 키보드 입력 대신 화면의 가상 키보드나 그래픽을 클릭하여 입력합니다.
- 키로거가 키 입력을 감지해도 실제 패스워드를 알 수 없습니다.

---

### 문제 7

**문제:** 컴퓨터에 의한 가상 현실을 이용자가 더욱 현실감 있게 체험할 수 있도록 고안된 옷

**정답:** 사이버 슈트 (cyber suit)

**해설:**
- 가상 현실(VR) 체험을 위한 착용형 장비입니다.
- 촉각, 온도 등 다양한 감각을 전달합니다.
- 몰입형 가상 현실 경험을 제공합니다.

---

### 문제 8

**문제:** 주소 위장으로 무효가 되었거나 구성이 잘못된 시스템에서 지정된 주소이기 때문에 경로 지정이 불가능한 IP 주소.

**정답:** 마션 주소 (Martian address)

**해설:**
- Martian address는 잘못 구성되거나 위장된 IP 주소입니다.
- 라우팅이 불가능한 주소로, 네트워크에서 차단되어야 합니다.
- 예: 사설 IP 주소가 공용 네트워크에 나타나는 경우

### 문제 9

**문제:** 동시에 여러 대상(디스크 또는 테이프)에 백업 데이터를 전송하는 기술

**정답:** 인라인 복제 (inline copy)

**해설:**
- 여러 백업 대상에 동시에 데이터를 복사하는 기술입니다.
- 백업 시간을 단축하고 효율성을 높입니다.
- 스토리지 관리에서 중요한 기술입니다.

### 문제 10

**문제:** 비즈니스를 통합하여 고객, 협력 업체, 공급 업체, 직원 등을 연결하는 기술로 기존의 클라이언트/서버 컴퓨팅 및 웹 컴퓨팅이 발전한 형태

**정답:** 포털 컴퓨팅 (portal computing)

**해설:**
- 기업의 다양한 이해관계자를 하나의 포털로 통합하는 기술입니다.
- 정보 공유와 협업을 효율화합니다.
- 기업 포털(Enterprise Portal)의 개념과 유사합니다.

### 문제 11

**문제:** 소니가 1999년에 SDMI(Secure Digital Music Initiative)의 일부로 선보인 복사 보호 기술이다. 파일 복사 방식을 제어하기 위하여 장치의 콘텐츠에 걸린 암호를 해제하고 기억 장치와 카드 리더 두 곳에 매직게이트 칩을 사용함으로써 동작한다.

**정답:** 매직 게이트 (magicgate)

**해설:**
- 디지털 저작권 보호(DRM) 기술입니다.
- 콘텐츠의 무단 복사를 방지합니다.
- 암호화된 콘텐츠를 안전하게 재생할 수 있게 합니다.

### 문제 12

**문제:** 사이버 공간에서의 만남과 관계. '사이버'(cyber)와 관계를 뜻하는 '리레이션' (relation)의 합성어로 카페와 미니홈피, 블로그, 소셜네트워크서비스(SNS)와 같이 우리 삶 속에 깊숙이 들어온 인터넷이 사람과 사람 사이의 관계에 중요한 역할을 하고 있는 현상

**정답:** 사이버레이션 (Cyberlation)

**해설:**
- 인터넷을 통한 인간관계의 변화를 나타내는 용어입니다.
- 온라인 커뮤니티와 SNS가 사회 관계에 미치는 영향을 설명합니다.
- 디지털 시대의 새로운 관계 형성 방식을 의미합니다.

### 문제 13

**문제:** 컴퓨터 통신망상에 구축된 가상적 세계를 항행하는 사람이라는 뜻으로, 인터넷 정보의 탐색에 매우 많은 시간을 소비하는 사람. 인터노트(Inter-naut)라고도 한다.

**정답:** 사이버노트 (cybernaut)

**해설:**
- 인터넷을 자유롭게 탐색하는 사람을 의미합니다.
- "naut"는 항해자(navigator)를 의미합니다.
- 인터넷 서핑에 많은 시간을 보내는 사람을 지칭합니다.

### 문제 14

**문제:** 그래픽 이미지가 하이퍼링크의 역할을 하는 외부 접속 기능

**정답:** 하이퍼그래픽 (hypergraphic)

**해설:**
- 이미지에 하이퍼링크 기능을 부여한 것입니다.
- 클릭하면 다른 페이지나 리소스로 이동합니다.
- 웹 페이지에서 흔히 사용되는 기능입니다.

### 문제 15

**문제:** 인터넷이나 다른 네트워크를 통해 정보 통신(IT) 응용 프로그램들을 조달하는 것

**정답:** 넷소싱 (netsourcing)

**해설:**
- 네트워크를 통한 소프트웨어 및 서비스 조달 방식입니다.
- 클라우드 컴퓨팅의 개념과 유사합니다.
- 외부에서 IT 서비스를 구매하여 사용하는 방식입니다.

### 문제 16

**문제:** 제작자의 명령을 받아 분산 서비스 거부 공격(DDos)이나 해킹 수단으로 악용되는 봇(bot) 계열 웜의 하나. 주로 메신저에서 사진 파일로 가장해 전파시킨다

**정답:** 샤봇 (Shabot)

**해설:**
- 봇넷을 구성하는 악성 웜입니다.
- 메신저를 통해 전파되며, 사진 파일로 위장합니다.
- 감염된 컴퓨터를 원격에서 제어하여 DDoS 공격에 활용합니다.

### 문제 17

**문제:** 음성 웹 브라우저 및 음성 이메일용 문자 음성 변환(TTS) 애플리케이션에서 음성 텍스트를 서술하는 생성 코드 및 기호. 확장성 생성 언어(XML)와 표준 범용 문서 생성 언어(SGML)에 기반을 두고 음성 텍스트 생성 언어(STML:Spoken Text Markup Language)와 자바 음성 생성 언어(JSML)를 조합한 것으로, 텍스트의 억양, 음높이, 속도 및 발음 제어 태그를 나타낸 텍스트 태그

**정답:** sable

**해설:**
- 음성 합성(Speech Synthesis)을 위한 마크업 언어입니다.
- XML 기반으로 텍스트의 음성 특성을 제어합니다.
- TTS(Text-To-Speech) 시스템에서 사용됩니다.

### 문제 18

**문제:** 정보를 얻기 위한 장비와 기본 지식 등의 부족으로 정보화 사회에서 요구되는 정보가 부족한 사람들을 지칭하는 말.

**정답:** 정보 거지 (information homeless)

**해설:**
- 디지털 정보 격차를 나타내는 용어입니다.
- 정보 접근 능력이 부족한 사람들을 의미합니다.
- 정보화 사회의 문제점 중 하나입니다.

### 문제 19

**문제:** 컴퓨터의 처리 작업 결과에 의하여 발생하는 오류가 아니라, 컴퓨터에 입력되기 이전의 자료가 잘못되었기 때문에 발생하게 되는 오류

**정답:** 원시 오류 (inherent error)

**해설:**
- 입력 데이터 자체의 오류를 의미합니다.
- GIGO(Garbage In, Garbage Out) 원칙과 관련이 있습니다.
- 데이터 검증이 중요한 이유입니다.

### 문제 20

**문제:** 질의에 대해 가능한 가장 밀접한 정보를 제공하는 인공 지능(AI)을 가미한 데이터베이스

- 전문가 시스템과 유사한 개념입니다.

## 문제 21-40

### 문제 21

**문제:** 스팸 기법의 시험, 스패머 추적, 스팸 차단 솔루션 개발 등의 목적으로 스팸 메일을 수집하기 위하여 생성한 가상의 메일 계정

**정답:** 스팸 함정 (spam trap)

**해설:**
- 스팸 메일을 수집하기 위한 허니팟(honeypot) 기법입니다.
- 실제로 사용하지 않는 가짜 메일 주소를 공개합니다.
- 스팸 발송자를 추적하고 차단하는 데 사용됩니다.

---

### 문제 22

**문제:** 지능망 요소들 간의 상호 작용을 지원하기 위한 응용 계층의 프로토콜 약자를 쓰시오.

**정답:** INAP (Intelligent Network Application Protocol)

**해설:**
- 지능망(Intelligent Network)에서 사용하는 프로토콜입니다.
- 통신망의 지능형 서비스를 제공하기 위한 표준입니다.
- ITU-T에서 표준화한 프로토콜입니다.

---

### 문제 23

**문제:** 갈기 갈기 찢기거나 폐기된 문서 조각들을 스캐닝하여 원래 문서대로 내용을 복원하는 기술

**정답:** 스마트 스캐닝 (smart scanning)

**해설:**
- 파편화된 문서를 디지털로 복원하는 기술입니다.
- 이미지 인식과 패턴 매칭을 활용합니다.
- 문서 관리 시스템에서 사용됩니다.

---

### 문제 24

**문제:** 공격자가 웹 서버와 사용자 브라우저 사이에 끼어들어 오가는 정보를 가로채는 공격 방법으로 일종의 중간자 공격 방법

**정답:** 웹 스푸핑 (web spoofing)

**해설:**
- Man-in-the-Middle(MITM) 공격의 일종입니다.
- 사용자와 서버 사이의 통신을 가로채서 정보를 탈취합니다.
- HTTPS를 사용하여 방어할 수 있습니다.

---

### 문제 25

**문제:** 이용자의 프리젠스 정보를 실시간으로 제공하고 네트워크에 연결되어 있는 이용자간에 간단한 메시지를 신속하게 주고받을 수 있는 통합 서비스 지원 통신 규약.

**정답:** IMPP (Instant Messaging and Presence Protocol)

**해설:**
- 인스턴트 메시징과 프리젠스 정보를 제공하는 프로토콜입니다.
- 사용자의 온라인 상태를 실시간으로 확인할 수 있습니다.
- 채팅 애플리케이션의 기반이 됩니다.

### 문제 26

**문제:** 웹에서 단순히 입력된 검색어가 포함된 검색 정보를 제공하는 방식이 아니라 사용자의 검색 의도까지 파악하여 검색 결과를 제공하는 기술.

**정답:** 맥락 검색 (Contextual Search)

**해설:**
- 의미 기반 검색(semantic search) 기술입니다.
- 사용자의 의도와 맥락을 이해하여 결과를 제공합니다.
- AI와 자연어 처리 기술을 활용합니다.

---

### 문제 27

**문제:** 인터넷으로 대용량의 콘텐츠를 분배 서버에서 복수 제공자의 기간망에 효율적으로 배분하는 기술. 동화상을 포함한 뉴스 등을 인터넷상에서 신속하게 배분해 주기 위해서는 이러한 기술이 필요하다.

**정답:** 멀티피드 (multifeed)

**해설:**

**해설:**
- 여러 서비스를 결합한 새로운 애플리케이션입니다.
- API를 활용한 서비스 통합입니다.
- 웹 2.0의 대표적인 기술입니다.

---

### 문제 85

**문제:** 지나치게 많은 메모리를 요구함으로써 그 효용성이 떨어진 소프트웨어.

**정답:** 블로트웨어 (Bloatware)

**해설:**
- 불필요한 기능이 많아 무거운 소프트웨어입니다.
- 시스템 리소스를 과도하게 사용합니다.
- 사용자 경험을 저하시킵니다.

---

### 문제 86

**문제:** 정상 소프트웨어와 바이러스 소프트웨어의 중간에 해당하는 일종의 악성 소프트웨어. 애드웨어, 스파이웨어, 트랙웨어, 기타 악성 코드나 악성 공유웨어 등을 말한다.

**정답:** 그레이웨어 (grayware, greyware)

**해설:**
- 명확히 악성은 아니지만 문제가 있는 소프트웨어입니다.
- 애드웨어, 스파이웨어 등이 포함됩니다.
- 사용자 동의 없이 설치되는 경우가 많습니다.

---

### 문제 87

**문제:** 조직 내의 신뢰받는 특정인을 대상으로 ID 및 패스워드 정보를 요구하는 일종의 피싱 공격.

**정답:** 스피어 피싱 (spear phishing)

**해설:**
- 특정 대상을 노린 피싱 공격입니다.
- 일반 피싱보다 정교하고 위험합니다.
- 사회 공학적 기법을 활용합니다.

---

### 문제 88

**문제:** 웹 클라이언트인 브라우저와 서버 간의 안전한 통신을 지원하기 위해 HTTP의 전송 계층에 암호 통신 규약을 적용한 웹 표준 기술.

**정답:** HTTPS (Hypertext Transfer Protocol over Secure Sockets Layer)

**해설:**
- HTTP에 SSL/TLS를 적용한 보안 프로토콜입니다.
- 데이터 암호화로 보안을 제공합니다.
- 웹 보안의 기본입니다.

---

### 문제 89

**문제:** 컴퓨터 사용자의 파일들을 암호화하여 금전을 요구하는 악성코드.

**정답:** 랜섬웨어 (ransomware)

**해설:**
- 파일을 암호화하여 몸값을 요구하는 악성코드입니다.
- 최근 가장 위험한 사이버 위협 중 하나입니다.
- 백업이 최선의 방어책입니다.

---

### 문제 90

**문제:** 검색 엔진의 색인 프로그램을 속여 검색 결과 자기의 사이트가 상위권에 들어가도록 하는 행위.

**정답:** 스팸덱싱 (spamdexing)

**해설:**
- 검색 엔진 최적화(SEO)의 악용입니다.
- 부정한 방법으로 검색 순위를 조작합니다.
- 검색 엔진의 품질을 저하시킵니다.

---

### 문제 91

**문제:** 공생하며 함께 사는 물체라는 뜻으로, 컴퓨터 시스템의 성능을 최대한으로 발휘하기 위해 백그라운드 상태로 실행되는 프로그램의 하나

**정답:** 심비온트 (symbiont)

**해설:**
- 백그라운드에서 실행되는 시스템 프로그램입니다.
- 시스템 성능 최적화에 기여합니다.
- 공생 프로그램의 개념입니다.

---

### 문제 92

**문제:** 일상생활에 지장을 느낄 정도로 지나치게 인터넷에 몰두하고, 인터넷에 접속하지 않으면 불안감을 느끼는 등의 인터넷 중독증 또는 의존증.

**정답:** 웨바홀리즘 (Webaholism)

**해설:**
- 인터넷 중독을 의미하는 용어입니다.
- "알코올 중독"(alcoholism)에서 유래했습니다.
- 디지털 시대의 사회 문제입니다.

---

### 문제 93

**문제:** 완전한 TCP 접속을 하지 않고도 통신 포트를 알아내기 위해 사용되는 해커들의 수단. 반개방(half-open) 스캐닝 또는 스텔스(Stealth) 스캐닝이라고도 한다. 서비스 거부(DOS) 공격을 실행하기 위해 사용되는 방법으로 완전한 TCP 연결을 맺지 않고, 대상 포트로 SYN 패킷을 전송하여 포트 상태를 알아낸다.

**정답:** 동기 스캐닝 (SYN scanning)

**해설:**
- SYN 패킷만 보내는 포트 스캔 기법입니다.
- 완전한 연결을 맺지 않아 탐지가 어렵습니다.
- 스텔스 스캐닝의 일종입니다.

---

### 문제 94

**문제:** 위조된 매체 접근 제어(MAC) 주소를 지속적으로 네트워크로 흘려 보내 스위치 저장 기능을 혼란시켜 더미 허브(dummy hub)처럼 작동토록하는 공격

**정답:** 스위치 재밍 공격 (switch jamming attack)

**해설:**
- 스위치의 MAC 테이블을 공격합니다.
- 스위치를 허브처럼 동작하게 만듭니다.
- 네트워크 보안의 취약점입니다.

---

### 문제 95

**문제:** 대량의 데이터가 서로의 변수 간에 어떤 관계가 있는지를 알아 내는 데이터 마이닝 기법의 하나.

**정답:** OLAP 큐브 (Online Analytical Processing Cube)

**해설:**
- 다차원 데이터 분석 도구입니다.
- 데이터 웨어하우스에서 사용됩니다.
- 비즈니스 인텔리전스의 핵심입니다.

---

### 문제 96

**문제:** 가상 랜과 가상 랜 사이에서 포트가 잘못 구성되어 접근이 가능한 포트에 많은 패킷을 보낼 수 있는 네트워크 공격의 하나. 정상적인 경우 서로 다른 가상 랜 간에는 통신을 하지 못하므로 공격자가 스위치를 위장하고, 변조된 ISL(Inter-Switch Link) 또는 802.1Q의 패킷을 스위치로 전송하여 스위치와 트렁크 포트로 연결함으로써 가상 랜과 관계없이 모든 네트워크로 데이터를 보낼 수 있다.

**정답:** 가상 랜 호핑 (virtual local area network hopping, VLAN hopping)

**해설:**
- VLAN 간 격리를 우회하는 공격입니다.
- 네트워크 세그멘테이션을 무력화합니다.
- VLAN 설정을 올바르게 해야 방어됩니다.

---

### 문제 97

**문제:** 월드와이드웹(www)에서 수집된 정보로부터 흥미로운 것이나 잠재적인 유용한 패턴, 프로파일, 추세, 명시적인 정보 등을 추출해서 분석하는 기법.

**정답:** 웹 마이닝 (Web Mining)

**해설:**
- 웹 데이터에서 지식을 추출하는 기술입니다.
- 웹 콘텐츠, 구조, 사용 패턴을 분석합니다.
- 데이터 마이닝의 한 분야입니다.

---

### 문제 98

**문제:** 다른 사람에게서 빌린 프로그램이 트로이 목마와 같은 역할을 하여 빌려준 사람이 파일을 훔치거나 변경함으로써 프로그램에 버그를 가져오는 것.

**정답:** 트로이 목마 (Trojan horse)

**해설:**
- 정상 프로그램으로 위장한 악성코드입니다.
- 사용자가 실행하면 시스템에 침투합니다.
- 바이러스와 달리 자기 복제하지 않습니다.

---

### 문제 99

**문제:** 공격자가 패킷의 출발지 주소(Address)나 포트(port)를 임의로 변경하여 출발지와 목적지의 주소(또는 포트)를 동일하게 함으로써, 공격 대상 컴퓨터의 실행 속도를 느리게 하거나 동작을 마비시켜 서비스 거부 상태에 빠지도록 하는 공격 방법.

**정답:** Land Attack (Local Area Network Denial Attack)

**해설:**
- 출발지와 목적지가 같은 패킷을 보냅니다.
- 시스템이 혼란에 빠져 DoS 상태가 됩니다.
- 네트워크 보안에서 차단해야 할 공격입니다.

---

### 문제 100

**문제:** 해킹한 정보를 온라인에 공개하는 행위

**정답:** 독싱 (doxing)

**해설:**
- 개인정보를 무단으로 공개하는 행위입니다.
- 프라이버시 침해에 해당합니다.
- 사이버 범죄로 처벌받을 수 있습니다.
