# 정보처리기사 실기 예상 문제 모음 - 네트워크/시스템

## 문제 1

**문제:** 인터넷에서 멀티캐스트를 위하여 사용되는 프로토콜

**정답:** IGMP

**해설:**
- IGMP (Internet Group Management Protocol)
- 인터넷 프로토콜 스위트에서 멀티캐스트 그룹 멤버십을 관리하는 통신 프로토콜
- 호스트가 멀티캐스트 그룹에 가입하거나 탈퇴할 때 사용

---

## 문제 2

**문제:** 원격 컴퓨터에 안전하게 액세스하기 위한 유닉스 기반의 명령 인터페이스 및 프로토콜로, 기본적으로 22번 포트를 사용하고, 클라이언트/서버 연결의 양단은 전자 서명을 사용하여 인증되며, 패스워드는 암호화하여 보호되는 것

**정답:** SSH (Secure Shell)

**해설:**
- SSH는 Secure Shell의 약자
- 네트워크 상에서 안전하게 통신하기 위한 암호화 네트워크 프로토콜
- 기본 포트: 22번
- 공개키 암호화 방식 사용
- Telnet의 보안 강화 버전

---

## 문제 3

**문제:** TLS를 통해 Application 계층 데이터를 암호화하여 보호해 주고 기본포트가 443으로 지정된 프로토콜

**정답:** HTTPS

**해설:**
- HTTPS (HyperText Transfer Protocol Secure)
- HTTP에 SSL/TLS 암호화를 추가한 프로토콜
- 기본 포트: 443번
- 웹 브라우저와 서버 간의 통신을 암호화하여 보안 강화

---

## 문제 4

**문제:** 물리적 하드웨어 주소를 IP Address로 매핑시키는 프로토콜

**정답:** RARP (Reverse Address Resolution Protocol)

**해설:**
- RARP는 물리 주소(MAC 주소)를 IP 주소로 변환하는 프로토콜
- ARP의 반대 기능
- 디스크 없는 워크스테이션이 자신의 IP 주소를 알아낼 때 사용

---

## 문제 5

**문제:** UDP 계열 프로토콜로, 원격 관리에 필요한 정보와 서버상태를 관리하는 것

**정답:** SNMP (Simple Network Management Protocol)

**해설:**
- SNMP는 네트워크 장치를 관리하고 모니터링하기 위한 프로토콜
- UDP 포트 161, 162 사용
- 네트워크 장치의 상태, 성능, 설정 등을 관리

---

## 문제 6

**문제:** 동적 라우팅 프로토콜 중에 링크 상태(Link State) 라우팅 프로토콜

**정답:** OSPF (Open Shortest Path First)

**해설:**
- OSPF는 링크 상태 라우팅 프로토콜
- 각 라우터가 네트워크 전체의 토폴로지를 파악
- 다익스트라 알고리즘을 사용하여 최단 경로 계산
- IGP(Interior Gateway Protocol)의 한 종류

---

## 문제 7

**문제:** 연결 없는 IP 기반의 프로토콜로 최소한의 오버헤드를 갖고 재송신 처리를 실행하지 못하기 때문에 신뢰성이 떨어지며 한 번에 많은 양의 데이터를 송신할 때 사용하는 프로토콜

**정답:** UDP (User Datagram Protocol)

**해설:**
- UDP는 비연결형 프로토콜
- 헤더가 작아 오버헤드가 적음
- 흐름 제어, 오류 제어, 재전송 기능 없음
- 실시간 스트리밍, DNS, SNMP 등에 사용

---

## 문제 8

**문제:** RAID 시스템 중 한 드라이브에 기록되는 모든 데이터를 다른 드라이브에 복사해 놓는 방법으로 복구 능력을 제공하며, 'Mirroring'으로 불리는 것

**정답:** RAID 1

**해설:**
- RAID 1은 미러링(Mirroring) 방식
- 데이터를 두 개 이상의 디스크에 동시에 기록
- 하나의 디스크가 고장나도 다른 디스크에서 복구 가능
- 디스크 용량의 50%만 사용 가능 (중복 저장)

---

## 문제 9

**문제:** 내부 통신에는 사설 IP 주소를 사용하고 외부와의 통신에는 공인 IP 주소를 사용할 수 있도록 하는 기술

**정답:** NAT (Network Address Translation)

**해설:**
- NAT는 사설 IP 주소를 공인 IP 주소로 변환하는 기술
- IPv4 주소 부족 문제 해결
- 내부 네트워크를 외부로부터 보호하는 방화벽 역할
- 라우터나 게이트웨이에서 수행

---

## 문제 10

**문제:** 하이퍼바이저를 사용하거나 게스트 운영체제도 설치하지 않고 서버 운영에 필요한 프로그램과 라이브러리만 이미지로 만들어 프로세스처럼 동작시키는 경량화된 가상화 방식이며 실행되는 이미지는 컨테이너라고 부르며, 가상화 레이어가 존재하지 않고 운영체제도 존재하지 않기 때문에 파일 시스템, 네트워크 속도가 상당히 빠르다

**정답:** Docker

**해설:**
- Docker는 컨테이너 기반 가상화 플랫폼
- 하이퍼바이저 없이 호스트 OS의 커널을 공유
- 애플리케이션과 의존성을 컨테이너로 패키징
- 가상머신보다 빠르고 경량화된 가상화 방식

## 문제 11

**문제:** 네트워킹에 필요한 모든 유형의 자원을 추상화하고, 소프트웨어 기반이며 자동으로 관리와 제어가 가능케 하는 가상화 기술

**정답:** NFV (Network Functions Virtualization)

**해설:**
- NFV는 네트워크 기능 가상화 기술
- 네트워크 장비의 기능을 소프트웨어로 구현
- 하드웨어 독립적으로 네트워크 기능 제공
- 클라우드 환경에서 네트워크 서비스 제공

## 문제 12

**문제:** 한 대의 스위치에서 네트워크를 나누어 마치 여러 대의 스위치처럼 사용할 수 있게 하고, 하나의 포트에 여러 개의 네트워크 정보를 전송할 수 있게 해주는 기능

**정답:** 가상 랜(Virtual LAN, VLAN)

**해설:**
- VLAN은 물리적 네트워크를 논리적으로 분할하는 기술
- 하나의 스위치를 여러 개의 논리적 네트워크로 분할
- 브로드캐스트 도메인 분리
- 네트워크 보안 및 관리 효율성 향상

## 문제 13

**문제:** 링크 상태 알고리즘을 적용한 대표적인 프로토콜로, 링크에서의 전송 시간을 링크 비용(거리)으로 사용하며 각 목적지 별 최단 경로를 다익스트라 알고리즘을 통해 알아내는 프로토콜

**정답:** OSPF (Open Shortest Path First)

**해설:**
- OSPF는 링크 상태 라우팅 프로토콜
- 각 라우터가 네트워크 전체의 링크 상태 정보를 유지
- 다익스트라 알고리즘으로 최단 경로 계산
- 대규모 네트워크에 적합

## 문제 14

**문제:** 패킷 전송의 최적 경로를 위해 다른 라우터들로부터 정보를 수집하는데, 최대 홉이 15를 넘지 못하는 프로토콜

**정답:** RIP (Routing Information Protocol)

**해설:**
- RIP는 거리 벡터 라우팅 프로토콜
- 최대 홉 수: 15 (16은 무한대를 의미)
- 30초마다 라우팅 테이블 업데이트
- 소규모 네트워크에 적합

## 문제 15

**문제:** OSI 7 layer 참조 모델에서 사용되는 Protocols 중 TCP와 UDP port를 함께 사용하는 프로토콜

**정답:** DNS (Domain Name System)

**해설:**
- DNS는 도메인 이름을 IP 주소로 변환하는 프로토콜
- TCP 포트 53: 존 전송(Zone Transfer)
- UDP 포트 53: 일반적인 DNS 쿼리
- 계층적 네임 서버 구조 사용

## 문제 16

**문제:** VPN의 터널링 프로토콜로 OSI 7계층 중 3계층 프로토콜로서 전송 모드와 터널 모드 2가지를 사용한다. 전송 모드는 IP 페이로드를 암호화하여 IP 헤더로 캡슐화하지만, 터널 모드는 IP 패킷을 모두 암호화하여 인터넷으로 전송한다

**정답:** IPSec (Internet Protocol Security)

**해설:**
- IPSec은 IP 계층에서의 보안 프로토콜
- 전송 모드: IP 페이로드만 암호화 (호스트 간 통신)
- 터널 모드: 전체 IP 패킷 암호화 (게이트웨이 간 통신)
- VPN 구축에 사용

## 문제 17

**문제:** Link State 알고리즘을 이용해 서로에게 자신의 현재 상태를 알려주며 네트워크 내 통신을 위해 사용하는 프로토콜

**정답:** OSPF (Open Shortest Path First)

**해설:**
- OSPF는 링크 상태 라우팅 프로토콜
- 각 라우터가 자신의 링크 상태를 LSA(Link State Advertisement)로 전파
- 모든 라우터가 동일한 네트워크 맵을 구성
- 최단 경로 계산을 위한 알고리즘 사용

## 문제 18

**문제:** TCP/IP 프로토콜 중에서 IP 계층의 한 부분으로 에러 메시지와 같은 상태 정보를 알려주는 프로토콜

**정답:** ICMP (Internet Control Message Protocol)

**해설:**
- ICMP는 IP 계층에서 오류 메시지와 상태 정보를 전달하는 프로토콜
- ping, traceroute 등에 사용
- IP 패킷 전송 중 오류 발생 시 오류 메시지 전송
- 네트워크 진단 도구로 활용

## 문제 19

**문제:** 단말이 네트워크에 접근하기 전 보안정책 준수여부를 검사하고 IP 및 MAC address의 인가 여부를 검사하여 네트워크 자원의 이용을 허용하는 방식

- 네트워크 접근 전 보안 정책 준수 여부 확인
- IP 주소, MAC 주소 인증
- 보안 소프트웨어 설치 여부 확인
- 비인가 단말의 네트워크 접근 차단

## 문제 20

**문제:** 서로 연결된 네트워크에서 사용자간 파일을 전송할 수 있도록 해주는 기능을 제공하며, 파일 전송시 2개의 포트를 연결하여 데이터를 전송한다. 이 때 20포트는 데이터 전송을 담당하고 21포트는 제어를 담당하는 프로토콜

- 포트 20: 데이터 연결 (Data Connection)
- 클라이언트-서버 모델 사용
- 인증을 통한 안전한 파일 전송

## 문제 21

**문제:** 다음은 잘 알려진 포트번호이다. 해당하는 용어를 쓰시오.

| 포트 | 이름 |
|------|------|
| 21 | ㄱ |
| 22 | ㄴ |
| 23 | ㄷ |
| 25 | ㄹ |
| 53 | ㅁ |
| 80 | ㅂ |
| 110 | ㅅ |
| 143 | ㅇ |
| 194 | ㅈ |
| 443 | ㅊ |

**정답:**

| 포트 | 이름 | 설명 |
|------|------|------|
| 21 | **FTP** | File Transfer Protocol - 파일 전송 프로토콜 (제어 포트) |
| 22 | **SSH** | Secure Shell - 원격 제어, 보안 기능 |
| 23 | **Telnet** | 원격 제어 프로토콜 |
| 25 | **SMTP** | Simple Mail Transfer Protocol - 이메일 전송 |
| 53 | **DNS** | Domain Name System - 도메인 이름 해석 |
| 80 | **HTTP** | HyperText Transfer Protocol - 웹 서비스 |
| 110 | **POP3** | Post Office Protocol 3 - 이메일 수신 |
| 143 | **IMAP** | Internet Message Access Protocol - 이메일 수신, 보관 기능 |
| 194 | **IRC** | Internet Relay Chat - 인터넷 채팅 프로토콜 |
| 443 | **HTTPS** | HTTP Secure - 보안 웹 서비스 |

**해설:**

### 주요 포트 번호 정리

#### 파일 전송 관련
- **포트 21 (FTP)**: 파일 전송 프로토콜의 제어 포트
- **포트 20 (FTP-DATA)**: 파일 전송 프로토콜의 데이터 포트

#### 원격 제어 관련
- **포트 22 (SSH)**: 보안 셸, 암호화된 원격 접속
- **포트 23 (Telnet)**: 텔넷, 암호화되지 않은 원격 접속

#### 이메일 관련
- **포트 25 (SMTP)**: 이메일 전송 프로토콜
- **포트 110 (POP3)**: 이메일 수신 프로토콜 (서버에서 다운로드)
- **포트 143 (IMAP)**: 이메일 수신 프로토콜 (서버에 보관)

#### 웹 관련
- **포트 80 (HTTP)**: 웹 서비스 프로토콜
- **포트 443 (HTTPS)**: 보안 웹 서비스 프로토콜

#### 기타
- **포트 53 (DNS)**: 도메인 이름 시스템
- **포트 194 (IRC)**: 인터넷 릴레이 채팅

## 학습 포인트

### 네트워크 프로토콜 분류

#### 라우팅 프로토콜
- **거리 벡터**: RIP (최대 홉 15)
- **링크 상태**: OSPF (다익스트라 알고리즘)

#### 전송 계층 프로토콜
- **TCP**: 연결형, 신뢰성 보장
- **UDP**: 비연결형, 빠른 전송

#### 보안 프로토콜
- **SSH**: 포트 22, 암호화된 원격 접속
- **HTTPS**: 포트 443, 암호화된 웹 통신
- **IPSec**: VPN 터널링 프로토콜

#### 네트워크 관리 프로토콜
- **SNMP**: 네트워크 장치 관리
- **ICMP**: 오류 메시지 및 상태 정보

### 가상화 기술
- **Docker**: 컨테이너 기반 가상화
- **NFV**: 네트워크 기능 가상화
- **VLAN**: 가상 랜
