.card-grid { display: grid; grid-template-columns: 1fr; gap: 20px; } @media (min-width: 768px) { .card-grid { grid-template-columns: repeat(2, 1fr); } } @media (min-width: 1024px) { .card-grid { grid-template-columns: repeat(3, 1fr); } }

헤더 메뉴 전환

위쪽 MENU 버튼을 눌러보세요. 768px 이상에서는 가로 메뉴로 바뀝니다.

.menu-toggle { display: block; } .nav { display: none; } .nav.open { display: flex; } @media (min-width: 768px) { .menu-toggle { display: none; } .nav { display: flex; flex-direction: row; } }
