16번. 버튼 hover

배경색 변경 + 위로 4px 이동 (0.3s ease)

마우스를 올리면 빨간색으로 바뀌며 위로 뜹니다.

.btn { background: #333; transition: background-color 0.3s ease, transform 0.3s ease; } .btn:hover { background: #e74c3c; transform: translateY(-4px); }

17번. 카드 확대

hover 시 scale(1.05) + 그림자

카드 제목

마우스를 올리면 살짝 커집니다.

.card { transition: transform 0.25s ease, box-shadow 0.25s ease; } .card:hover { transform: scale(1.05); box-shadow: 0 12px 28px rgba(0, 0, 0, 0.15); }
