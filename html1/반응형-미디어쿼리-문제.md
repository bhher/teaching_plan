## A. 객관식 (1~10)

### 1번

반응형 웹에서 모바일 화면에 맞게 표시하려면 HTML에 필요한 태그는?

① `<meta charset="UTF-8">`  
② `<meta name="viewport" content="width=device-width, initial-scale=1.0">`  
③ `<link rel="stylesheet">`  
④ `<meta name="description">`

---

### 2번

모바일 우선(Mobile First) 설계의 올바른 설명은?

① 큰 화면 CSS를 먼저 쓰고, 작은 화면으로 줄여 나간다.  
② 작은 화면 CSS를 먼저 쓰고, `min-width`로 큰 화면에 스타일을 추가한다.  
③ 모든 화면에서 같은 CSS만 사용한다.  
④ 모바일에서는 JavaScript만으로 레이아웃을 바꾼다.

---

### 3번

다음 미디어쿼리의 의미로 옳은 것은?

```css
@media (min-width: 768px) {
  .box { width: 50%; }
}
```

① 화면 너비가 768px **이하**일 때만 적용  
② 화면 너비가 768px **이상**일 때 적용  
③ 화면 높이가 768px일 때만 적용  
④ 모든 화면에서 항상 적용

---

### 4번

`max-width: 767px` 미디어쿼리의 의미는?

① 767px **이상**에서 적용  
② 767px **이하**에서 적용  
③ 정확히 767px에서만 적용  
④ 적용되지 않는다

---

### 5번

`box-sizing: border-box`를 쓰는 이유로 가장 적절한 것은?

① 글자 색을 바꾼다  
② padding과 border를 너비(width) 안에 포함시켜 크기 계산을 쉽게 한다  
③ Flex를 자동으로 만든다  
④ 이미지를 확대한다

---

### 6번

CSS Grid에서 카드 **3열**을 만드는 코드는?

① `grid-template-columns: 3;`  
② `grid-template-columns: repeat(3, 1fr);`  
③ `display: flex-3;`  
④ `columns: 3fr;`

---

### 7번

`min-width` 미디어쿼리에 대한 설명으로 **틀린** 것은?

① 지정한 너비 **이상**에서 적용된다  
② 모바일 우선 방식과 잘 맞는다  
③ 480px 규칙이 있으면 768px에서도 계속 적용될 수 있다  
④ 지정한 너비 **미만**에서만 적용된다

---

### 8번

모바일 우선 카드 레이아웃의 자연스러운 순서는?

① 3열 → 2열 → 1열  
② 1열 → 2열 → 3열  
③ 항상 3열 고정  
④ Grid는 반응형에 사용할 수 없다

---

### 9번

다음 코드에서 768px 화면일 때 `.card`의 열 수는?

```css
.card-grid { grid-template-columns: 1fr; }

@media (min-width: 480px) {
  .card-grid { grid-template-columns: repeat(2, 1fr); }
}

@media (min-width: 1024px) {
  .card-grid { grid-template-columns: repeat(3, 1fr); }
}
```

① 1열  
② 2열  
③ 3열  
④ 4열

---

### 10번

햄버거 메뉴(모바일)에서 메뉴를 보이게 하는 일반적인 방법은?

① `nav`에 `active` 클래스를 토글하고, CSS에서 `nav.active { display: flex; }`  
② `header` 배경색만 바꾼다  
③ `viewport`를 삭제한다  
④ `float: left`만 사용한다

## C. 코드 작성 (16~18)

### 16번. 모바일 우선 카드 그리드

요구사항:

- 기본(모바일): 1열
- 768px 이상: 2열
- 1024px 이상: 3열
- `gap: 20px`

`.card-grid` CSS를 작성하세요.

---

### 17번. 헤더 메뉴 전환

요구사항:

- 모바일: `.menu-toggle` 보임, `.nav` 숨김
- 768px 이상: `.menu-toggle` 숨김, `.nav` 가로 표시

CSS를 작성하세요.

---

### 18번. 사이드바 레이아웃

요구사항:

- 모바일: 세로 (`flex-direction: column`)
- 768px 이상: 가로, 사이드바 `250px` 고정, 본문 `flex: 1`

`.content-layout`, `.sidebar`, `.main` CSS를 작성하세요.

## D. OX 문제 (19~22)

### 19번

`min-width: 768px`는 768px **이상**에서 적용된다. (O / X)

---

### 20번

viewport 메타 태그 없이도 모바일에서 레이아웃이 항상 정상이다. (O / X)

---

### 21번

`min-width: 480px`에서 2열을 지정하면, 768px에서도 별도 선언 없이 2열이 유지될 수 있다. (O / X)

---

### 22번

`box-sizing: content-box`(기본값)에서는 padding이 너비 밖으로 더해져 `%` 레이아웃이 깨질 수 있다. (O / X)
