## A. 객관식 정답

| 문제 | 정답 | 해설 |
|------|------|------|
| 1 | ② | `viewport` 메타 태그가 있어야 모바일에 맞게 표시 |
| 2 | ② | 모바일 우선 = 작은 화면 기본 + `min-width`로 확장 |
| 3 | ② | `min-width` = **이상**에서 적용 |
| 4 | ② | `max-width` = **이하**에서 적용 |
| 5 | ② | `border-box`는 padding/border를 width 안에 포함 |
| 6 | ② | `repeat(3, 1fr)` = 같은 비율 3열 |
| 7 | ④ | ④가 틀림. 미만만 적용은 `max-width` |
| 8 | ② | 1열 → 2열 → 3열로 확장 |
| 9 | ② | 480~1023px은 2열, 768은 그 구간 |
| 10 | ① | `active` 클래스 토글이 일반적 |

## B. 빈칸 정답

### 12번

## C. 코드 작성 정답

### 16번. 카드 그리드

```css
.card-grid {
  display: grid;
  grid-template-columns: 1fr; /* 모바일 1열 */
  gap: 20px;
}

@media (min-width: 768px) {
  .card-grid {
    grid-template-columns: repeat(2, 1fr); /* 2열 */
  }
}

@media (min-width: 1024px) {
  .card-grid {
    grid-template-columns: repeat(3, 1fr); /* 3열 */
  }
}
```

### 17번. 헤더 메뉴

```css
.menu-toggle {
  display: block;
}

.nav {
  display: none;
}

.nav.open {
  display: flex;
  flex-direction: column;
}

@media (min-width: 768px) {
  .menu-toggle {
    display: none;
  }

  .nav {
    display: flex;
    flex-direction: row;
    gap: 16px;
  }
}
```

### 18번. 사이드바 레이아웃

```css
.content-layout {
  display: flex;
  flex-direction: column;
  gap: 20px;
}

@media (min-width: 768px) {
  .content-layout {
    flex-direction: row;
  }

  .sidebar {
    flex: 0 0 250px;
  }

  .main {
    flex: 1;
  }
}
```

## D. OX 정답

| 문제 | 정답 | 해설 |
|------|------|------|
| 19 | **O** | `min-width` = 이상 |
| 20 | **X** | viewport 없으면 모바일에서 축소/깨짐 발생 |
| 21 | **O** | `min-width`는 누적 적용 |
| 22 | **O** | `content-box`는 padding이 너비 밖 → 넘침 가능 |

## 브레이크포인트 정리

| 구간 | 예시 | 흔한 레이아웃 |
|------|------|----------------|
| ~767px | 모바일 | 1열, 햄버거 메뉴 |
| 768px~ | 태블릿 | 2열, 가로 메뉴 |
| 1024px~ | 데스크톱 | 3열, 사이드바 옆 |

## min-width vs max-width

```css
/* 모바일 우선 (권장) */
@media (min-width: 768px) { }   /* 768 이상 */

/* 데스크톱 우선 */
@media (max-width: 767px) { }   /* 767 이하 */
```
