# 챕터 5. 실무 팁

**대상:** 비전공 초보  
**이 챕터 목표:** “회사에서 첫날 들을 법한” 설정·습관을 미리 알기

---

## 1. 개념 설명

### 1-1. 왜 “실무 팁”이 따로 있나?

학습용 코드는 **동작**이 목표입니다. 실무는 **동작 + 유지보수 + 보안 + 협업**이 목표입니다.  
여기서는 **바로 적용 가능한 것**만 골랐습니다.

---

## 2. 설정 — `application.properties` / `application.yml`

### 2-1. 포트 바꾸기

```properties
server.port=8081
```

**왜?**  
→ 로컬에서 다른 서버와 **포트 충돌**이 날 때 (8080이 이미 사용 중 등)

### 2-2. 로그 레벨 (개발 중에만)

```properties
logging.level.com.example.demo=DEBUG
```

**왜?**  
→ **내 패키지**만 자세히 찍어서, 문제 찾기 쉽게 함. (운영에서는 보통 INFO 이상)

---

## 3. 프로파일 — local / prod 나누기 (개념)

**비유:** 집 열쇠(로컬 DB)와 회사 열쇠(운영 DB)를 **같은 코드**에서 바꿔 끼우기.

```
application.properties          ← 공통
application-local.properties   ← 내 PC
application-prod.properties    ← 서버
```

실행 시:

```properties
spring.profiles.active=local
```

**왜?**  
→ **운영 DB 주소**를 실수로 로컬에 넣어 **커밋**하는 사고를 줄입니다.

---

## 4. 코드 습관

### 4-1. 컨트롤러는 “얇게”

- **입력 검증·복잡한 계산**은 **Service** 클래스로 빼기 (팀 규칙)  
- 컨트롤러는 **HTTP ↔ DTO 변환**과 **응답 코드** 정도만

**왜?**  
→ 로직이 길어지면 **테스트·재사용**이 어렵습니다.

### 4-2. 비밀번호·키는 코드에 하드코딩하지 않기

**나쁜 예:** `String apiKey = "sk-xxx";` 를 GitHub에 올림  

**좋은 방향:** 환경 변수, 설정 서버, **시크릿 관리** (팀 도구)

**왜?**  
→ 유출 시 **서비스 전체**가 위험해집니다.

## 5. 빌드와 실행

### 5-1. Maven으로 JAR 만들기 (IntelliJ)

- Maven 탭 → **Lifecycle → package** 더블클릭  
- 또는 터미널: `mvnw -DskipTests package` (Windows)  

**결과:** `target/` 아래 `xxx-0.0.1-SNAPSHOT.jar`

**왜 JAR?**  
→ **서버에 파일 하나** 올리고 `java -jar ...` 로 실행하는 방식이 **가장 흔함** (클라우드 포함)

## 6. 에러 응답 (입문)

전역 예외 처리는 나중에 배우고, **컨트롤러에서** 먼저 맛을 볼 수 있습니다.

```java
import org.springframework.http.HttpStatus;
import org.springframework.web.bind.annotation.*;
import org.springframework.web.server.ResponseStatusException;

@RestController
public class UserController {

    @GetMapping("/api/users/{id}")
    public String getUser(@PathVariable Long id) {
        if (id < 1) {
            throw new ResponseStatusException(HttpStatus.BAD_REQUEST, "id는 1 이상");
        }
        return "ok";
    }
}
```

**왜 `ResponseStatusException`?**  
→ **HTTP 상태 코드**와 **메시지**를 한 번에 맞출 수 있습니다.
