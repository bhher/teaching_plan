# Spring Boot 교안 — 주제 템플릿

같은 구성(개념 → 구조 → 코드 → 실행 흐름 → 실무 팁 → 실습)으로 가르칠 때, **아래 `[주제]`만 바꿔서** 챕터 제목·예제 시나리오를 맞추면 됩니다.

---

## 쓰는 방법

1. 이번 시간에 다룰 **기능 이름**을 고른다.
2. 표에서 **한 줄**을 복사해 `[주제]` 자리에 넣는다.
3. 예제 코드·실습 문제는 그 주제에 맞게 **도메인 이름만** 바꾼다.  
   (예: `User` → `Post`, `join` → `login`)

---

## 주제 예시 (여기만 바꿔서 계속 쓰면 됨)

| 기능 | `[주제]` 한 줄 예시 |
|------|---------------------|
| 회원가입 | Spring Boot 회원가입 (Controller + Service + Repository + JPA) |
| 로그인 | Spring Boot 로그인 처리 (세션 기반 인증) |
| 게시판 CRUD | Spring Boot 게시판 CRUD (JPA + Thymeleaf) |
| 파일 업로드 | Spring Boot 파일 업로드 (Multipart + 로컬 저장) |
| 댓글 | Spring Boot 댓글 API (게시글과 연관 관계, JPA) |
| 페이징 목록 | Spring Boot 게시글 목록 (Pageable + QueryDSL 또는 JPA) |
| JWT | Spring Boot JWT 인증 (Stateless API) |
| OAuth2 소셜 로그인 | Spring Boot OAuth2 클라이언트 (소셜 로그인) |

---

## 챕터 제목에 붙이기 (복사용)

```text
[주제] Spring Boot 회원가입 (Controller + Service + Repository + JPA)
[주제] Spring Boot 로그인 처리 (세션 기반 인증)
[주제] Spring Boot 게시판 CRUD (JPA + Thymeleaf)
```

→ 강의 자료 표지·MD 첫머리·노션 제목에 그대로 사용 가능.
