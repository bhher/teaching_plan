## 선행 지식

- **Java 문법** (클래스, 메서드, `public` 정도)
- **HTTP**가 “요청/응답”이라는 것만 알면 됩니다. (챕터에서 다시 설명합니다.)

## 추천 실습 환경

- **JDK 17 이상** (LTS)
- **IntelliJ IDEA** + **Spring Initializr**로 프로젝트 생성 (챕터 2 참고)
