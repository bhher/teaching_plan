# Part A. 객관식 · 단답

### 1번
서브쿼리의 설명으로 가장 적절한 것은?

① 테이블을 삭제하는 명령  
② **쿼리 안에 포함된 또 다른 SELECT**  
③ 인덱스를 만드는 명령  
④ JOIN의 다른 이름만

### 2번
`WHERE 마일리지 = (SELECT MAX(마일리지) FROM 고객)` 에서  
`=` 오른쪽 서브쿼리가 지켜야 할 조건은?

① 여러 행·여러 열  
② **단일 행 · 단일 열 (값 1개)**  
③ FROM만 있으면 됨  
④ ORDER BY 필수

### 3번
`> ANY (부산 마일리지)` 와 **결과가 같은** 것은?

① `> ALL (부산 마일리지)`  
② `> MAX(부산 마일리지)`  
③ **`> MIN(부산 마일리지)`**  
④ `= AVG(부산 마일리지)`

### 4번
`> ALL (집합)` 과 **결과가 같은** 것은?

① `> MIN(집합)`  
② **`> MAX(집합)`**  
③ `IN (집합)`  
④ `EXISTS`

### 5번
다음 중 **다중 행** 서브쿼리에 쓰는 연산자가 **아닌** 것은?

① `IN`  ② `ANY`  ③ `ALL`  ④ **`=` (단독, 여러 행 반환 시)**

### 6번
`EXISTS`의 역할로 적절한 것은?

① 평균을 구한다  
② **안쪽 SELECT 결과가 1행이라도 있으면 참**  
③ 테이블을 조인만 한다  
④ NULL만 찾는다

### 7번
그룹(집계) **이후**에 서브쿼리 조건으로 거를 때 쓰는 절은?

① WHERE  ② **HAVING**  ③ FROM  ④ LIMIT

### 8번 (단답)
예제 6-2처럼 “주문번호로 고객을 찾는” 작업을  
서브쿼리 대신 같은 결과로 쓰려면 어떤 문법을 쓸 수 있는가? (한 단어)

### 9번 (단답)
`> ANY` ⇔ `> ?` , `> ALL` ⇔ `> ?`  
빈칸에 들어갈 집계함수를 순서대로 쓰시오.

### 10번
확인문제: 동일 결과 쌍 **2개**를 고르시오.

- (A) `마일리지 > ANY (부산 마일리지)`
- (B) `마일리지 > ALL (부산 마일리지)`
- (C) `마일리지 > (SELECT MAX(마일리지) … 부산)`
- (D) `마일리지 > (SELECT MIN(마일리지) … 부산)`

① (A)-(D), (B)-(C)  
② (A)-(C), (B)-(D)  
③ (A)-(B), (C)-(D)  
④ (A)-(C) 만

# Part B. SQL 작성 (예제 변형)

### 11번
마일리지가 **가장 적은** 고객의  
`고객번호`, `고객회사명`, `담당자명`, `마일리지`를 조회하시오.  
(예제 6-1 변형: MAX → MIN)

### 12번
주문번호 **`H0250`** 을 주문한 고객의  
`고객회사명`, `담당자명`을 **서브쿼리**로 조회하시오. (예제 6-2)

### 13번
12번과 **같은 결과**를 `INNER JOIN`으로 작성하시오.

### 14번
도시가 **'서울특별시'** 인 고객들의 마일리지 중  
**최솟값보다 큰** 고객의 `담당자명`, `고객회사명`, `마일리지`를 조회하시오.  
(예제 6-3 변형: 부산 → 서울)

### 15번
도시가 **'부산광역시'** 인 고객이 한 주문의 **건수**를  
`IN` 서브쿼리로 구하시오. (`주문건수` 별칭) (예제 6-4)

### 16번
`> ANY`를 사용해, 부산 고객 마일리지 중  
**하나라도 작은 값보다 큰**(즉 MIN보다 큰) 고객을 조회하시오.  
(`담당자명`, `고객회사명`, `마일리지`) (예제 6-5)

### 17번
`> ALL`과 `GROUP BY 지역`의 `AVG(마일리지)`를 사용해  
지역별 평균 **모두보다 마일리지가 큰** 고객을 조회하시오. (예제 6-6)

### 18번
`EXISTS`로 **주문이 한 건이라도 있는** 고객의  
`고객번호`, `고객회사명`을 조회하시오. (예제 6-7)

### 19번
18번과 같은 의미를 `IN` + `DISTINCT`로 작성하시오.

### 20번
도시별 `AVG(마일리지)`가 **전체 고객 평균 마일리지보다 큰** 도시만  
`도시`, `평균마일리지`로 조회하시오. (예제 6-8)

### 21번 (심화)
주문이 **한 번도 없는** 고객의 `고객번호`, `고객회사명`을  
`NOT EXISTS`로 조회하시오.

### 22번 (심화)
16번의 `> ANY`를 **`> MIN` 서브쿼리**로 바꿔 같은 의미의 SQL을 쓰시오.
