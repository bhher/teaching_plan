# MySQL Ch06 서브쿼리 정리

> **서브쿼리(Subquery)** = 쿼리 안에 들어 있는 또 다른 SELECT  
> Ch06 예제 6-1 ~ 6-8 (한빛무역 `고객` · `주문`) 기준

**문제:** [MySQL-Ch06-서브쿼리-문제.md](./MySQL-Ch06-서브쿼리-문제.md)  
**정답:** [MySQL-Ch06-서브쿼리-정답.md](./MySQL-Ch06-서브쿼리-정답.md)

한빛무역 DB가 있으면:

```sql
USE 한빛무역;   -- 실제 DB 이름에 맞게
```

---

## 1. 서브쿼리란?

```text
메인 쿼리
   └── WHERE / HAVING / FROM 안에
          └── ( SELECT … )  ← 서브쿼리
```

| 종류 | 특징 | 예 |
|------|------|-----|
| 단일 행 | 값이 **1개** | `= (SELECT MAX(...))` |
| 다중 행 | 값이 **여러 개** | `IN`, `ANY`, `ALL`, `EXISTS` |
| 상관 | 바깥 행을 **참조** | `EXISTS (… WHERE 주문.고객번호 = 고객.고객번호)` |

---

## 2. 예제 6-1 — 단일 행 (`=` + 집계)

마일리지가 **가장 많은** 고객

```sql
SELECT 고객번호, 고객회사명, 담당자명, 마일리지
FROM 고객
WHERE 마일리지 = (
    SELECT MAX(마일리지)
    FROM 고객
);
```

```text
서브쿼리: 전체 중 MAX(마일리지) → 숫자 1개
메인: 그 숫자와 같은 고객 행 조회
```

> `=` 오른쪽 서브쿼리는 **반드시 1행 1열**이어야 합니다.

---

## 3. 예제 6-2 — 서브쿼리 vs JOIN

주문번호 `H0250` 을 한 고객의 회사명·담당자명

### 방법 1) 서브쿼리

```sql
SELECT 고객회사명, 담당자명
FROM 고객
WHERE 고객번호 = (
    SELECT 고객번호
    FROM 주문
    WHERE 주문번호 = 'H0250'
);
```

### 방법 2) INNER JOIN (같은 결과)

```sql
SELECT 고객회사명, 담당자명
FROM 고객
INNER JOIN 주문
  ON 고객.고객번호 = 주문.고객번호
WHERE 주문번호 = 'H0250';
```

| 방식 | 특징 |
|------|------|
| 서브쿼리 | “먼저 고객번호를 구한 뒤” 고객 조회 |
| JOIN | 두 테이블을 **연결**해서 한 번에 조회 |

## 4. 예제 6-3 — `>` + `MIN`

부산 고객 중 **가장 작은 마일리지**보다 큰 고객

```sql
SELECT 담당자명, 고객회사명, 마일리지
FROM 고객
WHERE 마일리지 > (
    SELECT MIN(마일리지)
    FROM 고객
    WHERE 도시 = '부산광역시'
);
```

---

## 5. 예제 6-4 — `IN` (다중 행)

부산에 있는 고객들의 **주문 건수**

```sql
SELECT COUNT(*) AS 주문건수
FROM 주문
WHERE 고객번호 IN (
    SELECT 고객번호
    FROM 고객
    WHERE 도시 = '부산광역시'
);
```

```text
IN (값1, 값2, 값3, …)
  → 목록 중 하나와 같으면 참
```

---

## 6. 예제 6-5 — `> ANY` ⇔ `> MIN`

```sql
SELECT 담당자명, 고객회사명, 마일리지
FROM 고객
WHERE 마일리지 > ANY (
    SELECT 마일리지
    FROM 고객
    WHERE 도시 = '부산광역시'
);
```

| 연산자 | 의미 | 같은 표현 |
|--------|------|-----------|
| `> ANY` | 집합 중 **하나라도** 작으면(나보다 작은 값이 있으면) | `> MIN` |
| `> ALL` | 집합 **전부**보다 큼 | `> MAX` |

> 확인문제: `(A) > ANY` = `(D) > MIN`, `(B) > ALL` = `(C) > MAX`

예제 6-5는 사실상 예제 6-3과 **같은 조건**입니다. (`> ANY` 부산 = `> MIN` 부산)

---

## 7. 예제 6-6 — `> ALL` + 그룹 평균

**지역별 평균 마일리지**보다 모두 큰(즉, 지역 평균들 중 **최댓값**보다 큰) 고객

```sql
SELECT 담당자명, 고객회사명, 마일리지
FROM 고객
WHERE 마일리지 > ALL (
    SELECT AVG(마일리지)
    FROM 고객
    GROUP BY 지역
);
```

```text
지역별 AVG → 여러 값
> ALL → 그 모든 평균보다 큼
     ⇔ 지역 평균들 중 MAX보다 큼
```

## 8. 예제 6-7 — `EXISTS` / `IN` / JOIN

**한 번이라도 주문한** 고객

### ① EXISTS (상관 서브쿼리)

```sql
SELECT 고객번호, 고객회사명
FROM 고객
WHERE EXISTS (
    SELECT *
    FROM 주문
    WHERE 주문.고객번호 = 고객.고객번호
);
```

바깥 `고객` 한 행마다 안쪽을 검사합니다.  
주문이 **1건이라도 있으면** EXISTS = 참.

### ② IN

```sql
SELECT 고객번호, 고객회사명
FROM 고객
WHERE 고객번호 IN (
    SELECT DISTINCT 고객번호
    FROM 주문
);
```

### ③ JOIN

```sql
SELECT DISTINCT 고객.고객번호, 고객회사명
FROM 고객
INNER JOIN 주문
  ON 고객.고객번호 = 주문.고객번호;
```

세 방법 모두 **“주문 이력이 있는 고객”** 을 구합니다.

| 방식 | 포인트 |
|------|--------|
| `EXISTS` | 존재 여부만 보면 됨 (상관) |
| `IN` | 주문 고객번호 목록에 포함? |
| `JOIN` | 연결 후 `DISTINCT`로 중복 제거 |

## 9. 예제 6-8 — HAVING + 서브쿼리

도시별 평균 마일리지가 **전체 평균보다 큰** 도시

```sql
SELECT 도시
      ,AVG(마일리지) AS 평균마일리지
FROM 고객
GROUP BY 도시
HAVING AVG(마일리지) > (
    SELECT AVG(마일리지)
    FROM 고객
);
```

```text
WHERE  → 행을 거른 뒤 그룹
HAVING → 그룹(집계) 결과에 조건
```

전체 평균은 서브쿼리로 한 번 구하고,  
도시별 `AVG`와 비교합니다.

## 10. 연산자 한눈에 보기

| 상황 | 연산자 |
|------|--------|
| 단일 값과 같다 | `=` `(SELECT …)` |
| 목록에 있다 | `IN (SELECT …)` |
| 하나라도 만족 | `ANY` / `SOME` |
| 모두 만족 | `ALL` |
| 행이 존재하는가 | `EXISTS` |
| 그룹 후 조건 | `HAVING` + 서브쿼리 |

### 꼭 외울 등가

```text
컬럼 > ANY (집합)  ⇔  컬럼 > MIN(집합)
컬럼 > ALL (집합)  ⇔  컬럼 > MAX(집합)
```

## 11. 실행 순서 (개념)

```text
1) 서브쿼리 실행 (상관이면 바깥 행마다 반복)
2) 그 결과로 메인 WHERE / HAVING 판단
3) 메인 SELECT 결과 반환
```
