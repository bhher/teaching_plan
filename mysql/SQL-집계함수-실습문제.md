# SQL 집계함수 실습 문제

## 테이블 생성 및 더미 데이터

### 데이터베이스 생성

```sql
CREATE DATABASE school_db 
CHARACTER SET utf8mb4 
COLLATE utf8mb4_unicode_ci;

USE school_db;
```

### 테이블 생성

```sql
CREATE TABLE student (
    student_id INT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(50) NOT NULL,
    department VARCHAR(50),
    grade INT,
    korean INT,
    english INT,
    math INT,
    science INT,
    total_score INT,
    average DECIMAL(5,2)
) CHARACTER SET utf8mb4 
  COLLATE utf8mb4_unicode_ci;
```

**테이블 구조 설명:**
- `student_id`: 학생 번호 (자동 증가, 기본키)
- `name`: 학생 이름
- `department`: 학과
- `grade`: 학년
- `korean`: 국어 점수
- `english`: 영어 점수
- `math`: 수학 점수
- `science`: 과학 점수
- `total_score`: 총점
- `average`: 평균

## 집계함수 정리

### 주요 집계함수

| 함수 | 설명 | 예시 |
|------|------|------|
| `COUNT()` | 개수 | `COUNT(*)` |
| `SUM()` | 합계 | `SUM(score)` |
| `AVG()` | 평균 | `AVG(score)` |
| `MAX()` | 최대값 | `MAX(score)` |
| `MIN()` | 최소값 | `MIN(score)` |

### GROUP BY와 HAVING

- **GROUP BY**: 그룹화
- **HAVING**: 그룹화된 결과에 조건 적용 (WHERE는 그룹화 전 조건)

---

## 참고사항

- 집계함수는 NULL 값을 제외하고 계산합니다
- GROUP BY를 사용하면 그룹별로 집계합니다
- HAVING은 GROUP BY와 함께 사용합니다
- 집계함수와 일반 컬럼을 함께 사용할 때는 GROUP BY가 필요합니다
