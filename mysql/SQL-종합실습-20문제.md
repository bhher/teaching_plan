## 문제 2: 테이블 생성 - 직원 테이블 (10점)

다음 조건에 맞는 `employee` 테이블을 생성하시오.

**조건:**
- `emp_id`: 정수형, 기본키, 자동증가
- `emp_no`: 문자형(20자), 고유값, NULL 불가
- `name`: 문자형(50자), NULL 불가
- `department`: 문자형(50자)
- `position`: 문자형(30자)
- `salary`: 정수형
- `hire_date`: 날짜형

---

## 문제 3: 테이블 생성 - 프로젝트 테이블 (10점)

다음 조건에 맞는 `project` 테이블을 생성하시오.

**조건:**
- `project_id`: 정수형, 기본키, 자동증가
- `project_name`: 문자형(100자), NULL 불가
- `emp_no`: 문자형(20자) - employee 테이블의 emp_no 참조
- `start_date`: 날짜형
- `end_date`: 날짜형
- `status`: 문자형(20자), 기본값 '진행중'

## 참고: 테이블 구조

### employee 테이블
- emp_id (PK, AUTO_INCREMENT)
- emp_no (UNIQUE, NOT NULL)
- name (NOT NULL)
- department
- position
- salary
- hire_date

### project 테이블
- project_id (PK, AUTO_INCREMENT)
- project_name (NOT NULL)
- emp_no (FK → employee.emp_no)
- start_date
- end_date
- status (DEFAULT '진행중')
