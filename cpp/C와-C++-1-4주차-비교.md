# C vs C++ 비교 (1~4주차 교안 기준)

C언어 교안 1~4주차와 C++ 교안 1~4주차를 **나란히 비교**한 문서입니다.  
C를 배운 뒤 C++로 넘어올 때, **무엇이 같고 무엇이 다른지** 한눈에 보는 용도로 쓰세요.

## 한 줄 요약

| | C | C++ |
|--|---|-----|
| 정체 | 절차지향 언어 | C를 확장한 **절차 + 객체지향** 언어 |
| 1~4주차 핵심 | `printf` / `scanf`, `%d`, `char[]` | `cout` / `cin`, `string`, `bool` |
| 관계 | 기초 | C 문법 대부분 가능 + 편의 기능 추가 |

```
C로 배운 것 (변수, 연산자, if, for…)
        ↓
C++에서도 대부분 그대로 사용 가능
        ↓
추가로 cout/cin, string, bool, class…
```

| 주차 | C 교안 | C++ 교안 | 비교 포인트 |
|------|--------|----------|-------------|
| 1 | 개요 · 개발환경 · Hello World | 개요 · 개발환경 · Hello World | 헤더, 출력, 컴파일러 |
| 2 | 변수 · 자료형 · 서식 지정자 | 변수 · 자료형 · cout 서식 | `%d` vs `<<`, `string`/`bool` |

## 1주차 비교 — 개요 & Hello World

### 언어 특징

| 항목 | C | C++ |
|------|---|-----|
| 개발 | 1972, 데니스 리치 | 1980년대, 비야네 스트로스트루프 |
| 패러다임 | **절차지향** | 절차 + **객체지향** |
| 파일 확장자 | `.c` | `.cpp`, `.cc` |
| 컴파일러 | `gcc` | `g++` (또는 MSVC) |
| 실행 결과 | `.exe` (네이티브) | `.exe` (네이티브) |

### Hello World 코드 비교

**C**

```c
#include <stdio.h>

int main() {
    printf("Hello C\n");
    return 0;
}
```

```bash
gcc hello.c -o hello.exe
```

**C++**

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello C++" << endl;
    return 0;
}
```

```bash
g++ hello.cpp -o hello.exe
```

### 1주차 핵심 차이

| 항목 | C | C++ |
|------|---|-----|
| 헤더 | `#include <stdio.h>` | `#include <iostream>` |
| 출력 | `printf("...\n")` | `cout << "..." << endl;` |
| 네임스페이스 | 없음 | `using namespace std;` (수업용) |
| 줄바꿈 | `\n` | `endl` 또는 `\n` |

> C++에서도 `printf`를 쓸 수 있지만, **수업에서는 `cout` 중심**으로 통일합니다.

## 2주차 비교 — 변수와 자료형

### 공통 (거의 동일)

| 자료형 | C | C++ |
|--------|---|-----|
| `int`, `long`, `short`, `char` | ✅ | ✅ |
| `float`, `double` | ✅ | ✅ |
| `signed` / `unsigned` | ✅ | ✅ |

### C++에서 추가·편해진 것

| 타입 | C | C++ |
|------|---|-----|
| 논리값 | `int`로 0/1 표현 | **`bool`** (`true` / `false`) |
| 문자열 | **`char[]`** + `%s` | **`string`** (`#include <string>`) |
| 타입 추론 | 없음 | **`auto`** (C++11, 선택) |

### 출력 방식 비교

**C — 서식 지정자 필수**

```c
int age = 20;
double height = 170.5;
char name[] = "김철수";

printf("나이: %d\n", age);
printf("키: %.1f\n", height);
printf("이름: %s\n", name);
```

| 서식 | 의미 |
|------|------|
| `%d` | int |
| `%f` / `%lf` | float / double |
| `%c` | char |
| `%s` | 문자열(char 배열) |
| `%.2f` | 소수점 2자리 |

**C++ — 타입에 맞게 자동**

```cpp
int age = 20;
double height = 170.5;
string name = "김철수";
bool isStudent = true;

cout << "나이: " << age << endl;
cout << "키: " << height << endl;
cout << "이름: " << name << endl;
cout << "재학: " << isStudent << endl;  // 1
```

실수 자릿수:

```cpp
#include <iomanip>
cout << fixed << setprecision(2) << pi;  // 3.14
```

### 2주차 한눈에

| 항목 | C | C++ |
|------|---|-----|
| 출력 | `printf("%d", x)` | `cout << x` |
| 소수점 | `%.2f` | `fixed` + `setprecision(2)` |
| 문자열 | `char name[20]` | `string name` |
| 참/거짓 | `1` / `0` (int) | `bool` + `true`/`false` |

## 3주차 비교 — 입력 & 출력

### 기본 입력

**C — `scanf` + `&` 필수**

```c
int num;
printf("정수: ");
scanf("%d", &num);   // & 필수!
```

**C++ — `cin` (주소 연산자 없음)**

```cpp
int num;
cout << "정수: ";
cin >> num;          // & 없음
```

### 입력 비교표

| 항목 | C (`scanf`) | C++ (`cin`) |
|------|-------------|-------------|
| 정수 | `scanf("%d", &n);` | `cin >> n;` |
| 실수 | `scanf("%lf", &d);` | `cin >> d;` |
| 문자 | `scanf(" %c", &ch);` | `cin >> ch;` |
| 문자열 | `scanf("%s", name);` (`char[]`) | `cin >> name;` (`string`, **공백 전**) |
| 주소 `&` | **대부분 필수** | **불필요** |
| 서식 지정자 | `%d` 등 **직접** | **자동** |

### 공백 포함 문자열

| | C | C++ |
|--|---|-----|
| 방법 | `fgets(buf, size, stdin)` 등 | **`getline(cin, name)`** |
| 예 | 버퍼 처리 주의 | `cin >> age` 후 `cin.ignore()` 후 `getline` |

**C++ 예제**

```cpp
int age;
string name;
cin >> age;
cin.ignore();              // 남은 \n 제거
getline(cin, name);        // 공백 포함 한 줄
```

### 입력 버퍼

| | C | C++ |
|--|---|-----|
| 문제 | `\n`이 버퍼에 남음 | 동일 |
| 해결 예 | `while(getchar() != '\n');` / `scanf(" %c", …)` | `cin.ignore()` |

### 3주차 한눈에

```
C:    scanf("%d", &num);     ← 서식 + &
C++:  cin >> num;            ← 간단, 타입 자동
C++:  getline(cin, name);    ← 공백 포함 문자열 (강점)
```

## 4주차 비교 — 연산자

### 거의 동일 (C = C++)

| 종류 | 연산자 | 비고 |
|------|--------|------|
| 산술 | `+` `-` `*` `/` `%` | 정수 `/` → 소수 버림 |
| 대입 | `=` `+=` `-=` `*=` `/=` `%=` | 동일 |
| 비교 | `==` `!=` `<` `>` `<=` `>=` | 동일 |
| 논리 | `&&` `\|\|` `!` | 동일 |
| 증감 | `++` `--` (전위/후위) | 동일 |
| 형변환 | `(double)a / b` | C++도 동일 (캐스트) |

### 다른 점 (결과 타입)

| 항목 | C | C++ |
|------|---|-----|
| 비교·논리 결과 | `int` (0 / 1) | **`bool`** (`false` / `true`) |
| 출력 시 | `printf("%d", a > b);` → `0` 또는 `1` | `cout << (a > b);` → `0` 또는 `1` (bool도 숫자처럼 보일 수 있음) |

**예: 합격 여부**

```c
/* C */
int score = 85;
int pass = (score >= 60) && (score <= 100);  /* 1 또는 0 */
```

```cpp
// C++
int score = 85;
bool pass = score >= 60 && score <= 100;     // true / false
```

### 4주차 한눈에

> **연산자 자체는 C와 C++가 거의 같다.**  
> C++는 결과를 `bool`에 담아 의미가 더 분명하다.

## 전체 코드 한 장 비교 (1~4주 흐름)

### C 스타일 (요약)

```c
#include <stdio.h>

int main() {
    int age;
    char name[20];
    double height;

    printf("나이: ");
    scanf("%d", &age);
    printf("이름: ");
    scanf("%s", name);
    printf("키: ");
    scanf("%lf", &height);

    printf("%s (%d세) 키 %.1f\n", name, age, height);
    printf("성인: %d\n", age >= 18);  /* 0 또는 1 */

    return 0;
}
```

### C++ 스타일 (요약)

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    int age;
    string name;
    double height;

    cout << "나이: ";
    cin >> age;
    cout << "이름: ";
    cin >> name;
    cout << "키: ";
    cin >> height;

    cout << name << " (" << age << "세) 키 " << height << endl;
    bool adult = age >= 18;
    cout << "성인: " << (adult ? "예" : "아니오") << endl;

    return 0;
}
```

## 학생이 자주 헷갈리는 포인트

| 실수 | C | C++에서 |
|------|---|---------|
| `&` 빠뜨림 | `scanf("%d", num)` → 오류 | `cin >> num` 은 `&` 없음 ✅ |
| 서식 틀림 | `%d`에 double 넣기 | `cout`은 타입 자동 |
| 문자열 공백 | `scanf("%s")`는 공백에서 끊김 | `getline` 사용 |
| 문자열 타입 | `char name[20]` | `string name` + `#include <string>` |
| true/false | `1`/`0`만 익숙 | `bool`, `true`/`false` |
| 헤더 | `stdio.h` | `iostream` (+ `string`, `iomanip`) |
| 컴파일 | `gcc` | `g++` |

## 같은 것 / 다른 것 체크리스트

### ✅ 1~4주차에서 **같은 것**

- [ ] `int main()`, `return 0`
- [ ] 변수 선언·초기화 (`int a = 10`)
- [ ] 산술·대입·비교·논리·증감 연산자
- [ ] 정수 나눗셈 → 소수 버림
- [ ] 형 변환 `(double)a / b`
- [ ] 컴파일 → 실행파일 과정

### ⭐ 1~4주차에서 **다른 것 (C++ 쪽)**

- [ ] `#include <iostream>`, `using namespace std`
- [ ] `cout <<` / `cin >>`
- [ ] `string`, `bool`
- [ ] `getline`, `cin.ignore()`
- [ ] `fixed` + `setprecision`
- [ ] `scanf`의 `&` / `%d` 대신 스트림 연산

## 수업 진행 팁 (강사용)

1. **C를 먼저 배운 반**: “연산자·변수는 그대로, 입출력만 `cout`/`cin`으로 바꾼다”고 시작  
2. **C++만 배우는 반**: C 비교 표는 “나중에 C/레거시 코드 볼 때”용으로 가볍게  
3. **반드시 실습으로 대조**: 같은 문제를 C `printf`/`scanf`와 C++ `cout`/`cin`으로 각각 작성  
4. **3주차 버퍼**: C의 `&`·`%c` 공백과 C++의 `cin.ignore()`를 **같은 날** 비교하면 이해도가 높음

## 다음 주차 예고 (차이 더 커지는 지점)

| 이후 주제 | C | C++ |
|-----------|---|-----|
| 배열 | `int arr[5]` | `vector` 등 STL |
| 문자열 | `char[]`, `string.h` | `string` 클래스 |
| 메모리 | `malloc` / `free` | `new` / `delete` |
| 구조체 | `struct` | `class` (+ 멤버 함수) |
| 참조 | 포인터만 | **참조(`&`)** |

1~4주차까지는 **입출력·타입이 가장 큰 차이**이고,  
연산자·제어 흐름의 골격은 C와 C++가 **거의 같습니다**.
