# 5주차 정답

| 번호 | 정답 |
|------|------|
| 5-1 | ② 다음 case도 실행됨 (fall-through) |
| 5-2 | `B` |
| 5-3 | ③ string (수업에서는 if 권장) |
| 5-4 | age≥18 **그리고** score≥60 |

### 5-5

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    if (n % 2 == 0)
        cout << "짝수" << endl;
    else
        cout << "홀수" << endl;
    return 0;
}
```

### 5-6

```cpp
#include <iostream>
using namespace std;

int main() {
    int score;
    cin >> score;
    if (score >= 90) cout << "A" << endl;
    else if (score >= 80) cout << "B" << endl;
    else if (score >= 70) cout << "C" << endl;
    else if (score >= 60) cout << "D" << endl;
    else cout << "F" << endl;
    return 0;
}
```

### 5-7

```cpp
#include <iostream>
using namespace std;

int main() {
    int choice;
    cin >> choice;
    switch (choice) {
        case 1: cout << "프로그램 시작" << endl; break;
        case 2: cout << "종료" << endl; break;
        default: cout << "다시 선택" << endl;
    }
    return 0;
}
```

### 5-8

```cpp
#include <iostream>
using namespace std;

int main() {
    int year;
    cin >> year;
    if ((year % 4 == 0 && year % 100 != 0) || (year % 400 == 0))
        cout << "윤년" << endl;
    else
        cout << "평년" << endl;
    return 0;
}
```

# 6주차 정답

| 번호 | 정답 |
|------|------|
| 6-1 | 10번 (`i = 0 ~ 9`) |
| 6-2 | ② do-while은 최소 1번 실행 |
| 6-3 | `1 2 3 4 ` (5에서 break) |
| 6-4 | 이번 회차만 건너뛰고 다음 반복으로 |

### 6-5

```cpp
#include <iostream>
using namespace std;

int main() {
    for (int i = 1; i <= 10; i++)
        cout << i << " ";
    cout << endl;
    return 0;
}
```

### 6-6

```cpp
#include <iostream>
using namespace std;

int main() {
    int dan;
    cin >> dan;
    for (int i = 1; i <= 9; i++)
        cout << dan << " x " << i << " = " << dan * i << endl;
    return 0;
}
```

### 6-7

```cpp
#include <iostream>
using namespace std;

int main() {
    int sum = 0;
    for (int i = 1; i <= 100; i++) {
        if (i % 3 == 0)
            sum += i;
    }
    cout << "합: " << sum << endl;  // 1683
    return 0;
}
```

### 6-8

```cpp
#include <iostream>
using namespace std;

int main() {
    for (int i = 1; i <= 5; i++) {
        for (int j = 1; j <= i; j++)

    }

}
```

### 6-9

```cpp
#include <iostream>
using namespace std;

int main() {
    const int answer = 7;
    int guess;

        cout << "숫자 입력: ";
```

# 7주차 정답

| 번호 | 정답 |
|------|------|
| 7-1 | ① 0~4 |
| 7-2 | ② `#include <vector>` |
| 7-3 | ② 맨 뒤에 6 추가 |
| 7-4 | ② vector는 크기 가변 |

### 7-5

```cpp
#include <iostream>
using namespace std;

int main() {
    int arr[5] = {10, 20, 30, 40, 50};
    for (int i = 0; i < 5; i++)
        cout << arr[i] << " ";
    cout << endl;
    return 0;
}
```

### 7-6

```cpp
#include <iostream>
using namespace std;

int main() {
    int arr[5];
    for (int i = 0; i < 5; i++)
        cin >> arr[i];
    for (int i = 4; i >= 0; i--)
        cout << arr[i] << " ";
    cout << endl;
    return 0;
}
```

### 7-7

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> scores;
    int n, sum = 0;
    cin >> n;
    for (int i = 0; i < n; i++) {
        int s;
        cin >> s;
        scores.push_back(s);
        sum += s;
    }
    cout << "합: " << sum << ", 평균: " << (double)sum / n << endl;
    return 0;
}
```

### 7-8

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> v = {3, 9, 1, 7, 5};
    int maxVal = v[0];
    for (int x : v)
        if (x > maxVal) maxVal = x;
    cout << "최댓값: " << maxVal << endl;
    return 0;
}
```

### 7-9

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> v;
    for (int i = 0; i < 5; i++) {
        int x;
        cin >> x;
        v.push_back(x);
    }
    for (int x : v)
        if (x % 2 == 0)
            cout << x << " ";
    cout << endl;
    return 0;
}
```

# 8주차 정답

| 번호 | 정답 |
|------|------|
| 8-1 | ② `#include <string>` |
| 8-2 | ② 공백 전까지 |
| 8-3 | ② `getline(cin, s);` |
| 8-4 | 문자열의 **길이**(문자 개수) |

### 8-5

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string name;
    cout << "이름: ";
    getline(cin, name);
    cout << "안녕하세요, " << name << "님" << endl;
    return 0;
}
```

### 8-6

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string a = "Hello", b = " C++";
    string c = a + b;
    cout << c << " (길이: " << c.length() << ")" << endl;
    // Hello C++ (길이: 9)
    return 0;
}
```

### 8-7

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s, rev = "";
    cin >> s;
    for (int i = (int)s.length() - 1; i >= 0; i--)
        rev += s[i];
    cout << rev << endl;
    return 0;
}
```

### 8-8

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s;
    cin >> s;
    int count = 0;
    for (char c : s) {
        if (c == 'a' || c == 'e' || c == 'i' || c == 'o' || c == 'u')
            count++;
    }
    cout << "모음: " << count << endl;
    return 0;
}
```

### 8-9

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s;
    cin >> s;
    bool ok = true;
    int n = s.length();
    for (int i = 0; i < n / 2; i++) {
        if (s[i] != s[n - 1 - i]) {
            ok = false;
            break;
        }
    }
    if (ok) cout << "회문" << endl;
    else cout << "회문 아님" << endl;
    return 0;
}
```

## 핵심 정리

| 주차 | 핵심 |
|------|------|
| 5 | if / else if / switch + break, 윤년 조건 |
| 6 | for / while / do-while, break·continue, 중첩 for |
| 7 | 배열 vs `vector`, `push_back`, range-for, 인덱스 0~ |
| 8 | `string`, `getline`, `length`, `+`, 문자 순회 |

### C와의 차이 (이 구간)

| | C | C++ |
|--|---|-----|
| 반복 for 변수 | for 밖에서 선언 흔함 | `for (int i = 0; ...)` |
| 동적 배열 | 고정 배열 / malloc | **`vector`** |
| 문자열 | `char[]` | **`string`** |
