# 1주차 정답

| 번호 | 정답 |
|------|------|
| 1-1 | ② C를 확장, 절차 + 객체지향 |
| 1-2 | ② `.cpp` |
| 1-3 | ② `#include <iostream>` |
| 1-4 | `hello.exe` |

### 1-5

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "홍길동" << endl;
    return 0;
}
```

### 1-6

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello C++" << endl;
    cout << "반갑습니다" << endl;
    return 0;
}
```

### 1-7 (예시)

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "이름: 홍길동" << endl;
    cout << "과정: 풀스택" << endl;
    cout << "언어: C++" << endl;
    return 0;
}
```

# 2주차 정답

| 번호 | 정답 |
|------|------|
| 2-1 | ③ `bool` |
| 2-2 | ② `#include <string>` |
| 2-3 | ② `1` (`true`는 보통 1로 출력) |
| 2-4 | ② `fixed` + `setprecision(2)` (`<iomanip>`) |
| 2-5 | ② `int` |

### 2-6

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string name = "홍길동";
    int age = 20;
    double height = 170.5;

    cout << "이름: " << name << endl;
    cout << "나이: " << age << endl;
    cout << "키: " << height << endl;
    return 0;
}
```

### 2-7

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 10, b = 3;
    cout << "합: " << a + b << endl;
    cout << "차: " << a - b << endl;
    cout << "곱: " << a * b << endl;
    cout << "몫: " << a / b << endl;  // 3
    return 0;
}
```

### 2-8

```cpp
#include <iostream>
using namespace std;

int main() {
    int score = 85;
    bool pass = score >= 60;
    cout << "합격: " << (pass ? "예" : "아니오") << endl;
    return 0;
}
```

출력: `합격: 예`

### 2-9

```cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    double r = 5.0;
    double pi = 3.14159;
    double area = pi * r * r;

    cout << fixed << setprecision(2);
    cout << "넓이: " << area << endl;
    return 0;
}
```

출력: `넓이: 78.54`

# 3주차 정답

| 번호 | 정답 |
|------|------|
| 3-1 | ③ 타입 자동, `&` 불필요 |
| 3-2 | ② 공백 전까지 |
| 3-3 | ② `getline(cin, name);` |
| 3-4 | ② 버퍼에 남은 `\n` |
| 3-5 | ② `cin.ignore();` |

### 3-6

```cpp
#include <iostream>
using namespace std;

int main() {
    int num;
    cout << "정수를 입력하세요: ";
    cin >> num;
    cout << "입력값: " << num << endl;
    return 0;
}
```

### 3-7

```cpp
#include <iostream>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;
    cout << "합: " << a + b << endl;
    return 0;
}
```

### 3-8

```cpp
#include <iostream>
using namespace std;

int main() {
    int age;
    double height;
    cin >> age >> height;
    cout << "나이: " << age << ", 키: " << height << endl;
    return 0;
}
```

### 3-9

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    int age;
    string name;

    cout << "나이: ";
    cin >> age;
    cin.ignore();

    cout << "이름: ";
    getline(cin, name);

    cout << name << " (" << age << "세)" << endl;
    return 0;
}
```

# 4주차 정답

| 번호 | 정답 |
|------|------|
| 4-1 | ② `3` (정수 나눗셈, 소수 버림) |
| 4-2 | `1` |
| 4-3 | ② `(double)10 / 3` 또는 `10.0 / 3` |
| 4-4 | ② `a = a + 5` |
| 4-5 | ② `bool` |
| 4-6 | ② `6` |

### 4-7

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 10, b = 3;
    cout << "합: " << a + b << endl;
    cout << "몫: " << a / b << endl;
    cout << "나머지: " << a % b << endl;
    cout << "실수 나눗셈: " << (double)a / b << endl;
    return 0;
}
```

### 4-8

```cpp
#include <iostream>
using namespace std;

int main() {
    int score;
    cin >> score;
    bool pass = score >= 60 && score <= 100;
    cout << "합격: " << pass << endl;
    return 0;
}
```

### 4-9

```cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    double r, pi = 3.14159;
    cin >> r;

    cout << fixed << setprecision(2);
    cout << "둘레: " << 2 * pi * r << endl;
    cout << "넓이: " << pi * r * r << endl;
    return 0;
}
```

### 4-10

```cpp
#include <iostream>
using namespace std;

int main() {
    int a, b, c, maxv;
    cin >> a >> b >> c;

    maxv = a;
    if (b > maxv) maxv = b;
    if (c > maxv) maxv = c;

    cout << "최댓값: " << maxv << endl;
    return 0;
}
```

삼항 연산자 버전:

```cpp
int maxv = (a > b) ? a : b;
maxv = (maxv > c) ? maxv : c;
```

## 핵심 정리

| 주차 | 핵심 |
|------|------|
| 1 | `#include <iostream>`, `cout <<`, `endl`, `g++` |
| 2 | `bool`, `string`, `fixed`/`setprecision` |
| 3 | `cin >>` (공백 전), `getline` (한 줄), `cin.ignore()` |
| 4 | 정수 `/`는 버림, `(double)` 캐스팅, 비교 결과는 `bool` |

### C와의 차이 (입출력만)

| | C | C++ |
|--|---|-----|
| 출력 | `printf("%d", n);` | `cout << n;` |
| 입력 | `scanf("%d", &n);` | `cin >> n;` |
| 문자열 | `char[]` + `%s` | `string` + `cin` / `getline` |
