# 5주차 – 조건문 (if / switch)

## 객관식

### 5-1
`switch` 문에서 `break`를 빼면 어떻게 되나?

① 컴파일 오류  
② 다음 case도 이어서 실행됨 (fall-through)  
③ default만 실행  
④ 무한 루프  

### 5-2
점수 85일 때 아래 코드 출력은?

```cpp
if (score >= 90) cout << "A";
else if (score >= 80) cout << "B";
else cout << "F";
```

### 5-3
`switch`에 넣기 **어려운**(수업에서 if를 권장하는) 타입은?

① int  
② char  
③ string  
④ int 상수  

### 5-4
아래 코드에서 `pass`가 `true`가 되려면?

```cpp
bool pass = (age >= 18 && score >= 60);
```


# 7주차 – 배열 & vector

## 객관식

### 7-1
`int arr[5];` 에서 유효한 인덱스는?

① 0~4  ② 1~5  ③ 0~5  ④ 1~4  

### 7-2
`vector`를 쓰려면 필요한 헤더는?

① `#include <array>`  
② `#include <vector>`  
③ `#include <list>`  
④ `#include <map>`  

### 7-3
`v.push_back(6);` 의 의미는?

① 맨 앞에 6 추가  
② **맨 뒤에** 6 추가  
③ 6번째 요소 삭제  
④ 크기 6으로 고정  

### 7-4
배열과 vector의 차이로 **옳은** 것은?

① 배열은 크기가 가변이다  
② vector는 크기가 **가변**이다  
③ vector는 인덱스가 1부터다  
④ 배열만 range-for를 쓸 수 있다
