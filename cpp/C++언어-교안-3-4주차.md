## 📅 3주차 – 입력 & 출력

### 📌 학습 목표
- `cin`, `cout` 사용법 습득
- `getline`으로 문자열 한 줄 입력
- 입력 버퍼 개념 이해

### 📘 이론

#### 3.1 cout / cin
- **cout**: 표준 출력 (`<<`)
- **cin**: 표준 입력 (`>>`)
- C의 `printf`/`scanf`와 달리 **타입에 맞게 자동 처리**

```cpp
cout << "정수를 입력하세요: ";
cin >> num;
```

#### 3.2 cin과 자료형

| 입력 | 코드 | 비고 |
|------|------|------|
| int | `cin >> age;` | 공백까지 읽음 |
| double | `cin >> height;` | |
| char | `cin >> ch;` | 한 글자 |
| string | `cin >> name;` | **공백 전까지** |

#### 3.3 getline — 공백 포함 문자열

```cpp
#include <string>
string name;
getline(cin, name);  // 한 줄 전체 (공백 포함)
```

**주의:** `cin >> num` 직후 `getline`을 쓰면 남은 `\n` 때문에 빈 줄이 읽힐 수 있음.

```cpp
cin >> age;
cin.ignore();           // 버퍼 비우기
getline(cin, name);
```

#### 3.4 입력 버퍼
- 키보드 입력은 버퍼에 잠시 저장됨
- `\n`(엔터)도 버퍼에 남음
- `cin.ignore()`로 정리 가능

### 🧪 실습

#### 실습 1: 정수 입력

```cpp
#include <iostream>
using namespace std;

int main() {
    int num;
    cout << "정수를 입력하세요: ";
    cin >> num;
    cout << "입력값: " << num << endl;
    return 0;
}
```

#### 실습 2: 여러 값 입력

```cpp
#include <iostream>
using namespace std;

int main() {
    int age;
    double height;
    cout << "나이와 키를 입력하세요: ";
    cin >> age >> height;
    cout << "나이: " << age << ", 키: " << height << endl;
    return 0;
}
```

#### 실습 3: string + getline

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    int age;
    string name;
    cout << "나이: ";
    cin >> age;
    cin.ignore();
    cout << "이름(공백 가능): ";
    getline(cin, name);
    cout << name << " (" << age << "세)" << endl;
    return 0;
}
```

### 🎯 핵심 정리
- `cin >>` : 공백 기준으로 읽음
- `getline(cin, str)` : 한 줄 전체
- 숫자 입력 후 `getline` 전에 `cin.ignore()` 고려

### 📝 연습 문제
1. 두 정수를 입력받아 합 출력
2. 이름(getline)과 나이를 입력받아 한 줄로 출력

## 📅 4주차 – 연산자

### 📌 학습 목표
- 산술·대입·비교·논리 연산자 이해
- 증감 연산자(`++`, `--`) 사용
- 형 변환(casting) 기초

### 📘 이론

#### 4.1 산술 연산자

| 연산자 | 의미 | 예 |
|--------|------|-----|
| `+` `-` `*` `/` | 사칙연산 | `a + b` |
| `%` | 나머지 (정수) | `10 % 3` → 1 |

#### 4.2 대입·복합 대입

```cpp
a = 10;
a += 5;   // a = a + 5
a -= 3;
a *= 2;
a /= 4;
```

#### 4.3 비교·논리 연산자

| 비교 | 논리 |
|------|------|
| `==` `!=` `<` `>` `<=` `>=` | `&&` `||` `!` |

결과는 `bool` (`true` / `false`)

#### 4.4 증감 연산자

```cpp
++i;  // 선증가
i++;  // 후증가
```

#### 4.5 형 변환

```cpp
int a = 10, b = 3;
double result = (double)a / b;  // 3.333...
```

### 🧪 실습

#### 실습 1: 사칙연산

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 10, b = 3;
    cout << "합: " << a + b << endl;
    cout << "몫: " << a / b << endl;
    cout << "나머지: " << a % b << endl;
    cout << "실수 나눗셈: " << (double)a / b << endl;
    return 0;
}
```

#### 실습 2: 논리 연산

```cpp
#include <iostream>
using namespace std;

int main() {
    int score = 85;
    bool pass = score >= 60 && score <= 100;
    cout << "합격: " << pass << endl;
    return 0;
}
```

### 🎯 핵심 정리
- 정수 나눗셈 `10/3` → 3 (소수 버림)
- 실수 결과는 `(double)a / b`처럼 캐스팅
- C++에서 비교·논리 결과는 `bool`

### 📝 연습 문제
1. 반지름을 입력받아 원의 둘레·넓이 출력
2. 세 정수 중 최댓값 찾기 (if 없이 비교만 연습해도 됨 — 5주차 예고)
