# 10주차 정답

| 번호 | 정답 |
|------|------|
| 10-1 | `10` |
| 10-2 | ① `int& r = x;` 는 x의 별명 |
| 10-3 | ② 참조 전달 `int&` |
| 10-4 | `200` |
| 10-5 | ④ 참조는 `*` 없이 `r = 값`으로 바꿈 |

### 10-6

```cpp
#include <iostream>
using namespace std;

int main() {
    int n = 100;
    int* p = &n;
    cout << "n=" << n << ", *p=" << *p << endl;
    *p = 200;
    cout << "n=" << n << endl;
    return 0;
}
```

### 10-7

```cpp
#include <iostream>

void swapRef(int& a, int& b) {
    int t = a;
    a = b;
    b = t;
}

int main() {
    int x, y;
    cin >> x >> y;
    swapRef(x, y);
    cout << x << " " << y << endl;
    return 0;
}
```

### 10-9

int findMax(int* arr, int size) {
    int maxv = arr[0];
    for (int i = 1; i < size; i++)

    return maxv;
}

# 12주차 정답

| 번호 | 정답 |
|------|------|
| 12-1 | ② `ofstream` |
| 12-2 | ② `ifstream` |
| 12-3 | ① `if (!fin.is_open())` |
| 12-4 | ② `#include <fstream>` |

### 12-5

```cpp
#include <iostream>
#include <fstream>
using namespace std;

int main() {
    ofstream fout("score.txt");
    if (!fout.is_open()) {
        cout << "파일을 열 수 없습니다." << endl;
        return 1;
    }
    fout << "홍길동 85" << endl;
    fout << "김철수 92" << endl;
    fout.close();
    cout << "저장 완료" << endl;
    return 0;
}
```

### 12-6

```cpp
#include <iostream>
#include <fstream>
#include <string>
using namespace std;

int main() {
    ifstream fin("score.txt");
    if (!fin.is_open()) {
        cout << "파일을 열 수 없습니다." << endl;
        return 1;
    }
    string line;
    while (getline(fin, line))
        cout << line << endl;
    fin.close();
    return 0;
}
```

### 12-8

```cpp
#include <iostream>
#include <vector>
#include <string>
#include <fstream>
using namespace std;

class Student {
public:
    string name;
    int score;
    Student(string n, int s) : name(n), score(s) {}
    void print() { cout << name << ": " << score << endl; }
};

vector<Student> list;

void addStudent() {
    string name;
    int score;
    cout << "이름: "; cin >> name;
    cout << "점수: "; cin >> score;
    list.push_back(Student(name, score));
}

void printAll() {
    if (list.empty()) {
        cout << "등록된 학생이 없습니다." << endl;
        return;
    }
    for (auto& s : list) s.print();
}

void saveFile() {
    ofstream fout("students.txt");
    for (auto& s : list)
        fout << s.name << " " << s.score << endl;
    fout.close();
    cout << "저장됨" << endl;
}

int main() {
    int menu;
    while (true) {
        cout << "1.등록 2.목록 3.저장 0.종료: ";
        cin >> menu;
        if (menu == 0) break;
        if (menu == 1) addStudent();
        else if (menu == 2) printAll();
        else if (menu == 3) saveFile();
    }
    return 0;
}
```

### 12-9 (검색 예시)

```cpp
void searchStudent() {
    string name;
    cout << "검색할 이름: ";
    cin >> name;
    bool found = false;
    for (auto& s : list) {
        if (s.name == name) {
            s.print();
            found = true;
            break;
        }
    }
    if (!found) cout << "학생이 없습니다." << endl;
}

void deleteStudent() {
    string name;
    cout << "삭제할 이름: ";
    cin >> name;
    for (size_t i = 0; i < list.size(); i++) {
        if (list[i].name == name) {
            list.erase(list.begin() + i);
            cout << "삭제 완료" << endl;
            return;
        }
    }
    cout << "삭제할 학생이 없습니다." << endl;
}
```

## 핵심 정리

| 주차 | 핵심 |
|------|------|
| 9 | 함수, 오버로딩, 기본 인수, 지역/전역 |
| 10 | 포인터 `*`/`&`, 참조 `int&`, swap, 배열+포인터 |
| 11 | struct / class, public·private, 생성자, 메서드 |
| 12 | `ofstream`/`ifstream`, vector+class+메뉴 종합 |

### C와의 차이 (이 구간)

| | C | C++ |
|--|---|-----|
| 함수 | 오버로딩 없음 | **오버로딩·기본 인수** |
| 원본 수정 | 포인터 | **참조 `int&`** 권장 |
| 묶음 | struct | **class** + 메서드 |
| 파일 | `FILE*`, fprintf | **fstream** |
