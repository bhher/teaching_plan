# 9주차 – 함수

## 객관식

### 9-1
함수 선언(프로토타입)의 역할로 **옳은** 것은?

① 함수 본문을 실행한다  
② 컴파일 전에 함수의 존재·형식을 알려 준다  
③ main보다 반드시 뒤에 써야 한다  
④ 반환값이 없으면 선언할 수 없다  

### 9-2
**함수 오버로딩**에 대한 설명으로 **옳은** 것은?

① 함수 이름이 달라야 한다  
② 이름 같고 **매개변수 타입·개수**가 다르면 된다  
③ 반환 타입만 다르면 오버로딩이다  
④ C에서는 가능하고 C++에서는 불가하다  

### 9-3
아래 코드 실행 결과는?

```cpp
void greet(string name = "손님") {
    cout << name;
}
int main() {
    greet();
}
```

### 9-4
지역변수에 대한 설명으로 **틀린** 것은?

① 함수 안에서 선언한다  
② 함수가 끝나면 소멸한다  
③ 다른 함수에서 자유롭게 접근한다  
④ main의 지역변수는 main 밖에서는 보이지 않는다

# 10주차 – 포인터 & 참조

## 객관식

### 10-1
`int x = 10; int* p = &x;` 일 때 `*p`의 값은?

### 10-2
C++ **참조(reference)** 에 대한 설명으로 **옳은** 것은?

① `int& r = x;` 는 x의 별명이다  
② 참조는 반드시 null로 초기화한다  
③ 참조는 나중에 다른 변수를 가리키게 바꿀 수 있다  
④ 참조는 C에만 있고 C++에는 없다  

### 10-3
함수에서 원본 두 변수를 교환할 때 C++에서 **권장**하는 방식은?

① `void swap(int a, int b)` 값 전달  
② `void swap(int& a, int& b)` 참조 전달  
③ 전역변수만 사용  
④ 반환값으로만 교환  

### 10-4
아래 실행 후 `n`의 값은?

```cpp
int n = 100;
int* p = &n;
*p = 200;
```

### 10-5
포인터와 참조의 차이로 **틀린** 것은?

① 포인터는 주소를 저장한다  
② 참조는 선언 시 반드시 초기화한다  
③ 포인터는 null이 가능하다  
④ 참조는 `*`로 역참조해야 값을 바꾼다

# 11주차 – 구조체 & 클래스

## 객관식

### 11-1
`struct`와 `class`의 기본 접근 지정자로 **옳은** 것은?

① struct=private, class=public  
② struct=public, class=private  
③ 둘 다 private  
④ 둘 다 public  

### 11-2
클래스 **생성자**에 대한 설명으로 **옳은** 것은?

① 반환 타입이 void이다  
② 클래스 이름과 같고, 객체 생성 시 호출된다  
③ 반드시 private이어야 한다  
④ main에서만 정의한다  

### 11-3
`public` 멤버의 의미는?

① 클래스 안에서만 접근  
② **어디서나** 접근 가능  
③ 상속받은 클래스만 접근  
④ 파일 안에서만 접근  

### 11-4
아래 코드에서 `s.print()` 가 하는 일은?

```cpp
class Student {
public:
    string name;
    void print() { cout << name; }
};
```

# 12주차 – 파일 입출력 & 종합

## 객관식

### 12-1
파일에 **쓰기**할 때 사용하는 클래스는?

① `ifstream`  
② `ofstream`  
③ `stringstream`  
④ `iostream` 만  

### 12-2
파일에서 **읽기**할 때 사용하는 클래스는?

① `ofstream`  
② `ifstream`  
③ `fstream` 쓰기 전용만  
④ `printf`  

### 12-3
파일 열기 실패를 확인하는 코드로 **적절한** 것은?

① `if (!fin.is_open())`  
② `if (fin == 0)`  
③ `if (fin.fail == true)` 만 가능  
④ 확인할 필요 없다  

### 12-4
파일 입출력에 필요한 헤더는?

① `#include <stdio.h>`  
② `#include <fstream>`  
③ `#include <file>`  
④ `#include <string>` 만
