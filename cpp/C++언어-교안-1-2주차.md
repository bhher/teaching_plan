## 📅 1주차 – C++ 개요 & 개발환경

### 📌 학습 목표
- C++ 언어의 특징과 역사 이해
- C vs C++ vs Java 차이점 파악
- 컴파일 과정 이해
- 개발 환경 설정 및 첫 프로그램 작성

### 📘 이론

#### 1.1 C++란?
- **C 언어를 확장한 프로그래밍 언어**
- 1980년대 비야네 스트로스트루프(Bjarne Stroustrup)가 개발
- **절차지향 + 객체지향** 모두 지원
- 게임, 시스템, 임베디드, 고성능 애플리케이션 등에 사용

#### 1.2 C++의 특징
- **C의 상위 집합**: C 문법 대부분 그대로 사용 가능
- **객체지향**: 클래스, 상속, 다형성
- **STL**: vector, string 등 표준 라이브러리 제공
- **컴파일 언어**: 소스코드를 기계어로 변환 후 실행
- **메모리 제어**: C처럼 직접 제어 가능 + `new`/`delete`, 스마트 포인터

#### 1.3 C vs C++ vs Java 비교

| 항목 | C | C++ | Java |
|------|---|-----|------|
| 패러다임 | 절차지향 | 절차 + 객체지향 | 객체지향 |
| 파일 확장자 | `.c` | `.cpp`, `.cc` | `.java` |
| 입출력 | `printf` / `scanf` | `cout` / `cin` (또는 C 방식) | `System.out` |
| 문자열 | `char[]` | `string` 클래스 | `String` |
| 메모리 | `malloc` / `free` | `new` / `delete` (+ RAII) | GC |
| 실행 | 컴파일 → exe | 컴파일 → exe | JVM 위 실행 |

#### 1.4 컴파일 과정

```
소스코드(.cpp) → 전처리 → 컴파일 → 어셈블리 → 링크 → 실행파일(.exe)
```

**단계별 설명:**
1. **전처리**: `#include`, `#define` 처리
2. **컴파일**: C++ 코드를 어셈블리 코드로 변환
3. **어셈블**: 어셈블리 코드를 기계어로 변환
4. **링크**: 라이브러리와 연결

#### 1.5 개발 환경 설정
- **컴파일러**: g++ (MinGW-w64) 또는 MSVC
- **에디터**: VS Code
- **확장**: C/C++ Extension (Microsoft)

상세 설치: [VSCode-C-C++-설치가이드.md](../VSCode-C-C++-설치가이드.md)

### 🧪 실습

#### 실습 1: Hello World 프로그램

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello C++" << endl;
    return 0;
}
```

**컴파일 및 실행:**
```bash
g++ hello.cpp -o hello.exe
hello.exe
```

**출력:**
```
Hello C++
```

#### 실습 2: 여러 줄 출력

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "안녕하세요" << endl;
    cout << "C++를 배워봅시다!" << endl;
    return 0;
}
```

#### 실습 3: C 방식도 가능 (참고)

C++에서도 C 스타일 입출력을 쓸 수 있습니다. (1주차는 `cout` 위주로 학습)

```cpp
#include <iostream>
using namespace std;

int main() {
    printf("Hello from printf\n");  // C 스타일
    cout << "Hello from cout" << endl;
    return 0;
}
```

> `#include <cstdio>` 또는 `<stdio.h>` 필요

### 🎯 핵심 정리
- `#include <iostream>`: 입출력 스트림 라이브러리
- `using namespace std;`: `std::cout` 대신 `cout` 사용 (수업용, 실무에서는 네임스페이스 생략 주의)
- `cout << "문자열"`: 화면 출력 (`<<` = 데이터를 흘려보냄)
- `endl`: 줄바꿈 + 버퍼 비우기
- `int main()`: 프로그램 시작점
- `return 0`: 정상 종료

### 📝 연습 문제
1. 자신의 이름을 `cout`으로 출력하는 프로그램 작성
2. 여러 줄로 자기소개를 출력하는 프로그램 작성
3. `Hello C++`와 `반갑습니다`를 각각 다른 줄에 출력

## 📅 2주차 – 변수와 자료형

### 📌 학습 목표
- C++ 기본 자료형 이해
- `bool`, `string` 등 C++에서 추가·편해진 타입 습득
- 변수 선언과 초기화 방법 익히기
- `cout`으로 다양한 형식 출력하기

### 📘 이론

#### 2.1 자료형 종류

**정수형:** (C와 동일)
- `int`: 정수
- `long`: 긴 정수
- `short`: 짧은 정수
- `char`: 문자

**실수형:** (C와 동일)
- `float`: 단정밀도 실수
- `double`: 배정밀도 실수

**C++에서 특히 자주 쓰는 타입:**
- `bool`: `true` / `false` (논리값)
- `string`: 문자열 (`#include <string>`)

**부호:**
- `signed`: 부호 있음 (기본값)
- `unsigned`: 부호 없음 (0 이상만)

#### 2.2 변수 선언과 초기화

```cpp
// 선언만
int age;
double height;

// 선언과 동시에 초기화
int age = 20;
double height = 170.5;
char grade = 'A';
bool pass = true;
string name = "홍길동";

// C++11: 타입 추론 (선택)
auto score = 95;        // int로 추론
auto pi = 3.14;         // double로 추론
```

#### 2.3 출력 방법 비교

| 방식 | 예시 | 비고 |
|------|------|------|
| `cout` | `cout << age;` | C++ 기본 |
| `cout` + 조작자 | `cout << fixed << setprecision(2) << pi;` | `<iomanip>` |
| `printf` | `printf("%d", age);` | C 스타일 (C++에서도 가능) |

**cout vs printf (참고)**

| | cout | printf |
|--|------|--------|
| 타입 안전 | 상대적으로 좋음 | 서식 지정자 직접 맞춰야 함 |
| 사용 | `cout << 변수` | `printf("%d", 변수)` |
| 문자열 | `string` 그대로 출력 | `%s` + char 배열 |

#### 2.4 cout 서식 (2주차에서 쓸 것)

```cpp
#include <iostream>
#include <iomanip>
using namespace std;

double pi = 3.14159;
cout << fixed << setprecision(2) << pi;  // 3.14
```

| 코드 | 의미 |
|------|------|
| `fixed` | 고정 소수점 표기 |
| `setprecision(n)` | 소수점 n자리 |

### 🧪 실습

#### 실습 1: 기본 자료형 사용

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    int age = 20;
    double height = 170.5;
    char grade = 'A';
    bool isStudent = true;
    string name = "김철수";

    cout << "이름: " << name << endl;
    cout << "나이: " << age << endl;
    cout << "키: " << height << endl;
    cout << "등급: " << grade << endl;
    cout << "재학 여부: " << isStudent << endl;  // 1 (true)

    return 0;
}
```

**출력:**
```
이름: 김철수
나이: 20
키: 170.5
등급: A
재학 여부: 1
```

#### 실습 2: 여러 변수 출력

```cpp
#include <iostream>
using namespace std;

int main() {
    int num1 = 10, num2 = 20;
    double avg = 15.5;

    cout << "첫 번째 수: " << num1 << endl;
    cout << "두 번째 수: " << num2 << endl;
    cout << "평균: " << avg << endl;

    return 0;
}
```

#### 실습 3: 실수 출력 정밀도 제어

```cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    double pi = 3.14159;

    cout << "기본: " << pi << endl;
    cout << fixed << setprecision(2);
    cout << "소수점 2자리: " << pi << endl;
    cout << setprecision(4);
    cout << "소수점 4자리: " << pi << endl;

    return 0;
}
```

**출력:**
```
기본: 3.14159
소수점 2자리: 3.14
소수점 4자리: 3.1416
```

#### 실습 4: bool과 string 활용

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string id = "user01";
    int score = 85;
    bool pass = score >= 60;

    cout << "아이디: " << id << endl;
    cout << "점수: " << score << "점" << endl;
    cout << "합격: " << (pass ? "예" : "아니오") << endl;

    return 0;
}
```

**출력:**
```
아이디: user01
점수: 85점
합격: 예
```

### 🎯 핵심 정리
- C++은 C의 자료형을 그대로 쓰면서 `bool`, `string` 등을 추가로 활용
- `cout << A << B` 로 여러 값을 이어서 출력
- 실수 자릿수는 `<iomanip>`의 `fixed`, `setprecision` 사용
- `string`은 `#include <string>` 후 `"문자열"` 대입·출력 가능
- C의 `printf`도 쓸 수 있지만, C++ 수업에서는 **`cout` 중심**으로 통일

### 📝 연습 문제
1. 이름(`string`), 나이(`int`), 키(`double`)를 변수에 저장하고 `cout`으로 출력
2. 두 정수의 합, 차, 곱, 몫(정수 나눗셈)을 계산하여 출력
3. 점수가 60점 이상이면 `bool pass = true`로 두고, 합격/불합격 메시지 출력
4. 원의 반지름 `r = 5.0`일 때 원의 넓이(πr²)를 소수점 2자리까지 출력 (`pi = 3.14159`)
