## 📅 11주차 – 구조체 & 클래스

### 📌 학습 목표
- `struct`로 데이터 묶기
- **class**로 객체지향 기초 (멤버·메서드)
- 생성자, `this` 개념

### 📘 이론

#### 11.1 struct (C와 유사)

```cpp
struct Student {
    string name;
    int age;
    int score;
};

Student s1;
s1.name = "홍길동";
s1.age = 20;
```

#### 11.2 class — struct + 메서드

```cpp
class Student {
public:
    string name;
    int age;
    int score;

    void print() {
        cout << name << " (" << age << "세) " << score << "점" << endl;
    }

    string getGrade() {
        if (score >= 90) return "A";
        if (score >= 80) return "B";
        return "F";
    }
};
```

#### 11.3 접근 지정자

| | 의미 |
|--|------|
| `public` | 어디서나 접근 |
| `private` | 클래스 내부만 (캡슐화) |

#### 11.4 생성자

```cpp
class Student {
public:
    string name;
    int score;

    Student(string n, int s) {  // 생성자
        name = n;
        score = s;
    }
};

Student s("김철수", 85);  // 생성과 동시에 초기화
```

#### 11.5 struct vs class

| | struct | class |
|--|--------|-------|
| 기본 접근 | public | private |
| 용도 | 단순 데이터 | 객체 + 행동 |

### 🧪 실습

#### 실습 1: struct 배열

```cpp
#include <iostream>
#include <string>
using namespace std;

struct Student {
    string name;
    int age;
    int score;
};

int main() {
    Student s[2] = {{"홍길동", 20, 85}, {"김철수", 22, 92}};
    for (int i = 0; i < 2; i++)
        cout << s[i].name << ": " << s[i].score << endl;
    return 0;
}
```

#### 실습 2: class + 메서드

```cpp
#include <iostream>
#include <string>
using namespace std;

class Student {
public:
    string name;
    int score;

    void print() {
        cout << name << " - " << score << "점" << endl;
    }

    string getGrade() {
        if (score >= 90) return "A";
        if (score >= 80) return "B";
        return "F";
    }
};

int main() {
    Student s;
    s.name = "이영희";
    s.score = 88;
    s.print();
    cout << "등급: " << s.getGrade() << endl;
    return 0;
}
```

#### 실습 3: 생성자

```cpp
#include <iostream>
#include <string>
using namespace std;

class Product {
public:
    string name;
    int price;

    Product(string n, int p) : name(n), price(p) {}

    void show() {
        cout << name << " : " << price << "원" << endl;
    }
};

int main() {
    Product p("노트북", 1200000);
    p.show();
    return 0;
}
```

### 🎯 핵심 정리
- struct = 데이터 묶음
- class = 데이터 + **함수(메서드)**
- Java 클래스와 개념 유사 (다음 심화: 상속, 다형성)

## 📅 12주차 – 파일 입출력 & 종합 실습

### 📌 학습 목표
- `fstream`으로 파일 읽기·쓰기
- 지금까지 문법 종합
- 미니 프로젝트 완성

### 📘 이론

#### 12.1 ofstream — 쓰기

```cpp
#include <fstream>
ofstream fout("data.txt");
fout << "Hello File" << endl;
fout.close();
```

#### 12.2 ifstream — 읽기

```cpp
ifstream fin("data.txt");
string line;
while (getline(fin, line)) {
    cout << line << endl;
}
fin.close();
```

#### 12.3 파일 열기 확인

```cpp
ifstream fin("data.txt");
if (!fin.is_open()) {
    cout << "파일을 열 수 없습니다." << endl;
    return 1;
}
```

#### 실습 3: 종합 — 학생 관리 미니 프로젝트

**기능:**
1. vector + class `Student`
2. 메뉴: 등록 / 목록 / 평균 / 파일 저장 / 종료
3. (선택) 파일에서 불러오기

```cpp
#include <iostream>
#include <vector>
#include <string>
#include <fstream>
using namespace std;

class Student {
public:
    string name;
    int score;
    Student(string n, int s) : name(n), score(s) {}
    void print() { cout << name << ": " << score << endl; }
};

vector<Student> list;

void addStudent() {
    string name;
    int score;
    cout << "이름: "; cin >> name;
    cout << "점수: "; cin >> score;
    list.push_back(Student(name, score));
}

void printAll() {
    for (auto& s : list) s.print();
}

void saveFile() {
    ofstream fout("students.txt");
    for (auto& s : list)
        fout << s.name << " " << s.score << endl;
    fout.close();
    cout << "저장됨" << endl;
}

int main() {
    int menu;
    while (true) {
        cout << "1.등록 2.목록 3.저장 0.종료: ";
        cin >> menu;
        if (menu == 0) break;
        if (menu == 1) addStudent();
        else if (menu == 2) printAll();
        else if (menu == 3) saveFile();
    }
    return 0;
}
```

### 🎯 핵심 정리
- `#include <fstream>` — `ifstream` / `ofstream`
- 사용 후 `close()` (또는 소멸 시 자동)
- 12주차 = **vector + class + 파일 + 메뉴** 종합
