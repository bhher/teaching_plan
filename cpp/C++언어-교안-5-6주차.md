## 📅 5주차 – 조건문 (if / switch)

### 📌 학습 목표
- if-else, switch-case 구조 이해
- 중첩 조건문 작성
- `bool`과 조건식 활용

### 📘 이론

#### 5.1 if / if-else / else if

```cpp
if (score >= 90) {
    cout << "A" << endl;
} else if (score >= 80) {
    cout << "B" << endl;
} else {
    cout << "F" << endl;
}
```

#### 5.2 switch-case

```cpp
switch (menu) {
    case 1:
        cout << "조회" << endl;
        break;
    case 2:
        cout << "등록" << endl;
        break;
    default:
        cout << "잘못된 메뉴" << endl;
        break;
}
```

- `break` 없으면 다음 case도 실행 (fall-through)
- `switch`는 **정수·char** 등에 사용 (string은 if 권장)

### 🧪 실습

#### 실습 1: 합격 판정

```cpp
#include <iostream>
using namespace std;

int main() {
    int score;
    cout << "점수: ";
    cin >> score;
    if (score >= 60)
        cout << "합격" << endl;
    else
        cout << "불합격" << endl;
    return 0;
}
```

#### 실습 2: 등급 + switch 메뉴

```cpp
#include <iostream>
using namespace std;

int main() {
    int choice;
    cout << "1.시작 2.종료 선택: ";
    cin >> choice;
    switch (choice) {
        case 1: cout << "프로그램 시작" << endl; break;
        case 2: cout << "종료" << endl; break;
        default: cout << "다시 선택" << endl;
    }
    return 0;
}
```

### 🎯 핵심 정리
- 조건식 결과: 0이 아니면 참 (C++에서는 `bool` 권장)
- `switch`에는 `break` 습관화

### 📝 연습 문제
1. 짝수/홀수 판별
2. 윤년 판별 프로그램

## 📅 6주차 – 반복문 (for / while)

### 📌 학습 목표
- for, while, do-while 사용
- 중첩 반복문
- break, continue

### 📘 이론

#### 6.1 for

```cpp
for (int i = 0; i < 10; i++) {
    cout << i << " ";
}
```

#### 6.2 while / do-while

```cpp
while (조건) { ... }

do {
    ...
} while (조건);  // 최소 1번 실행
```

#### 6.3 break / continue

| | 동작 |
|--|------|
| `break` | 반복 즉시 탈출 |
| `continue` | 이번 회차 건너뛰고 다음 |

### 🧪 실습

#### 실습 1: 1~10 합

```cpp
#include <iostream>
using namespace std;

int main() {
    int sum = 0;
    for (int i = 1; i <= 10; i++)
        sum += i;
    cout << "합: " << sum << endl;
    return 0;
}
```

#### 실습 2: 구구단

```cpp
#include <iostream>
using namespace std;

int main() {
    int dan = 3;
    for (int i = 1; i <= 9; i++)
        cout << dan << " x " << i << " = " << dan * i << endl;
    return 0;
}
```

#### 실습 3: 메뉴 반복 (while)

```cpp
#include <iostream>
using namespace std;

int main() {
    int choice = 0;
    while (choice != 3) {
        cout << "1.출력 2.계산 3.종료: ";
        cin >> choice;
        if (choice == 1) cout << "Hello" << endl;
        else if (choice == 2) cout << "10+20=" << 30 << endl;
    }
    return 0;
}
```

### 🎯 핵심 정리
- C++ for에서 `int i = 0` 선언 가능 (for 안 지역변수)
- 무한 루프: `while (true)` + break로 탈출

### 📝 연습 문제
1. 1~100 중 3의 배수 합
2. 별 찍기 (삼각형 패턴)
3. 숫자 맞히기 (while + if)
