## 📅 9주차 – 함수

### 📌 학습 목표
- 함수 선언·정의·호출
- 매개변수, 반환값
- **함수 오버로딩**, **기본 인수** (C++)

### 📘 이론

#### 9.1 함수 구조

```cpp
반환타입 함수명(매개변수) {
    return 값;
}
```

#### 9.2 선언과 정의

```cpp
int add(int a, int b);  // 선언 (프로토타입)

int main() {
    cout << add(10, 20);
    return 0;
}

int add(int a, int b) {   // 정의
    return a + b;
}
```

#### 9.3 C++만의 기능

**함수 오버로딩** — 이름 같고 매개변수 다름

```cpp
int add(int a, int b) { return a + b; }
double add(double a, double b) { return a + b; }
```

**기본 인수**

```cpp
void greet(string name = "손님") {
    cout << "안녕, " << name << endl;
}
greet();           // 안녕, 손님
greet("홍길동");   // 안녕, 홍길동
```

#### 9.4 지역·전역 변수

- **지역**: 함수 안, 함수 끝나면 소멸
- **전역**: 함수 밖, 프로그램 전체 (남용 금지)

#### 실습 2: 오버로딩

```cpp
#include <iostream>
using namespace std;

int maxVal(int a, int b) { return a > b ? a : b; }
double maxVal(double a, double b) { return a > b ? a : b; }

int main() {
    cout << maxVal(3, 7) << endl;
    cout << maxVal(3.5, 2.1) << endl;
    return 0;
}
```

#### 실습 3: 기본 인수

```cpp
#include <iostream>

using namespace std;

void printLine(string text = "---", int count = 3) {
    for (int i = 0; i < count; i++)
        cout << text << endl;
}

int main() {
    printLine();
    printLine("===", 2);
    return 0;
}
```

## 📅 10주차 – 포인터 & 참조 (★★난이도)

### 📌 학습 목표
- 포인터 개념 (`*`, `&`)
- **참조(reference)** `&` — C++ 특화
- 값 전달 vs 참조 전달

### 📘 이론

#### 10.1 포인터

```cpp
int x = 10;
int* p = &x;    // p는 x의 주소
cout << *p;     // 10 (역참조)
```

#### 10.2 참조 (Reference)

```cpp
int x = 10;
int& ref = x;   // x의 별명
ref = 20;       // x도 20
```

| | 포인터 | 참조 |
|--|--------|------|
| 선언 | `int* p = &x;` | `int& r = x;` |
| null | 가능 | **반드시 초기화** |
| 재할당 | 가능 | 불가 (한 번만) |

#### 10.3 swap — 값 vs 참조

```cpp
// 값 전달 → 원본 안 바뀜
void swapBad(int a, int b) { ... }

// 참조 전달 → 원본 바뀜 (C++ 스타일)
void swapRef(int& a, int& b) {
    int temp = a;
    a = b;
    b = temp;
}
```

#### 10.4 new / delete (간단 소개)

```cpp
int* p = new int(10);
delete p;
```

> 스마트 포인터(`unique_ptr`)는 심화에서

### 🧪 실습

#### 실습 1: 포인터 기본

```cpp
#include <iostream>
using namespace std;

int main() {
    int n = 100;
    int* p = &n;
    cout << "n=" << n << ", *p=" << *p << endl;
    *p = 200;
    cout << "n=" << n << endl;
    return 0;
}
```

#### 실습 2: 참조 swap

```cpp
#include <iostream>
using namespace std;

void swapRef(int& a, int& b) {
    int t = a; a = b; b = t;
}

int main() {
    int x = 10, y = 20;
    swapRef(x, y);
    cout << x << ", " << y << endl;  // 20, 10
    return 0;
}
```

#### 실습 3: 배열과 포인터

```cpp
#include <iostream>
using namespace std;

int main() {
    int arr[3] = {1, 2, 3};
    int* p = arr;
    for (int i = 0; i < 3; i++)
        cout << *(p + i) << " ";
    cout << endl;
    return 0;
}
```

### 🎯 핵심 정리
- `&` 변수 앞: 주소 / 선언: 참조
- `*` 포인터 역참조
- 함수에서 원본 수정 → **참조 매개변수** (`int&`)
