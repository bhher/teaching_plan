## 📅 7주차 – 배열 & vector (★중요)

### 📌 학습 목표
- 1차원 배열 선언·접근
- `vector` 기본 사용 (STL)
- 배열/vector와 반복문 조합

### 📘 이론

#### 7.1 C 스타일 배열

```cpp
int arr[5] = {10, 20, 30, 40, 50};
arr[0] = 10;  // 인덱스 0부터
```

#### 7.2 vector (C++ 추천)

```cpp
#include <vector>
vector<int> v = {1, 2, 3, 4, 5};
v.push_back(6);      // 뒤에 추가
cout << v.size();    // 크기
cout << v[0];        // 접근
```

| | 배열 | vector |
|--|------|--------|
| 크기 | 고정 | 가변 |
| 헤더 | 없음 | `<vector>` |
| 실무 | 임베디드 등 | 일반 C++ |

#### 7.3 range-based for (C++11)

```cpp
for (int x : v) {
    cout << x << " ";
}
```

### 🧪 실습

#### 실습 1: 배열 출력

```cpp
#include <iostream>
using namespace std;

int main() {
    int arr[5] = {10, 20, 30, 40, 50};
    for (int i = 0; i < 5; i++)
        cout << arr[i] << " ";
    cout << endl;
    return 0;
}
```

#### 실습 2: vector 입력·합계

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> scores;
    int n, sum = 0;
    cout << "개수: ";
    cin >> n;
    for (int i = 0; i < n; i++) {
        int s;
        cin >> s;
        scores.push_back(s);
        sum += s;
    }
    cout << "합: " << sum << ", 평균: " << (double)sum / n << endl;
    return 0;
}
```

#### 실습 3: 최댓값

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> v = {3, 9, 1, 7, 5};
    int maxVal = v[0];
    for (int x : v)
        if (x > maxVal) maxVal = x;
    cout << "최댓값: " << maxVal << endl;
    return 0;
}
```

### 🎯 핵심 정리
- 인덱스는 0부터, 범위 초과 주의
- 수업·실무에서는 `vector` + range-for 적극 사용

### 📝 연습 문제
1. 5개 정수 입력 후 역순 출력
2. vector에서 짝수만 출력

## 📅 8주차 – 문자열 (string)

### 📌 학습 목표
- `string` 클래스 사용
- C 스타일 `char[]`와 비교
- 문자열 함수 (`length`, `find`, `substr`)

### 📘 이론

#### 8.1 string 기본

```cpp
#include <string>
string s = "Hello";
s = "C++";
cout << s.length();  // 또는 s.size()
```

#### 8.2 입력

```cpp
string word;
cin >> word;              // 공백 전까지
getline(cin, line);       // 한 줄
```

#### 8.3 자주 쓰는 메서드

| 메서드 | 의미 |
|--------|------|
| `length()` / `size()` | 길이 |
| `s[i]` | i번째 문자 |
| `s + t` | 연결 |
| `find("abc")` | 찾기 |
| `substr(0, 3)` | 부분 문자열 |

#### 8.4 C char[] vs string

| | char[] | string |
|--|--------|--------|
| 헤더 | `<cstring>` | `<string>` |
| 길이 | 직접 관리 | 자동 |
| + 연결 | `strcat` | `+` |

### 🧪 실습

#### 실습 1: string 입출력

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string name;
    cout << "이름: ";
    getline(cin, name);
    cout << "안녕하세요, " << name << "님" << endl;
    return 0;
}
```

#### 실습 2: 문자열 길이·연결

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string a = "Hello", b = " C++";
    string c = a + b;
    cout << c << " (길이: " << c.length() << ")" << endl;
    return 0;
}
```

#### 실습 3: 문자열 뒤집기

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s = "abcde", rev = "";
    for (int i = s.length() - 1; i >= 0; i--)
        rev += s[i];
    cout << rev << endl;
    return 0;
}
```

### 🎯 핵심 정리
- C++에서는 **`string` 우선** 사용
- `char[]`는 C 호환·레거시 코드에서 등장
