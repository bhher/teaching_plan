# Part 5. 객체 복사 · 참조 정답

| 문제 | 정답 | 해설 |
|------|------|------|
| 18 | `김철수` | `user2 = user1` → **참조 복사**, 같은 객체 |
| 19 | `홍길동` | `{ ...user1 }` → **얕은 복사**, 새 객체 |
| 20 | ③ | `user2 = user` 는 복사가 아니라 참조 대입 |
| 21 | ② | 얕은 복사 시 **중첩 객체는 주소 공유** |
| 22 | ② | `JSON.parse(JSON.stringify())` 로 깊은 복사 (제한 있음) |

### 참조 vs 얕은 복사 도식

```
참조:     user1 ──→ [ name: 홍길동 ]
          user2 ──→ (같은 객체)

얕은복사: user1 ──→ [ name: 홍길동 ]
          user2 ──→ [ name: 김철수 ]  (별도 객체, 1단계만 복사)
```

# Part 8. 코드 작성 정답 (29~33)

## 29번. 객체 생성 및 접근

```javascript
let person = {
    name: '홍길동',
    age: 25,
    address: '서울'
};

console.log(person.name);
console.log(person.age);
console.log(person.address);
```

또는 대괄호:

```javascript
console.log(person['name']);
console.log(person['age']);
console.log(person['address']);
```

## 30번. 계산기 객체

```javascript
let calculator = {
    result: 0,
    add(a, b) {
        this.result = a + b;
        return this;
    },
    subtract(n) {
        this.result -= n;
        return this;
    }
};

calculator.add(10, 5);    // result = 15
calculator.subtract(3);   // result = 12
console.log(calculator.result);  // 12
```

또는 교안 스타일 (`add`가 누적):

```javascript
let calculator = {
    result: 0,
    add(num) {
        this.result += num;
        return this;
    },
    subtract(num) {
        this.result -= num;
        return this;
    }
};

calculator.add(10).add(5).subtract(3);
console.log(calculator.result);  // 12
```

## 31번. for...in 순회

```javascript
let product = { id: 1, name: '노트북', price: 1200000 };

for (let key in product) {
    console.log(`${key}: ${product[key]}`);
}
```

출력:

```
id: 1
name: 노트북
price: 1200000
```

`Object.keys` 버전:

```javascript
Object.keys(product).forEach(key => {
    console.log(`${key}: ${product[key]}`);
});
```

## 32번. 객체 배열 평균 점수

```javascript
let students = [
    { name: '홍길동', score: 85 },
    { name: '김철수', score: 92 },
    { name: '이영희', score: 78 }
];

let sum = students.reduce((acc, student) => acc + student.score, 0);
let average = sum / students.length;

console.log(`평균 점수: ${average}`);
// 평균 점수: 85
```

for문 버전:

```javascript
let sum = 0;
for (let i = 0; i < students.length; i++) {
    sum += students[i].score;
}
console.log(`평균 점수: ${sum / students.length}`);
```

## 33번. 구조 분해

```javascript
let user = { name: '홍길동', age: 25, city: '서울' };

let { name, age } = user;

console.log(`이름: ${name}, 나이: ${age}`);
// 이름: 홍길동, 나이: 25
```

## 핵심 정리

| 주제 | 핵심 |
|------|------|
| 접근 | `.속성` / `['속성']` / 변수 키 → `[key]` |
| 메서드 | `this`는 **일반 함수** 메서드에서 해당 객체 |
| 순회 | `for...in`, `Object.keys/values/entries` |
| 참조 | `user2 = user1` → 같은 객체 |
| 얕은 복사 | `{...obj}`, `Object.assign({}, obj)` |
| 깊은 복사 | `JSON.parse(JSON.stringify(obj))` (제한적) |
| 구조 분해 | `let { name, age } = user` |
