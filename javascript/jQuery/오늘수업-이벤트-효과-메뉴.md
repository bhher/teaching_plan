## 1. 이벤트 연습

### HTML 구조 (요약)

- `#textZone` — 스타일을 바꿀 문단  
- `#btn1` click / `#btn2` mouseover·focus / `#btn3` on(여러 이벤트)  
- `#listWrap` + `.list1` — 메뉴 펼침  
- `.hover` — hover 메서드  

### ① click

```javascript
$("#btn1").click(function () {
  $("#textZone").css("color", "blue");
});
```

### ② mouseover · focus

```javascript
$("#btn2").mouseover(function () {
  $("#textZone").css("background-color", "yellow");
});
$("#btn2").focus(function () {
  $("#textZone").css("background-color", "yellow");
});
```

### ③ on — 이벤트 여러 개 한 번에 (예전: `bind`)

```javascript
$("#btn3").on("mouseover focus", function () {
  $("#textZone").css("color", "green").css("font-weight", "bold");
  // 체이닝: .css().css()
});
```

| 예전 | 지금 |
|------|------|
| `.bind("click", fn)` | `.on("click", fn)` |

### ④ mouseenter / mouseleave (드롭다운에 자주 사용)

```javascript
// 마우스가 #listWrap 안으로 들어오면 목록 보이기
$("#listWrap").mouseenter(function () {
  $(".list1").css("display", "block");
});
// 나가면 숨기기
$("#listWrap").mouseleave(function () {
  $(".list1").css("display", "none");
});
```

| 메서드 | 비슷한 것 | 특징 |
|--------|-----------|------|
| `mouseenter` | `mouseover` | **자식으로 이동해도** enter가 다시 안 일어남 → 메뉴에 유리 |
| `mouseleave` | `mouseout` | 마찬가지로 leave가 안정적 |

CSS로 `.list1 { display: none; }` 초기값을 두는 것이 좋습니다.

### ⑤ hover (들어올 때 / 나갈 때 함수 2개)

```javascript
$(".hover").hover(
  function () {
    $(this).css("color", "aqua");  // mouseenter
  },
  function () {
    $(this).css("color", "red");   // mouseleave
  }
);
```

### 수업 포인트

- **이벤트** = 클릭, 마우스 이동 등 행위  
- **이벤트 핸들러** = 그때 실행할 함수  
- `this` = DOM, `$(this)` = jQuery 객체

## 2. Effect (효과)

시간 인자: `"fast"` / `"normal"` / `"slow"` 또는 **밀리초** (`1000` = 1초)

### show / hide / toggle

```javascript
$("#btn1").click(function () {
  $(".box1").hide("slow");   // display:none 쪽으로 애니메이션
});
$("#btn2").click(function () {
  $(".box1").show(1000);     // 1초 동안 보이기
});
$("#btn3").click(function () {
  $(".box2").toggle(500);    // 보이면 숨김, 숨으면 보임
});
```

### slideUp / slideDown / slideToggle

버튼의 **부모 다음 형제** 문단을 접고 펼침 → `$(this).parent().next()`

```javascript
$("#btn4").click(function () {
  $(this).parent().next().slideUp(500);
});
$("#btn5").click(function () {
  $(this).parent().next().slideDown("fast");
});
$("#btn6").click(function () {
  $(this).parent().next().slideToggle("fast");
});
```

```text
<p> <button> … </button> </p>   ← parent()
<p> 효과 대상 문단 </p>         ← next()
```

### fadeOut / fadeIn / fadeToggle / fadeTo

```javascript
$("#btn7").click(function () {
  $(this).parent().next().fadeOut(1000);      // 서서히 사라짐
});
$("#btn8").click(function () {
  $(this).parent().next().fadeIn("slow");
});
$("#btn9").click(function () {
  $(this).parent().next().fadeToggle("normal");
});
$("#btn10").click(function () {
  $(this).parent().next().fadeTo("slow", 0.3); // 투명도 0.3
});
$("#btn11").click(function () {
  $(this).parent().next().fadeTo("slow", 1);   // 불투명
});
```

| 메서드 | 의미 |
|--------|------|
| `hide` / `show` | 숨김 / 표시 |
| `toggle` | 둘 중 반대로 |
| `slideUp` / `slideDown` | 위로 말아 숨김 / 아래로 펼침 |
| `fadeOut` / `fadeIn` | 투명해지며 사라짐 / 나타남 |
| `fadeTo(시간, 투명도)` | 원하는 투명도까지 (0~1) |

## 3. animate

`position: relative`(또는 absolute)인 박스에서 `left` 등을 바꿉니다.

```css
#box1 {
  width: 100px;
  height: 100px;
  background-color: #f00;
  position: relative;
}
```

```javascript
$(function () {
  $("#box1")
    .animate(
      {
        left: "500px",
        width: "200px",
        height: "200px",
        opacity: 0.5
      },
      2000
    )
    .animate(
      {
        left: "0",
        width: "100px",
        height: "100px",
        opacity: 1
      },
      1000
    );
});
```

- 첫 번째 애니 2초 → 커지며 오른쪽으로  
- 이어서 1초 → 원래 크기·위치로  
- **체이닝**: `.animate().animate()` 는 큐에 쌓여 **순서대로** 실행  

CSS `transition`과 비교하면, 수업용·레거시 UI에 `animate`를 쓰는 경우가 많습니다.

## 4. 세로 메뉴 (vertical menu)

### HTML

```html
<ul class="m_menu">
  <li>
    <a href="#">회사소개</a>
    <ul class="sub">…</ul>
  </li>
  …
</ul>
```

### CSS 요점

- `.m_menu` 너비 200px, 가운데  
- 1depth `a` — 초록 배경, 흰 글씨  
- `.sub li` — 연한 배경, hover 시 더 밝게  

### JS (`vertical-jq.js` — 수업 코드)

```javascript
$(function () {
  // 서브메뉴 전부 숨김 (아래 3줄은 같은 의미)
  // $(".m_menu li ul").css("display", "none");
  $(".sub").hide();
  // $(".sub").css("display", "none");

  // .sub 중 첫 번째만 보이기 (아래도 같은 효과)
  $(".sub").eq(0).show();
  // $(".m_menu li:nth-child(1) ul").css("display", "block");
  // $(".m_menu li:nth-child(1) ul").show();
  // $(".m_menu li:eq(0) ul").show();
  // $(".m_menu li:first ul").show();

  $(".m_menu > li > a").click(function (e) {
    e.preventDefault(); // a 기본 이동·맨 위로 스크롤 방지

    // 클릭한 a 바로 다음 .sub 의 display → "none" 또는 "block"
    var status = $(this).next(".sub").css("display");

    if (status == "none") {
      // 닫혀 있으면: 다른 서브 모두 접고, 이 서브만 펼침
      $(".sub").slideUp();
      $(this).next(".sub").slideDown();
    } else {
      // 이미 열려 있으면: 전부 접기
      $(".sub").slideUp();
    }

    // return false;  // e.preventDefault() 대신 써도 비슷한 효과
  });
});
```

#### 흐름

```text
초기: 모든 .sub 숨김 → 첫 번째 .sub만 show
         ↓
1depth a 클릭
         ↓
다음 .sub 가 none?  ──예──► 전부 slideUp → 내 .sub만 slideDown
         │
         └─아니오(이미 열림)──► 전부 slideUp (닫기)
```

#### 같은 뜻인 선택자들

| 하고 싶은 일 | 쓸 수 있는 코드 |
|--------------|-----------------|
| 서브 전부 숨김 | `$(".sub").hide()` / `.css("display","none")` |
| 첫 서브만 보임 | `$(".sub").eq(0).show()` / `$("li:first ul").show()` / `$("li:eq(0) ul").show()` |

**호버 버전(참고):**

```javascript
$(".m_menu > li").hover(
  function () {
    $(this).children(".sub").stop().slideDown(300);
  },
  function () {
    $(this).children(".sub").stop().slideUp(300);
  }
);
```

`.stop()` — 호버를 빠르게 왔다 갔다 할 때 애니 쌓임 방지.

## 5. 햄버거 버튼 + 사이드 nav

### 동작

1. `.ham` 클릭 → `.ham`에 `on`, `nav`에 `active` 토글 (메뉴 아이콘 ↔ X, 패널 슬라이드 인)  
2. 서브 `.sub`는 처음 숨김  
3. `nav > ul > li > a` 클릭  
   - 다음 `.sub`가 `none`이면 → 다른 서브 닫고 이 서브만 `slideDown`  
   - 이미 열려 있으면 → 전부 `slideUp`  
4. `return false` — `a` 기본 이동 막기 (`preventDefault`와 비슷)

### CSS 요점

```css
nav {
  width: 200px;
  position: absolute;
  top: 70px;
  right: -200px;           /* 화면 밖 */
  transition: all 0.3s;
}
nav.active {
  right: 0;                /* 들어옴 */
}
header p.ham.on {
  /* X 아이콘 이미지 */
}
```

### JS

```javascript
$(function () {
  $(".ham").click(function () {
    $(".ham").toggleClass("on");
    $("nav").toggleClass("active");
  });

  $(".sub").hide();

  $("nav > ul > li > a").click(function () {
    var status = $(this).next(".sub").css("display"); // none 또는 block
    if (status == "none") {
      $(".sub").slideUp(500);
      $(this).next(".sub").slideDown(500);
    } else {
      $(".sub").slideUp(500);
    }
    return false;
  });
});
```

| 클래스 | 역할 |
|--------|------|
| `.ham.on` | 햄버거 → 닫기(X) 아이콘 |
| `nav.active` | `right: 0` 으로 메뉴 표시 |

이미지가 없으면 `background-color`나 글자(☰ / ✕)로 대체해도 됩니다.

## 6. dl / dt / dd 아코디언 (Step)

이미 문제·정답으로 분리함 → [아코디언-dl-문제.md](./아코디언-dl-문제.md)

### 핵심 코드

```javascript
$("dd").hide();
$("dd").eq(0).show();
$("dt").eq(0).addClass("selected");

$("dl dt").click(function () {
  if ($(this).next("dd").css("display") === "none") {
    $("dd").slideUp("slow");
    $(this).next().slideDown("slow");
    $("dl dt").removeClass("selected");
    $(this).addClass("selected");
  }
});

$("dl dt").mouseover(function () {
  $(this).addClass("over");
});
$("dl dt").mouseout(function () {
  $(this).removeClass("over");
});
```

- `selected` — 현재 열린 스텝  
- `over` — 마우스 오버  
- **이미 열린 dt 재클릭** → `display !== 'none'` 이라 if에 안 들어감 (안 닫힘)

## 오늘 한눈에 비교

| 상황 | 쓰는 것 |
|------|---------|
| 버튼 한 번 클릭 | `.click()` 또는 `.on("click")` |
| 이벤트 여러 개 동시 | `.on("mouseover focus", fn)` |
| 메뉴 영역 호버 | `mouseenter` / `mouseleave` 또는 `.hover()` |
| 접었다 펴기 | `slideUp` / `slideDown` / `slideToggle` |
| 투명도 | `fade*` / `fadeTo` |
| 위치·크기 애니 | `animate` (+ `position`) |
| 클래스 켜고 끄기 | `toggleClass` / `addClass` / `removeClass` |
| “다음 형제” 패널 | `.next()` · 버튼이면 `.parent().next()` |
