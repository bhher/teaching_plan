## 실습 1. 탭 메뉴

**목표:** 탭 클릭 시 해당 패널만 보이게

```
[공지사항] [자료실] [Q&A]
-------------------------
  (선택된 탭 내용)
```

### 요구사항

1. 탭 버튼 3개, 패널 3개  
2. 클릭한 탭에 `active` 클래스 추가, 나머지 제거  
3. 같은 index의 패널만 `show`, 나머지는 `hide`  
4. `$(this).index()` 활용 가능  

**힌트:** `$(".tab").on("click", …)` · `eq(index)` · `addClass` / `removeClass`

## 실습 2. 아코디언

**목표:** 제목 클릭 시 바로 아래 답변만 펼침/접힘

```
Q. Java란?
   A. ...   ← slideToggle

Q. Spring이란?
   A. ...
```

### 요구사항

1. `.title` 클릭 → `$(this).next()` 에 `slideToggle(300)`  
2. (선택) 다른 답은 `slideUp` 으로 닫기

## 실습 3. 이미지 갤러리

**목표:** 작은 썸네일 클릭 → 큰 이미지 `src` 변경

### 요구사항

1. 썸네일 3개 이상  
2. 클릭 시 `$("#big").attr("src", $(this).attr("src"))`  
3. (선택) 클릭한 썸네일에 `active` 테두리  

---

## 실습 4. 롤링 배너

**목표:** 가로로 나열된 배너가 일정 간격으로 한 칸씩 이동

### 요구사항

1. `ul` 안에 `li` 이미지(또는 색 박스) 여러 개  
2. `setInterval` + `animate({ marginLeft: … })`  
3. 한 칸 이동 후 첫 장을 맨 뒤로 `append` 하고 `marginLeft` 리셋  

**힌트:** 예전에 Vanilla로 만든 롤링을 jQuery `animate`로 다시 구현

---

## 실습 5. 회원가입 유효성 검사

**필드:** 아이디, 비밀번호, 비밀번호 확인, 이름, 이메일, 전화번호

### 요구사항

1. `submit` 시 `e.preventDefault()`  
2. 비어 있으면 해당 입력란 아래(또는 alert)에 오류 메시지  
3. 비밀번호 ≠ 비밀번호 확인 이면 오류  
4. 이메일 `@` 포함 여부 간단 체크  
5. 통과 시 `"가입 완료"` alert (또는 메시지)  

**사용:** `val()`, `on("submit")`, (선택) `blur`로 실시간 검사

## 실습 6. 동적 테이블

**목표:** 입력한 학생을 테이블에 행으로 추가

### 요구사항

1. 이름·점수 입력 + [추가] 버튼  
2. `$("tbody").append("<tr>…</tr>")`  
3. 각 행에 [삭제] 버튼 → **이벤트 위임**으로 `remove`  
4. `$("#list").on("click", ".del", …)`

## 실습 8. AJAX 게시판 ⭐⭐⭐

백엔드 없이 **JSONPlaceholder** 사용:

- 목록: `GET https://jsonplaceholder.typicode.com/posts?_limit=5`  
- (선택) 상세: `GET .../posts/{id}`  

### 요구사항

1. 페이지 로드 시 `$.ajax` 또는 `$.getJSON`으로 글 목록 받기  
2. `success`에서 `title`을 `ul`에 `append`  
3. 로딩 중 `"불러오는 중…"` 표시, 끝나면 제거  
4. `error` 시 오류 메시지  
5. (심화) 항목 클릭 시 body를 아래 영역에 표시  

```text
jQuery → AJAX → REST API(JSON) → 화면 append
```

Spring Boot 연동 시 URL만 `/api/posts` 등으로 바꾸면 됩니다.
