## 실습 1. 탭 메뉴 — 핵심 코드

```javascript
$(".tab").on("click", function () {
  var i = $(this).index();
  $(".tab").removeClass("active");
  $(this).addClass("active");
  $(".panel").hide().eq(i).show();
});
$(".panel").hide().eq(0).show();
$(".tab").eq(0).addClass("active");
```

## 실습 5. 회원가입 유효성

```javascript
$("#joinForm").on("submit", function (e) {
  e.preventDefault();
  var id = $("#userId").val().trim();
  var pw = $("#pw").val();
  var pw2 = $("#pw2").val();
  // ... 비어 있으면 return
  if (pw !== pw2) {
    alert("비밀번호가 다릅니다");
    return;
  }
  if ($("#email").val().indexOf("@") < 0) {
    alert("이메일 형식 오류");
    return;
  }
  alert("가입 완료");
});
```

## 실습 6. 동적 테이블

```javascript
$("#addBtn").on("click", function () {
  var name = $("#name").val();
  var score = $("#score").val();
  $("#tbody").append(
    "<tr><td>" + name + "</td><td>" + score +
    "</td><td><button class='del'>삭제</button></td></tr>"
  );
});

$("#tbody").on("click", ".del", function () {
  $(this).closest("tr").remove();
});
```

## 실습 7. 전체 선택 체크박스

```javascript
$("#all").on("click", function () {
  $("input[name=hobby]").prop("checked", this.checked);
});

$("input[name=hobby]").on("click", function () {
  var all = $("input[name=hobby]").length;
  var checked = $("input[name=hobby]:checked").length;
  $("#all").prop("checked", all === checked);
});
```

→ `examples/07-전체선택체크박스.html`

## 실습 8. AJAX 게시판

```javascript
$("#msg").text("불러오는 중…");
$.ajax({
  url: "https://jsonplaceholder.typicode.com/posts?_limit=5",
  type: "GET",
  dataType: "json",
  success: function (data) {
    $("#msg").text("");
    $.each(data, function (i, post) {
      $("#list").append(
        "<li data-id='" + post.id + "'>" + post.title + "</li>"
      );
    });
  },
  error: function () {
    $("#msg").text("오류가 발생했습니다");
  }
});

$("#list").on("click", "li", function () {
  var id = $(this).data("id");
  $.getJSON("https://jsonplaceholder.typicode.com/posts/" + id, function (post) {
    $("#detail").html("<h3>" + post.title + "</h3><p>" + post.body + "</p>");
  });
});
```

→ `examples/08-AJAX게시판.html`

> Spring Boot 연동 시 `url`만 `/api/posts` 등으로 교체하면 됩니다.

## attr vs prop 한줄

- `attr` → HTML 속성 (`src`, `href`)  
- `prop` → DOM 상태 (`checked`, `disabled`)
