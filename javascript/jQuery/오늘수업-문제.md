# 문제 1. 이벤트 연습

## HTML (제공)

```html
<p id="textZone">이벤트와 이벤트 핸들러를 연습합니다.</p>
<button id="btn1">click</button>
<button id="btn2">mouseover</button>
<button id="btn3">on</button>

<div id="listWrap">
  <h3>관련 사이트</h3>
  <ul class="list1" style="display:none;">
    <li><a href="#">list1</a></li>
    <li><a href="#">list2</a></li>
  </ul>
</div>

<a href="#" class="hover">hover</a>
```

## 할 일

| 번호 | 동작 |
|------|------|
| 1-1 | `#btn1` **클릭** → `#textZone` 글자색 `blue` |
| 1-2 | `#btn2` **mouseover** 와 **focus** → `#textZone` 배경 `yellow` |
| 1-3 | `#btn3`에 **`on('mouseover focus', …)`** → 글자색 `green`, 굵게 (`font-weight: bold`) — **체이닝** 사용 |
| 1-4 | `#listWrap` **mouseenter** → `.list1` 을 `display:block` / **mouseleave** → `none` |
| 1-5 | `.hover`에 **`.hover(함수1, 함수2)`** → 들어오면 `aqua`, 나가면 `red` |

### 서술

1. 예전 `bind` 대신 지금 쓰는 메서드 이름은?  
2. `mouseenter`가 메뉴에서 `mouseover`보다 유리한 이유는?  
3. `this`와 `$(this)`의 차이는?

# 문제 2. Effect

## HTML (요약)

```html
<button id="btn1">hide</button>
<button id="btn2">show</button>
<p class="box1">show/hide 대상</p>

<button id="btn3">toggle</button>
<p class="box2">toggle 대상</p>

<p>
  <button id="btn4">slideUp</button>
  <button id="btn5">slideDown</button>
  <button id="btn6">slideToggle</button>
</p>
<p>slide 대상 문단</p>

<p>
  <button id="btn7">fadeOut</button>
  <button id="btn8">fadeIn</button>
  <button id="btn9">fadeToggle</button>
</p>
<p>fade 대상 문단</p>

<p>
  <button id="btn10">fadeTo(0.3)</button>
  <button id="btn11">fadeTo(1)</button>
</p>
<p>fadeTo 대상 문단</p>
```

## 할 일

| 번호 | 동작 |
|------|------|
| 2-1 | `#btn1` → `.box1` **hide("slow")** |
| 2-2 | `#btn2` → `.box1` **show(1000)** (1초) |
| 2-3 | `#btn3` → `.box2` **toggle(500)** |
| 2-4 | `#btn4`~`#btn6` → `$(this).parent().next()` 에 각각 **slideUp(500)** / **slideDown("fast")** / **slideToggle("fast")** |
| 2-5 | `#btn7`~`#btn9` → 같은 방식으로 **fadeOut(1000)** / **fadeIn("slow")** / **fadeToggle("normal")** |
| 2-6 | `#btn10` → **fadeTo("slow", 0.3)** / `#btn11` → **fadeTo("slow", 1)** |

### 서술

4. `$(this).parent().next()` 가 가리키는 요소는 HTML에서 어디인가?  
5. `"slow"` / `1000` 의 의미 차이는?

# 문제 3. animate

## HTML · CSS

```html
<style>
  #box1 {
    width: 100px; height: 100px; background: #f00;
    position: relative;
  }
</style>
<div id="box1">박스</div>
```

## 할 일

페이지 로드 시 `#box1`에 **animate 두 번 체이닝**

1. 2초(`2000`): `left: 500px`, `width·height: 200px`, `opacity: 0.5`  
2. 이어서 1초(`1000`): `left: 0`, `width·height: 100px`, `opacity: 1`  

### 서술

6. `position: relative`가 없으면 `left` 애니메이션이 잘 안 보이는 이유는?  
7. `.animate().animate()` 는 동시에 실행되나, 순서대로 실행되나?

# 문제 4. 세로 메뉴

## HTML (요약)

```html
<ul class="m_menu">
  <li>
    <a href="#">회사소개</a>
    <ul class="sub">…</ul>
  </li>
  <li>
    <a href="#">제품소개</a>
    <ul class="sub">…</ul>
  </li>
  <!-- 커뮤니티, 다운로드 동일 -->
</ul>
```

## 할 일

1. 모든 `.sub` **숨기기** (`hide`)  
2. **첫 번째** `.sub`만 `show`  
3. `.m_menu > li > a` **클릭** 시  
   - `e.preventDefault()` 로 링크 기본 동작 막기  
   - 클릭한 `a`의 다음 `.sub`의 `display`를 `status`에 저장  
   - `status == "none"` 이면 → 모든 `.sub` `slideUp` 후, 내 `.sub`만 `slideDown`  
   - 아니면(이미 열림) → 모든 `.sub` `slideUp`  

### 서술

8. `$(".sub").eq(0).show()` 와 `$(".m_menu li:first ul").show()` 는 같은가?  
9. `e.preventDefault()`를 쓰는 이유는?

## 동작 요구

1. `.ham` 클릭 → `.ham`에 `on` 토글, `nav`에 `active` 토글
