## 문제 1. 이벤트 — 코드

```javascript
$(function () {
  $("#btn1").click(function () {
    $("#textZone").css("color", "blue");
  });

  $("#btn2").mouseover(function () {
    $("#textZone").css("background-color", "yellow");
  });
  $("#btn2").focus(function () {
    $("#textZone").css("background-color", "yellow");
  });

  $("#btn3").on("mouseover focus", function () {
    $("#textZone").css("color", "green").css("font-weight", "bold");
  });

  $("#listWrap").mouseenter(function () {
    $(".list1").css("display", "block");
  });
  $("#listWrap").mouseleave(function () {
    $(".list1").css("display", "none");
  });

  $(".hover").hover(
    function () {
      $(this).css("color", "aqua");
    },
    function () {
      $(this).css("color", "red");
    }
  );
});
```

### 서술 답

1. **`on`** (예: `.on("click", fn)`)  
2. 자식으로 마우스가 들어가도 **enter가 다시 발생하지 않아** 메뉴가 깜빡이지 않음  
3. **`this`** = DOM 객체 / **`$(this)`** = jQuery 객체 (`.css()` 등 사용)

## 문제 2. Effect — 코드

```javascript
$(function () {
  $("#btn1").click(function () {
    $(".box1").hide("slow");
  });
  $("#btn2").click(function () {
    $(".box1").show(1000);
  });
  $("#btn3").click(function () {
    $(".box2").toggle(500);
  });

  $("#btn4").click(function () {
    $(this).parent().next().slideUp(500);
  });
  $("#btn5").click(function () {
    $(this).parent().next().slideDown("fast");
  });
  $("#btn6").click(function () {
    $(this).parent().next().slideToggle("fast");
  });

  $("#btn7").click(function () {
    $(this).parent().next().fadeOut(1000);
  });
  $("#btn8").click(function () {
    $(this).parent().next().fadeIn("slow");
  });
  $("#btn9").click(function () {
    $(this).parent().next().fadeToggle("normal");
  });

  $("#btn10").click(function () {
    $(this).parent().next().fadeTo("slow", 0.3);
  });
  $("#btn11").click(function () {
    $(this).parent().next().fadeTo("slow", 1);
  });
});
```

### 서술 답

4. 버튼을 감싼 `<p>`의 **다음 형제** `<p>` (효과 대상 문단)  
5. `"slow"` = jQuery 기본 느린 속도 키워드 / `1000` = **1000ms = 1초**

## 문제 3. animate — 코드

```javascript
$(function () {
  $("#box1")
    .animate(
      {
        left: "500px",
        width: "200px",
        height: "200px",
        opacity: 0.5
      },
      2000
    )
    .animate(
      {
        left: "0",
        width: "100px",
        height: "100px",
        opacity: 1
      },
      1000
    );
});
```

### 서술 답

6. static 요소는 `left`가 레이아웃에 거의 안 먹혀 **움직여 보이지 않음**. `relative`/`absolute` 필요  
7. **순서대로**(큐에 쌓여 첫 애니 끝난 뒤 다음)

## 문제 4. 세로 메뉴 — 코드

```javascript
$(function () {
  $(".sub").hide();
  $(".sub").eq(0).show();

  $(".m_menu > li > a").click(function (e) {
    e.preventDefault();

    var status = $(this).next(".sub").css("display");

    if (status == "none") {
      $(".sub").slideUp();
      $(this).next(".sub").slideDown();
    } else {
      $(".sub").slideUp();
    }
  });
});
```

### 서술 답

8. **같다**(첫 번째 `li` 안의 서브 메뉴를 보이는 것). 선택자만 다른 표현  
9. `href="#"` 클릭 시 **페이지 맨 위로 튀거나** 이동하는 기본 동작을 막기 위함

## 문제 5. 햄버거 — 코드

```javascript
$(function () {
  $(".ham").click(function () {
    $(".ham").toggleClass("on");
    $("nav").toggleClass("active");
  });

  $(".sub").hide();

  $("nav > ul > li > a").click(function () {
    var status = $(this).next(".sub").css("display");
    if (status == "none") {
      $(".sub").slideUp(500);
      $(this).next(".sub").slideDown(500);
    } else {
      $(".sub").slideUp(500);
    }
    return false;
  });
});
```

### 서술 답

10. `active`가 붙으면 CSS `nav.active { right: 0 }`이 적용되어 **화면 밖(`-200px`)에 있던 메뉴가 들어옴**

## 문제 6. dl/dt/dd — 코드

전문: [아코디언-dl-정답.md](./아코디언-dl-정답.md)

```javascript
$("dd").hide();
$("dd").eq(0).show();
$("dt").eq(0).addClass("selected");

$("dl dt").click(function () {
  if ($(this).next("dd").css("display") === "none") {
    $("dd").slideUp("slow");
    $(this).next().slideDown("slow");
    $("dl dt").removeClass("selected");
    $(this).addClass("selected");
  }
});

$("dl dt").mouseover(function () {
  $(this).addClass("over");
});
$("dl dt").mouseout(function () {
  $(this).removeClass("over");
});
```
