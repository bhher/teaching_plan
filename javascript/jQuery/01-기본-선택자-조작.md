## 1. jQuery 기본 개념 ⭐

### jQuery란?

JavaScript를 **짧게·쉽게** 쓰게 해 주는 **라이브러리**입니다.  
선택자, DOM, 이벤트, 애니메이션, AJAX를 통일된 `$()` 문법으로 다룹니다.

### JavaScript와 관계

```text
JavaScript (언어)
    └── jQuery (그 위에 올라간 도구/라이브러리)
```

jQuery로 쓴 코드도 결국 브라우저에서 JS로 실행됩니다.

### 장점

- CSS 선택자로 요소를 쉽게 찾음  
- 브라우저 차이 완화 (특히 구버전 IE 시대)  
- 체이닝으로 코드가 짧아짐  
- AJAX·Effect가 간단  

### CDN 연결

```html
<script src="https://code.jquery.com/jquery-3.7.1.min.js"></script>
```

### `$()` / `$(function(){})`

```javascript
// DOM이 준비된 뒤 실행 (= document.ready)
$(function () {
  console.log("실행");
});

// 같은 의미
$(document).ready(function () {
  console.log("실행");
});
```

`$("선택자")` → 해당 요소들을 담은 **jQuery 객체**를 반환합니다.

## 2. 선택자 ⭐⭐⭐

| 종류 | 예 | 의미 |
|------|-----|------|
| 태그 | `$("p")` | 모든 p |
| 클래스 | `$(".box")` | class="box" |
| 아이디 | `$("#title")` | id="title" |
| 후손 | `$("ul li")` | ul 안 모든 li |
| 자식 | `$("ul > li")` | 직계 li만 |
| 속성 | `$("input[type=text]")` | type=text |
| 속성 존재 | `$("a[href]")` | href 있는 a |
| 여러 개 | `$("p, div")` | p와 div |
| 첫/끝 | `$("li:first")` `$("li:last")` | |
| 인덱스 | `$("li:eq(2)")` | 0부터 3번째 |
| n번째 자식 | `$("li:nth-child(2)")` | CSS와 동일(1부터) |

```javascript
$("li:eq(2)").css("color", "red");
```

## 3. jQuery 객체 vs DOM 객체 ⭐⭐⭐

```javascript
let $box = $(".box");                    // jQuery 객체
let box = document.querySelector(".box"); // DOM 객체
```

| | jQuery | DOM |
|--|--------|-----|
| 메서드 | `.css()` `.html()` `.on()` | `.style` `.innerHTML` `.addEventListener` |
| 여러 개 | 컬렉션처럼 한 번에 조작 | `querySelectorAll` + 반복 |

### 변환

```javascript
// jQuery → DOM
let el = $(".box")[0];
let el2 = $(".box").get(0);

// DOM → jQuery
let $el = $(document.querySelector(".box"));
let $el2 = $(el);
```

## 4. 내용 변경 ⭐⭐

```javascript
$("#box").html("<b>Hello</b>");  // HTML 포함 (태그가 먹힘)
$("#box").text("Hello");         // 텍스트만 (태그는 글자로)

let t = $("#box").text();        // 가져오기
let h = $("#box").html();

$("input").val();                // 값 읽기
$("input").val("홍길동");        // 값 쓰기
```

| 메서드 | 대상 | 태그 |
|--------|------|------|
| `html()` | 요소 내용 | 해석함 |
| `text()` | 요소 내용 | 이스케이프 |
| `val()` | input/select/textarea | — |

## 5. 속성(attribute) ⭐⭐⭐

```javascript
$("img").attr("src");                    // 읽기
$("img").attr("src", "image.jpg");       // 쓰기
$("img").attr({ src: "a.jpg", alt: "사진" });
$("img").removeAttr("alt");
```

체크박스 `checked` / `disabled`는 **27. attr vs prop** 참고 (`prop` 권장).

## 6. CSS 조작 ⭐⭐⭐

```javascript
$("#box").css("color", "red");

$("#box").css({
  color: "red",
  backgroundColor: "yellow",  // CSS: background-color → camelCase
  fontSize: "20px"
});

let color = $("#box").css("color");  // 읽기 (rgb로 나올 수 있음)
```

## 7. 클래스 조작 ⭐⭐⭐

```javascript
$("#box").addClass("active");
$("#box").removeClass("active");
$("#box").toggleClass("active");

if ($("#box").hasClass("active")) {
  console.log("active 있음");
}
```

탭·메뉴·모달에서 **가장 많이** 씁니다.

## 8. 크기 ⭐⭐

```javascript
$("#box").width();        // content
$("#box").height();
$("#box").innerWidth();   // + padding
$("#box").innerHeight();
$("#box").outerWidth();   // + border
$("#box").outerWidth(true); // + margin
```

## 9. 위치 ⭐⭐

```javascript
let pos = $("#box").offset();   // 문서(document) 기준
console.log(pos.top, pos.left);

let p = $("#box").position();   // offset 부모 기준
```

| jQuery | Vanilla 비슷한 것 |
|--------|-------------------|
| `offset()` | 문서 기준 좌표 (스크롤 포함 계산) |
| — | `getBoundingClientRect()` → **뷰포트** 기준 |

```javascript
let r = document.querySelector("#box").getBoundingClientRect();
console.log(r.top, r.left);  // 화면 기준
```

## 미니 예제 (복사해서 실행)

```html
<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8" />
  <title>01 기본</title>
  <style>
    .box { width: 120px; height: 80px; background: #eee; margin: 8px; }
    .active { background: tomato; color: #fff; }
  </style>
</head>
<body>
  <div id="title" class="box">제목</div>
  <input type="text" id="name" />
  <button id="btn">적용</button>

  <script src="https://code.jquery.com/jquery-3.7.1.min.js"></script>
  <script>
    $(function () {
      $("#btn").on("click", function () {
        $("#title")
          .html("<b>" + $("#name").val() + "</b>")
          .addClass("active")
          .css("fontSize", "18px");
      });
    });
  </script>
</body>
</html>
```
