## 프로젝트 개요

성남시청 슬라이더는 동일한 디자인과 기능을 가진 슬라이더를 다양한 라이브러리로 구현한 교육용 프로젝트입니다.

### 프로젝트 목적
- 다양한 슬라이더 라이브러리 비교 학습
- 각 라이브러리의 특징과 사용법 이해
- 실무 적용 가능한 슬라이더 구현

### 구현된 버전
1. **Vanilla JS** (순수 JavaScript) - `성남시청슬라이드/`
2. **bxSlider** - `성남시청슬라이드_bxslider/`
3. **Slick Slider** - `성남시청슬라이드_slick/` ✅ **최종 버전**
4. **Swiper** - `성남시청슬라이드_swiper/`

## 버전별 구현 비교

### 1. Vanilla JS 버전 (순수 JavaScript)

**특징:**
- jQuery 없이 순수 JavaScript로 구현
- 완전한 제어 가능
- 파일 크기 작음

**코드 구조:**
```javascript
$(function(){
  var popCurrent = 0;
  var popIndex = 0;
  var total = $('.pop_slide li').length;
  
  // 다음 버튼
  pop_next.click(function(){
    popIndex = popCurrent + 1;
    if(popIndex == total) popIndex = 0;
    // 애니메이션 처리
    pop_cu.css('left',0).stop().animate({'left':'-100%'});
    pop_ne.css('left','100%').stop().animate({'left':'0'});
    popCurrent = popIndex;
    $('.slide_but p strong').text(popIndex+1);
  });
  
  // 자동 재생
  function popAuto(){
    id = setInterval(function(){
      pop_next.trigger('click');
    },3000);
  }
});
```

**장점:**
- ✅ 의존성 없음
- ✅ 완전한 제어
- ✅ 파일 크기 작음

**단점:**
- ❌ 코드가 길고 복잡
- ❌ 직접 구현 필요

### 2. bxSlider 버전

**특징:**
- jQuery 기반
- 간단한 설정
- 안정적인 동작

**코드 구조:**
```javascript
$(function(){
  var slider = $('.bxslider').bxSlider({
    mode: 'horizontal',
    speed: 500,
    auto: true,
    autoHover: true,
    pause: 3000,
    controls: false,
    pager: false,
    onSlideAfter: function($slideElement, oldIndex, newIndex){
      $('#current-slide').text(newIndex + 1);
    }
  });

  var totalSlides = slider.getSlideCount();
  $('#total-slides').text(totalSlides);
  
  // 버튼 제어
  $('.prev').click(function(e){
    slider.goToPrevSlide();
  });
});
```

**장점:**
- ✅ 설정 간단
- ✅ 안정적
- ✅ 다양한 옵션

**단점:**
- ❌ jQuery 의존성
- ❌ 파일 크기 큼

### 3. Slick Slider 버전 (최종) ✅

**특징:**
- jQuery 기반
- 강력한 기능
- 반응형 지원
- **현재 사용 중인 버전**

**코드 구조:**
```javascript
$(function(){
  var slider = $('.slick-slider').slick({
    autoplay: true,
    arrows: false,
    dots: false,
  });

  // 초기화 이벤트
  slider.on('init', function(event, slick){
    $('#total-slides').text(slick.slideCount);
    $('#current-slide').text(slick.currentSlide + 1);
  });

  // 슬라이드 변경 이벤트
  slider.on('afterChange', function(event, slick, currentSlide){
    $('#current-slide').text(slick.currentSlide + 1);
  });

  // 버튼 제어
  $('.prev').click(function(e){
    slider.slick('slickPrev');
  });
  
  $('.next').click(function(e){
    slider.slick('slickNext');
  });
  
  // 일시정지/재생
  $('.pause').click(function(e){
    if(!isPaused){
      slider.slick('slickPause');
      $(this).addClass('on');
      isPaused = true;
    } else {
      slider.slick('slickPlay');
      $(this).removeClass('on');
      isPaused = false;
    }
  });
});
```

**장점:**
- ✅ 강력한 기능
- ✅ 반응형 지원
- ✅ 이벤트 리스너 방식으로 안정적
- ✅ 숫자 카운팅 정확히 작동

**단점:**
- ❌ jQuery 의존성
- ❌ 파일 크기 큼

### 4. Swiper 버전

**특징:**
- jQuery 불필요 (순수 JavaScript)
- 모던한 API
- 다양한 효과 지원

**코드 구조:**
```javascript
document.addEventListener('DOMContentLoaded', function(){
  var swiper = new Swiper('.swiper', {
    slidesPerView: 1,
    autoplay: {
      delay: 3000,
      pauseOnMouseEnter: true
    },
    on: {
      init: function() {
        var totalSlides = this.slides.length;
        document.getElementById('total-slides').textContent = totalSlides;
      },
      slideChange: function() {
        var currentIndex = this.realIndex + 1;
        document.getElementById('current-slide').textContent = currentIndex;
      }
    }
  });
  
  // 버튼 제어
  document.querySelector('.prev').addEventListener('click', function(e){
    swiper.slidePrev();
  });
});
```

**장점:**
- ✅ jQuery 불필요
- ✅ 모던한 API
- ✅ 다양한 효과

**단점:**
- ❌ 파일 크기 큼
- ❌ 학습 곡선 있음

## 주요 기능

### 1. 자동 재생
- 3초 간격으로 자동 슬라이드 변경
- 마우스 호버 시 일시정지 (옵션)

### 2. 수동 제어
- **이전 버튼**: 이전 슬라이드로 이동
- **다음 버튼**: 다음 슬라이드로 이동
- **일시정지/재생 버튼**: 자동 재생 제어

### 3. 슬라이드 카운터
- 현재 슬라이드 번호 표시 (예: 1 / 11)
- 실시간 업데이트

### 4. 디자인
- 고정된 크기 (718px × 385px)
- 이미지 전체 화면 표시
- 컨트롤 바 (파란색 배경)

```html

      <p><strong id="current-slide">1</strong> / <span id="total-slides">11</span></p>
      <p>
        <a href="#" class="prev"></a>
        <a href="#" class="pause"></a>
        <a href="#" class="next"></a>
      </p>
    </div>
  </article>
</section>
```

#### JavaScript 초기화
```javascript
$(function(){
  // 슬라이더 초기화
  var slider = $('.slick-slider').slick({
    autoplay: true,      // 자동 재생
    arrows: false,       // 기본 화살표 숨김
    dots: false,         // 기본 점 네비게이션 숨김
  });
```

#### 이벤트 리스너 (핵심)
```javascript
  // 초기화 이벤트
  slider.on('init', function(event, slick){
    // 전체 슬라이드 개수 표시
    $('#total-slides').text(slick.slideCount);
    // 초기 슬라이드 번호 표시
    $('#current-slide').text(slick.currentSlide + 1);
  });

  // 슬라이드 변경 이벤트
  slider.on('afterChange', function(event, slick, currentSlide){
    // 현재 슬라이드 번호 업데이트
    $('#current-slide').text(slick.currentSlide + 1);
  });
```

**핵심 포인트:**
- `slick.currentSlide`: 현재 슬라이드 인덱스 (0부터 시작)
- `slick.slideCount`: 전체 슬라이드 개수
- `+ 1`: 인덱스를 번호로 변환 (1부터 시작)

#### 버튼 제어
```javascript
  // 이전 버튼

    e.preventDefault();
    slider.slick('slickNext');
    return false;
  });

  // 일시정지/재생 버튼

    e.preventDefault();

      slider.slick('slickPlay');
```

## 문제 해결 과정

### 문제 1: 숫자 카운팅이 작동하지 않음

**원인:**
- 콜백 함수의 매개변수 형식 오류
- 이벤트 리스너 방식 미사용

**해결:**
```javascript
// ❌ 잘못된 방법
onAfterChange: function(slick, currentSlide){
  $('#current-slide').text(currentSlide + 1);
}

// ✅ 올바른 방법
slider.on('afterChange', function(event, slick, currentSlide){
  $('#current-slide').text(slick.currentSlide + 1);
});
```

**핵심 차이점:**
- 이벤트 리스너 방식 사용 (`slider.on()`)
- `slick.currentSlide` 사용 (매개변수 `currentSlide` 대신)
- `init` 이벤트로 초기화 시 숫자 표시

### 문제 2: 초기화 시 숫자가 표시되지 않음

**해결:**
```javascript
slider.on('init', function(event, slick){
  $('#total-slides').text(slick.slideCount);
  $('#current-slide').text(slick.currentSlide + 1);
});
```

### 문제 3: 버튼 클릭 시 숫자가 업데이트되지 않음

**해결:**
- `afterChange` 이벤트가 자동으로 발생하므로 별도 처리 불필요
- Slick이 내부적으로 이벤트를 발생시킴

## 학습 포인트

### 1. 이벤트 리스너 vs 콜백 함수
- **이벤트 리스너**: `slider.on('afterChange', ...)` - 더 안정적
- **콜백 함수**: `onAfterChange: function(...)` - 간단하지만 제한적

### 2. Slick 객체의 속성
- `slick.currentSlide`: 현재 슬라이드 인덱스
- `slick.slideCount`: 전체 슬라이드 개수
- `slick.options`: 설정 옵션

### 3. 메서드 호출
- `slider.slick('slickPrev')`: 이전 슬라이드
- `slider.slick('slickNext')`: 다음 슬라이드
- `slider.slick('slickPause')`: 일시정지
- `slider.slick('slickPlay')`: 재생
