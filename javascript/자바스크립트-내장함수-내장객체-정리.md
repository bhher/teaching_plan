# 자바스크립트 내장 함수 · 내장 객체 정리

자바스크립트가 **처음부터 제공하는** 함수와 객체를 수업용으로 모았습니다.  
직접 `function`으로 만들 필요 없이, 이름만 호출하면 됩니다.

> **구분**  
> - **내장 함수(전역 함수)**: `parseInt("10")` 처럼 **바로 호출**  
> - **내장 객체**: `Math.round(3.7)`, `"hello".toUpperCase()` 처럼 **객체.메서드**  
> - **브라우저 전역**: `alert`, `setTimeout` — 브라우저에만 있음 (Node.js에는 없음)

배열·객체 상세는 기존 장을 함께 보세요.  
→ [9장_배열.md](./9장_배열.md) · [10장_객체.md](./10장_객체.md) · [4장_데이터_타입.md](./4장_데이터_타입.md)

## 1. 한눈에 보기

| 종류 | 예시 | 언제 쓰나 |
|------|------|-----------|
| 전역 함수 | `parseInt`, `Number`, `isNaN` | 문자열 ↔ 숫자, 유효성 검사 |
| `Math` | `Math.floor`, `Math.random` | 반올림, 난수, 최댓값 |
| `String` | `"ab".split()`, `.includes()` | 자르기, 찾기, 대소문자 |

| `Date` | `new Date()`, `.getFullYear()` | 날짜·시간 |
| `JSON` | `JSON.parse`, `JSON.stringify` | 객체 ↔ 문자열 (API) |
| `Object` | `Object.keys()` | 객체의 키/값 꺼내기 |
| 브라우저 | `setTimeout`, `alert` | 지연 실행, 알림 |

## 2. 전역 함수 (내장 함수)

어디에도 붙이지 않고 **그냥 호출**합니다.

### 형변환

```javascript
Number("10");      // 10
Number("10.5");    // 10.5
Number("10px");    // NaN   ← 전체가 숫자여야 함

parseInt("10px");  // 10    ← 앞에서부터 숫자만
parseInt("10.9");  // 10    ← 정수만
parseFloat("10.9"); // 10.9
parseInt("abc");   // NaN

String(100);       // "100"
Boolean(1);        // true
Boolean(0);        // false
Boolean("");       // false
```

| 함수 | 역할 | 주의 |
|------|------|------|
| `Number(값)` | 숫자로 변환 | `"10px"` → `NaN` |
| `parseInt(값)` | 정수로 변환 | `"10px"` → `10`, 소수점 버림 |
| `parseFloat(값)` | 실수로 변환 | `"3.14abc"` → `3.14` |
| `String(값)` | 문자열로 | `100` → `"100"` |
| `Boolean(값)` | true/false | `0`, `""`, `null`, `undefined`, `NaN` → `false` |

```javascript
// 진법 (2번째 인자는 기수)
parseInt("1010", 2);   // 10 (2진수)
parseInt("FF", 16);    // 255 (16진수)
```

### NaN · 유한수 검사

```javascript
isNaN("hello");           // true  (숫자가 아님)
isNaN(10);                // false
Number.isNaN("hello");    // false ← 진짜 NaN만 true (권장)
Number.isNaN(NaN);        // true

isFinite(10);             // true
isFinite(Infinity);       // false
```

> `isNaN("hello")`는 먼저 숫자로 바꾼 뒤 검사해서 `true`가 됩니다.  
> **진짜 NaN인지** 보려면 `Number.isNaN()`을 쓰세요.

### URI 인코딩 (주소에 한글 넣을 때)

```javascript
encodeURIComponent("자바 스크립트");
// "%EC%9E%90%EB%B0%94%20%EC%8A%A4%ED%81%AC%EB%A6%BD%ED%8A%B8"

decodeURIComponent("%EC%9E%90%EB%B0%94");  // "자바"
```

| 함수 | 용도 |
|------|------|
| `encodeURIComponent` | 쿼리스트링 값 (권장) |
| `decodeURIComponent` | 다시 원래 문자로 |
| `encodeURI` | URL 전체 (/, ? 는 그대로) |

## 3. 브라우저 전역 함수

웹 페이지에서만 됩니다. `window.` 를 생략한 것과 같습니다.

```javascript
alert("저장되었습니다");           // 알림만
confirm("삭제할까요?");            // 확인/취소 → true / false
prompt("이름을 입력하세요");       // 입력창 → 문자열 또는 null

setTimeout(함수, 밀리초);          // 한 번 지연 실행
setInterval(함수, 밀리초);         // 반복 실행
clearTimeout(id);
clearInterval(id);
```

```javascript
// 2초 후 한 번
setTimeout(() => {
    console.log("2초 지남");
}, 2000);

// 1초마다 (나중에 멈추려면 id 저장)
const id = setInterval(() => {
    console.log("틱");
}, 1000);

// clearInterval(id);
```

## 4. Math 객체

수학 계산. **`new` 하지 않고** `Math.` 로만 씁니다.

```javascript
Math.round(3.5);    // 4   반올림
Math.floor(3.9);    // 3   내림 (소수점 버림)
Math.ceil(3.1);     // 4   올림
Math.trunc(3.9);    // 3   정수 부분만
Math.abs(-7);       // 7   절댓값

Math.max(3, 9, 1);  // 9
Math.min(3, 9, 1);  // 1
Math.max(...[3, 9, 1]);  // 배열이면 전개 연산자

Math.pow(2, 10);    // 1024  (2 ** 10 과 같음)
Math.sqrt(16);      // 4     제곱근

Math.random();      // 0 이상 1 미만
```

### 난수 공식 (자주 씀)

```javascript
// 0 ~ 9 정수
Math.floor(Math.random() * 10);

// 1 ~ 100 정수
Math.floor(Math.random() * 100) + 1;

// min ~ max 정수 (둘 다 포함)
function randomInt(min, max) {
    return Math.floor(Math.random() * (max - min + 1)) + min;
}
```

| 메서드 | 의미 |
|--------|------|
| `round` | 반올림 |
| `floor` | 내림 |
| `ceil` | 올림 |
| `abs` | 절댓값 |
| `max` / `min` | 최댓값 / 최솟값 |
| `random` | 난수 |
| `pow` / `sqrt` | 거듭제곱 / 제곱근 |
| `PI` | 원주율 `3.14159...` |

## 5. String (문자열)

문자열은 원시값이지만, 메서드를 호출하면 **잠깐 객체처럼** 동작합니다.

```javascript
let s = "Hello JavaScript";

s.length;                 // 16
s.toUpperCase();          // "HELLO JAVASCRIPT"
s.toLowerCase();          // "hello javascript"

s.includes("Java");       // true
s.indexOf("Java");        // 6  (없으면 -1)
s.startsWith("Hello");    // true
s.endsWith("pt");         // true

s.slice(0, 5);            // "Hello"
s.substring(0, 5);        // "Hello"
s.replace("Java", "Type"); // "Hello TypeScript" (첫 번째만)
s.replaceAll("a", "A");   // 전부 바꿈 (비교적 최신)

s.trim();                 // 앞뒤 공백 제거
s.split(" ");             // ["Hello", "JavaScript"]
s.repeat(2);
s.charAt(0);              // "H"
s[0];                     // "H" (대괄호 접근)
```

### 템플릿 리터럴

```javascript
const name = "홍길동";
const age = 20;
`이름: ${name}, 나이: ${age}`;
```

> 문자열 메서드는 **원본을 바꾸지 않고** 새 문자열을 반환합니다.

## 6. Number

```javascript
let n = 123.456;

n.toFixed(2);          // "123.46"  ← 문자열!
n.toString();          // "123.456"
n.toString(16);        // 16진수 문자열

Number.isInteger(10);  // true
Number.isNaN(NaN);     // true
Number.parseInt("10"); // parseInt와 같음
```

```javascript
// 금액 표시: toFixed 후 다시 숫자로 쓰려면 Number()
const price = 123.456;
Number(price.toFixed(0));  // 123
```

| 값 | 의미 |
|----|------|
| `Number.MAX_SAFE_INTEGER` | 안전한 최대 정수 |
| `Infinity` | 무한대 |
| `NaN` | 숫자가 아님 |

## 7. Array (배열) — 자주 쓰는 것만

자세한 설명은 [9장_배열.md](./9장_배열.md)를 보세요.

```javascript
const arr = [3, 1, 4, 1, 5];

arr.push(9);           // 끝에 추가 (원본 변경)
arr.pop();             // 끝 제거
arr.unshift(0);        // 앞에 추가
arr.shift();           // 앞 제거

arr.includes(4);       // true
arr.indexOf(1);        // 1
arr.join("-");         // "3-1-4-1-5"
arr.slice(0, 2);       // [3, 1]  원본 유지
arr.concat([9]);       // 합친 새 배열

arr.forEach(n => console.log(n));
arr.map(n => n * 2);           // [6, 2, 8, 2, 10]
arr.filter(n => n > 3);        // [4, 5]
arr.find(n => n > 3);          // 4  (첫 번째만)
arr.some(n => n > 4);          // true
arr.every(n => n > 0);         // true
arr.reduce((합, n) => 합 + n, 0);

arr.sort((a, b) => a - b);     // 숫자 오름차순 (원본 변경)
[...arr].sort((a, b) => a - b); // 복사본 정렬

Array.isArray(arr);            // true
Array.from("abc");             // ["a", "b", "c"]
```

### 원본을 바꾸는지

| 원본 변경 | 새 배열/값 반환 |
|-----------|-----------------|
| `push` `pop` `shift` `unshift` | `map` `filter` `slice` `concat` |
| `sort` `reverse` `splice` | `join` `find` `includes` |

## 8. Date (날짜)

```javascript
const now = new Date();
const d = new Date(2026, 7, 18);       // 월은 0부터 → 8월 18일
const d2 = new Date("2026-08-18");

now.getFullYear();   // 2026
now.getMonth();      // 0~11  (1월이 0)
now.getDate();       // 일 (1~31)
now.getDay();        // 요일 (0=일 ~ 6=토)
now.getHours();
now.getMinutes();
now.getSeconds();

now.getTime();       // 1970-01-01부터 밀리초
Date.now();          // 지금 밀리초 (객체 없이)
```

```javascript
// 오늘 날짜 문자열
const t = new Date();
const ymd = `${t.getFullYear()}-${t.getMonth() + 1}-${t.getDate()}`;

// n일 뒤
const later = new Date();
later.setDate(later.getDate() + 7);
```

> `getMonth()`는 **0이 1월**입니다. 화면에 찍을 때 `+ 1` 하세요.

## 9. JSON

서버와 데이터를 주고받을 때 쓰는 **문자열 형식**입니다.

```javascript
const user = { name: "홍길동", age: 25 };

const str = JSON.stringify(user);
// '{"name":"홍길동","age":25}'   ← 전송·저장용 문자열

const obj = JSON.parse(str);
// { name: "홍길동", age: 25 }    ← 다시 객체
```

| 메서드 | 방향 |
|--------|------|
| `JSON.stringify(객체)` | 객체 → 문자열 |
| `JSON.parse(문자열)` | 문자열 → 객체 |

```javascript
// 보기 좋게 (들여쓰기 2칸)
JSON.stringify(user, null, 2);
```

> 함수, `undefined`는 JSON에 안 들어갑니다. `Date`는 문자열로 바뀝니다.

## 10. Object

```javascript
const user = { name: "홍길동", age: 25 };

Object.keys(user);     // ["name", "age"]
Object.values(user);   // ["홍길동", 25]
Object.entries(user);  // [["name", "홍길동"], ["age", 25]]

Object.assign({}, user, { city: "서울" });  // 합친 새 객체
const copy = { ...user };                   // 전개로 얕은 복사
```

```javascript
for (const key of Object.keys(user)) {
    console.log(key, user[key]);
}
```

## 11. 그 밖에 알아 두면 좋은 것

### Map · Set (ES6)

```javascript
const set = new Set([1, 2, 2, 3]);  // 중복 제거 → {1, 2, 3}
[...set];                           // [1, 2, 3]

const map = new Map();
map.set("name", "홍길동");
map.get("name");                    // "홍길동"
```

### 콘솔 (개발자 도구)

```javascript
console.log("일반");
console.table([{ a: 1 }, { a: 2 }]);
console.error("에러");
```

### 쓰지 말 것

- **`eval()`**: 문자열을 코드로 실행. 보안 위험.
- **`document.write()`**: 페이지를 덮어쓸 수 있음. DOM API 사용.

## 12. 실전에서 자주 묶이는 패턴

```javascript
// 1) 입력값 → 숫자
const n = Number(prompt("숫자를 입력하세요"));
if (Number.isNaN(n)) {
    alert("숫자가 아닙니다");
}

// 2) 배열에서 조건 걸러 합계
const scores = [70, 85, 90, 60];
const sum = scores.filter(s => s >= 80).reduce((a, b) => a + b, 0);

// 3) 1~6 주사위
const dice = Math.floor(Math.random() * 6) + 1;

// 4) API 응답 문자열 → 객체
const data = JSON.parse('{"ok":true}');

// 5) 2초 후 실행
setTimeout(() => console.log("완료"), 2000);
```

## 13. 치트시트

```javascript
// 형변환
Number("10")        parseInt("10px")     parseFloat("1.5")

// 수학
Math.round  Math.floor  Math.ceil  Math.abs

// 문자열
str.length  str.includes()  str.indexOf()

// 배열
arr.push/pop    arr.map    arr.filter

// JSON
```

### 한 줄 요약

> **전역 함수**는 바로 호출하고, **내장 객체**는 `Math.` / `"문자열".` / `[배열].` 뒤에 메서드를 붙인다.  
> 수업에서 가장 많이 쓰는 것은 **`parseInt` · `Math` · `String` · `Array` · `Date` · `JSON`** 이다.
