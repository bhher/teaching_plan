# 6장 조건문 정답

|------|------|------|

# 코드 작성 정답 (33~42)

## 33번. 홀짝 판별

```javascript
let num = 7;

if (num % 2 === 0) {
    console.log("짝수");
} else {
    console.log("홀수");
}
```

출력: `홀수`

---

## 34번. 학점

```javascript
let score = 92;

if (score >= 90) {
    console.log("A");
} else if (score >= 80) {
    console.log("B");
} else if (score >= 70) {
    console.log("C");
} else {
    console.log("F");
}
```

출력: `A`

---

## 35번. switch 요일

```javascript
let day = 2;
let name;

switch (day) {
    case 1:
        name = "월";
        break;
    case 2:
        name = "화";
        break;
    case 3:
        name = "수";
        break;
    default:
        name = "기타";
}

console.log(name);
```

출력: `화`

---

## 36번. 1부터 10까지 합

```javascript
let sum = 0;

for (let i = 1; i <= 10; i++) {
    sum += i;
}

console.log(sum); // 55
```

---

## 37번. 짝수만 출력

```javascript
for (let i = 1; i <= 10; i++) {
    if (i % 2 === 0) {
        console.log(i);
    }
}
```

출력: `2 4 6 8 10`

---

## 38번. while로 카운트

```javascript
let i = 1;

while (i <= 5) {
    console.log(i);
    i++;
}
```

출력: `1 2 3 4 5`

---

## 39번. 구구단 2단

```javascript
for (let i = 1; i <= 9; i++) {
    console.log(`2 x ${i} = ${2 * i}`);
}
```

---

## 40번. 더하기 함수

```javascript
function add(a, b) {
    return a + b;
}

console.log(add(10, 20)); // 30
```

---

## 41번. 화살표 함수

```javascript
const avg = (a, b, c) => (a + b + c) / 3;

console.log(avg(80, 90, 100)); // 90
```

---

## 42번. 함수 + 조건 + 반복

```javascript
function printEven(n) {
    for (let i = 1; i <= n; i++) {
        if (i % 2 === 0) {
            console.log(i);
        }
    }
}

printEven(10);
```

출력: `2 4 6 8 10`

| 장 | 핵심 |

## 자주 헷갈리는 포인트

```javascript
// 1) else if 순서가 중요
// 90 이상 검사를 80 이상보다 먼저 해야 A가 나옴

// 2) switch는 break 필수
switch (x) {
    case 1:
        console.log("1");
        break; // 없으면 다음 case까지 실행
}

// 3) for...in vs for...of
let arr = ["a", "b"];
for (let i in arr) console.log(i);      // 0, 1 (인덱스)
for (let v of arr) console.log(v);      // a, b (값)

// 4) return 아래는 실행 안 됨
function demo() {
    return 1;
    console.log("실행 안 됨");
}

// 5) 화살표 함수 한 줄은 return 생략
const add = (a, b) => a + b;
```
