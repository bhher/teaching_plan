# 6장. 조건문

## 1번

조건문의 역할로 옳은 것은?

① 코드를 여러 번 반복 실행한다  
② 조건에 따라 다른 코드를 실행한다  
③ 함수를 선언한다  
④ 변수의 타입을 바꾼다

---

## 2번

다음 코드의 출력은?

```javascript
let age = 18;

if (age >= 20) {
    console.log("성인");
} else {
    console.log("미성년자");
}
```

① `성인`  
② `미성년자`  
③ `18`  
④ 아무것도 출력되지 않는다

    console.log("C");

}

④ `F`

## 5번

다음 코드의 출력은?

```javascript
let day = 3;
let name;

switch (day) {
    case 1:
        name = "월";
        break;
    case 2:
        name = "화";
        break;
    case 3:
        name = "수";
        break;
    default:
        name = "기타";
}

console.log(name);
```

① `월`  
② `화`  
③ `수`  
④ `기타`

# 7장. 반복문

## 11번

반복 횟수를 정확히 알 때 가장 많이 쓰는 반복문은?

① `if`  
② `for`  
③ `switch`  
④ `function`

---

## 12번

다음 코드의 출력은?

```javascript
for (let i = 1; i <= 3; i++) {
    console.log(i);
}
```

① `1 2 3`  
② `0 1 2`  
③ `1 2 3 4`  
④ `3 2 1`

---

## 13번

다음 코드의 출력은?

```javascript
for (let i = 5; i >= 1; i--) {
    console.log(i);
}
```

① `1 2 3 4 5`  
② `5 4 3 2 1`  
③ `5 6 7`  
④ `0 1 2 3 4 5`

---

## 14번

`while` 문의 특징으로 옳은 것은?

① 조건이 `true`인 동안 반복한다  
② 무조건 1번은 실행된다  
③ 반복 횟수를 반드시 알아야 한다  
④ 배열에서만 사용할 수 있다

---

## 15번

`do-while`과 `while`의 차이로 옳은 것은?

① 차이가 없다  
② `do-while`은 조건을 나중에 검사해서 **최소 1번** 실행된다  
③ `while`만 무한 반복이 가능하다  
④ `do-while`은 함수 전용이다

---

## 16번

배열 값을 하나씩 꺼낼 때 적합한 반복문은? (ES6+)

① `for...in`  
② `for...of`  
③ `switch`  
④ `if`

## 27번

② `const add => (a, b) { a + b }`

---

## 28번

함수 선언과 함수 표현식의 차이로 옳은 것은?

① 함수 선언은 호이스팅되어 선언 전에도 호출할 수 있다  
② 함수 표현식만 호이스팅된다  
③ 둘 다 선언 전에 호출하면 항상 에러이다  
④ 화살표 함수는 함수가 아니다
