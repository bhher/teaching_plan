### 애니메이션 상세 설명

```javascript
// 현재 슬라이드 (cu)
cu.css('left', '0')                    // 초기 위치: 0%
    .stop()                            // 진행 중인 애니메이션 중지
    .animate({'left': '-100%'}, 500); // 왼쪽으로 이동 (0.5초)

// 다음 슬라이드 (ne)
ne.css('left', '100%')                 // 초기 위치: 오른쪽 밖 (100%)
    .stop()                            // 진행 중인 애니메이션 중지
    .animate({'left': '0%'}, 500);    // 중앙으로 이동 (0.5초)
```

## 핵심 로직 설명

### 1. move() 함수 상세 분석

```javascript
function move(){
    // 1. 현재 슬라이드와 클릭한 슬라이드가 같으면 종료
    if(current == i) return;
    
    // 2. 현재 슬라이드와 다음 슬라이드 요소 선택
    var cu = visual.eq(current);  // 현재 보이는 슬라이드
    var ne = visual.eq(i);        // 이동할 슬라이드
    
    // 3. 현재 슬라이드: 왼쪽으로 사라지게
    cu.css('left', '0')                    // 위치: 0%
        .stop()                            // 기존 애니메이션 중지
        .animate({'left': '-100%'}, 500);  // -100%로 이동 (0.5초)
    
    // 4. 다음 슬라이드: 오른쪽에서 들어오게
    ne.css('left', '100%')                 // 위치: 100% (오른쪽 밖)
        .stop()                            // 기존 애니메이션 중지
        .animate({'left': '0%'}, 500);     // 0%로 이동 (0.5초)
    
    // 5. 현재 인덱스 업데이트
    current = i;
}
```

### 2. timer() 함수 상세 분석

```javascript
function timer(){
    // setInterval로 3초마다 실행
    id = setInterval(function(){
        // 다음 슬라이드 인덱스 계산
        var n = current + 1;
        
        // 마지막 슬라이드면 첫 번째로
        if(n === 3) {n = 0;}
        
        // 해당 버튼을 프로그래밍적으로 클릭
        button.eq(n).trigger('click');
        // → 이렇게 하면 버튼 클릭 이벤트가 발생하여
        //   move() 함수가 자동으로 호출됨
        
    }, 3000); // 3초 (3000ms)
}
```

## 주요 포인트 정리

### 1. CSS Position 활용
- **부모**: `position: relative` → 기준점 설정
- **자식**: `position: absolute` → 절대 위치 지정
- **left 값**: `0%`, `100%`, `200%` → 슬라이드 위치 제어

### 2. 애니메이션 전략
- **현재 슬라이드**: `0% → -100%` (왼쪽으로 사라짐)
- **다음 슬라이드**: `100% → 0%` (오른쪽에서 들어옴)
- **동시 애니메이션**: 두 슬라이드가 동시에 움직여 자연스러운 전환

### 3. 자동 재생 구현
- `setInterval`로 3초마다 실행
- `trigger('click')`으로 버튼 클릭 이벤트 발생
- 기존 클릭 로직 재사용으로 코드 중복 방지

### 4. 상태 관리
- `current`: 현재 활성화된 슬라이드 인덱스
- `i`: 클릭한 버튼의 인덱스
- `current == i` 체크로 불필요한 애니메이션 방지

## 개선 가능한 부분

### 1. 무한 루프 개선
현재는 마지막 슬라이드에서 첫 번째로 갈 때 위치가 이상해질 수 있습니다.

**개선안**: 슬라이드 복제를 사용한 진정한 무한 루프

### 2. 애니메이션 방향
현재는 항상 오른쪽에서 왼쪽으로만 이동합니다.

**개선안**: 이전/다음 버튼에 따라 방향 변경

### 3. 자동 재생 일시정지
마우스 호버 시 자동 재생이 멈추지 않습니다.

**개선안**: `mouseenter`/`mouseleave` 이벤트 추가
