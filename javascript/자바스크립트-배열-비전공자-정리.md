# 자바스크립트 배열(Array) 정리 (비전공자)

JavaScript에서 **배열(Array)** 은 가장 많이 사용하는 자료구조입니다.

비전공자 기준으로 **기초 → 활용 → 실무** 순서대로 예제를 정리했습니다.

> **배열이란?**  
> 여러 값을 **순서대로** 하나에 담아 두는 상자입니다.  
> 각 칸은 **인덱스(번호)** 로 접근하며, **0번부터** 시작합니다.

---

## Part 1. 기초 (생성 · 접근 · 변경)

### 1. 배열 생성

```javascript
let fruits = ["사과", "바나나", "오렌지"];
console.log(fruits);
// ["사과", "바나나", "오렌지"]
```

---

### 2. 인덱스로 접근

```javascript
let fruits = ["사과", "바나나", "오렌지"];

console.log(fruits[0]);   // 사과
console.log(fruits[1]);   // 바나나
console.log(fruits[2]);   // 오렌지
```

| 인덱스 | 값 |
|--------|-----|
| 0 | 사과 |
| 1 | 바나나 |
| 2 | 오렌지 |

---

### 3. 길이 (`length`)

```javascript
let fruits = ["사과", "바나나", "오렌지"];
console.log(fruits.length);   // 3
```

---

### 4. 값 변경

```javascript
let fruits = ["사과", "바나나", "오렌지"];

fruits[1] = "포도";
console.log(fruits);
// ["사과", "포도", "오렌지"]
```

---

## Part 2. 추가 · 삭제

### 5. 마지막에 추가 — `push()`

```javascript
let fruits = ["사과", "바나나"];

fruits.push("딸기");
console.log(fruits);
// ["사과", "바나나", "딸기"]
```

---

### 6. 마지막 삭제 — `pop()`

```javascript
let fruits = ["사과", "바나나", "딸기"];

let item = fruits.pop();
console.log(item);      // 딸기
console.log(fruits);    // ["사과", "바나나"]
```

---

### 7. 맨 앞 추가 — `unshift()`

```javascript
let fruits = ["사과", "바나나"];

fruits.unshift("포도");
console.log(fruits);
// ["포도", "사과", "바나나"]
```

---

### 8. 맨 앞 삭제 — `shift()`

```javascript
let fruits = ["포도", "사과", "바나나"];

let item = fruits.shift();
console.log(item);      // 포도
console.log(fruits);    // ["사과", "바나나"]
```

| 메서드 | 위치 | 동작 |
|--------|------|------|
| `push()` | 끝 | 추가 |
| `pop()` | 끝 | 삭제 |
| `unshift()` | 앞 | 추가 |
| `shift()` | 앞 | 삭제 |

---

## Part 3. 반복 (순회)

### 9. `for`문

```javascript
let fruits = ["사과", "바나나", "오렌지"];

for (let i = 0; i < fruits.length; i++) {
    console.log(fruits[i]);
}
```

---

### 10. `for...of`

```javascript
let fruits = ["사과", "바나나", "오렌지"];

for (let fruit of fruits) {
    console.log(fruit);
}
```

출력:

```text
사과
바나나
오렌지
```

---

### 11. `forEach()`

```javascript
let fruits = ["사과", "바나나", "오렌지"];

fruits.forEach(function(item) {
    console.log(item);
});

// 화살표 함수 (람다식)
fruits.forEach(item => console.log(item));
```

---

## Part 4. 찾기 · 확인

### 12. `indexOf()` — 위치 찾기

```javascript
let fruits = ["사과", "바나나", "오렌지"];

console.log(fruits.indexOf("바나나"));   // 1
console.log(fruits.indexOf("포도"));     // -1 (없음)
```

| 결과 | 의미 |
|------|------|
| `0` 이상 | 해당 인덱스 |
| `-1` | 없음 |

---

### 13. `includes()` — 있는지 확인

```javascript
let fruits = ["사과", "바나나", "오렌지"];

console.log(fruits.includes("사과"));   // true
console.log(fruits.includes("포도"));   // false
```

---

## Part 5. 잘라내기 · 정렬 · 연결

### 14. `splice()` — 중간 추가 / 삭제

**삭제** — `splice(시작인덱스, 삭제개수)`

```javascript
let fruits = ["사과", "바나나", "오렌지"];

fruits.splice(1, 1);   // 1번부터 1개 삭제
console.log(fruits);
// ["사과", "오렌지"]
```

**추가** — `splice(시작인덱스, 0, 넣을값...)`

```javascript
let fruits = ["사과", "오렌지"];

fruits.splice(1, 0, "포도");   // 1번 위치에 포도 삽입
console.log(fruits);
// ["사과", "포도", "오렌지"]
```

> `splice`는 **원본 배열을 바꿉니다.**

---

### 15. `slice()` — 일부 복사

```javascript
let fruits = ["사과", "바나나", "오렌지", "포도"];

let result = fruits.slice(1, 3);   // 1번 ~ 2번 (3번 전까지)
console.log(result);
// ["바나나", "오렌지"]
```

> `slice`는 **원본을 바꾸지 않고** 새 배열을 만듭니다.

---

### 16. `sort()` — 정렬

**문자열 정렬**

```javascript
let fruits = ["banana", "apple", "orange"];

fruits.sort();
console.log(fruits);
// ["apple", "banana", "orange"]
```

**숫자 정렬 — 주의!**

```javascript
let nums = [10, 5, 30, 2];

nums.sort();
console.log(nums);
// [10, 2, 30, 5]  ← 문자열처럼 비교하기 때문!
```

**숫자 오름차순 정렬**

```javascript
nums.sort((a, b) => a - b);
console.log(nums);
// [2, 5, 10, 30]
```

**숫자 내림차순**

```javascript
nums.sort((a, b) => b - a);
// [30, 10, 5, 2]
```

---

### 17. `reverse()` — 역순

```javascript
let nums = [1, 2, 3, 4];

nums.reverse();
console.log(nums);
// [4, 3, 2, 1]
```

---

### 18. `join()` — 문자열로 연결

```javascript
let fruits = ["사과", "바나나", "오렌지"];

console.log(fruits.join("-"));
// 사과-바나나-오렌지
```

## Part 6. 활용 (map · filter · find · reduce)

> 아래 메서드는 **원본을 바꾸지 않고** 새 결과를 만듭니다.

### 19. `filter()` — 조건에 맞는 것만

```javascript
let nums = [10, 20, 30, 40, 50];

let result = nums.filter(n => n >= 30);
console.log(result);
// [30, 40, 50]
```

---

### 20. `map()` — 모든 요소 변경

```javascript
let nums = [1, 2, 3];

let result = nums.map(n => n * 10);
console.log(result);
// [10, 20, 30]
```

---

### 21. `find()` — 첫 번째 찾기

```javascript
let nums = [10, 20, 30, 40];

let result = nums.find(n => n > 25);
console.log(result);
// 30
```

---

### 25. 총점 계산 — `reduce()`

```javascript
let scores = [80, 90, 100];

let sum = scores.reduce((total, n) => total + n, 0);
console.log(sum);
// 270
```

| 인자 | 의미 |
|------|------|
| `(total, n) => total + n` | 누적값 + 현재값 |
| `0` | 시작값 (초기 total) |

**평균 구하기**

```javascript
let avg = scores.reduce((t, n) => t + n, 0) / scores.length;
// 90
```

---

## Part 7. 실무 — 객체 배열

### 22. 객체 배열

```javascript
let students = [
    { name: "홍길동", score: 90 },
    { name: "김철수", score: 80 },
    { name: "이영희", score: 95 }
];

students.forEach(s => {
    console.log(s.name, s.score);
});
```

출력:

```text
홍길동 90
김철수 80
이영희 95
```

---

### 23. 객체 배열 정렬

```javascript
students.sort((a, b) => a.score - b.score);
console.log(students);
// 점수 오름차순 정렬
```

---

### 24. 객체 배열 검색

```javascript
let student = students.find(s => s.name == "홍길동");
console.log(student);
// { name: "홍길동", score: 90 }
```

## Part 8. 학생들이 꼭 익혀야 하는 배열 메서드

| 메서드 | 설명 | 원본 변경 |
|--------|------|-----------|
| `push()` | 마지막 추가 | O |
| `pop()` | 마지막 삭제 | O |
| `shift()` | 첫 번째 삭제 | O |
| `unshift()` | 첫 번째 추가 | O |
| `splice()` | 중간 추가/삭제 | O |
| `slice()` | 일부 복사 | X |
| `sort()` | 정렬 | O |
| `reverse()` | 역순 | O |
| `join()` | 문자열로 연결 | X |
| `indexOf()` | 위치 찾기 | X |
| `includes()` | 포함 여부 | X |
| `forEach()` | 반복 | X |
| `map()` | 요소 변환 | X |
| `filter()` | 조건에 맞는 요소만 선택 | X |
| `find()` | 첫 번째 요소 찾기 | X |
| `reduce()` | 합계, 평균 등 누적 계산 | X |

## 치트시트

```javascript
// 기초
let arr = ["a", "b", "c"];
arr[0]              // 접근
arr.length          // 길이
arr.push("d")       // 끝 추가
arr.pop()           // 끝 삭제

// 반복
for (let i = 0; i < arr.length; i++) { }
for (let item of arr) { }
arr.forEach(item => { });

// 찾기
arr.indexOf("b")    // 1
arr.includes("b")   // true

// 가공
arr.filter(x => 조건)
arr.map(x => 변환)
arr.find(x => 조건)
arr.reduce((누적, x) => ..., 시작값)

// 정렬
arr.sort((a, b) => a - b)   // 숫자 오름차순
```

### 한 줄 요약

> **기초**: `[]` 로 만들고 `[0]` 으로 접근  
> **추가/삭제**: `push` `pop` `shift` `unshift` `splice`  
> **가공**: `map` `filter` `find` `reduce`  
> **숫자 sort** 는 `(a, b) => a - b` 필수!
