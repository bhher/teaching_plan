## 스와이프 슬라이더란?

**스와이프 슬라이더**는 터치 제스처(스와이프)나 마우스 드래그로 슬라이드를 이동시킬 수 있는 슬라이더입니다.

### 특징
- ✅ 터치 스와이프 지원 (모바일)
- ✅ 마우스 드래그 지원 (데스크톱)
- ✅ 자연스러운 사용자 경험
- ✅ 모던 웹 표준
- ✅ 직관적인 인터랙션

### 사용 사례
- 모바일 앱 스타일 웹사이트
- 이미지 갤러리
- 제품 카탈로그
- 뉴스 피드

## 터치 이벤트 기본 개념

### 터치 이벤트 종류

| 이벤트 | 설명 | 사용 시점 |
|--------|------|----------|
| `touchstart` | 터치 시작 | 손가락이 화면에 닿을 때 |
| `touchmove` | 터치 이동 중 | 손가락이 화면 위에서 움직일 때 |
| `touchend` | 터치 종료 | 손가락이 화면에서 떨어질 때 |
| `touchcancel` | 터치 취소 | 시스템이 터치를 취소할 때 |

### 마우스 이벤트

| 이벤트 | 설명 | 사용 시점 |
|--------|------|----------|
| `mousedown` | 마우스 버튼 누름 | 버튼을 누를 때 |
| `mousemove` | 마우스 이동 | 버튼을 누른 채로 이동할 때 |
| `mouseup` | 마우스 버튼 놓음 | 버튼을 놓을 때 |
| `mouseleave` | 마우스가 요소를 벗어남 | 요소 밖으로 나갈 때 |

### 터치 좌표 가져오기

```javascript
// 터치 이벤트
element.addEventListener('touchstart', function(e) {
    var touch = e.touches[0]; // 첫 번째 터치
    var x = touch.clientX; // X 좌표
    var y = touch.clientY; // Y 좌표
});

// 마우스 이벤트
element.addEventListener('mousedown', function(e) {
    var x = e.clientX; // X 좌표
    var y = e.clientY; // Y 좌표
});
```

## Vanilla JS 구현

### 기본 구조

```javascript
let startX = 0;
let currentX = 0;
let isDragging = false;

// 터치 시작
slider.addEventListener('touchstart', function(e) {
    isDragging = true;
    startX = e.touches[0].clientX;
});

// 터치 이동
slider.addEventListener('touchmove', function(e) {
    if (!isDragging) return;
    e.preventDefault();
    currentX = e.touches[0].clientX;
    var diff = currentX - startX;
    // 슬라이더 이동
});

// 터치 종료
slider.addEventListener('touchend', function(e) {
    if (!isDragging) return;
    isDragging = false;
    var diff = currentX - startX;
    // 스와이프 판단 및 슬라이드 이동
});
```

## 라이브러리별 구현

### 1. bxSlider

#### 기본 설정
```javascript
$('.slider').bxSlider({
    touchEnabled: true,        // 터치 활성화
    swipeThreshold: 50,        // 스와이프 임계값 (px)
    oneToOneTouch: true,       // 1:1 터치 비율
    preventDefaultSwipeX: true // X축 스와이프 기본 동작 방지
});
```

#### 옵션 설명

| 옵션 | 타입 | 기본값 | 설명 |
|------|------|--------|------|
| `touchEnabled` | boolean | true | 터치 제스처 활성화 |
| `swipeThreshold` | number | 50 | 스와이프로 인식할 최소 거리 (px) |
| `oneToOneTouch` | boolean | true | 1:1 터치 비율 사용 |
| `preventDefaultSwipeX` | boolean | true | X축 스와이프 기본 동작 방지 |
| `preventDefaultSwipeY` | boolean | false | Y축 스와이프 기본 동작 방지 |

### 2. Slick Slider

#### 기본 설정
```javascript
$('.slider').slick({
    swipe: true,           // 스와이프 활성화
    touchMove: true,       // 터치 이동 활성화
    swipeToSlide: true,    // 스와이프로 슬라이드 이동
    draggable: true,       // 드래그 가능
    touchThreshold: 5      // 터치 임계값
});
```

#### 옵션 설명

| 옵션 | 타입 | 기본값 | 설명 |
|------|------|--------|------|
| `swipe` | boolean | true | 스와이프 제스처 활성화 |
| `touchMove` | boolean | true | 터치 이동 활성화 |
| `swipeToSlide` | boolean | false | 스와이프로 슬라이드 이동 |
| `draggable` | boolean | true | 드래그 가능 |
| `touchThreshold` | number | 5 | 터치 임계값 |

### 3. Swiper.js

#### 기본 설정
```javascript
const swiper = new Swiper('.swiper', {
    touchEventsTarget: 'container',
    threshold: 10,
    touchRatio: 1,
    touchAngle: 45,
    grabCursor: true
});
```

#### 옵션 설명

| 옵션 | 타입 | 기본값 | 설명 |
|------|------|--------|------|
| `touchEventsTarget` | string | 'container' | 터치 이벤트 대상 |
| `threshold` | number | 5 | 스와이프 임계값 |
| `touchRatio` | number | 1 | 터치 비율 |
| `touchAngle` | number | 45 | 터치 각도 |
| `grabCursor` | boolean | true | 드래그 커서 표시 |

## 실전 예제

### 예제 1: 기본 스와이프 슬라이더 (Vanilla JS)

```html
<!DOCTYPE html>
<html>
<head>
    <style>
        .slider-container {
            position: relative;
            overflow: hidden;
            width: 100%;
            height: 400px;
        }
        .slider {
            display: flex;
            transition: transform 0.3s ease;
        }
        .slide {
            min-width: 100%;
            height: 400px;
        }
    </style>
</head>
<body>
    <div class="slider-container">
        <div class="slider" id="slider">
            <div class="slide">Slide 1</div>
            <div class="slide">Slide 2</div>
            <div class="slide">Slide 3</div>
        </div>
    </div>
    
    <script>
        const slider = document.getElementById('slider');
        let startX = 0;
        let currentX = 0;
        let isDragging = false;
        let currentIndex = 0;
        
        // 터치 시작
        slider.addEventListener('touchstart', function(e) {
            isDragging = true;
            startX = e.touches[0].clientX;
        });
        
        // 터치 이동
        slider.addEventListener('touchmove', function(e) {
            if (!isDragging) return;
            e.preventDefault();
            currentX = e.touches[0].clientX;
            const diff = currentX - startX;
            slider.style.transition = 'none';
            slider.style.transform = `translateX(${-currentIndex * 100}% + ${diff}px)`;
        });
        
        // 터치 종료
        slider.addEventListener('touchend', function(e) {
            if (!isDragging) return;
            isDragging = false;
            const diff = currentX - startX;
            const threshold = 50;
            
            slider.style.transition = 'transform 0.3s ease';
            
            if (Math.abs(diff) > threshold) {
                if (diff > 0) {
                    currentIndex = Math.max(0, currentIndex - 1);
                } else {
                    currentIndex = Math.min(2, currentIndex + 1);
                }
            }
            
            slider.style.transform = `translateX(${-currentIndex * 100}%)`;
        });
    </script>
</body>
</html>
```

## 문제 해결

### 문제 1: 스와이프가 작동하지 않음

**원인**: 터치 이벤트가 차단됨

**해결책**:
```javascript
// preventDefault 사용
slider.addEventListener('touchmove', function(e) {
    e.preventDefault();
});
```

### 문제 2: 스와이프가 너무 민감함

**원인**: 임계값이 너무 작음

**해결책**:
```javascript
// 임계값 증가
const threshold = 100; // 50에서 100으로 증가
```

### 문제 3: 세로 스크롤과 충돌

**원인**: X축과 Y축 스와이프 구분 없음

**해결책**:
```javascript
let startY = 0;

slider.addEventListener('touchstart', function(e) {
    startX = e.touches[0].clientX;
    startY = e.touches[0].clientY;
});

slider.addEventListener('touchmove', function(e) {
    const diffX = Math.abs(e.touches[0].clientX - startX);
    const diffY = Math.abs(e.touches[0].clientY - startY);
    
    // X축 이동이 Y축 이동보다 클 때만 스와이프
    if (diffX > diffY) {
        e.preventDefault();
        // 스와이프 처리
    }
});
```

### 문제 4: 드래그 중 슬라이더가 튐

**원인**: transition이 드래그 중에도 적용됨

**해결책**:
```javascript
// 드래그 시작 시 transition 제거
slider.style.transition = 'none';

// 드래그 종료 시 transition 복원
slider.style.transition = 'transform 0.3s ease';
```
