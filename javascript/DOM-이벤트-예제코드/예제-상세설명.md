## 예제 1: 클릭 카운터

### 📁 파일명
`example1_click_counter.html`

### 🎯 목적
버튼 클릭 시 카운터가 증가하고, 리셋 버튼으로 초기화할 수 있는 간단한 예제입니다.

### 📋 주요 기능
- 클릭 버튼: 클릭할 때마다 카운터 증가
- 리셋 버튼: 카운터를 0으로 초기화
- 실시간 카운터 표시

### 🔍 코드 분석

#### HTML 구조
```html
<h1>클릭 카운터</h1>
<div id="counter">클릭 횟수: 0</div>
<button id="btn">클릭</button>
<button id="resetBtn">리셋</button>
```

**요소:**
- `#counter`: 카운터 값을 표시하는 div
- `#btn`: 클릭 버튼
- `#resetBtn`: 리셋 버튼

#### JavaScript 핵심 코드

**1. 요소 선택**
```javascript
let count = 0;
const counter = document.getElementById('counter');
const btn = document.getElementById('btn');
const resetBtn = document.getElementById('resetBtn');
```

**설명:**
- `count`: 클릭 횟수를 저장하는 변수
- `getElementById()`: ID로 요소 선택

**2. 클릭 이벤트 리스너**
```javascript
btn.addEventListener('click', function() {
    count++;
    counter.textContent = `클릭 횟수: ${count}`;
});
```

**동작:**
- 버튼 클릭 시 `count` 변수 증가
- `textContent`로 카운터 표시 업데이트
- 템플릿 리터럴 사용 (`${count}`)

**3. 리셋 기능**
```javascript
resetBtn.addEventListener('click', function() {
    count = 0;
    counter.textContent = `클릭 횟수: ${count}`;
});
```

**동작:**
- `count`를 0으로 초기화
- 카운터 표시도 0으로 업데이트

### 📚 학습 포인트

1. **DOM 요소 선택**
   - `getElementById()`: ID로 단일 요소 선택

2. **이벤트 리스너**
   - `addEventListener('click', function)`: 클릭 이벤트 처리

3. **텍스트 내용 변경**
   - `textContent`: 요소의 텍스트 내용 변경

4. **템플릿 리터럴**
   - 백틱(`)과 `${}`를 사용한 문자열 보간

### 🎨 CSS 스타일링

- 중앙 정렬 레이아웃
- 버튼 호버 효과 (`:hover`)
- 반응형 디자인 (`viewport` 메타 태그)

## 예제 2: 할 일 목록

### 📁 파일명
`example2_todo_list.html`

### 🎯 목적
할 일을 추가하고 삭제할 수 있는 동적 To-Do List 예제입니다.

### 📋 주요 기능
- 할 일 추가: 입력 필드에 입력 후 추가 버튼 클릭 또는 Enter 키
- 할 일 삭제: 각 항목의 삭제 버튼 클릭
- 빈 목록 메시지: 항목이 없을 때 안내 메시지 표시
- 입력 필드 자동 포커스: 추가 후 입력 필드에 포커스

### 🔍 코드 분석

#### HTML 구조
```html
<input type="text" id="todoInput" placeholder="할 일을 입력하세요">
<button id="addBtn">추가</button>
<ul id="todoList">
    <li class="empty">할 일이 없습니다. 추가해보세요!</li>
</ul>
```

**요소:**
- `#todoInput`: 할 일 입력 필드
- `#addBtn`: 추가 버튼
- `#todoList`: 할 일 목록을 담는 ul

#### JavaScript 핵심 코드

**1. 요소 선택**
```javascript
const todoInput = document.getElementById('todoInput');
const addBtn = document.getElementById('addBtn');
const todoList = document.getElementById('todoList');
```

**2. 추가 버튼 클릭 이벤트**
```javascript
addBtn.addEventListener('click', function() {
    addTodo();
});
```

**3. Enter 키 이벤트**
```javascript
todoInput.addEventListener('keypress', function(event) {
    if (event.key === 'Enter') {
        addTodo();
    }
});
```

**설명:**
- `keypress` 이벤트로 키보드 입력 감지
- `event.key === 'Enter'`: Enter 키 확인

**4. 할 일 추가 함수**
```javascript
function addTodo() {
    const text = todoInput.value.trim();
    
    if (text === '') {
        alert('할 일을 입력하세요');
        return;
    }

    // 빈 메시지 제거
    const emptyMsg = todoList.querySelector('.empty');
    if (emptyMsg) {
        emptyMsg.remove();
    }

    // 새로운 li 요소 생성
    const li = document.createElement('li');
    
    // 텍스트 추가
    const span = document.createElement('span');
    span.textContent = text;
    li.appendChild(span);

    // 삭제 버튼 추가
    const deleteBtn = document.createElement('span');
    deleteBtn.textContent = '삭제';
    deleteBtn.className = 'delete';
    deleteBtn.addEventListener('click', function() {
        li.remove();
        
        // 모든 항목이 삭제되면 빈 메시지 표시
        if (todoList.children.length === 0) {
            const emptyMsg = document.createElement('li');
            emptyMsg.className = 'empty';
            emptyMsg.textContent = '할 일이 없습니다. 추가해보세요!';
            todoList.appendChild(emptyMsg);
        }
    });
    li.appendChild(deleteBtn);

    // 목록에 추가
    todoList.appendChild(li);

    // 입력 필드 초기화
    todoInput.value = '';
    todoInput.focus();
}
```

**핵심 동작:**
1. 입력값 검증 (`trim()`으로 공백 제거)
2. 빈 메시지 제거 (`querySelector()`로 찾아서 `remove()`)
3. 동적 요소 생성 (`createElement()`)
4. 요소 조립 (`appendChild()`)
5. 삭제 이벤트 리스너 추가
6. 목록에 추가
7. 입력 필드 초기화 및 포커스

**5. 삭제 기능**
```javascript
deleteBtn.addEventListener('click', function() {
    li.remove();
    
    if (todoList.children.length === 0) {
        // 빈 메시지 다시 추가
    }
});
```

**설명:**
- `remove()`: 요소를 DOM에서 제거
- `children.length`: 자식 요소 개수 확인

### 📚 학습 포인트

1. **동적 요소 생성**
   - `createElement()`: 새 요소 생성
   - `appendChild()`: 부모 요소에 자식 추가

2. **요소 제거**
   - `remove()`: 요소 삭제
   - `querySelector()`: 조건에 맞는 요소 찾기

3. **키보드 이벤트**
   - `keypress`: 키 입력 감지
   - `event.key`: 입력된 키 확인

4. **입력 필드 제어**
   - `value`: 입력값 가져오기/설정
   - `focus()`: 포커스 설정
   - `trim()`: 공백 제거

5. **조건부 렌더링**
   - 빈 목록일 때 메시지 표시/숨김

### 🎨 CSS 스타일링

- Flexbox 레이아웃 (`display: flex`)
- 호버 효과 (`:hover`)
- 트랜지션 효과 (`transition`)
- 반응형 디자인

## 예제 3: 폼 유효성 검사

### 📁 파일명
`example3_form_validation.html`

### 🎯 목적
회원가입 폼의 입력값을 실시간으로 검증하는 예제입니다.

### 📋 주요 기능
- 이름 검증: 2자 이상 입력 확인
- 이메일 검증: 정규표현식으로 이메일 형식 확인
- 비밀번호 검증: 6자 이상 입력 확인
- 실시간 피드백: 입력 필드 포커스를 잃을 때(`blur`) 검증
- 시각적 피드백: 에러/성공 상태에 따른 스타일 변경
- 폼 제출 방지: 유효성 검사 실패 시 제출 차단

### 🔍 코드 분석

#### HTML 구조
```html
<form id="signupForm">
    <div class="form-group">
        <label for="name">이름:</label>
        <input type="text" id="name" required>
        <div class="error" id="nameError"></div>
    </div>
    
    <div class="form-group">
        <label for="email">이메일:</label>
        <input type="email" id="email" required>
        <div class="error" id="emailError"></div>
    </div>
    
    <div class="form-group">
        <label for="password">비밀번호:</label>
        <input type="password" id="password" required>
        <div class="error" id="passwordError"></div>
    </div>
    
    <button type="submit">가입하기</button>
</form>
```

**요소:**
- 각 입력 필드와 에러 메시지를 표시할 div
- `required` 속성으로 HTML5 기본 검증

#### JavaScript 핵심 코드

**1. 요소 선택**
```javascript
const form = document.getElementById('signupForm');
const nameInput = document.getElementById('name');
const emailInput = document.getElementById('email');
const passwordInput = document.getElementById('password');
```

**2. 이름 유효성 검사**
```javascript
nameInput.addEventListener('blur', function() {
    validateName();
});

function validateName() {
    const name = nameInput.value.trim();
    const errorDiv = document.getElementById('nameError');
    
    if (name.length < 2) {
        nameInput.classList.add('error');
        nameInput.classList.remove('valid');
        errorDiv.textContent = '이름은 2자 이상이어야 합니다';
        return false;
    } else {
        nameInput.classList.remove('error');
        nameInput.classList.add('valid');
        errorDiv.textContent = '';
        return true;
    }
}
```

**설명:**
- `blur` 이벤트: 입력 필드에서 포커스가 벗어날 때 발생
- `classList.add/remove`: CSS 클래스 동적 추가/제거
- `textContent`: 에러 메시지 표시/제거

**3. 이메일 유효성 검사**
```javascript
emailInput.addEventListener('blur', function() {
    validateEmail();
});

function validateEmail() {
    const email = emailInput.value.trim();
    const errorDiv = document.getElementById('emailError');
    const emailPattern = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
    
    if (!emailPattern.test(email)) {
        emailInput.classList.add('error');
        emailInput.classList.remove('valid');
        errorDiv.textContent = '올바른 이메일 형식이 아닙니다';
        return false;
    } else {
        emailInput.classList.remove('error');
        emailInput.classList.add('valid');
        errorDiv.textContent = '';
        return true;
    }
}
```

**정규표현식 설명:**
- `/^[^\s@]+@[^\s@]+\.[^\s@]+$/`
  - `^`: 문자열 시작
  - `[^\s@]+`: 공백이나 @가 아닌 문자 1개 이상
  - `@`: @ 기호
  - `[^\s@]+`: @ 이후 공백이나 @가 아닌 문자 1개 이상
  - `\.`: 점(.) (이스케이프 필요)
  - `[^\s@]+`: 점 이후 공백이나 @가 아닌 문자 1개 이상
  - `$`: 문자열 끝

**4. 비밀번호 유효성 검사**
```javascript
passwordInput.addEventListener('blur', function() {
    validatePassword();
});

function validatePassword() {
    const password = passwordInput.value;
    const errorDiv = document.getElementById('passwordError');
    
    if (password.length < 6) {
        passwordInput.classList.add('error');
        passwordInput.classList.remove('valid');
        errorDiv.textContent = '비밀번호는 6자 이상이어야 합니다';
        return false;
    } else {
        passwordInput.classList.remove('error');
        passwordInput.classList.add('valid');
        errorDiv.textContent = '';
        return true;
    }
}
```

**5. 폼 제출 처리**
```javascript
form.addEventListener('submit', function(event) {
    event.preventDefault();
    
    const isNameValid = validateName();
    const isEmailValid = validateEmail();
    const isPasswordValid = validatePassword();
    
    if (isNameValid && isEmailValid && isPasswordValid) {
        alert('가입이 완료되었습니다!');
        form.reset();
        // 모든 입력 필드에서 클래스 제거
        [nameInput, emailInput, passwordInput].forEach(input => {
            input.classList.remove('error', 'valid');
        });
    } else {
        alert('모든 항목을 올바르게 입력해주세요');
    }
});
```

**핵심 동작:**
1. `preventDefault()`: 폼 기본 제출 동작 방지
2. 모든 필드 검증 실행
3. 모두 통과하면 성공 메시지 및 폼 리셋
4. 실패하면 경고 메시지

### 📚 학습 포인트

1. **이벤트 타입**
   - `blur`: 포커스 잃을 때
   - `submit`: 폼 제출 시

2. **정규표현식**
   - `test()`: 패턴 매칭 확인
   - 이메일 형식 검증

3. **CSS 클래스 제어**
   - `classList.add()`: 클래스 추가
   - `classList.remove()`: 클래스 제거

4. **폼 제어**
   - `preventDefault()`: 기본 동작 방지
   - `reset()`: 폼 초기화

5. **배열 메서드**
   - `forEach()`: 배열 순회

### 🎨 CSS 스타일링

- `.error`: 빨간 테두리 (에러 상태)
- `.valid`: 초록 테두리 (성공 상태)
- 에러 메시지 스타일링

## 예제 4: 모달 창

### 📁 파일명
`example4_modal.html`

### 🎯 목적
버튼 클릭 시 나타나는 모달 창 예제입니다.

### 📋 주요 기능
- 모달 열기: 버튼 클릭 시 모달 표시
- 모달 닫기: 여러 방법으로 닫기 가능
  - X 버튼 클릭
  - 닫기 버튼 클릭
  - 배경 클릭
  - ESC 키 입력
- 애니메이션: 모달이 나타날 때 슬라이드 다운 효과

### 🔍 코드 분석

#### HTML 구조
```html
<button id="openModal">모달 열기</button>

<div id="modal" class="modal">
    <div class="modal-content">
        <span class="close">&times;</span>
        <h2>모달 제목</h2>
        <p>모달 내용입니다.</p>
        <button id="closeModal">닫기</button>
    </div>
</div>
```

**요소:**
- `#openModal`: 모달을 여는 버튼
- `#modal`: 모달 배경 (오버레이)
- `.modal-content`: 모달 내용 영역
- `.close`: X 버튼
- `#closeModal`: 닫기 버튼

#### CSS 핵심 스타일

```css
.modal {
    display: none;
    position: fixed;
    top: 0;
    left: 0;
    width: 100%;
    height: 100%;
    background-color: rgba(0, 0, 0, 0.5);
    z-index: 1000;
    justify-content: center;
    align-items: center;
}
.modal.active {
    display: flex;
}
```

**설명:**
- `display: none`: 기본적으로 숨김
- `position: fixed`: 화면에 고정
- `rgba(0, 0, 0, 0.5)`: 반투명 검은 배경
- `z-index: 1000`: 다른 요소 위에 표시
- `.active` 클래스 추가 시 `display: flex`로 표시

#### JavaScript 핵심 코드

**1. 요소 선택**
```javascript
const openBtn = document.getElementById('openModal');
const modal = document.getElementById('modal');
const closeBtn = document.querySelector('.close');
const closeModalBtn = document.getElementById('closeModal');
```

**2. 모달 열기**
```javascript
openBtn.addEventListener('click', function() {
    modal.classList.add('active');
});
```

**설명:**
- `classList.add('active')`: active 클래스 추가
- CSS에서 `display: flex`로 변경되어 모달 표시

**3. 모달 닫기 (X 버튼)**
```javascript
closeBtn.addEventListener('click', function() {
    modal.classList.remove('active');
});
```

**4. 모달 닫기 (닫기 버튼)**
```javascript
closeModalBtn.addEventListener('click', function() {
    modal.classList.remove('active');
});
```

**5. 배경 클릭 시 닫기**
```javascript
modal.addEventListener('click', function(event) {
    if (event.target === modal) {
        modal.classList.remove('active');
    }
});
```

**설명:**
- `event.target`: 실제 클릭된 요소
- `event.target === modal`: 배경(modal)을 클릭했는지 확인
- 모달 내용(modal-content)을 클릭하면 닫히지 않음

**6. ESC 키로 닫기**
```javascript
document.addEventListener('keydown', function(event) {
    if (event.key === 'Escape' && modal.classList.contains('active')) {
        modal.classList.remove('active');
    }
});
```

**설명:**
- `keydown`: 키보드 키를 누를 때
- `event.key === 'Escape'`: ESC 키 확인
- `classList.contains('active')`: 모달이 열려있는지 확인

### 📚 학습 포인트

1. **CSS 클래스 토글**
   - `classList.add()`: 클래스 추가
   - `classList.remove()`: 클래스 제거
   - `classList.contains()`: 클래스 존재 확인

2. **이벤트 타겟 확인**
   - `event.target`: 실제 클릭된 요소
   - 이벤트 전파 제어

3. **키보드 이벤트**
   - `keydown`: 키 입력 감지
   - `event.key`: 입력된 키 확인

4. **CSS 애니메이션**
   - `@keyframes`: 애니메이션 정의
   - `animation`: 애니메이션 적용

5. **레이어링**
   - `z-index`: 요소의 층위 제어
   - `position: fixed`: 고정 위치

### 🎨 CSS 스타일링

- 반투명 배경 (`rgba`)
- 중앙 정렬 (`flexbox`)
- 애니메이션 효과 (`@keyframes slideDown`)
- 호버 효과

## 예제 5: 탭 메뉴

### 📁 파일명
`example5_tab_menu.html`

### 🎯 목적
여러 탭을 클릭하여 콘텐츠를 전환하는 탭 메뉴 예제입니다.

### 📋 주요 기능
- 탭 전환: 탭 클릭 시 해당 콘텐츠 표시
- 활성 탭 표시: 현재 선택된 탭 강조
- 부드러운 전환: 페이드 인 애니메이션
- data 속성 활용: 탭과 콘텐츠 연결

### 🔍 코드 분석

#### HTML 구조
```html
<div class="tabs">
    <button class="tab active" data-tab="tab1">홈</button>
    <button class="tab" data-tab="tab2">소개</button>
    <button class="tab" data-tab="tab3">연락처</button>
</div>

<div id="tab1" class="tab-content active">
    <h2>홈</h2>
    <p>홈 페이지 내용입니다.</p>
</div>

<div id="tab2" class="tab-content">
    <h2>소개</h2>
    <p>소개 페이지 내용입니다.</p>
</div>

<div id="tab3" class="tab-content">
    <h2>연락처</h2>
    <p>연락처 페이지 내용입니다.</p>
</div>
```

**요소:**
- `.tabs`: 탭 버튼 컨테이너
- `.tab`: 각 탭 버튼
- `data-tab`: 탭과 콘텐츠를 연결하는 속성
- `.tab-content`: 각 탭의 콘텐츠

#### CSS 핵심 스타일

```css
.tab-content {
    display: none;
}
.tab-content.active {
    display: block;
    animation: fadeIn 0.3s;
}
.tab.active {
    background-color: #007bff;
    color: white;
}
```

**설명:**
- 기본적으로 모든 콘텐츠 숨김 (`display: none`)
- `.active` 클래스가 있으면 표시 (`display: block`)
- 페이드 인 애니메이션 적용

#### JavaScript 핵심 코드

**1. 요소 선택**
```javascript
const tabs = document.querySelectorAll('.tab');
const contents = document.querySelectorAll('.tab-content');
```

**설명:**
- `querySelectorAll()`: 여러 요소 선택 (NodeList 반환)

**2. 탭 클릭 이벤트**
```javascript
tabs.forEach(tab => {
    tab.addEventListener('click', function() {
        // 모든 탭과 콘텐츠에서 active 제거
        tabs.forEach(t => t.classList.remove('active'));
        contents.forEach(c => c.classList.remove('active'));

        // 클릭한 탭에 active 추가
        tab.classList.add('active');

        // 해당 콘텐츠에 active 추가
        const tabId = tab.getAttribute('data-tab');
        const content = document.getElementById(tabId);
        if (content) {
            content.classList.add('active');
        }
    });
});
```

**핵심 동작:**
1. 모든 탭과 콘텐츠에서 `active` 클래스 제거
2. 클릭한 탭에 `active` 클래스 추가
3. `data-tab` 속성값으로 콘텐츠 ID 찾기
4. 해당 콘텐츠에 `active` 클래스 추가

**3. data 속성 활용**
```javascript
const tabId = tab.getAttribute('data-tab');
const content = document.getElementById(tabId);
```

**설명:**
- `getAttribute('data-tab')`: data 속성값 가져오기
- `data-tab="tab1"` → `tabId = "tab1"`
- `getElementById(tabId)`: 해당 ID의 콘텐츠 찾기
