테마 변경 예제

data-theme 속성을 사용하여 페이지 테마를 동적으로 변경합니다.

현재 테마: 라이트 모드

콘텐츠 영역

이 영역의 색상이 테마에 따라 변경됩니다.

CSS 변수와 data-theme 속성을 활용하여 구현했습니다.

구현 방법:

  1. body 요소에 data-theme 속성 설정
  2. CSS에서 [data-theme="값"] 선택자로 스타일 정의
  3. JavaScript의 setAttribute()로 테마 변경
  4. getAttribute()로 현재 테마 확인

코드 예제:

// 테마 변경
function changeTheme(theme) {
    document.body.setAttribute('data-theme', theme);
    localStorage.setItem('theme', theme);
}

// 현재 테마 읽기
const currentTheme = document.body.getAttribute('data-theme');
