## 예제 1: 클릭 카운터

**파일명:** `example1_click_counter.html`

**설명:** 버튼 클릭 시 카운터가 증가하는 간단한 예제입니다.

**주요 학습 내용:**
- `getElementById()`로 요소 선택
- `addEventListener()`로 이벤트 리스너 추가
- `textContent`로 텍스트 내용 변경

**데모 링크:** [https://bhher.github.io/webdesign/example1_click_counter.html](https://bhher.github.io/webdesign/example1_click_counter.html)

**로컬 파일:** `example1_click_counter.html`

## 예제 2: 할 일 목록

**파일명:** `example2_todo_list.html`

**설명:** 할 일을 추가하고 삭제할 수 있는 To-Do List 예제입니다.

**주요 학습 내용:**
- `createElement()`로 동적 요소 생성
- `appendChild()`로 요소 추가
- `remove()`로 요소 삭제
- `keypress` 이벤트로 Enter 키 처리

**데모 링크:** [https://bhher.github.io/webdesign/example2_todo_list.html](https://bhher.github.io/webdesign/example2_todo_list.html)

## 예제 3: 폼 유효성 검사

**파일명:** `example3_form_validation.html`

**설명:** 회원가입 폼의 입력값을 실시간으로 검증하는 예제입니다.

**주요 학습 내용:**
- `blur` 이벤트로 포커스 잃을 때 검증
- 정규표현식으로 이메일 형식 검사
- `classList.add/remove`로 스타일 동적 변경
- `preventDefault()`로 폼 제출 방지

**데모 링크:** [https://bhher.github.io/webdesign/example3_form_validation.html](https://bhher.github.io/webdesign/example3_form_validation.html)

**로컬 파일:** `example3_form_validation.html`

## 예제 4: 모달 창

**파일명:** `example4_modal.html`

**설명:** 버튼 클릭 시 나타나는 모달 창 예제입니다.

**주요 학습 내용:**

## 예제 5: 탭 메뉴

**파일명:** `example5_tab_menu.html`

**설명:** 여러 탭을 클릭하여 콘텐츠를 전환하는 탭 메뉴 예제입니다.

**주요 학습 내용:**
- `querySelectorAll()`로 여러 요소 선택
- `data-*` 속성 활용
- `forEach()`로 반복 처리
- `getAttribute()`로 속성값 가져오기
