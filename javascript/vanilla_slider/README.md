# Vanilla JS 슬라이더 모음집

jQuery 없이 순수 JavaScript로 구현한 다양한 슬라이더 예제 모음입니다.

## 📁 슬라이더 종류

1. **기본 슬라이더** (`basic/`) - 가장 간단한 형태
2. **페이드 슬라이더** (`fade/`) - 페이드 인/아웃 효과
3. **슬라이드 효과** (`slide/`) - 좌우 슬라이드 효과
4. **무한 루프** (`infinite/`) - 끝없이 반복되는 슬라이더
5. **썸네일 슬라이더** (`thumbnail/`) - 썸네일 네비게이션 포함
6. **자동 재생** (`autoplay/`) - 자동으로 넘어가는 슬라이더
7. **Slick-like 슬라이더** (`slick-like/`) - Slick Slider와 유사한 기능 (여러 슬라이드 표시, 터치 스와이프, 반응형)

각 폴더에는 `index.html`, `css/style.css`, `js/main.js` 파일이 포함되어 있습니다.
