## 정답 예시

### 문제 1 정답

```javascript
// 익명 함수
const multiply1 = function(a, b) {
    return a * b;
};

// 화살표 함수
const multiply2 = (a, b) => a * b;
```

### 문제 2 정답

```javascript
// 2-1
const result1 = numbers.map(function(num) { return num + 5; });
const result2 = numbers.map(num => num + 5);

// 2-2
const result3 = numbers.filter(function(num) { return num > 30; });
const result4 = numbers.filter(num => num > 30);

// 2-3
const result5 = numbers.reduce(function(acc, num) { return acc + num; }, 0);
const result6 = numbers.reduce((acc, num) => acc + num, 0);
```

### 문제 4 정답

```javascript
const calculator = {
    value: 0,
    
    add: function(num) {
        this.value += num;
    },
    
    subtract: function(num) {
        this.value -= num;
```

### 문제 9 정답
