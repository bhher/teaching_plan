# 코드 작성 정답 (35~40)

## 35번. 사칙연산 + 나머지

```javascript
let a = 15;
let b = 4;

console.log(a + b); // 19
console.log(a - b); // 11
console.log(a * b); // 60
console.log(a / b); // 3.75
console.log(a % b); // 3
```

---

## 36번. 템플릿 리터럴

```javascript
let name = "홍길동";
let age = 25;

let message = `이름: ${name}, 나이: ${age}`;
console.log(message);
```

---

## 37번. 삼항 연산자

```javascript
let score = 85;
let result = score >= 80 ? "합격" : "불합격";
console.log(result); // 합격
```

---

## 38번. 전위 / 후위 증가

```javascript
let n = 5;
console.log(n++); // 5 (출력 후 6)
console.log(n);   // 6

n = 5;
console.log(++n); // 6 (증가 후 출력)
console.log(n);   // 6
```

---

## 39번. 할인 계산

```javascript
let price = 10000;
let rate = 0.2;

let discount = price * rate;      // 2000
let finalPrice = price - discount; // 8000

console.log("할인 금액:", discount);
console.log("최종 금액:", finalPrice);
```

---

## 40번. 논리 연산자

```javascript
let age = 25;
let check = age >= 20 && age <= 39;
console.log(check); // true
```

## 자주 헷갈리는 포인트

```javascript
// 1) ==  vs  ===
10 == "10"   // true  (타입 변환)
10 === "10"  // false (타입까지 비교)

// 2) 후위 vs 전위
let x = 1;
x++  // 쓰고 나서 +1
++x  // 먼저 +1 하고 사용

// 3) typeof null
typeof null  // "object"  (언어 초기의 버그로 유명)

// 4) const
const PI = 3.14;
// PI = 3;  // 에러 (재할당 불가)
```
