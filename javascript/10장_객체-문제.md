# Part 1. 객체 기본 · 속성 접근

## 1번

**객체(Object)** 에 대한 설명으로 **올바른** 것은?

① 키 하나에 값 하나만 저장할 수 있다  
② 키(key)와 값(value)의 쌍으로 데이터를 저장한다  
③ 실행 중에 속성을 추가·삭제할 수 없다  
④ 객체는 값 타입(primitive)이다

① `new Object()`  
② 객체 리터럴 `{ }`  
③ `Array()`  
④ `String()`

## 4번

변수를 키로 사용해 속성에 접근할 때 **올바른** 방법은?

① `user.name` (name이 변수일 때)  
② `user[name]`  
③ `user.'name'`  
④ `user->name`  

---

## 5번

```javascript

delete user.city;
```

① `{ name: '홍길동', age: 25 }`  
② `{ name: '홍길동', age: 25, city: '서울' }`  
③ `{ city: '서울' }`  
④ 컴파일 오류

# Part 2. 메서드 · this

## 7번

객체 **메서드**에 대한 설명으로 **올바른** 것은?

① 객체에 속한 변수이다  
② 객체에 속한 함수이다  
③ 배열에서만 사용할 수 있다  
④ `function` 키워드로 정의할 수 없다  

---

## 8번

다음 코드의 출력 결과는?

```javascript
let user = {
    name: '홍길동',
    greet: function() {
        return `안녕하세요, ${this.name}님!`;
    }
};
console.log(user.greet());
```

---

## 9번

객체 메서드에서 **화살표 함수**를 쓰면 `this`가 어떻게 되는가?

① 항상 해당 객체를 가리킨다  
② `this`가 다르게 동작해 `this.name`이 `undefined`일 수 있다  
③ `this`를 사용할 수 없다 (문법 오류)  
④ `this`는 항상 `window`만 가리킨다  

---

## 10번

ES6+ 메서드 **단축 문법**으로 올바른 것은?

① `greet: function() { }`  
② `greet() { }`  
③ `function greet() { }`  
④ `greet => { }`

# Part 4. 중첩 객체 · 객체 배열

# Part 5. 객체 복사 · 참조

## 18번

다음 코드 실행 후 `user1.name`은?

```javascript
let user1 = { name: '홍길동' };
let user2 = user1;
user2.name = '김철수';
```

---

## 19번

다음 코드 실행 후 `user1.name`은?

```javascript
let user1 = { name: '홍길동', age: 25 };
let user2 = { ...user1 };
user2.name = '김철수';
```

---

## 20번

**얕은 복사(Shallow Copy)** 로 객체를 복사하는 방법이 **아닌** 것은?

① `{ ...user }`  
② `Object.assign({}, user)`  
③ `user2 = user`  
④ `Object.assign({}, user1)`  

---

## 21번

중첩 객체가 있을 때 얕은 복사 후 안쪽 객체를 수정하면?

```javascript
let user1 = { name: '홍', address: { city: '서울' } };
let user2 = { ...user1 };
user2.address.city = '부산';
```

① `user1.address.city`는 그대로 `'서울'`이다  
② `user1.address.city`도 `'부산'`으로 바뀐다  
③ `user1`이 삭제된다  
④ 문법 오류가 난다  

---

## 22번

깊은 복사를 **간단히** 할 때 자주 쓰는 방법은? (함수·Date 등은 제한적)

① `user2 = user1`  
② `JSON.parse(JSON.stringify(user1))`  
③ `delete user1`  
④ `Object.keys(user1)`

# Part 7. 코드 결과 예측

## 27번

다음 코드의 출력 결과는?

```javascript
let calculator = {
    result: 0,
    add(num) {
        this.result += num;
        return this;
    },
    getResult() {
        return this.result;
    }
};
calculator.add(10).add(5);
console.log(calculator.getResult());
```

---

## 28번

다음 코드의 출력 결과는?

```javascript
let students = [
    { name: '홍길동', score: 80 },
    { name: '김철수', score: 90 }
];
let sum = students.reduce((acc, s) => acc + s.score, 0);
console.log(sum / students.length);
```
