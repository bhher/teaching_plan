### 1단계: BxSlider 초기화 (5점)

#### 문제
`.bxslider` 클래스를 가진 요소에 BxSlider를 초기화하세요.

#### 요구사항
- 슬라이더 변수명: `slider`
- 자동 재생: 활성화 (`auto: true`)
- 자동 재생 속도: 3초 (`pause: 3000`)
- 슬라이드 전환 속도: 500ms (`speed: 500`)
- 마우스 호버 시 일시정지: 활성화 (`autoHover: true`)
- 기본 컨트롤/페이저: 비활성화 (`controls: false`, `pager: false`)

#### 힌트
```javascript
var slider = $('.bxslider').bxSlider({
  // 옵션을 여기에 작성하세요
});
```

#### 정답 예시
```javascript
var slider = $('.bxslider').bxSlider({
  mode: 'horizontal',
  speed: 500,
  auto: true,
  autoHover: true,
  pause: 3000,
  controls: false,
  pager: false
});
```

#### 체크리스트
- [ ] `$('.bxslider').bxSlider()` 호출
- [ ] `auto: true` 설정
- [ ] `pause: 3000` 설정
- [ ] `slider` 변수에 저장

### 2단계: 슬라이드 번호 표시 (5점)

#### 문제
슬라이드가 변경될 때마다 현재 슬라이드 번호를 업데이트하고, 전체 슬라이드 개수를 표시하세요.

#### 요구사항
- 전체 슬라이드 개수를 `#total-slides` 요소에 표시
- 슬라이드 변경 시 `#current-slide` 요소에 현재 슬라이드 번호 표시
- 슬라이드 번호는 1부터 시작 (인덱스가 0부터 시작하므로 +1 필요)

#### 힌트
```javascript
// 전체 슬라이드 개수 가져오기
var totalSlides = slider.getSlideCount();

// 슬라이드 변경 이벤트 콜백
onSlideAfter: function($slideElement, oldIndex, newIndex){
  // newIndex는 0부터 시작하므로 +1 필요
}
```

#### 정답 예시
```javascript
// 1단계 코드에 추가
onSlideAfter: function($slideElement, oldIndex, newIndex){
  $('#current-slide').text(newIndex + 1);
}

// 1단계 코드 아래에 추가
var totalSlides = slider.getSlideCount();
$('#total-slides').text(totalSlides);
```

#### 체크리스트
- [ ] `getSlideCount()` 메서드로 전체 개수 가져오기
- [ ] `#total-slides`에 전체 개수 표시
- [ ] `onSlideAfter` 콜백 함수 작성
- [ ] `newIndex + 1`로 현재 번호 계산
- [ ] `#current-slide`에 현재 번호 표시

### 3단계: 이전/다음 버튼 구현 (8점)

#### 문제
`.prev`와 `.next` 클래스를 가진 버튼을 클릭하면 이전/다음 슬라이드로 이동하도록 구현하세요.

#### 요구사항
- `.prev` 버튼 클릭 시 이전 슬라이드로 이동
- `.next` 버튼 클릭 시 다음 슬라이드로 이동
- 기본 링크 동작 방지 (`e.preventDefault()`)
- 이벤트 전파 방지 (`return false`)

#### 힌트
```javascript
// 이전 버튼
$('.prev').click(function(e){
  e.preventDefault();
  // 이전 슬라이드로 이동하는 메서드 호출
  return false;
});

// 다음 버튼
$('.next').click(function(e){
  e.preventDefault();
  // 다음 슬라이드로 이동하는 메서드 호출
  return false;
});
```

#### 정답 예시
```javascript
// 이전 버튼
$('.prev').click(function(e){
  e.preventDefault();
  slider.goToPrevSlide();
  return false;
});

// 다음 버튼
$('.next').click(function(e){
  e.preventDefault();
  slider.goToNextSlide();
  return false;
});
```

#### 체크리스트
- [ ] `.prev` 클릭 이벤트 리스너 등록
- [ ] `.next` 클릭 이벤트 리스너 등록
- [ ] `e.preventDefault()` 호출
- [ ] `goToPrevSlide()` 메서드 호출
- [ ] `goToNextSlide()` 메서드 호출
- [ ] `return false` 추가

### 4단계: 일시정지/재생 버튼 구현 (7점)

#### 문제
`.pause` 버튼을 클릭하면 자동 재생을 일시정지/재생 토글하도록 구현하세요.

#### 요구사항
- 버튼 클릭 시 자동 재생 상태 토글
- 일시정지 상태일 때 버튼에 `on` 클래스 추가
- 재생 상태일 때 버튼에서 `on` 클래스 제거
- 상태를 추적하기 위한 변수 사용 (`isPaused`)

#### 힌트
```javascript
var isPaused = false;

$('.pause').click(function(e){
  e.preventDefault();
  
  if(!isPaused){
    // 일시정지 처리
    // 버튼에 'on' 클래스 추가
    // isPaused를 true로 변경
  } else {
    // 재생 처리
    // 버튼에서 'on' 클래스 제거
    // isPaused를 false로 변경
  }
  
  return false;
});
```

#### 정답 예시
```javascript
var isPaused = false;
$('.pause').click(function(e){
  e.preventDefault();
  if(!isPaused){
    slider.stopAuto();
    $(this).addClass('on');
    isPaused = true;
  } else {
    slider.startAuto();
    $(this).removeClass('on');
    isPaused = false;
  }
  return false;
});
```

#### 체크리스트
- [ ] `isPaused` 변수 선언 및 초기화
- [ ] `.pause` 클릭 이벤트 리스너 등록
- [ ] `e.preventDefault()` 호출
- [ ] `if(!isPaused)` 조건문 작성
- [ ] `stopAuto()` 메서드 호출
- [ ] `startAuto()` 메서드 호출
- [ ] `addClass('on')` / `removeClass('on')` 처리
- [ ] `isPaused` 상태 업데이트
- [ ] `return false` 추가

## 🎨 완성된 코드 예시

```javascript
$(function(){
  // 1단계: BxSlider 초기화
  var slider = $('.bxslider').bxSlider({
    mode: 'horizontal',
    speed: 500,
    auto: true,
    autoHover: true,
    pause: 3000,
    controls: false,
    pager: false,
    onSlideAfter: function($slideElement, oldIndex, newIndex){
      // 2단계: 슬라이드 번호 업데이트
      $('#current-slide').text(newIndex + 1);
    }
  });

  // 2단계: 전체 슬라이드 개수 표시
  var totalSlides = slider.getSlideCount();
  $('#total-slides').text(totalSlides);

  // 3단계: 이전 버튼
  $('.prev').click(function(e){
    e.preventDefault();
    slider.goToPrevSlide();
    return false;
  });

  // 3단계: 다음 버튼
  $('.next').click(function(e){
    e.preventDefault();
    slider.goToNextSlide();
    return false;
  });

  // 4단계: 일시정지/재생 버튼
  var isPaused = false;
  $('.pause').click(function(e){
    e.preventDefault();
    if(!isPaused){
      slider.stopAuto();
      $(this).addClass('on');
      isPaused = true;
    } else {
      slider.startAuto();
      $(this).removeClass('on');
      isPaused = false;
    }
    return false;
  });
});
```

## 📚 참고 자료

### BxSlider 주요 메서드

| 메서드 | 설명 |
|--------|------|
| `getSlideCount()` | 전체 슬라이드 개수 반환 |
| `goToPrevSlide()` | 이전 슬라이드로 이동 |
| `goToNextSlide()` | 다음 슬라이드로 이동 |
| `stopAuto()` | 자동 재생 중지 |
| `startAuto()` | 자동 재생 시작 |

### BxSlider 주요 옵션

| 옵션 | 타입 | 기본값 | 설명 |
|------|------|-------|------|
| `auto` | Boolean | false | 자동 재생 여부 |
| `pause` | Number | 4000 | 자동 재생 간격 (ms) |
| `speed` | Number | 500 | 슬라이드 전환 속도 (ms) |
| `autoHover` | Boolean | false | 마우스 호버 시 일시정지 |
| `controls` | Boolean | true | 이전/다음 버튼 표시 |
| `pager` | Boolean | true | 페이저(점) 표시 |

### 콜백 함수

| 콜백 | 매개변수 | 설명 |
|------|---------|------|
| `onSlideAfter` | `$slideElement, oldIndex, newIndex` | 슬라이드 변경 후 실행 |

## 🐛 문제 해결 가이드

### 슬라이더가 작동하지 않을 때
1. jQuery가 로드되었는지 확인
2. BxSlider 라이브러리가 로드되었는지 확인
3. 콘솔에서 에러 메시지 확인
4. `$(function(){})` 안에 코드가 있는지 확인

### 버튼이 작동하지 않을 때
1. 이벤트 리스너가 올바르게 등록되었는지 확인
2. `e.preventDefault()`를 호출했는지 확인
3. `slider` 변수가 올바르게 선언되었는지 확인

### 슬라이드 번호가 업데이트되지 않을 때
1. `onSlideAfter` 콜백이 올바르게 작성되었는지 확인
2. `newIndex + 1`을 사용했는지 확인
3. `#current-slide` 선택자가 올바른지 확인
