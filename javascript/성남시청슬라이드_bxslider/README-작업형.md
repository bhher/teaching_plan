## 💡 사용 방법

### 방법 1: 작업용 파일 사용 (권장)

1. `index.html` 파일을 열어서 다음 줄을 수정:
   ```html
   <!-- 기존 -->
   <script src="js/main.js"></script>
   
   <!-- 변경 -->
   <script src="js/main_작업용.js"></script>
   ```

2. `js/main_작업용.js` 파일에서 코드 작성

3. 브라우저에서 테스트

### 방법 2: main.js 직접 수정

1. `js/main.js` 파일을 백업
2. `js/main.js` 파일 내용을 삭제하고 새로 작성
3. 브라우저에서 테스트

## 🎯 단계별 진행 가이드

### 1단계: BxSlider 초기화
- `.bxslider` 요소 선택
- `bxSlider()` 메서드 호출
- 옵션 객체 전달

### 2단계: 슬라이드 번호 표시
- `getSlideCount()` 메서드 사용
- `onSlideAfter` 콜백 함수 작성
- `newIndex + 1` 계산

### 3단계: 버튼 구현
- `.prev`, `.next` 클릭 이벤트
- `goToPrevSlide()`, `goToNextSlide()` 메서드
- `e.preventDefault()` 호출

### 4단계: 일시정지/재생
- `isPaused` 변수로 상태 관리
- `stopAuto()`, `startAuto()` 메서드
- `addClass('on')`, `removeClass('on')` 사용

## 🐛 문제 해결

### 슬라이더가 보이지 않을 때
- 브라우저 콘솔에서 에러 확인
- jQuery와 BxSlider 라이브러리 로드 확인
- `$(function(){})` 안에 코드가 있는지 확인

### 버튼이 작동하지 않을 때
- 이벤트 리스너가 올바르게 등록되었는지 확인
- `slider` 변수가 올바르게 선언되었는지 확인
- `e.preventDefault()`를 호출했는지 확인

### 번호가 업데이트되지 않을 때
- `onSlideAfter` 콜백이 올바르게 작성되었는지 확인
- `newIndex + 1`을 사용했는지 확인
- 선택자(`#current-slide`)가 올바른지 확인
