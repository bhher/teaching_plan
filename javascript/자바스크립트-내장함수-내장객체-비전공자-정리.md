# 자바스크립트 내장 함수 · 내장 객체 정리 (비전공자)

JavaScript에는 브라우저나 JavaScript 엔진에서 **기본으로 제공하는 함수(내장 함수, Built-in Function)** 가 많이 있습니다.

비전공자 기준으로 **가장 많이 사용하는 내장 함수**와 **자주 쓰는 내장 객체**를 정리했습니다.

> **구분**  
> - **내장 함수**: `alert("안녕")` 처럼 **이름만 쓰고 바로 호출**  
> - **내장 객체 메서드**: `Math.floor(3.8)`, `"hello".length` 처럼 **객체.메서드** 형태

---

## Part 1. 비전공자가 꼭 알아야 하는 내장 함수 (17가지)

### 1. `alert()`

메시지 창을 띄웁니다.

```javascript
alert("안녕하세요!");
```

**실행 화면**

```text
┌─────────────┐
│ 안녕하세요! │
│    확인     │
└─────────────┘
```

---

### 2. `prompt()`

사용자에게 **입력**을 받습니다.

```javascript
let name = prompt("이름을 입력하세요.");
console.log(name);
```

| 입력 | 출력 |
|------|------|
| 홍길동 | 홍길동 |

---

### 3. `confirm()`

**확인 / 취소**를 선택하는 창입니다.

```javascript
let result = confirm("삭제하시겠습니까?");
console.log(result);
```

| 선택 | 반환값 |
|------|--------|
| 확인 | `true` |
| 취소 | `false` |

---

### 4. `Number()`

문자열을 **숫자**로 변환합니다.

```javascript
let num = Number("100");
console.log(num);           // 100
console.log(typeof num);    // "number"
```

---

### 5. `String()`

숫자를 **문자열**로 변환합니다.

```javascript
let str = String(100);
console.log(str);           // "100"
console.log(typeof str);    // "string"
```

---

### 6. `Boolean()`

**논리형(true / false)** 으로 변환합니다.

```javascript
console.log(Boolean(1));        // true
console.log(Boolean(0));        // false
console.log(Boolean(""));       // false
console.log(Boolean("Java"));   // true
```

---

### 7. `parseInt()`

문자열을 **정수**로 변환합니다.

```javascript
let num = parseInt("123");
console.log(num);   // 123
```

문자가 섞여 있어도 **앞쪽 숫자만** 읽습니다.

```javascript
console.log(parseInt("100원"));   // 100
```

---

### 8. `parseFloat()`

문자열을 **실수(소수)** 로 변환합니다.

```javascript
console.log(parseFloat("3.14"));   // 3.14
```

---

### 9. `isNaN()`

**숫자인지 확인**합니다.

```javascript
console.log(isNaN(100));      // false
console.log(isNaN("Java"));   // true
```

| 결과 | 의미 |
|------|------|
| `false` | 숫자이다 |
| `true` | 숫자가 아니다 |

---

### 10. `encodeURIComponent()`

한글 등을 **URL 안전한 문자열**로 변환합니다.

```javascript
let url = encodeURIComponent("홍길동");
console.log(url);
// %ED%99%8D%EA%B8%B8%EB%8F%99
```

---

### 11. `decodeURIComponent()`

인코딩된 URL 문자열을 **다시 원래 문자**로 되돌립니다.

```javascript
console.log(
    decodeURIComponent("%ED%99%8D%EA%B8%B8%EB%8F%99")
);
// 홍길동
```

---

### 12. `eval()`

문자열을 **JavaScript 코드**로 실행합니다.

```javascript
console.log(eval("10+20"));   // 30
```

> ⚠️ **실무에서는 보안 문제 때문에 거의 사용하지 않습니다.**

---

### 13. `setTimeout()`

**일정 시간이 지난 후** 한 번 실행합니다.

```javascript
setTimeout(function() {
    console.log("3초 후 실행");
}, 3000);
```

3초 뒤 출력:

```text
3초 후 실행
```

---

### 14. `setInterval()`

**일정 시간마다 반복** 실행합니다.

```javascript
setInterval(function() {
    console.log("1초마다 실행");
}, 1000);
```

출력 예:

```text
1초마다 실행
1초마다 실행
1초마다 실행
...
```

---

### 15. `clearInterval()`

`setInterval`로 시작한 **반복을 종료**합니다.

```javascript
let timer = setInterval(function() {
    console.log("실행");
}, 1000);

clearInterval(timer);   // 반복 중지
```

---

### 16. `encodeURI()` / `decodeURI()`

**URL 전체**를 인코딩·디코딩합니다. (`/`, `?` 등 일부 문자는 그대로 둡니다.)

```javascript
let url = encodeURI("http://test.com/홍길동");
console.log(url);
```

| 함수 | 용도 |
|------|------|
| `encodeURIComponent` | 쿼리 **값** 하나 (한글 이름 등) |
| `encodeURI` | **URL 전체** |

---

### 17. `escape()` (거의 사용 안 함)

```javascript
console.log(escape("홍길동"));
```

현재는 **`encodeURIComponent` 사용을 권장**합니다. `escape()`는 권장되지 않습니다.

---

## Part 2. 실무에서 많이 사용하는 내장 객체 메서드

### Math

수학 계산. `new` 없이 `Math.` 로만 사용합니다.

```javascript
console.log(Math.random());          // 0.324234... (0 이상 1 미만)
console.log(Math.floor(3.8));        // 3  (내림)
console.log(Math.ceil(3.2));         // 4  (올림)
console.log(Math.round(3.5));        // 4  (반올림)
console.log(Math.max(10, 20, 30));    // 30 (최댓값)
console.log(Math.min(10, 20, 30));    // 10 (최솟값)
```

| 메서드 | 설명 |
|--------|------|
| `Math.random()` | 난수 (0 ~ 1 미만) |
| `Math.floor()` | 내림 |
| `Math.ceil()` | 올림 |
| `Math.round()` | 반올림 |
| `Math.max()` | 최댓값 |
| `Math.min()` | 최솟값 |

---

### Date

현재 **날짜와 시간**을 다룹니다. `new Date()` 로 객체를 만듭니다.

```javascript
let today = new Date();

console.log(today);
console.log(today.getFullYear());    // 2026
console.log(today.getMonth() + 1);   // 8  (월은 0부터 → +1)
console.log(today.getDate());          // 18
console.log(today.getDay());           // 0~6 (0=일요일)
```

> `getMonth()`는 **0이 1월**입니다. 화면에 보여 줄 때는 `+ 1` 하세요.

---

### String

문자열 **검색, 자르기, 변경**에 씁니다.

```javascript
let str = "JavaScript";

console.log(str.length);                  // 10
console.log(str.toUpperCase());           // "JAVASCRIPT"
console.log(str.toLowerCase());           // "javascript"
console.log(str.indexOf("S"));            // 4
console.log(str.substring(0, 4));         // "Java"
console.log(str.replace("Java", "HTML")); // "HTMLScript"
```

> 문자열 메서드는 **원본을 바꾸지 않고** 새 문자열을 반환합니다.

---

### Array

데이터 **추가, 삭제, 정렬** 등에 씁니다.

```javascript
let arr = [10, 20, 30];

arr.push(40);       // 끝에 40 추가
arr.pop();          // 끝 요소 제거
console.log(arr);   // [10, 20, 30]

arr.reverse();      // 순서 뒤집기
console.log(arr);   // [30, 20, 10]

arr.sort();         // 정렬 (문자 기준 — 숫자는 주의)
console.log(arr);   // [10, 20, 30]
```

| 메서드 | 설명 |
|--------|------|
| `push()` | 끝에 추가 |
| `pop()` | 끝에서 제거 |
| `reverse()` | 순서 뒤집기 |
| `sort()` | 정렬 |

숫자 배열 오름차순 정렬:

```javascript
arr.sort((a, b) => a - b);
```

## Part 3. 한눈에 보는 표 (치트시트)

### 비전공자 필수 내장 함수

| 함수 | 설명 | 예제 |
|------|------|------|
| `alert()` | 메시지 창 | `alert("안녕")` |
| `prompt()` | 입력받기 | `prompt("이름")` |
| `confirm()` | 확인/취소 | `confirm("삭제?")` |
| `Number()` | 숫자 변환 | `Number("100")` |
| `String()` | 문자열 변환 | `String(100)` |
| `Boolean()` | 논리형 변환 | `Boolean(1)` |
| `parseInt()` | 정수 변환 | `parseInt("123")` |
| `parseFloat()` | 실수 변환 | `parseFloat("3.14")` |
| `isNaN()` | 숫자인지 확인 | `isNaN("ABC")` |
| `setTimeout()` | 일정 시간 후 실행 | `setTimeout(fn, 1000)` |
| `setInterval()` | 반복 실행 | `setInterval(fn, 1000)` |
| `clearInterval()` | 반복 종료 | `clearInterval(id)` |

### 꼭 익혀두면 좋은 내장 객체

| 객체 | 주요 용도 |
|------|-----------|
| **Math** | 난수 생성, 반올림, 최대/최소값 |
| **Date** | 현재 날짜와 시간 처리 |
| **String** | 문자열 검색, 자르기, 변경 |
| **Array** | 데이터 추가(`push`), 삭제(`pop`), 정렬(`sort`) 등 |

---

## 마무리

**Math · Date · String · Array** 네 가지 객체는 JavaScript에서 가장 자주 사용됩니다.  
위 **내장 함수 17가지**와 함께 익혀 두면 실무와 학습 모두에 큰 도움이 됩니다.
