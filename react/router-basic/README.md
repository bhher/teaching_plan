# React Router 기초 예제

이론: [../routerBasic.md](../routerBasic.md)

## 실행

```bash
npm install
npm run dev
```

## 라우트

| 경로 | 컴포넌트 | 학습 |
|------|----------|------|
| `/` | Home | 기본 Route |
| `/about` | About | Link 이동 |
| `/products` | Products | map + Link |
| `/products/:id` | ProductDetail | useParams, navigate(-1) |
| `/contact` | Contact | 기본 |
| `/login` | Login | useNavigate |

## 핵심 6개

BrowserRouter · Routes · Route · Link · useParams · useNavigate
