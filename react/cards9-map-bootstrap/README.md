# 카드 9장 — react-bootstrap + map

`<Container>` · `<Row>` · `<Col>` · `<Card>` 컴포넌트로 카드 9장을 그립니다.

## 관련

| 폴더 | 내용 |
|------|------|
| `cards9-map` | 원본 (className) |
| **이 폴더** `cards9-map-bootstrap` | react-bootstrap |
| `boot/examples/07-카드9장.html` | HTML Bootstrap |

## 실행

```bash
cd react/cards9-map-bootstrap
npm install
npm run dev
```
