## 1. 빌드

### 1.1 빌드란?

**빌드**는 개발 코드를 프로덕션용으로 변환하는 과정입니다.

**과정:**
- 코드 최적화
- 파일 압축
- 번들링

### 1.2 빌드 실행

```bash
npm run build
```

**결과:**
- `dist/` 폴더에 빌드 결과 생성
- 최적화된 파일들

---

## 2. Vercel 배포

### 2.1 Vercel이란?

**Vercel**은 프론트엔드 배포 플랫폼입니다.

**특징:**
- ✅ 무료 플랜 제공
- ✅ GitHub 연동
- ✅ 자동 배포
- ✅ 빠른 속도

### 2.2 배포 방법

**방법 1: GitHub 연동**
1. GitHub에 코드 푸시
2. Vercel에서 Import
3. 자동 배포

**방법 2: Vercel CLI**
```bash
npm install -g vercel
vercel
```
