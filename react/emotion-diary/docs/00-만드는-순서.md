# 감정일기장 만드는 순서

## 체크리스트

| 순서 | 작업 | 파일 |
|:---:|------|------|
| 1 | 프로젝트 생성 | `npm create vite@latest emotion-diary -- --template react` |
| 2 | 의존성 설치 | `cd emotion-diary && npm install` |
| 3 | 루트 HTML | `index.html` |
| 4 | 진입점 | `src/main.jsx` |
| 5 | 전역 스타일 | `src/index.css` |
| 6 | 상수 정의 | `src/constants.js` |
| 7 | 최상위 컴포넌트 | `src/App.jsx` |
| 8 | 감정 선택기 | `src/components/EmotionPicker.jsx` |
| 9 | 일기 폼 | `src/components/DiaryForm.jsx` |
| 10 | 일기 카드 | `src/components/DiaryEntry.jsx` |
| 11 | 일기 목록 | `src/components/DiaryList.jsx` |
| 12 | Vite 설정 | `vite.config.js` |
| 13 | 패키지 설정 | `package.json` |

## 의존 관계

```
App.jsx
├── DiaryForm.jsx
│   └── EmotionPicker.jsx ← constants.js
└── DiaryList.jsx
    └── DiaryEntry.jsx ← constants.js
```

## 권장 작성 순서 (아래→위)

1. **constants.js** — 감정 목록 (의존성 없음)
2. **EmotionPicker** — 감정 버튼
3. **DiaryForm** — EmotionPicker + textarea
4. **DiaryEntry** — 일기 카드 한 건
5. **DiaryList** — 빈 상태 + DiaryEntry 목록
6. **App** — entries 상태, localStorage, CRUD 핸들러
