## SPA란?

**SPA (Single Page Application)** = **단일 페이지 애플리케이션**

- **한 개의 HTML 페이지**만 로드
- 페이지 전환 시 **전체 새로고침 없이** JavaScript로 화면만 갱신
- 필요한 데이터는 **AJAX/fetch**로 서버에서 가져옴

### 특징

- 초기 로딩 시 HTML 1개 + JS 번들 다운로드
- 이후 화면 전환은 클라이언트(브라우저)에서 처리
- URL 변경은 `History API`로 처리 (예: React Router)

### 대표 예시

- Gmail, Facebook, Netflix
- React, Vue, Angular로 만든 웹앱

---

## MPA란?

**MPA (Multi Page Application)** = **다중 페이지 애플리케이션**

- **여러 개의 HTML 페이지**로 구성
- 링크 클릭 시 **서버에 새 요청** → **전체 페이지 새로고침**
- 전통적인 웹사이트 구조

### 특징

- 페이지마다 별도 HTML 문서
- 서버가 매 요청마다 새 HTML을 만들어 응답
- JSP, PHP, ASP 등 서버 사이드 렌더링(SSR)과 잘 맞음

### 대표 예시

- 일반 기업 홈페이지, 블로그
- JSP 게시판, PHP 쇼핑몰

## 비교표

| 구분 | SPA | MPA |
|------|-----|-----|
| **페이지 수** | HTML 1개 | HTML 여러 개 |
| **페이지 전환** | JS로 화면만 교체 (새로고침 없음) | 전체 페이지 새로고침 |
| **서버 요청** | 초기 1번 + API 호출 | 페이지마다 전체 HTML 요청 |
| **렌더링** | 클라이언트(브라우저) | 서버 또는 클라이언트 |
| **URL** | History API로 변경 | 실제 다른 HTML 경로 |
| **SEO** | 추가 설정 필요 | 기본적으로 유리 |
| **초기 로딩** | JS 번들 크기에 따라 느릴 수 있음 | 페이지별로 가벼울 수 있음 |
| **개발** | React, Vue, Angular 등 | JSP, PHP, Thymeleaf 등 |

## 동작 방식

### SPA 동작 흐름

```
1. 최초 접속 → index.html + app.js 로드
2. 사용자가 "목록" 클릭
   → JS가 URL 변경 (History API)
   → JS가 해당 화면 컴포넌트 렌더링
   → 필요 시 API로 데이터 fetch
3. 전체 페이지 새로고침 없음
```

### MPA 동작 흐름

```
1. 최초 접속 → index.html 로드
2. 사용자가 "목록" 클릭
   → 브라우저가 /list.html 요청
   → 서버가 list.html 응답
   → 전체 페이지 새로고침
3. 매 전환마다 새 HTML 다운로드
```

## 장단점

### SPA

| 장점 | 단점 |
|------|------|
| 페이지 전환이 빠르고 부드러움 | 초기 로딩이 느릴 수 있음 |
| 서버 부하 감소 (HTML 재생성 적음) | SEO 대응을 위해 SSR 등 추가 작업 필요 |
| 앱처럼 사용 가능 (오프라인 등) | JS 비활성화 시 동작 어려움 |
| 프론트/백엔드 분리 개발 용이 | 빌드 도구 필요 |

### MPA

| 장점 | 단점 |
|------|------|
| SEO에 유리 | 페이지 전환 시 깜빡임 |
| 초기 로딩이 단순할 수 있음 | 서버 요청이 많아짐 |
| JS 없이도 기본 동작 가능 | 사용자 경험(UX)이 SPA보다 떨어질 수 있음 |
| 구조가 단순하고 이해하기 쉬움 | 페이지마다 중복 코드 가능 |

## 언제 무엇을 사용할까?

| 상황 | 추천 |
|------|------|
| 대시보드, 관리자 페이지 | **SPA** |
| SNS, 메일, 실시간 앱 | **SPA** |
| 검색 노출이 중요한 블로그/뉴스 | **MPA** 또는 **SSR(Next.js 등)** |
| 소규모 기업 홈페이지 | **MPA** |
| 복잡한 인터랙션, 앱형 웹 | **SPA** |
| 정적 콘텐츠 위주 | **MPA** |

---

## 요약

| | SPA | MPA |
|---|-----|-----|
| **한 줄 요약** | 한 페이지에서 JS로 화면만 바꿈 | 페이지마다 새 HTML 요청 |
| **대표 기술** | React, Vue, Angular | JSP, PHP, Thymeleaf |
| **적합한 경우** | 앱형 웹, 대시보드 | 블로그, 기업 사이트 |
