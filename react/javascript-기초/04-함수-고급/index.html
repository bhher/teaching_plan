함수 고급 예제

React에서 자주 사용하는 함수 개념들을 학습합니다!

1. 화살표 함수와 this

this 바인딩 차이

// 일반 함수: this가 호출한 객체를 가리킴 const obj1 = { name: "객체1", greet: function() { console.log(this.name); } }; // 화살표 함수: this가 상위 스코프를 가리킴 const obj2 = { name: "객체2", greet: () => { console.log(this.name); // undefined } };

2. 고차 함수 (Higher-Order Function)

함수를 반환하는 함수

function multiplyBy(n) { return function(x) { return x * n; }; } const double = multiplyBy(2); const triple = multiplyBy(3); console.log(double(5)); // 10 console.log(triple(5)); // 15

3. 클로저 (Closure)

외부 변수에 접근하는 함수

function createCounter() { let count = 0; return function() { count++; return count; }; } const counter = createCounter(); console.log(counter()); // 1 console.log(counter()); // 2 console.log(counter()); // 3

4. 콜백 함수 (Callback Function)

함수를 매개변수로 전달

function processData(data, callback) { const result = data.map(item => item * 2); callback(result); } processData([1, 2, 3], (result) => { console.log("결과:", result); });

5. 즉시 실행 함수 (IIFE)

정의와 동시에 실행

(function() { const message = "즉시 실행!"; console.log(message); })(); // 화살표 함수 버전 (() => { console.log("화살표 함수로 즉시 실행!"); })();

6. 함수 합성 (Function Composition)

여러 함수를 조합

const add = x => x + 1; const multiply = x => x * 2; const square = x => x * x; // 함수 합성 const compose = (f, g, h) => x => f(g(h(x))); const result = compose(square, multiply, add)(3); // add(3) = 4, multiply(4) = 8, square(8) = 64

7. 커링 (Currying)

여러 매개변수를 하나씩 받는 함수

// 일반 함수 function add(a, b, c) { return a + b + c; } // 커링 함수 function addCurried(a) { return function(b) { return function(c) { return a + b + c; }; }; } const result1 = add(1, 2, 3); const result2 = addCurried(1)(2)(3);

8. React에서 사용하는 패턴

이벤트 핸들러

// React 컴포넌트 예시 function Button() { const handleClick = (e) => { console.log("클릭됨!", e); }; return <button onClick={handleClick}>클릭</button>; } // 매개변수 전달 function Button() { const handleClick = (id) => { return (e) => { console.log("ID:", id); }; }; return <button onClick={handleClick(123)}>클릭</button>; }
