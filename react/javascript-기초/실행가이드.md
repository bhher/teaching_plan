# JavaScript 기초 예제 - 실행 가이드

모든 예제는 `npm run dev`로 실행할 수 있습니다.

## 실행 방법

각 폴더로 이동 후:

```bash
cd 폴더명
npm install
npm run dev
```

브라우저에서 http://localhost:5173 접속
