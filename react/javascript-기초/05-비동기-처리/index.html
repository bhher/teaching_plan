비동기 처리 예제

React에서 API 호출 시 필수적인 개념입니다!

1. Promise 기본

Promise 생성 및 사용

const promise = new Promise((resolve, reject) => { setTimeout(() => { resolve("성공!"); }, 1000); }); promise.then(result => { console.log(result); // "성공!" });

2. Promise 체이닝

여러 비동기 작업 순차 실행

fetchUser(1) .then(user => fetchPosts(user.id)) .then(posts => console.log(posts)) .catch(error => console.error(error));

3. async/await

비동기 코드를 동기처럼 작성

async function fetchData() { try { const user = await fetchUser(1); const posts = await fetchPosts(user.id); return posts; } catch (error) { console.error(error); } }

4. Promise.all()

여러 Promise를 동시에 실행

const promises = [ fetchUser(1), fetchUser(2), fetchUser(3) ]; Promise.all(promises) .then(users => { console.log("모든 사용자:", users); });

5. fetch API

HTTP 요청 보내기

fetch('https://api.example.com/users') .then(response => response.json()) .then(data => console.log(data)) .catch(error => console.error(error));

6. React에서 사용하는 패턴

useEffect에서 비동기 처리

// React 컴포넌트 예시 function UserProfile({ userId }) { const [user, setUser] = useState(null); useEffect(() => { async function fetchUser() { try { const response = await fetch(`/api/users/${userId}`); const data = await response.json(); setUser(data); } catch (error) { console.error(error); } } fetchUser(); }, [userId]); return <div>{user?.name}</div>; }
