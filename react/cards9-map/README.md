# 카드 9장 — 원본 (className + map)

Bootstrap CSS 클래스를 `className`으로 쓰고, `map`으로 카드 9장을 그립니다.

## 관련

| 폴더 | 내용 |
|------|------|
| **이 폴더** `cards9-map` | 원본 (className) |
| `cards9-map-bootstrap` | react-bootstrap 컴포넌트 |
| `boot/examples/07-카드9장.html` | HTML Bootstrap |

## 실행

```bash
cd react/cards9-map
npm install
npm run dev
```
