# Ex10PricingModal 해설 — 가격표 + 모달

예제는 앞의 **Ex07~Ex09**에서 배운 **Grid + `map()` + 조건부 렌더링 + Tailwind + React `useState`**를 합쳐서 만든 **가격표 + 모달(Modal)** 예제입니다.

관련 파일: `react/tailwind-examples/src/examples/Ex10PricingModal.jsx`

특히 학생들이 꼭 이해해야 할 핵심은:

> **버튼 클릭 → `useState` 변경 → React 재렌더링 → 모달 표시**

---

## 1. 전체 동작 구조

### 가격표

```
┌──────────┐ ┌──────────┐ ┌──────────┐
│ Basic    │ │ Pro      │ │ Team     │
│ $0/월    │ │ $19/월   │ │ $49/월   │
│          │ │ 추천     │ │          │
│ 예제 10개│ │ 모든Basic│ │ 모든Pro  │
│ CDN 실습 │ │ Vite     │ │ 팀 좌석5 │
│ 커뮤니티 │ │ 우선답변 │ │ 커스텀   │
│          │ │          │ │          │
│ [선택]   │ │ [선택]   │ │ [선택]   │
└──────────┘ └──────────┘ └──────────┘
                       ↓
                 선택하기 클릭
                       ↓
                  모달 열림
```

### 모달

```
┌─────────────────────────┐
│ Pro 플랜                 │
│                         │
│ 월 $19 — 확인...        │
│                         │
│       [취소] [확인]      │
└─────────────────────────┘
```

## 2. `plans` 배열

가격표 데이터를 JavaScript 배열로 관리합니다.

```js
const plans = [
  {
    name: 'Basic',
    price: '0',
    features: ['예제 10개', 'CDN 실습', '커뮤니티'],
    highlight: false,
  },
  {
    name: 'Pro',
    price: '19',
    features: ['모든 Basic', 'Vite 템플릿', '우선 답변'],
    highlight: true,
  },
  {
    name: 'Team',
    price: '49',
    features: ['모든 Pro', '팀 좌석 5', '커스텀 테마'],
    highlight: false,
  },
];
```

구조:

```
plans
│
├── Basic  → price, features, highlight
├── Pro    → price, features, highlight
└── Team   → price, features, highlight
```

---

## 3. `highlight`는 무엇인가?

```js
highlight: false  // 또는 true
```

의미: **이 가격표를 강조해서 보여줄 것인가?**

| 플랜 | highlight |
|------|-----------|
| Basic | `false` |
| Pro | `true` ← 강조 |
| Team | `false` |

---

## 4. `useState`가 핵심

```js
const [open, setOpen] = useState(false);
const [selected, setSelected] = useState(null);
```

State가 **2개** 있습니다.

### 첫 번째 — 모달 열림 여부

```js
const [open, setOpen] = useState(false);
```

| 값 | 의미 |
|----|------|
| `open = false` | 모달 닫힘 |
| `open = true` | 모달 열림 |

### 두 번째 — 선택한 플랜

```js
const [selected, setSelected] = useState(null);
```

| 시점 | 값 |
|------|-----|
| 처음 | `selected = null` |
| Pro 선택 후 | `selected = Pro 객체` |

---

## 5. `openModal()` 함수

이 예제에서 **가장 중요한 함수**입니다.

```js
const openModal = (plan) => {
  setSelected(plan);
  setOpen(true);
};
```

흐름:

```
선택하기 클릭
      ↓
openModal(plan)
      ↓
setSelected(plan)  → 선택한 상품 저장
      ↓
setOpen(true)      → 모달 열기
```

## 8. Template Literal로 조건부 `className`

```jsx
className={`flex flex-col rounded-xl bg-white p-6 shadow-sm ${
  plan.highlight ? 'ring-2 ring-teal-500' : ''

```

**백틱(\`)**으로 문자열을 만듭니다.  
그 안에 `${ ... }`로 JavaScript 식을 넣습니다.

## 9. `${}`와 삼항 연산자

```js
${plan.highlight ? 'ring-2 ring-teal-500' : ''}
```

형태:

```
조건 ? 참일 때 : 거짓일 때
```

| `highlight` | 결과 |
|-------------|------|
| `true` | `ring-2 ring-teal-500` 추가 |
| `false` | 빈 문자열 (클래스 추가 없음) |

## 11. `plan.highlight && (...)` — 조건부 렌더링

```jsx
{plan.highlight && (
  <span>추천</span>
)}
```

형태: **`조건 && JSX`**

| 조건 | 결과 |
|------|------|
| `true` | JSX 표시 |
| `false` | 표시 안 함 |

| 플랜 | “추천” 뱃지 |
|------|-------------|
| Basic | 없음 |
| Pro | **표시** |
| Team | 없음 |

## 12. 가격 표시

```jsx
<span className="text-3xl font-bold">${plan.price}</span>
<span className="text-slate-500">/월</span>
```

Pro라면 `plan.price`가 `"19"` → 화면: **$19 /월**

## 13. 중첩된 `map()`

```jsx
<ul>
  {plan.features.map((f) => (
    <li key={f}>✓ {f}</li>
  ))}
</ul>
```

- **바깥:** `plans.map(...)` — 플랜마다 카드  
- **안쪽:** `plan.features.map(...)` — 그 플랜의 기능 목록  

Basic의 `features` 예:

```
✓ 예제 10개
✓ CDN 실습
✓ 커뮤니티
```

Pro·Team도 각자 `features`를 사용합니다.

## 14. 선택하기 버튼

```jsx
<button
  type="button"
  onClick={() => openModal(plan)}
>
  선택하기
</button>
```

`onClick={() => openModal(plan)}`  
→ 클릭 시 **현재 `plan`**을 `openModal`에 전달  

Pro 버튼이면 → `openModal(Pro)`

## 15. 클릭부터 모달까지 전체 흐름

수업에서 그림으로 설명하면 좋습니다.

```
[Pro 선택하기]
      │
      ▼
onClick
      │
      ▼
openModal(Pro)
      │
      ├───────────────┐
      ▼               ▼
setSelected(Pro)   setOpen(true)
      │               │
      ▼               ▼
선택한 플랜 저장      모달 열기
      │               │
      └───────┬───────┘
              ▼
          React 재렌더링
              │
              ▼
       {open && (...)}
              │
              ▼
           모달 표시
```

이것이 이 예제의 **가장 중요한 React 흐름**입니다.

## 16. `{open && (...)}`

|--------|------|

## 17. `fixed inset-0`

```jsx
<div className="fixed inset-0 z-50 flex items-center justify-center p-4">
```

모달을 **화면 전체**에 덮는 것이 핵심입니다.

### `fixed`

```css
position: fixed;
```

브라우저 화면 기준 위치.

### `inset-0`

```css
top: 0; right: 0; bottom: 0; left: 0;
```

화면 전체를 차지합니다.

```
┌──────────────────────────────┐
│                              │
│          모달 영역            │
│                              │
└──────────────────────────────┘
```

```
│██████████████████████████████│
```


| 레이어 | 역할 |
|--------|------|
| `fixed inset-0` | 화면 전체 배경 |
| `relative max-w-md` | 가운데 흰색 모달 박스 |

## 21. `selected?.name` — Optional Chaining

```jsx
<h3>{selected?.name} 플랜</h3>
```

`?.` = **옵셔널 체이닝(Optional Chaining)**

처음에는 `selected = null`일 수 있습니다.  
`selected.name`을 바로 쓰면 오류가 날 수 있으므로:

```js
selected?.name
```

의미: **selected가 있으면 `name`을 가져오고, 없으면 `undefined`**

## 23. 취소와 확인 버튼

둘 다 현재 코드에서는:

```js
onClick={() => setOpen(false)}
```

| 버튼 | 동작 |
|------|------|
| 취소 | 모달 닫기 |
| 확인 | 모달 닫기 |

실제 결제·가입은 없고 **모달 동작만 보여주는 데모**입니다.

## 꼭 가르칠 핵심 7가지

### ① `useState`

```js
const [open, setOpen] = useState(false);
```

상태를 관리합니다.

### ② 이벤트

```js
onClick={() => openModal(plan)}
```

클릭하면 함수를 실행합니다.

### ③ 상태 변경

```js
setOpen(true);
```

React 상태를 변경합니다.

### ④ 조건부 렌더링

```jsx
{open && (...)}
```

`open`이 `true`일 때만 JSX를 보여줍니다.

### ⑤ 배열 `map()`

```js
plans.map((plan) => ...)
```

데이터를 반복해서 UI로 만듭니다.

### ⑥ 조건부 `className`

```js
plan.highlight ? 'ring-2 ring-teal-500' : ''
```

데이터에 따라 CSS를 다르게 적용합니다.

### ⑦ Optional Chaining

```js
selected?.name
selected?.price
```

`null` / `undefined`일 수 있을 때 안전하게 속성에 접근합니다.

---

## 전체 React 동작 — 한 줄 흐름

```
plans 배열
   ↓
map()
   ↓
가격표 출력
   ↓
선택하기 클릭
   ↓
openModal(plan)
   ↓
selected에 선택한 plan 저장
   ↓
open = true
   ↓
{open && (...)}
   ↓
모달 출력
   ↓
확인 / 취소
   ↓
setOpen(false)
   ↓
모달 닫힘
```

### `setOpen(true)`만으로 모달이 나타나는 이유

> React에서는 **State가 변경되면 컴포넌트가 다시 렌더링**되고,  
> `open`이 `false`에서 `true`가 되었기 때문에 `{open && (...)}` 부분이 화면에 나타난다.

이렇게 설명하면 **`useState`와 조건부 렌더링의 관계**까지 자연스럽게 연결할 수 있습니다.
