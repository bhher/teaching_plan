# Tailwind React 예제

Vite + React + Tailwind(CDN)로 자주 쓰는 UI 패턴을 탭으로 확인합니다.

## 실행

```bash
cd react/tailwind-examples
npm install
npm run dev
```

## 예제 목록

| 탭 | 파일 | 내용 |
|----|------|------|
| 01 | `Ex01Basics.jsx` | 텍스트 · 색 · 간격 · 둥글기 |
| 02 | `Ex02Buttons.jsx` | 버튼 · 뱃지 · 알림 |
| 03 | `Ex03Cards.jsx` | 카드 Grid · map |
| 04 | `Ex04Nav.jsx` | Flex 헤더 · 모바일 메뉴 |
| 05 | `Ex05Form.jsx` | 폼 · focus:ring |
| 06 | `Ex06Hero.jsx` | 히어로 섹션 |
| 07 | `Ex07FlexGrid.jsx` | Flex / Grid 비교 |
| 08 | `Ex08Responsive.jsx` | sm / md / lg |
| 09 | `Ex09Landing.jsx` | 미니 랜딩 |
| 10 | `Ex10PricingModal.jsx` | 가격표 · 모달 |

이론 정리: [../Tailwind-사용법-예제-정리.md](../Tailwind-사용법-예제-정리.md)

> 수업 편의를 위해 `index.html`에 Tailwind CDN을 넣었습니다.  
> 실무 프로젝트는 Vite 플러그인(`@tailwindcss/vite`) 설치를 권장합니다.
