# Boot2

React + Bootstrap + **react-slick** 슬라이더로 만든 데모 페이지입니다.

## 실행

```bash
cd react/boot2
npm install
npm run dev
```

## 구성

| 경로 | 설명 |
|------|------|
| `/` | 홈 — 네비, **Slick 히어로**, 이미지 카드, CTA |
| `/services` | 서비스 소개 (플랜 카드) |
| `/contact` | 문의 폼 (데모 제출) |

## 스택

- Vite, React 18, React Router 6
- react-bootstrap, Bootstrap 5
- react-slick, slick-carousel (CSS)
