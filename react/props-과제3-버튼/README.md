# 과제 3 — 버튼 컴포넌트 (Props)

`react-4차시-Props.md` 과제 3 결과물

## 실행

```bash
npm install
npm run dev
```

## Props

| props | 설명 | 예 |
|-------|------|-----|
| `text` | 버튼 글자 | `"클릭하세요"` |
| `color` | blue / green / red / gray / orange | `"blue"` |
| `size` | small / medium / large | `"large"` |
| `onClick` | 클릭 핸들러 | `() => alert('클릭!')` |
