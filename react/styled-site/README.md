# Styled Site (styled-components)

`styled-components`를 이용해 “컴포넌트 단위 스타일 + 테마 + 전역 스타일”을 한 번에 보여주는 작은 랜딩 페이지 예제입니다.

## 실행

```bash
npm install
npm run dev
```

## 폴더

- `src/styles/GlobalStyle.js`: 전역 스타일
- `src/styles/theme.js`: 테마(색/토큰)
- `src/components/*`: styled-components 기반 UI 컴포넌트
- `src/data/content.js`: 섹션에 들어갈 데이터
