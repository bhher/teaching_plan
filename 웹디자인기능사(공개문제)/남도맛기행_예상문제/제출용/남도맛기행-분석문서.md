## HTML 구조 분석

### 1. 기본 구조

```html

<head>
```

**분석 포인트:**
- HTML5 문서 타입
- 한국어 설정 (`lang="ko"`)

## JavaScript 기능 분석

### 1. jQuery 준비 함수

```javascript
$(function(){
    // 코드 내용
});
```

**의미:**
- `$(function(){})`: `$(document).ready()`의 축약형
- DOM이 준비된 후 실행
- jQuery 1.12.3 버전 사용

### 2. 서브메뉴 호버 효과

```javascript
$(".gnb>li>a").mouseenter(function(){
    $(".gnb>li>ul").css("display","none");
    $(this).next("ul").css("display","block");
});

$(".gnb>li").mouseleave(function(){
    $(".gnb>li>ul").css("display","none");
});
```

**동작 원리:**
1. **mouseenter 이벤트:**
   - 메인 메뉴 링크에 마우스 진입 시
   - 모든 서브메뉴 숨김 (`display:none`)
   - 현재 링크의 다음 요소(`next("ul")`) 서브메뉴 표시 (`display:block`)

2. **mouseleave 이벤트:**
   - 메인 메뉴 항목에서 마우스 벗어날 때
   - 모든 서브메뉴 숨김

**jQuery 메서드:**
- `.mouseenter()`: 마우스 진입 이벤트
- `.mouseleave()`: 마우스 벗어남 이벤트
- `.next()`: 다음 형제 요소 선택
- `.css()`: CSS 속성 설정

**동작 흐름:**
```
[협회소개] (마우스 진입)
  ↓
모든 서브메뉴 숨김
  ↓
[협회소개]의 서브메뉴 표시
  ├─ 인사말
  ├─ 명인
  └─ 오시는길
```

### 3. 이미지 슬라이드 자동 전환

```javascript
var i = 0;

setInterval(function(){
    i++;
    if(i==3){
        i=0;
    }
    $(".img_slide>ul>li").eq(i).css("left","100%").stop().animate({
        "left":0
    });
    $(".img_slide>ul>li").eq(i-1).css("left","0%").stop().animate({
        "left":"-100%"
    });
},3000);
```

**동작 원리:**
1. **변수 초기화:**
   - `var i = 0`: 현재 슬라이드 인덱스

2. **setInterval:**
   - 3초(3000ms)마다 실행
   - 무한 반복

3. **인덱스 증가:**
   - `i++`: 다음 슬라이드로 이동
   - `if(i==3){ i=0; }`: 마지막 슬라이드 후 첫 번째로

4. **새 슬라이드 표시:**
   - `.eq(i)`: i번째 슬라이드 선택
   - `css("left","100%")`: 오른쪽 밖으로 이동
   - `.stop()`: 진행 중인 애니메이션 중지
   - `.animate({left:0})`: 왼쪽으로 슬라이드

5. **이전 슬라이드 숨김:**
   - `.eq(i-1)`: 이전 슬라이드 선택
   - `css("left","0%")`: 현재 위치
   - `.animate({left:"-100%"})`: 왼쪽 밖으로 슬라이드

**애니메이션 흐름:**
```
초기: [슬라이드1] (left:0)
     [슬라이드2] (left:100%)
     [슬라이드3] (left:100%)

3초 후: [슬라이드1] → left:-100% (왼쪽으로 사라짐)
        [슬라이드2] → left:0 (오른쪽에서 나타남)
        [슬라이드3] (left:100%)

6초 후: [슬라이드2] → left:-100%
        [슬라이드3] → left:0
        [슬라이드1] (left:100%)
```

**jQuery 메서드:**
- `.eq(index)`: 인덱스로 요소 선택
- `.stop()`: 애니메이션 중지
- `.animate()`: CSS 속성 애니메이션
- `setInterval()`: 반복 실행

### 4. 탭 메뉴 전환

```javascript
$(".menu ul li").click(function(){
    var i = $(this).index();

    $(".btn").css("display","none").eq(i).css("display","block");
    $(".menu ul li").removeClass("on").eq(i).addClass("on");
});
```

**동작 원리:**
1. **클릭 이벤트:**
   - `.menu ul li` 클릭 시 실행

2. **인덱스 가져오기:**
   - `$(this).index()`: 클릭한 요소의 인덱스

3. **콘텐츠 전환:**
   - 모든 `.btn` 숨김 (`display:none`)
   - 선택한 인덱스의 `.btn` 표시 (`display:block`)

4. **메뉴 활성화:**
   - 모든 메뉴에서 `on` 클래스 제거
   - 선택한 메뉴에 `on` 클래스 추가

**현재 코드의 문제점:**
- 현재 HTML에는 각 컬럼에 하나의 메뉴만 있음
- 탭 기능이 제대로 작동하지 않을 수 있음
- 여러 탭이 있을 때를 위한 코드

**jQuery 메서드:**
- `.index()`: 요소의 인덱스 반환
- `.removeClass()`: 클래스 제거
- `.addClass()`: 클래스 추가
- `.eq()`: 인덱스로 선택

### 5. 팝업 모달 열기/닫기

```javascript
$(".t1").click(function(){
    $(".pop").stop().fadeIn();
});

$("button").click(function(){
    $(".pop").stop().fadeOut();
});
```

**동작 원리:**
1. **팝업 열기:**
   - `.t1` (공지사항 첫 번째 행) 클릭 시
   - `.pop` 요소에 `.fadeIn()` 적용
   - `.stop()`: 진행 중인 애니메이션 중지

2. **팝업 닫기:**
   - `button` (닫기 버튼) 클릭 시
   - `.pop` 요소에 `.fadeOut()` 적용

**fadeIn/fadeOut:**
- `fadeIn()`: 투명 → 불투명 (서서히 나타남)
- `fadeOut()`: 불투명 → 투명 (서서히 사라짐)
- 기본 지속 시간: 400ms

**jQuery 메서드:**
- `.fadeIn()`: 페이드 인 효과
- `.fadeOut()`: 페이드 아웃 효과
- `.stop()`: 애니메이션 중지

```
              └─────────────┘
```

### 3. 슬라이드 애니메이션 원리

**초기 상태:**
```css
li:first-child { left: 0; }    /* 보임 */
li:nth-child(2) { left: 100%; } /* 오른쪽 밖 */
li:nth-child(3) { left: 100%; } /* 오른쪽 밖 */
```

**전환 과정:**
1. 새 슬라이드를 `left:100%`로 설정 (오른쪽 밖)
2. `animate({left:0})`로 왼쪽으로 슬라이드
3. 현재 슬라이드를 `animate({left:-100%})`로 왼쪽 밖으로 이동

**애니메이션 타이밍:**
- `setInterval(..., 3000)`: 3초마다 실행
- `.animate()`: 기본 400ms 지속 시간
- `.stop()`: 이전 애니메이션 중지 (겹침 방지)

### 4. 팝업 모달 레이어 구조

```css
.pop {
    position: fixed;
    width: 100%;
    height: 100%;
    background: rgba(0,0,0,0.3);
}
```

**레이어 구조:**
```
┌─────────────────────────┐
│   .pop (전체 화면)       │ ← position:fixed
│   (반투명 배경)          │
│                          │
│      ┌─────────────┐    │
│      │ .pop_cover  │    │ ← 중앙 정렬
│      │ (팝업 내용) │    │

└─────────────────────────┘
```

**중앙 정렬 방법:**
```css
.pop_cover {
    position: absolute;
    top: 50%;
    left: 50%;

}
```

- `top:50%; left:50%`: 요소의 왼쪽 상단 모서리를 중앙에 배치
- `transform:translate(-50%,-50%)`: 요소 자체를 반만큼 이동하여 정확한 중앙 정렬
