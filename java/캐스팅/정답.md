## Part 4. 코드 작성 정답

### 16번. 기본형 캐스팅

```java
double d = 12.8;
int n = (int) d;
System.out.println(n);  // 12
```

Animal[] animals = new Animal[2];
animals[0] = new Dog();
animals[1] = new Cat();

for (Animal a : animals) {
    a.sound();

### 18번. 안전한 다운캐스팅

```java
public static void checkAnimal(Animal a) {
    if (a instanceof Dog) {
        Dog d = (Dog) a;
        d.wag();
    } else if (a instanceof Cat) {
        Cat c = (Cat) a;
        c.climb();
    } else {
        System.out.println("알 수 없는 동물");
    }
}
```

**Java 16+ 패턴 매칭 (참고)**

```java
if (a instanceof Dog d) {
    d.wag();
} else if (a instanceof Cat c) {
    c.climb();
} else {
    System.out.println("알 수 없는 동물");
}
```

### 19번. Shape 다형성

```java
class Shape {
    void draw() {
        System.out.println("도형을 그립니다");
    }
}

class Circle extends Shape {
    double radius;

    Circle(double radius) {
        this.radius = radius;
    }

    @Override
    void draw() {
        System.out.println("원을 그립니다");
    }
}

class Rectangle extends Shape {
    int width;
    int height;

    Rectangle(int width, int height) {
        this.width = width;
        this.height = height;
    }

    @Override
    void draw() {
        System.out.println("사각형을 그립니다");
    }
}

public class ShapeMain {
    public static void main(String[] args) {
        Shape s1 = new Circle(5.0);       // 업캐스팅
        Shape s2 = new Rectangle(10, 20); // 업캐스팅
        s1.draw();  // 원을 그립니다
        s2.draw();  // 사각형을 그립니다
    }
}
```

### 20번. 직원 · Manager

```java
class Employee {
    String name;
    int salary;

    Employee(String name, int salary) {
        this.name = name;
        this.salary = salary;
    }

    void showInfo() {
        System.out.println("이름: " + name + ", 급여: " + salary);
    }
}

class Manager extends Employee {
    int bonus;

    Manager(String name, int salary, int bonus) {
        super(name, salary);
        this.bonus = bonus;
    }

    @Override
    void showInfo() {
        System.out.println("이름: " + name + ", 급여: " + (salary + bonus));
    }

    void manage() {
        System.out.println("팀을 관리합니다");
    }
}

public class EmployeeMain {
    public static void main(String[] args) {
        Employee e = new Manager("홍길동", 3000, 500);  // 업캐스팅
        e.showInfo();  // 이름: 홍길동, 급여: 3500

        if (e instanceof Manager) {
            Manager m = (Manager) e;  // 다운캐스팅
            m.manage();              // 팀을 관리합니다
        }
    }
}
```

## 핵심 정리표

| 구분 | 방향 | 표기 | 위험 |
|------|------|------|------|
| 확대 변환 | 작은 → 큰 기본형 | 생략 가능 | 거의 없음 |
| 축소 변환 | 큰 → 작은 기본형 | `(int)` 등 | 값 손실 |
| 업캐스팅 | 자식 → 부모 | 자동 | 자식 전용 멤버 접근 불가 |
| 다운캐스팅 | 부모 → 자식 | `(Dog) a` | `ClassCastException` |

```text
메서드(오버라이딩)  →  실제 객체(자식) 기준
필드               →  참조 변수 타입(부모) 기준
```

```text
안전한 다운캐스팅
  if (a instanceof Dog) {
      Dog d = (Dog) a;
  }
```
