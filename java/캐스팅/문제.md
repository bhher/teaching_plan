# 자바 캐스팅(Casting) 종합 문제

기본형 변환 · 업캐스팅 · 다운캐스팅 · `instanceof` 를 다루는 문제입니다.

정답: [정답.md](./정답.md)

---

## 학습 목표

1. **기본형(primitive)** 확대/축소 변환
2. **업캐스팅** — 자식 → 부모 (자동)
3. **다운캐스팅** — 부모 → 자식 (명시 + 위험)
4. **`instanceof`** 로 안전한 다운캐스팅
5. 오버라이딩과 필드 접근의 차이

## Part 2. 업캐스팅 · 다운캐스팅 (결과 예측)

다음 클래스를 기준으로 6~12번을 푸세요.

```java
class Animal {
    String name = "동물";

    void sound() {
        System.out.println("동물이 소리를 낸다");
    }
}

class Dog extends Animal {
    String name = "강아지";

    @Override
    void sound() {
        System.out.println("멍멍");
    }

    void wag() {
        System.out.println("꼬리 흔들기");
    }
}

class Cat extends Animal {
    @Override
    void sound() {
        System.out.println("야옹");
    }

    void climb() {
        System.out.println("나무 오르기");
    }
}
```

---

### 6번

다음 코드의 출력은?

```java
Animal a = new Dog();  // 업캐스팅
a.sound();
```

① `동물이 소리를 낸다`  
② `멍멍`  
③ 컴파일 오류  
④ 런타임 오류

---

### 7번

다음 코드의 출력은?

```java
Animal a = new Dog();
System.out.println(a.name);
```

① `동물`  
② `강아지`  
③ 컴파일 오류  
④ `null`

---

### 8번

다음 중 **컴파일 오류**가 나는 것은?

① `Animal a = new Dog();`  
② `Dog d = new Dog(); Animal a = d;`  
③ `Animal a = new Dog(); a.wag();`  
④ `Animal a = new Dog(); a.sound();`

---

### 9번

다음 코드의 출력은?

```java
Animal a = new Dog();
Dog d = (Dog) a;  // 다운캐스팅
d.wag();
```

① `꼬리 흔들기`  
② 컴파일 오류  
③ `ClassCastException`  
④ `멍멍`

---

### 10번

다음 코드 실행 결과는?

```java
Animal a = new Cat();
Dog d = (Dog) a;
d.wag();
```

① `꼬리 흔들기`  
② 컴파일 오류  
③ `ClassCastException` (런타임 오류)  
④ `야옹`

---

### 11번

다음 코드의 출력은?

```java
Animal a = new Dog();
if (a instanceof Dog) {
    Dog d = (Dog) a;
    d.wag();
} else {
    System.out.println("Dog가 아님");
}
```

① `꼬리 흔들기`  
② `Dog가 아님`  
③ 컴파일 오류  
④ `멍멍`

## Part 3. 개념 정리 (객관식)

### 13번

업캐스팅에 대한 설명으로 **옳은** 것은?

① 반드시 `(부모타입)` 을 적어야 한다  
② 부모 참조로 자식만의 메서드를 바로 호출할 수 있다  
③ 오버라이딩된 메서드는 자식 버전이 호출된다  
④ 필드도 항상 자식 필드가 출력된다

---

### 14번

다운캐스팅에 대한 설명으로 **옳은** 것은?

① 항상 자동으로 된다  
② 실제 객체가 해당 자식이 아니면 `ClassCastException` 가능  
③ `instanceof` 없이도 항상 안전하다  
④ 업캐스팅보다 먼저 해야 한다

---

### 15번

`instanceof` 의 역할로 알맞은 것은?

① 객체를 새로 생성한다  
② 변수가 특정 타입(또는 그 자식)인지 검사한다  
③ 무조건 true를 반환한다  
④ 캐스팅을 자동으로 수행한다

### 19번. Shape 다형성 (코딩)

아래 구조를 구현하고 `main`에서 업캐스팅으로 `draw()` 를 호출하세요.

```text
Shape (부모)
  ├── draw() → "도형을 그립니다"
  │
  ├── Circle (자식)
  │     draw() → "원을 그립니다"
  │     double radius 필드
  │
  └── Rectangle (자식)
        draw() → "사각형을 그립니다"
        int width, height 필드
```

`main` 예:

```java
Shape s1 = new Circle(5.0);
Shape s2 = new Rectangle(10, 20);
s1.draw();
s2.draw();
```

### 20번. 직원 급여 출력 (실전형)

```text
Employee (부모)
  - String name
  - int salary
  - void showInfo() → "이름: ○○, 급여: ○○"

Manager extends Employee
  - int bonus
  - showInfo() 오버라이딩 → 급여+보너스 합산 출력
  - void manage() → "팀을 관리합니다"
```

요구:

1. `Employee e = new Manager("홍길동", 3000, 500);` (업캐스팅)
2. `e.showInfo()` 호출
3. `instanceof` 확인 후 `manage()` 호출

예상 출력 예:

```text
이름: 홍길동, 급여: 3500
팀을 관리합니다
```

## 체크리스트

- [ ] 기본형: 큰→작은은 `(타입)` 필요, 소수→정수 시 **버림**
- [ ] 업캐스팅: 자동, 부모 멤버만 직접 접근
- [ ] 메서드 오버라이딩 → **자식** 실행 / 필드 → **참조 타입** 기준
- [ ] 다운캐스팅: `(자식타입)` + 실제 객체가 맞아야 함
- [ ] `instanceof` 후 다운캐스팅
