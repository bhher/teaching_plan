## 기본 개념

### 업캐스팅(Upcasting)이란?

**정의:** 자식 클래스 객체를 부모 클래스 타입으로 변환하는 것

**특징:**
- 자동 변환 (묵시적 변환)
- 부모 클래스 참조 변수로 자식 객체 참조 가능
- 부모 클래스의 멤버만 접근 가능
- 메서드 오버라이딩 시 자식 클래스의 메서드가 호출됨 (동적 바인딩)

**예제:**
```java
class Parent {
    void show() { System.out.println("Parent"); }
}

class Child extends Parent {
    void show() { System.out.println("Child"); }
}

Parent p = new Child();  // 업캐스팅
p.show();  // "Child" 출력 (오버라이딩된 메서드 호출)
```

## 기본 문제 (1-5번)

### 문제 1: 기본 업캐스팅

**문제:** 다음 코드의 출력 결과를 쓰시오.

```java
class Animal {
    void sound() {
        System.out.println("동물 소리");
    }
}

class Dog extends Animal {
    void sound() {
        System.out.println("멍멍");
    }
}

public class Main {
    public static void main(String[] args) {
        Animal animal = new Dog();
        animal.sound();
    }
}
```

### 문제 11: 다형성과 오버라이딩

**문제:** 다음 코드의 출력 결과를 쓰시오.

```java
class Base {
    int value = 10;
    
    void show() {
        System.out.println("Base: " + value);
    }
}

class Derived extends Base {
    int value = 20;
    
    void show() {
        System.out.println("Derived: " + value);
    }
    
    void showParent() {
        System.out.println("Parent value: " + super.value);
    }
}

public class Main {
    public static void main(String[] args) {
        Base b = new Derived();
        System.out.println(b.value);
        b.show();
        
        Derived d = (Derived) b;
        d.showParent();
    }
}
```

## 정답 및 해설

### 문제 1 정답

**답:** `멍멍`

**해설:**
- `Animal animal = new Dog();`: 업캐스팅 (Dog 객체를 Animal 타입으로 참조)
- `animal.sound()`: 오버라이딩된 메서드 호출
- 동적 바인딩에 의해 실제 객체(Dog)의 `sound()` 메서드가 호출됨

**핵심 개념:**
- 업캐스팅은 자동으로 이루어짐
- 메서드 오버라이딩 시 자식 클래스의 메서드가 호출됨

---

### 문제 2 정답

**답:**
```
100
Child: 200
```

**해설:**
- `Parent p = new Child();`: 업캐스팅
- `p.x`: 부모 클래스의 필드에 접근 → `100`
- `p.show()`: 오버라이딩된 메서드 호출 → `"Child: 200"`

**핵심 개념:**
- 필드는 참조 변수의 타입에 따라 결정됨 (정적 바인딩)
- 메서드는 실제 객체의 타입에 따라 결정됨 (동적 바인딩)

---

### 문제 3 정답

**답:**
```
자동차 시동
차량 정지
```

**해설:**
- `Vehicle v = new Car();`: 업캐스팅
- `v.start()`: 오버라이딩된 메서드 → `"자동차 시동"`
- `v.stop()`: 부모 클래스의 메서드 → `"차량 정지"`
- `v.drive()`: 컴파일 오류 (부모 클래스에 없는 메서드)

**핵심 개념:**
- 업캐스팅 시 부모 클래스에 정의된 멤버만 접근 가능
- 자식 클래스에만 있는 메서드는 호출 불가

### 문제 4 정답

**답:**
```
Parent 생성자
Child 생성자
Child method
```

**해설:**
- 객체 생성 시 부모 생성자부터 호출됨
- `super()`가 자동으로 호출되어 부모 생성자 실행
- 그 다음 자식 생성자 실행
- `p.method()`: 오버라이딩된 메서드 호출

**핵심 개념:**
- 생성자 호출 순서: 부모 → 자식
- `super()`는 자동으로 호출됨

### 문제 6 정답

**답:**
```
B
C

```

**해설:**
- `A a1 = new B();`: B 객체를 A 타입으로 참조
  - `a1.display()` → B의 `display()` 호출
- `A a2 = new C();`: C 객체를 A 타입으로 참조
  - `a2.display()` → C의 `display()` 호출
- `B b = new C();`: C 객체를 B 타입으로 참조
  - `b.display()` → C의 `display()` 호출

**핵심 개념:**
- 다중 상속 계층에서도 동적 바인딩 적용
- 실제 객체의 타입에 따라 메서드가 호출됨

### 문제 8 정답

**답:**
```
Parent static
Child instance
```

**해설:**
- `p.method()`: static 메서드는 오버라이딩되지 않음 → `"Parent static"`
- `p.instanceMethod()`: 인스턴스 메서드는 오버라이딩됨 → `"Child instance"`

**핵심 개념:**
- static 메서드는 오버라이딩되지 않음 (메서드 숨김)
- 인스턴스 메서드만 동적 바인딩 적용

### 문제 10 정답

**답:**
```

```

**해설:**
- `p.process(p)`: `Parent` 타입 매개변수 → `"Child process Parent"`
- `p.process(c)`: `Child` 타입이지만 참조 변수 타입이 `Parent`이므로 `Parent` 타입으로 처리 → `"Child process Parent"`

**핵심 개념:**
- 오버로딩은 컴파일 타임에 결정됨
- 참조 변수의 타입에 따라 메서드가 선택됨

```

- `d.showParent()`: `super.value`로 부모 클래스의 필드 접근 → `10`

**핵심 개념:**
- 필드는 참조 변수 타입에 따라 결정

B test
C test
C test
B testB
```

**해설:**
- `A a1 = new B();`: B 객체를 A 타입으로 참조
  - `a1.test()` → B의 `test()` 호출
- `A a2 = new C();`: C 객체를 A 타입으로 참조
  - `a2.test()` → C의 `test()` 호출
- `B b = new C();`: C 객체를 B 타입으로 참조
  - `b.test()` → C의 `test()` 호출
  - `b.testB()` → B의 `testB()` 호출 가능

**핵심 개념:**
- 다중 상속 계층에서의 업캐스팅
- 참조 변수 타입에 따라 접근 가능한 멤버 결정

## 핵심 개념 정리

### 1. 업캐스팅의 특징

**자동 변환:**
```java
Parent p = new Child();  // 자동으로 업캐스팅
```

**접근 제한:**
- 부모 클래스에 정의된 멤버만 접근 가능
- 자식 클래스에만 있는 멤버는 접근 불가

**메서드 호출:**
- 오버라이딩된 메서드는 자식 클래스의 메서드 호출 (동적 바인딩)
- 필드는 부모 클래스의 필드에 접근 (정적 바인딩)

### 2. 필드 vs 메서드

| 구분 | 필드 | 메서드 |
|------|------|--------|
| 바인딩 | 정적 바인딩 | 동적 바인딩 |
| 결정 시점 | 컴파일 타임 | 런타임 |
| 참조 기준 | 참조 변수 타입 | 실제 객체 타입 |

### 3. static 메서드

- static 메서드는 오버라이딩되지 않음
- 메서드 숨김(Method Hiding) 개념
- 참조 변수 타입에 따라 호출됨

### 4. 생성자 호출 순서

1. 부모 초기화 블록
2. 부모 생성자
3. 자식 초기화 블록
4. 자식 생성자

### 5. 다운캐스팅

```java
Parent p = new Child();
Child c = (Child) p;  // 다운캐스팅 (명시적 변환 필요)
```

- 업캐스팅된 객체를 다시 자식 타입으로 변환
- 명시적 캐스팅 필요
- 잘못된 캐스팅 시 `ClassCastException` 발생
