# HashMap 연습문제 — 도서(Book) 관리

`Student` + `Map` 예제와 같은 방식으로,  
**학번 → Student** 대신 **도서번호 → Book** 을 저장하는 프로그램을 작성하세요.

---

## 학습 목표

- `Map<String, Book>` 에 객체를 저장한다
- `put`, `get`, `remove`, `keySet`, `entrySet` 을 사용한다
- Key로 조회·수정·삭제한다

---

## Map 구조

```text
Map<String, Book>

┌──────────┬──────────────────────────────┐
│ Key      │ Value                        │
├──────────┼──────────────────────────────┤
│ B001     │ Book(자바의 정석, 남궁성, 30000) │
│ B002     │ Book(혼자 공부하는 자바, 신용권, 28000) │
│ B003     │ Book(이것이 자바다, 신용권, 35000) │
└──────────┴──────────────────────────────┘

Key   : 도서번호 (String)
Value : Book 객체
```

---

## 예제 1. Book 클래스

다음 필드를 가진 `Book` 클래스를 작성하세요.

| 필드 | 타입 | 설명 |
|------|------|------|
| `title` | `String` | 제목 |
| `author` | `String` | 저자 |
| `price` | `int` | 가격 |

요구사항:

- 생성자: `Book(String title, String author, int price)`
- Getter: `getTitle()`, `getAuthor()`, `getPrice()`
- Setter: `setPrice(int price)` 만 작성
- `toString()` 출력 형식:

```text
제목 : 자바의 정석, 저자 : 남궁성, 가격 : 30000
```

---

## 예제 2. HashMap에 객체 저장 + 전체 출력

`BookMapTest` 클래스를 만들고 다음을 구현하세요.

```java
Map<String, Book> bookMap = new HashMap<>();
```

저장할 데이터:

| 도서번호 | 제목 | 저자 | 가격 |
|----------|------|------|------|
| B001 | 자바의 정석 | 남궁성 | 30000 |
| B002 | 혼자 공부하는 자바 | 신용권 | 28000 |
| B003 | 이것이 자바다 | 신용권 | 35000 |

`keySet()`으로 전체 도서를 출력하세요.

### 실행 결과 예시

```text
=== 전체 도서 ===
B001 : 제목 : 자바의 정석, 저자 : 남궁성, 가격 : 30000
B002 : 제목 : 혼자 공부하는 자바, 저자 : 신용권, 가격 : 28000
B003 : 제목 : 이것이 자바다, 저자 : 신용권, 가격 : 35000
```

## 예제 4. 가격 수정

`"B002"` 도서의 가격을 `25000`으로 수정한 뒤 다시 출력하세요.

힌트:

```java
bookMap.get("B002").setPrice(25000);
```


도서번호 `"B003"` 을 삭제하세요.

## Student 예제와 비교

| Student 예제 | Book 예제 (이번 문제) |
|--------------|------------------------|
| `Map<String, Student>` | `Map<String, Book>` |
| Key = 학번 | Key = 도서번호 |
| Value = Student | Value = Book |
| `setScore()` | `setPrice()` |
| 이름, 나이, 점수 | 제목, 저자, 가격 |

2. 저자가 `"신용권"`인 도서 개수 세기
3. Scanner로 도서번호 입력받아 조회하기
