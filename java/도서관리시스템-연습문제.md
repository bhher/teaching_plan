# 도서 관리 시스템 연습문제

## 문제 설명

Main.java와 BookDAO 코드를 참고하여 **도서 관리 시스템**을 구현하세요.

### 요구사항

1. **Book 클래스**를 만들어야 합니다.
   - 도서 ID (id: int)
   - 도서 제목 (title: String)
   - 저자명 (author: String)
   - ISBN (isbn: String)
   - 가격 (price: double)

2. **BookManager 클래스**를 만들어야 합니다.
   - 도서 목록을 `ArrayList<Book>`로 관리
   - 파일 경로: `c:/Users/TJ/memo/book.txt`
   - 디렉토리 자동 생성 기능 포함

3. **필수 기능**
   - 도서 추가 (제목, 저자, ISBN, 가격 입력)
   - 도서 삭제 (제목으로 찾아서 삭제)
   - 도서 검색 (제목으로 검색)
   - 도서 수정 (제목으로 찾아서 정보 수정)
   - 도서 목록 보기 (전체 도서 출력)
   - 파일 저장
   - 파일 불러오기

### 파일 저장 형식

```
ID|제목|저자|ISBN|가격
```

**예시:**
```
0|자바의 정석|남궁성|12345|32000.0
1|Effective Java|Joshua Bloch|54321|45000.0
2|Clean Code|Robert C. Martin|67890|38000.0
```

```

```

### 기능 상세 설명

#### 1. 도서 추가
- 도서 제목, 저자명, ISBN, 가격을 입력받아 도서를 추가합니다.
- 도서 ID는 자동으로 부여됩니다 (현재 목록 크기).
- 가격은 숫자만 입력 가능하며, 잘못된 입력 시 재입력을 요청합니다.
- 도서가 추가되면 "도서가 추가되었습니다." 메시지를 출력합니다.

#### 2. 도서 삭제
- 도서 제목을 입력받아 해당 도서를 찾습니다.
- 도서를 찾으면 삭제하고 "도서명을 제거하였습니다." 메시지를 출력합니다.
- 도서를 찾지 못하면 "찾는 도서가 없습니다." 메시지를 출력합니다.

#### 3. 도서 검색
- 도서 제목을 입력받아 해당 도서를 찾습니다.
- 도서를 찾으면 도서 정보를 출력합니다.
- 도서를 찾지 못하면 "찾는 도서가 없습니다." 메시지를 출력합니다.

#### 4. 도서 수정
- 도서 제목을 입력받아 해당 도서를 찾습니다.
- 도서를 찾으면 새로운 제목, 저자, ISBN, 가격을 입력받아 수정합니다.
- 도서를 찾지 못하면 "찾는 도서가 없습니다." 메시지를 출력합니다.
- 수정 완료 시 "도서 정보가 수정되었습니다." 메시지를 출력합니다.

#### 5. 도서 목록 보기
- 등록된 모든 도서의 정보를 출력합니다.
- 도서가 없으면 "등록된 도서가 없습니다." 메시지를 출력합니다.
- 각 도서는 번호와 함께 출력됩니다.

#### 6. 파일 저장
- 현재 메모리에 있는 모든 도서 정보를 파일에 저장합니다.
- 디렉토리가 없으면 자동으로 생성합니다.
- 저장 완료 시 "파일 저장 완료: 파일경로" 메시지를 출력합니다.

#### 7. 파일 불러오기
- 파일에서 도서 정보를 읽어와 메모리에 로드합니다.
- 파일이 없으면 "파일이 없습니다. 새로 시작합니다." 메시지를 출력합니다.
- 불러오기 완료 시 "파일 불러오기 완료! (도서 수)권" 메시지를 출력합니다.

### 평가 기준

1. **기본 기능 구현 (40점)**

   - BookManager 클래스 기본 구조

2. **핵심 기능 구현 (40점)**

   - 도서 검색 (제목으로 찾기)
   - 도서 수정 (제목으로 찾아서 수정)
   - 도서 목록 보기
