## 1. 람다 표현식 기초

### 1-1. 람다 표현식이란?

**람다 표현식(Lambda Expression)**은 Java 8에서 도입된 기능으로, **익명 함수(Anonymous Function)**를 간결하게 표현하는 방법입니다.

#### 기존 방식 vs 람다 표현식

**기존 방식 (익명 클래스):**
```java
// Runnable 인터페이스 구현
Runnable r = new Runnable() {
    @Override
    public void run() {
        System.out.println("Hello World");
    }
};
```

**람다 표현식:**
```java
Runnable r = () -> System.out.println("Hello World");
```

### 1-2. 람다 표현식 기본 문법

#### 기본 구조

```java
(매개변수) -> { 실행문 }
```

#### 문법 규칙

1. **매개변수가 1개인 경우**: 괄호 생략 가능
   ```java
   x -> x * 2
   (x) -> x * 2  // 둘 다 동일
   ```

2. **매개변수가 없는 경우**: 빈 괄호 사용
   ```java
   () -> System.out.println("Hello")
   ```

3. **매개변수가 2개 이상인 경우**: 괄호 필수
   ```java
   (x, y) -> x + y
   ```

4. **실행문이 1개인 경우**: 중괄호 생략 가능
   ```java
   x -> x * 2
   x -> { return x * 2; }  // 둘 다 동일
   ```

5. **return 문만 있는 경우**: return 키워드 생략 가능
   ```java
   x -> x * 2
   x -> { return x * 2; }  // 둘 다 동일
   ```

### 1-3. 람다 표현식 예제

#### 예제 1: 단순 연산

```java
// 덧셈
BinaryOperator<Integer> add = (a, b) -> a + b;
System.out.println(add.apply(5, 3));  // 8

// 곱셈
BinaryOperator<Integer> multiply = (a, b) -> a * b;
System.out.println(multiply.apply(4, 5));  // 20
```

#### 예제 2: 조건 검사

```java
// 짝수 판별
Predicate<Integer> isEven = x -> x % 2 == 0;
System.out.println(isEven.test(4));  // true
System.out.println(isEven.test(5));  // false

// 양수 판별
Predicate<Integer> isPositive = x -> x > 0;
System.out.println(isPositive.test(10));  // true
```

#### 예제 3: 문자열 처리

```java
// 문자열 길이 반환
Function<String, Integer> length = s -> s.length();
System.out.println(length.apply("Hello"));  // 5

// 대문자 변환
Function<String, String> toUpper = s -> s.toUpperCase();
System.out.println(toUpper.apply("hello"));  // HELLO
```

### 1-4. 람다 표현식의 장점

- ✅ **코드 간결성**: 불필요한 보일러플레이트 코드 제거
- ✅ **가독성 향상**: 의도가 명확하게 드러남
- ✅ **함수형 프로그래밍 지원**: 함수를 값으로 다룰 수 있음
- ✅ **병렬 처리 용이**: 스트림과 함께 사용 시 병렬 처리 쉬움

## 2. 함수형 인터페이스

### 2-1. 함수형 인터페이스란?

**함수형 인터페이스(Functional Interface)**는 **단 하나의 추상 메서드만** 가진 인터페이스입니다.

```java
@FunctionalInterface
public interface MyFunction {
    int calculate(int a, int b);
    // 추상 메서드가 1개만 있어야 함
}
```

### 2-2. @FunctionalInterface 어노테이션

```java
@FunctionalInterface
public interface Calculator {
    int operate(int a, int b);
    
    // default 메서드는 허용됨
    default void printResult(int result) {
        System.out.println("결과: " + result);
    }
    
    // static 메서드도 허용됨
    static void info() {
        System.out.println("계산기 인터페이스");
    }
}
```

### 2-3. Java에서 제공하는 주요 함수형 인터페이스

#### 1. Predicate<T> - 조건 검사

```java
// T 타입을 받아서 boolean 반환
Predicate<Integer> isEven = x -> x % 2 == 0;
Predicate<String> isEmpty = s -> s.isEmpty();

// 메서드
boolean test(T t);           // 조건 검사
Predicate<T> and(Predicate<T> other);  // AND 연산
Predicate<T> or(Predicate<T> other);   // OR 연산
Predicate<T> negate();                 // NOT 연산

// 예제
Predicate<Integer> isPositive = x -> x > 0;
Predicate<Integer> isEven = x -> x % 2 == 0;
Predicate<Integer> isPositiveAndEven = isPositive.and(isEven);
```

#### 2. Function<T, R> - 변환 함수

```java
// T 타입을 받아서 R 타입 반환
Function<String, Integer> length = s -> s.length();
Function<Integer, String> toString = i -> String.valueOf(i);

// 메서드
R apply(T t);                    // 함수 적용
Function<T, V> andThen(Function<R, V> after);  // 함수 합성
Function<V, R> compose(Function<V, T> before);

// 예제
Function<String, Integer> length = s -> s.length();
Function<Integer, Integer> doubleIt = x -> x * 2;
Function<String, Integer> lengthThenDouble = length.andThen(doubleIt);
```

#### 3. Consumer<T> - 소비 함수

```java
// T 타입을 받아서 아무것도 반환하지 않음
Consumer<String> printer = s -> System.out.println(s);
Consumer<Integer> square = x -> System.out.println(x * x);

// 메서드
void accept(T t);  // 값 소비
Consumer<T> andThen(Consumer<T> after);  // 체이닝

// 예제
Consumer<String> print = s -> System.out.print(s);
Consumer<String> newLine = s -> System.out.println();
Consumer<String> printWithNewLine = print.andThen(newLine);
```

#### 4. Supplier<T> - 공급 함수

```java
// 아무것도 받지 않고 T 타입 반환
Supplier<String> greeting = () -> "Hello";
Supplier<Integer> random = () -> (int)(Math.random() * 100);

// 메서드
T get();  // 값 생성

// 예제
Supplier<LocalDateTime> now = () -> LocalDateTime.now();
Supplier<List<String>> emptyList = () -> new ArrayList<>();
```

#### 5. BinaryOperator<T> - 이항 연산

```java
// 같은 타입 T 두 개를 받아서 T 반환
BinaryOperator<Integer> add = (a, b) -> a + b;
BinaryOperator<String> concat = (a, b) -> a + b;

// 예제
BinaryOperator<Integer> max = (a, b) -> a > b ? a : b;
BinaryOperator<Integer> min = Integer::min;  // 메서드 참조 사용
```

#### 6. UnaryOperator<T> - 단항 연산

```java
// T 타입을 받아서 T 반환
UnaryOperator<Integer> square = x -> x * x;
UnaryOperator<String> toUpper = s -> s.toUpperCase();

// 예제
UnaryOperator<Integer> increment = x -> x + 1;
UnaryOperator<Integer> doubleIt = x -> x * 2;
```

### 2-4. 함수형 인터페이스 조합

```java
// Predicate 조합
Predicate<Integer> isPositive = x -> x > 0;
Predicate<Integer> isEven = x -> x % 2 == 0;
Predicate<Integer> isPositiveAndEven = isPositive.and(isEven);
Predicate<Integer> isPositiveOrEven = isPositive.or(isEven);
Predicate<Integer> isNotPositive = isPositive.negate();

// Function 조합
Function<Integer, Integer> addOne = x -> x + 1;
Function<Integer, Integer> multiplyTwo = x -> x * 2;
Function<Integer, Integer> addOneThenMultiplyTwo = addOne.andThen(multiplyTwo);
Function<Integer, Integer> multiplyTwoThenAddOne = addOne.compose(multiplyTwo);

// Consumer 체이닝
Consumer<String> print = System.out::print;
Consumer<String> printWithNewLine = print.andThen(s -> System.out.println());
```

## 3. 메서드 참조

### 3-1. 메서드 참조란?

**메서드 참조(Method Reference)**는 람다 표현식을 더 간결하게 만드는 방법입니다. 이미 존재하는 메서드를 참조하여 사용할 수 있습니다.

### 3-2. 메서드 참조 종류

#### 1. 정적 메서드 참조

```java
// 람다 표현식
Function<String, Integer> parseInt = s -> Integer.parseInt(s);

// 메서드 참조
Function<String, Integer> parseInt = Integer::parseInt;

// 예제
List<String> numbers = Arrays.asList("1", "2", "3");
List<Integer> integers = numbers.stream()
    .map(Integer::parseInt)
    .collect(Collectors.toList());
```

#### 2. 인스턴스 메서드 참조

```java
// 람다 표현식
Function<String, String> toUpper = s -> s.toUpperCase();

// 메서드 참조
Function<String, String> toUpper = String::toUpperCase;

// 예제
List<String> names = Arrays.asList("apple", "banana", "cherry");
List<String> upperNames = names.stream()
    .map(String::toUpperCase)
    .collect(Collectors.toList());
```

#### 3. 특정 객체의 인스턴스 메서드 참조

```java
// 람다 표현식
String str = "Hello";
Consumer<String> printer = s -> System.out.println(s);

// 메서드 참조
Consumer<String> printer = System.out::println;

// 예제
List<String> names = Arrays.asList("Alice", "Bob", "Charlie");
names.forEach(System.out::println);
```

#### 4. 생성자 참조

```java
// 람다 표현식
Supplier<List<String>> listSupplier = () -> new ArrayList<>();

// 생성자 참조
Supplier<List<String>> listSupplier = ArrayList::new;

// 예제
List<String> names = Arrays.asList("Alice", "Bob", "Charlie");
List<String> newList = names.stream()
    .collect(Collectors.toCollection(ArrayList::new));
```

### 3-3. 메서드 참조 예제

```java
// 정적 메서드
Math::max
Collections::sort
Arrays::asList

// 인스턴스 메서드
String::length
String::toUpperCase
String::isEmpty

// 특정 객체의 메서드
System.out::println
System.err::println

// 생성자
ArrayList::new
HashMap::new
StringBuilder::new
```

## 4. 스트림 API 기초

### 4-1. 스트림이란?

**스트림(Stream)**은 Java 8에서 도입된 데이터 처리 추상화입니다. 컬렉션의 요소를 선언적으로 처리할 수 있게 해줍니다.

#### 스트림의 특징

- ✅ **선언적 프로그래밍**: 무엇을 할지 선언 (어떻게 할지는 스트림이 결정)
- ✅ **파이프라인 처리**: 여러 연산을 연결하여 처리
- ✅ **지연 평가**: 최종 연산이 호출될 때까지 중간 연산이 실행되지 않음
- ✅ **병렬 처리 지원**: parallel() 메서드로 쉽게 병렬 처리 가능

### 4-2. 스트림 생성 방법

#### 1. 컬렉션에서 생성

```java
List<String> list = Arrays.asList("apple", "banana", "cherry");
Stream<String> stream = list.stream();
```

#### 2. 배열에서 생성

```java
String[] array = {"apple", "banana", "cherry"};
Stream<String> stream = Arrays.stream(array);
Stream<String> stream2 = Stream.of("apple", "banana", "cherry");
```

#### 3. 값으로 생성

```java
Stream<String> stream = Stream.of("apple", "banana", "cherry");
Stream<Integer> numbers = Stream.of(1, 2, 3, 4, 5);
```

#### 4. 빈 스트림 생성

```java
Stream<String> emptyStream = Stream.empty();
```

#### 5. 무한 스트림 생성

```java
// 무한 스트림 (제한 필요)
Stream<Integer> infinite = Stream.iterate(0, n -> n + 1);
Stream<Integer> limited = infinite.limit(10);

// 난수 스트림
Stream<Double> randomNumbers = Stream.generate(Math::random);
```

#### 6. 범위로 생성

```java
// IntStream
IntStream range = IntStream.range(1, 10);  // 1~9
IntStream rangeClosed = IntStream.rangeClosed(1, 10);  // 1~10

// LongStream
LongStream longRange = LongStream.range(1, 100);
```

### 4-3. 스트림의 구조

```java
// 스트림 파이프라인 구조
리스트.stream()                    // 스트림 생성
    .filter(조건)                  // 중간 연산
    .map(변환)                     // 중간 연산
    .sorted()                      // 중간 연산
    .collect(Collectors.toList()); // 최종 연산
```

### 4-4. 스트림 연산 종류

#### 중간 연산 (Intermediate Operations)

- **지연 평가**: 최종 연산이 호출될 때까지 실행되지 않음
- **여러 개 연결 가능**: 체이닝 가능
- **반환 타입**: Stream<T>

```java
.filter()    // 필터링
.map()       // 변환
.sorted()    // 정렬
.distinct()  // 중복 제거
.limit()     // 개수 제한
.skip()      // 건너뛰기
```

#### 최종 연산 (Terminal Operations)

- **즉시 실행**: 호출 즉시 실행됨
- **스트림 종료**: 스트림을 소비하여 더 이상 사용 불가
- **반환 타입**: void 또는 다른 타입

```java
.forEach()   // 각 요소에 대해 작업 수행
.collect()   // 결과 수집
.count()     // 개수 반환
.reduce()    // 축소 연산
.findFirst() // 첫 번째 요소 찾기
.anyMatch()  // 조건 만족하는 요소 존재 여부
```

## 5. 스트림 중간 연산

### 5-1. filter() - 필터링

```java
// 짝수만 필터링
List<Integer> numbers = Arrays.asList(1, 2, 3, 4, 5, 6);
List<Integer> evens = numbers.stream()
    .filter(n -> n % 2 == 0)
    .collect(Collectors.toList());
// 결과: [2, 4, 6]

// 문자열 길이 필터링
List<String> names = Arrays.asList("Alice", "Bob", "Charlie", "David");
List<String> longNames = names.stream()
    .filter(name -> name.length() > 4)
    .collect(Collectors.toList());
// 결과: ["Alice", "Charlie", "David"]
```

### 5-2. map() - 변환

```java
// 숫자를 제곱으로 변환
List<Integer> numbers = Arrays.asList(1, 2, 3, 4, 5);
List<Integer> squares = numbers.stream()
    .map(n -> n * n)
    .collect(Collectors.toList());
// 결과: [1, 4, 9, 16, 25]

// 문자열을 대문자로 변환
List<String> names = Arrays.asList("apple", "banana", "cherry");
List<String> upperNames = names.stream()
    .map(String::toUpperCase)
    .collect(Collectors.toList());
// 결과: ["APPLE", "BANANA", "CHERRY"]

// 객체의 특정 필드 추출
List<Student> students = Arrays.asList(
    new Student("Alice", 20),
    new Student("Bob", 22)
);
List<String> studentNames = students.stream()
    .map(Student::getName)
    .collect(Collectors.toList());
```

### 5-3. flatMap() - 평탄화

```java
// 중첩 리스트를 평탄화
List<List<Integer>> nestedList = Arrays.asList(
    Arrays.asList(1, 2, 3),
    Arrays.asList(4, 5, 6),
    Arrays.asList(7, 8, 9)
);
List<Integer> flatList = nestedList.stream()
    .flatMap(List::stream)
    .collect(Collectors.toList());
// 결과: [1, 2, 3, 4, 5, 6, 7, 8, 9]

// 문자열을 문자로 분리
List<String> words = Arrays.asList("Hello", "World");
List<String> letters = words.stream()
    .flatMap(word -> Arrays.stream(word.split("")))
    .collect(Collectors.toList());
// 결과: ["H", "e", "l", "l", "o", "W", "o", "r", "l", "d"]
```

### 5-4. distinct() - 중복 제거

```java
// 중복 제거
List<Integer> numbers = Arrays.asList(1, 2, 2, 3, 3, 3, 4);
List<Integer> unique = numbers.stream()
    .distinct()
    .collect(Collectors.toList());
// 결과: [1, 2, 3, 4]

// 문자열 중복 제거
List<String> names = Arrays.asList("Alice", "Bob", "Alice", "Charlie");
List<String> uniqueNames = names.stream()
    .distinct()
    .collect(Collectors.toList());
// 결과: ["Alice", "Bob", "Charlie"]
```

### 5-5. sorted() - 정렬

```java
// 자연 순서 정렬
List<Integer> numbers = Arrays.asList(3, 1, 4, 1, 5, 9);
List<Integer> sorted = numbers.stream()
    .sorted()
    .collect(Collectors.toList());
// 결과: [1, 1, 3, 4, 5, 9]

// 역순 정렬
List<Integer> reversed = numbers.stream()
    .sorted(Comparator.reverseOrder())
    .collect(Collectors.toList());
// 결과: [9, 5, 4, 3, 1, 1]

// 커스텀 정렬
List<String> names = Arrays.asList("Alice", "Bob", "Charlie");
List<String> sortedByNameLength = names.stream()
    .sorted(Comparator.comparing(String::length))
    .collect(Collectors.toList());
// 결과: ["Bob", "Alice", "Charlie"]
```

### 5-6. limit() - 개수 제한

```java
// 처음 3개만 가져오기
List<Integer> numbers = Arrays.asList(1, 2, 3, 4, 5, 6, 7, 8);
List<Integer> firstThree = numbers.stream()
    .limit(3)
    .collect(Collectors.toList());
// 결과: [1, 2, 3]
```

### 5-7. skip() - 건너뛰기

```java
// 처음 3개 건너뛰기
List<Integer> numbers = Arrays.asList(1, 2, 3, 4, 5, 6, 7, 8);
List<Integer> skipped = numbers.stream()
    .skip(3)
    .collect(Collectors.toList());
// 결과: [4, 5, 6, 7, 8]

// 페이징 구현
List<Integer> page = numbers.stream()
    .skip(3)  // 페이지 번호 * 페이지 크기
    .limit(3) // 페이지 크기
    .collect(Collectors.toList());
```

### 5-8. peek() - 디버깅용

```java
// 중간 결과 확인 (디버깅용)
List<String> names = Arrays.asList("Alice", "Bob", "Charlie");
List<String> result = names.stream()
    .filter(name -> name.length() > 3)
    .peek(name -> System.out.println("필터링됨: " + name))
    .map(String::toUpperCase)
    .peek(name -> System.out.println("대문자 변환: " + name))
```

## 부록: 유용한 팁과 주의사항

### 스트림 사용 시 주의사항

1. **스트림은 일회용**: 한 번 사용한 스트림은 재사용 불가
   ```java
   Stream<String> stream = list.stream();
   stream.forEach(System.out::println);
   stream.forEach(System.out::println);  // 오류 발생!
   ```

2. **지연 평가 이해**: 중간 연산은 최종 연산이 호출될 때 실행됨
   ```java
   // 이 코드는 아무것도 출력하지 않음
   list.stream()
       .filter(n -> {
           System.out.println("필터링: " + n);
           return n % 2 == 0;
       });
   
   // 최종 연산이 있어야 실행됨
   list.stream()
       .filter(n -> {
           System.out.println("필터링: " + n);
           return n % 2 == 0;
       })
       .collect(Collectors.toList());  // 이제 실행됨
   ```

3. **병렬 스트림 신중 사용**: 항상 빠른 것은 아님
   - 작은 데이터셋: 순차 스트림이 더 빠를 수 있음
   - 큰 데이터셋: 병렬 스트림이 유리할 수 있음

### 성능 최적화 팁

1. **필터링을 먼저**: 불필요한 요소를 먼저 제거
   ```java
   // 좋은 예: 필터링을 먼저
   list.stream()
       .filter(조건)
       .map(변환)
       .collect(...);
   
   // 나쁜 예: 변환을 먼저
   list.stream()
       .map(변환)
       .filter(조건)
       .collect(...);
   ```

2. **distinct() 위치 고려**: 가능한 한 뒤에 배치
   ```java
   // 좋은 예
   list.stream()
       .filter(조건)
       .distinct()
       .collect(...);
   ```

3. **limit() 활용**: 필요한 만큼만 처리
   ```java
   list.stream()
       .filter(조건)
       .limit(10)  // 처음 10개만
       .collect(...);
   ```
