## 기본 문제 정답 (1-5번)

### 문제 1 정답

**답:**
```
수수료: 3000
총액: 103000
```

**해설:**
- `PaymentMethod payment = new CreditCard(100000);`: 업캐스팅
- `payment.calculateFee()`: CreditCard의 `calculateFee()` 호출
  - 100000 × 0.03 = 3000
- `payment.getTotalAmount()`: `amount + calculateFee()`
  - 100000 + 3000 = 103000

**핵심 개념:**
- 업캐스팅: 자식 객체를 부모 타입으로 참조
- 동적 바인딩: 오버라이딩된 메서드는 실제 객체 타입에 따라 호출

---

### 문제 2 정답

**답:** `총 수수료: 9000`

**해설:**
- payments[0]: CreditCard(100000) → 수수료 3000
- payments[1]: CashPayment(50000) → 수수료 0
- payments[2]: CreditCard(200000) → 수수료 6000
- 총 수수료: 3000 + 0 + 6000 = 9000

**계산 과정:**
```
CreditCard(100000): 100000 × 0.03 = 3000
CashPayment(50000): 0
CreditCard(200000): 200000 × 0.03 = 6000
합계: 3000 + 0 + 6000 = 9000
```

**핵심 개념:**
- 배열과 업캐스팅: 다양한 타입을 하나의 배열로 관리
- 다형성: 각 객체의 실제 타입에 맞는 메서드 실행

---

### 문제 3 정답

**답:**
```
결제수단: 신용카드
카드 결제 처리
결제수단: 계좌이체
계좌 이체 처리
```

**해설:**
- `p1.printInfo()`: 부모 클래스의 메서드 호출 → "결제수단: 신용카드"
- `p1.processPayment()`: 오버라이딩된 메서드 호출 (동적 바인딩) → "카드 결제 처리"
- `p2.printInfo()`: 부모 클래스의 메서드 호출 → "결제수단: 계좌이체"
- `p2.processPayment()`: 오버라이딩된 메서드 호출 → "계좌 이체 처리"

**핵심 개념:**
- 부모 클래스 메서드: 참조 변수 타입에 따라 호출
- 오버라이딩된 메서드: 실제 객체 타입에 따라 호출

### 문제 4 정답

**답:**
```
카드 수수료: 3000
모바일 수수료: 2000
```

**해설:**
- `p1.calculateFee()`: CreditCard의 `calculateFee()` 호출
  - 100000 × 0.03 = 3000
- `p2.calculateFee()`: MobilePayment의 `calculateFee()` 호출
  - 100000 × 0.02 = 2000

**핵심 개념:**
- 각 결제 수단마다 다른 수수료율
- 같은 메서드 호출이 타입에 따라 다른 결과

- 빈칸 1: `super(amount)`
- 빈칸 2: `new CreditCard(100000)`

**해설:**
- 빈칸 1: `super(amount)` - 부모 생성자 호출
- 빈칸 2: `new CreditCard(100000)` - CreditCard 객체 생성 후 업캐스팅

## 핵심 개념 정리

### 1. 업캐스팅과 다형성

**업캐스팅:**
```java
PaymentMethod payment = new CreditCard(100000);
```

**다형성:**
- 같은 메서드 호출이 객체 타입에 따라 다른 동작
- `payment.calculateFee()` 호출 시 실제 객체 타입에 맞는 메서드 실행

---

### 2. 추상 클래스와 추상 메서드

**추상 클래스:**
- `abstract class`: 인스턴스 생성 불가
- 공통 속성과 행동 정의

**추상 메서드:**
- `abstract double calculateFee()`
- 자식 클래스에서 반드시 구현해야 함
- 다형성의 기반

---

### 3. 배열과 업캐스팅

**배열 선언:**
```java
PaymentMethod[] payments = new PaymentMethod[5];
```

**다양한 타입 저장:**
```java
payments[0] = new CreditCard(...);
payments[1] = new BankTransfer(...);
payments[2] = new CashPayment(...);
```

**공통 처리:**
```java
for (PaymentMethod p : payments) {
    p.calculateFee();  // 각 타입에 맞는 계산
}
```

---

### 4. instanceof와 다운캐스팅

**타입 확인:**
```java
if (payment instanceof CreditCard) {
    // CreditCard인 경우
}
```

**다운캐스팅:**
```java
CreditCard cc = (CreditCard) payment;
cc.checkLimit();  // 자식 클래스 고유 메서드 호출
```

## 계산 공식 정리

### 수수료 계산

- **CreditCard**: `amount × 0.03` (3%)
- **BankTransfer**: `amount × 0.001` (0.1%)
- **MobilePayment**: `amount × 0.02` (2%)
- **CashPayment**: `0` (수수료 없음)

### 총액 계산

- **총액** = `amount + calculateFee()`
- **총 결제금액** = 모든 결제의 `amount` 합계
- **총 수수료** = 모든 결제의 `calculateFee()` 합계
- **최종 총액** = 총 결제금액 + 총 수수료
