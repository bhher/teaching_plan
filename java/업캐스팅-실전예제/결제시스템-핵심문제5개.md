## 문제 1: 기본 업캐스팅과 다형성

**문제:** 다음 코드의 출력 결과를 쓰시오.

```java
abstract class PaymentMethod {
    protected double amount;
    
    PaymentMethod(double amount) {
        this.amount = amount;
    }
    
    abstract double calculateFee();
    
    double getTotalAmount() {
        return amount + calculateFee();
    }
}

class CreditCard extends PaymentMethod {
    private static final double FEE_RATE = 0.03;
    
    CreditCard(double amount) {
        super(amount);
    }
    
    @Override
    double calculateFee() {
        return amount * FEE_RATE;
    }
}

public class Main {
    public static void main(String[] args) {
        PaymentMethod payment = new CreditCard(100000);
        System.out.println("수수료: " + (int)payment.calculateFee());
        System.out.println("총액: " + (int)payment.getTotalAmount());
    }
}
```

### 정답 및 풀이

**답:**
```
수수료: 3000
총액: 103000
```

**풀이:**
1. `PaymentMethod payment = new CreditCard(100000);`
   - 업캐스팅: CreditCard 객체를 PaymentMethod 타입으로 참조
   
2. `payment.calculateFee()`
   - 오버라이딩된 메서드 호출
   - 실제 객체 타입(CreditCard)의 `calculateFee()` 실행
   - 계산: 100000 × 0.03 = 3000
   
3. `payment.getTotalAmount()`
   - 부모 클래스의 메서드 호출
   - 내부에서 `calculateFee()` 호출 시 실제 객체 타입에 맞는 메서드 실행
   - 계산: 100000 + 3000 = 103000

**핵심 개념:**
- 업캐스팅: 자식 객체를 부모 타입으로 참조
- 동적 바인딩: 오버라이딩된 메서드는 실제 객체 타입에 따라 호출됨

## 문제 2: 배열과 업캐스팅

**문제:** 다음 코드의 출력 결과를 쓰시오.

```java
abstract class PaymentMethod {
    protected String methodName;
    protected double amount;
    
    PaymentMethod(String methodName, double amount) {
        this.methodName = methodName;
        this.amount = amount;
    }
    
    abstract double calculateFee();
}

class CreditCard extends PaymentMethod {
    CreditCard(double amount) {
        super("신용카드", amount);
    }
    
    @Override
    double calculateFee() {
        return amount * 0.03;
    }
}

class CashPayment extends PaymentMethod {
    CashPayment(double amount) {
        super("현금", amount);
    }
    
    @Override
    double calculateFee() {
        return 0;
    }
}

public class Main {
    public static void main(String[] args) {
        PaymentMethod[] payments = new PaymentMethod[3];
        payments[0] = new CreditCard(100000);
        payments[1] = new CashPayment(50000);
        payments[2] = new CreditCard(200000);
        
        double totalFee = 0;
        for (PaymentMethod p : payments) {
            totalFee += p.calculateFee();
        }
        System.out.println("총 수수료: " + (int)totalFee);
    }
}
```

### 정답 및 풀이

**답:** `총 수수료: 9000`

**풀이:**
1. 배열에 다양한 타입의 객체 저장 (업캐스팅)
   - payments[0]: CreditCard(100000) → 업캐스팅
   - payments[1]: CashPayment(50000) → 업캐스팅
   - payments[2]: CreditCard(200000) → 업캐스팅

2. 각 결제의 수수료 계산
   - payments[0]: CreditCard → 100000 × 0.03 = 3000
   - payments[1]: CashPayment → 0
   - payments[2]: CreditCard → 200000 × 0.03 = 6000

3. 총 수수료 합산
   - 3000 + 0 + 6000 = 9000

**핵심 개념:**
- 배열과 업캐스팅: 다양한 타입을 하나의 배열로 관리
- 다형성: 반복문으로 공통 처리 가능
- 각 객체의 실제 타입에 맞는 메서드 자동 실행

## 문제 3: instanceof와 다운캐스팅

**문제:** 다음 코드의 출력 결과를 쓰시오.

```java
abstract class PaymentMethod {
    protected String methodName;
    
    PaymentMethod(String methodName) {
        this.methodName = methodName;
    }
    
    abstract void processPayment();
}

class CreditCard extends PaymentMethod {
    CreditCard() {
        super("신용카드");
    }
    
    @Override
    void processPayment() {
        System.out.println("카드 결제");
    }
    
    void checkLimit() {
        System.out.println("한도 확인");
    }
}

class CashPayment extends PaymentMethod {
    CashPayment() {
        super("현금");
    }
    
    @Override
    void processPayment() {
        System.out.println("현금 결제");
    }
    
    void giveChange() {
        System.out.println("거스름돈");
    }
}

public class Main {
    public static void main(String[] args) {
        PaymentMethod[] payments = new PaymentMethod[3];
        payments[0] = new CreditCard();
        payments[1] = new CashPayment();
        payments[2] = new CreditCard();
        
        for (PaymentMethod p : payments) {
            p.processPayment();
            if (p instanceof CreditCard) {
                CreditCard cc = (CreditCard) p;
                cc.checkLimit();
            } else if (p instanceof CashPayment) {
                CashPayment cp = (CashPayment) p;
                cp.giveChange();
            }
        }
    }
}
```

### 정답 및 풀이

**답:**
```
카드 결제
한도 확인
현금 결제
거스름돈
카드 결제
한도 확인
```

**풀이:**
1. payments[0] (CreditCard):
   - `p.processPayment()` → "카드 결제" (오버라이딩된 메서드)
   - `p instanceof CreditCard` → true
   - 다운캐스팅: `CreditCard cc = (CreditCard) p`
   - `cc.checkLimit()` → "한도 확인"

2. payments[1] (CashPayment):
   - `p.processPayment()` → "현금 결제" (오버라이딩된 메서드)
   - `p instanceof CashPayment` → true
   - 다운캐스팅: `CashPayment cp = (CashPayment) p`
   - `cp.giveChange()` → "거스름돈"

3. payments[2] (CreditCard):
   - payments[0]과 동일한 과정 반복

**핵심 개념:**
- `instanceof`: 객체의 실제 타입 확인
- 다운캐스팅: 부모 타입을 자식 타입으로 변환
- 타입별 특수 기능 처리 가능

## 문제 4: 총액 계산

**문제:** 다음 코드의 출력 결과를 쓰시오.

```java
abstract class PaymentMethod {
    protected double amount;
    
    PaymentMethod(double amount) {
        this.amount = amount;
    }
    
    abstract double calculateFee();
    
    double getTotalAmount() {
        return amount + calculateFee();
    }
}

class CreditCard extends PaymentMethod {
    CreditCard(double amount) {
        super(amount);
    }
    
    @Override
    double calculateFee() {
        return amount * 0.03;
    }
}

class BankTransfer extends PaymentMethod {
    BankTransfer(double amount) {
        super(amount);
    }
    
    @Override
    double calculateFee() {
        return amount * 0.001;
    }
}

public class Main {
    public static void main(String[] args) {
        PaymentMethod[] payments = new PaymentMethod[3];
        payments[0] = new CreditCard(100000);
        payments[1] = new BankTransfer(50000);
        payments[2] = new CreditCard(200000);
        
        double total = 0;
        for (PaymentMethod p : payments) {
            total += p.getTotalAmount();
        }
        System.out.println("총액: " + (int)total);
    }
}
```

### 정답 및 풀이

**답:** `총액: 359050`

**풀이:**
1. 각 결제의 총액 계산:
   - payments[0]: CreditCard(100000)
     - 수수료: 100000 × 0.03 = 3000
     - 총액: 100000 + 3000 = 103000
   
   - payments[1]: BankTransfer(50000)
     - 수수료: 50000 × 0.001 = 50
     - 총액: 50000 + 50 = 50050
   
   - payments[2]: CreditCard(200000)
     - 수수료: 200000 × 0.03 = 6000
     - 총액: 200000 + 6000 = 206000

2. 전체 총액 합산:
   - 103000 + 50050 + 206000 = 359050

**계산 과정:**
```
CreditCard(100000):
  - 수수료: 100000 × 0.03 = 3000
  - 총액: 100000 + 3000 = 103000

BankTransfer(50000):
  - 수수료: 50000 × 0.001 = 50
  - 총액: 50000 + 50 = 50050

CreditCard(200000):
  - 수수료: 200000 × 0.03 = 6000
  - 총액: 200000 + 6000 = 206000

전체 총액: 103000 + 50050 + 206000 = 359050
```

**핵심 개념:**
- `getTotalAmount()`: 부모 클래스의 메서드
- 내부에서 `calculateFee()` 호출 시 실제 객체 타입에 맞는 메서드 실행
- 다형성을 활용한 공통 처리

## 문제 5: 실전 복합 문제

**문제:** 다음 코드의 출력 결과를 쓰시오.

```java
abstract class PaymentMethod {
    protected String methodName;
    protected double amount;
    
    PaymentMethod(String methodName, double amount) {
        this.methodName = methodName;
        this.amount = amount;
    }
    
    abstract double calculateFee();
    
    abstract void processPayment();
    
    void printPaymentInfo() {
        System.out.println(methodName + " - 금액: " + (int)amount + 
                          ", 수수료: " + (int)calculateFee());
    }
}

class CreditCard extends PaymentMethod {
    private String cardCompany;
    
    CreditCard(double amount, String cardCompany) {
        super("신용카드", amount);
        this.cardCompany = cardCompany;
    }
    
    @Override
    double calculateFee() {
        return amount * 0.03;
    }
    
    @Override
    void processPayment() {
        System.out.println(cardCompany + " 카드로 결제");
    }
    
    void checkLimit() {
        System.out.println("한도 확인");
    }
}

class BankTransfer extends PaymentMethod {
    private String bankName;
    
    BankTransfer(double amount, String bankName) {
        super("계좌이체", amount);
        this.bankName = bankName;
    }
    
    @Override
    double calculateFee() {
        return amount * 0.001;
    }
    
    @Override
    void processPayment() {
        System.out.println(bankName + " 계좌로 이체");
    }
}

public class Main {
    public static void main(String[] args) {
        PaymentMethod[] payments = new PaymentMethod[3];
        payments[0] = new CreditCard(100000, "삼성카드");
        payments[1] = new BankTransfer(50000, "국민은행");
        payments[2] = new CreditCard(200000, "신한카드");
        
        System.out.println("=== 결제 정보 ===");
        for (PaymentMethod p : payments) {
            p.printPaymentInfo();
        }
        
        System.out.println("\n=== 결제 처리 ===");
        for (PaymentMethod p : payments) {
            p.processPayment();
            if (p instanceof CreditCard) {
                CreditCard cc = (CreditCard) p;
                cc.checkLimit();
            }
        }
    }
}
```

### 정답 및 풀이

**답:**
```
=== 결제 정보 ===
신용카드 - 금액: 100000, 수수료: 3000
계좌이체 - 금액: 50000, 수수료: 50
신용카드 - 금액: 200000, 수수료: 6000

=== 결제 처리 ===
삼성카드 카드로 결제
한도 확인
국민은행 계좌로 이체
신한카드 카드로 결제
한도 확인
```

**풀이:**

**1단계: 결제 정보 출력**
- payments[0]: CreditCard(100000, "삼성카드")
  - `printPaymentInfo()` 호출
  - 내부에서 `calculateFee()` 호출 → 100000 × 0.03 = 3000
  - 출력: "신용카드 - 금액: 100000, 수수료: 3000"

- payments[1]: BankTransfer(50000, "국민은행")
  - `printPaymentInfo()` 호출
  - 내부에서 `calculateFee()` 호출 → 50000 × 0.001 = 50
  - 출력: "계좌이체 - 금액: 50000, 수수료: 50"

- payments[2]: CreditCard(200000, "신한카드")
  - `printPaymentInfo()` 호출
  - 내부에서 `calculateFee()` 호출 → 200000 × 0.03 = 6000
  - 출력: "신용카드 - 금액: 200000, 수수료: 6000"

**2단계: 결제 처리**
- payments[0]: CreditCard
  - `processPayment()` → "삼성카드 카드로 결제"
  - `instanceof CreditCard` → true
  - 다운캐스팅 후 `checkLimit()` → "한도 확인"

- payments[1]: BankTransfer
  - `processPayment()` → "국민은행 계좌로 이체"
  - `instanceof CreditCard` → false
  - 특수 기능 없음

- payments[2]: CreditCard
  - `processPayment()` → "신한카드 카드로 결제"
  - `instanceof CreditCard` → true
  - 다운캐스팅 후 `checkLimit()` → "한도 확인"

**핵심 개념:**
- 다형성: 같은 메서드 호출이 타입에 따라 다른 동작
- 업캐스팅: 배열에 다양한 타입 저장
- 다운캐스팅: 타입별 특수 기능 처리
- 실전 활용 패턴의 종합

## 핵심 개념 요약

### 1. 업캐스팅 (Upcasting)

```java
PaymentMethod payment = new CreditCard(100000);
```

- 자식 객체를 부모 타입으로 참조
- 자동 변환 (묵시적 변환)
- 부모 클래스 멤버만 접근 가능

### 2. 다형성 (Polymorphism)

```java
payment.calculateFee();  // 실제 객체 타입에 따라 다른 메서드 실행
```

- 같은 메서드 호출이 객체 타입에 따라 다른 동작
- 오버라이딩된 메서드는 실제 객체 타입에 따라 호출됨
- 동적 바인딩

### 3. 배열과 업캐스팅

```java
PaymentMethod[] payments = new PaymentMethod[3];
payments[0] = new CreditCard(...);
payments[1] = new BankTransfer(...);
```

- 다양한 타입을 하나의 배열로 관리
- 반복문으로 공통 처리 가능
- 코드 재사용성 향상

### 4. instanceof와 다운캐스팅

```java
if (payment instanceof CreditCard) {
    CreditCard cc = (CreditCard) payment;
    cc.checkLimit();
}
```

- 타입 확인 후 안전한 다운캐스팅
- 자식 클래스 고유 메서드 호출 가능

### 5. 추상 클래스와 추상 메서드

```java
abstract class PaymentMethod {
    abstract double calculateFee();
}
```

- 추상 클래스: 인스턴스 생성 불가
- 추상 메서드: 자식 클래스에서 반드시 구현해야 함
- 다형성의 기반이 됨
