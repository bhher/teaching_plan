### 1. Coffee.java - 싱글톤 패턴으로 메뉴 관리

#### 1.1 싱글톤 패턴 (Singleton Pattern)

```java
private static Coffee instance;  // 유일한 인스턴스
private Coffee(){};  // private 생성자로 외부에서 new 불가능

public static Coffee getInstance(){
    if(instance == null){
        instance = new Coffee();
    }
    return instance;
}
```

**해설:**
- **싱글톤 패턴**: 프로그램 전체에서 객체를 하나만 생성하는 디자인 패턴
- **private 생성자**: 외부에서 `new Coffee()`로 객체 생성 불가
- **getInstance()**: 유일한 인스턴스를 반환하는 정적 메서드
- **첫 호출 시**: `instance == null`이면 새로 생성
- **이후 호출**: 이미 생성된 인스턴스 반환

**장점:**
- 메모리 효율: 객체를 하나만 생성하여 메모리 절약
- 전역 접근: 어디서든 같은 메뉴 객체에 접근 가능
- 데이터 일관성: 메뉴 정보가 항상 동일하게 유지

**사용 예시:**
```java
Coffee coffee1 = Coffee.getInstance();  // 첫 번째 호출 - 새로 생성
Coffee coffee2 = Coffee.getInstance();  // 두 번째 호출 - 같은 객체 반환
// coffee1 == coffee2 (같은 객체)
```

#### 1.2 메뉴 초기화

```java
ArrayList<String> coffeeList;      // 커피 종류
ArrayList<Integer> coffeePrice;   // 커피 가격
Map<String, Integer> menu;         // 최종 메뉴 맵

public void getMenu(){
    menu = new LinkedHashMap<String, Integer>();
    coffeeList = new ArrayList<>();
    coffeePrice = new ArrayList<>();
    
    // 커피 이름 추가
    coffeeList.add("아메리카노");
    coffeeList.add("카푸치노");
    // ...
    
    // 가격 추가
    coffeePrice.add(2000);
    coffeePrice.add(4500);
    // ...
    
    // ArrayList를 Map으로 변환
    for(int i = 0; i < coffeeList.size(); i++){
        menu.put(coffeeList.get(i), coffeePrice.get(i));
    }
}
```

**해설:**
- **ArrayList 사용**: 순서가 있는 리스트로 메뉴와 가격을 각각 저장
- **LinkedHashMap**: 순서가 보장되는 HashMap
  - 일반 HashMap과 달리 입력 순서 유지
  - 메뉴 출력 시 번호 순서대로 표시
- **for 루프**: 두 ArrayList를 하나의 Map으로 결합

**왜 LinkedHashMap을 사용했을까?**
- 메뉴 번호가 중요함 (1번, 2번, 3번...)
- 일반 HashMap은 순서가 보장되지 않음
- LinkedHashMap은 입력 순서대로 저장됨

#### 2.3 order() 메서드 - 주문 받기

```java
private void order() {
    System.out.println("\n 취소를 원하시면 0번을 눌러주세요");
    end:while (true) {
        try{
            System.out.print("\n원하는 음료의 번호를 선택해주세요 :");
            String choice = sc.next();
            int choiceNum = Integer.parseInt(choice.substring(0,1));
            
            if(choiceNum == 0){
                System.out.println("주문을 취소합니다.");
                System.exit(0);
            }
            
            sc.nextLine();
            String coffeeName = coffee.coffeeList.get(choiceNum-1);
            System.out.println("선택 하신 음료는 : "+coffeeName+"입니다. 몆잔 주문?");
            int orderCount = sc.nextInt();
            sc.nextLine();
            
            // 재주문 처리
            if(reOrder){
                for(String coff : orderList.keySet()){
                    if(coff.equals(coffeeName)){
                        int addCount = orderList.get(coff).intValue()+orderCount;
                        orderList.replace(coffeeName, addCount);
                    } else {
                        orderList.put(coffeeName, orderCount);
                        break;
                    }
                }
            } else {
                orderList.put(coffeeName, orderCount);
            }
            
            customer.setCoffeeOrder(orderList);
            addOrder();
            break end;
        } catch(Exception e) {
            System.out.println("잘못된 선택입니다");
        }
    }
}
```

**해설:**

**1. 라벨이 있는 while 루프:**
```java
end:while (true) {
    // ...
    break end;  // 라벨을 사용하여 특정 루프 종료
}
```
- **라벨(`end:`)**: 중첩된 루프에서 특정 루프를 종료할 때 사용
- `break end;`: `end:` 라벨이 붙은 루프를 종료

**2. 입력 처리:**
```java
String choice = sc.next();
int choiceNum = Integer.parseInt(choice.substring(0,1));
```
- `sc.next()`: 문자열 입력 (공백 전까지)
- `substring(0,1)`: 첫 번째 문자만 추출
- `Integer.parseInt()`: 문자열을 정수로 변환
- **예시**: "123" 입력 → "1" 추출 → 1로 변환

**3. 인덱스 조정:**
```java
String coffeeName = coffee.coffeeList.get(choiceNum-1);
```
- 사용자는 1번부터 선택 (1, 2, 3, ...)
- ArrayList는 0번부터 시작 (0, 1, 2, ...)
- `choiceNum-1`: 사용자 입력을 인덱스로 변환
- **예시**: 사용자 입력 1 → 인덱스 0 (첫 번째 메뉴)

**4. 재주문 처리:**
```java
if(reOrder){
    for(String coff : orderList.keySet()){
        if(coff.equals(coffeeName)){
            // 같은 커피를 다시 주문하면 수량 추가
            int addCount = orderList.get(coff).intValue()+orderCount;
            orderList.replace(coffeeName, addCount);
        } else {
            // 다른 커피면 새로 추가
            orderList.put(coffeeName, orderCount);
            break;
        }
    }
} else {
    // 첫 주문
    orderList.put(coffeeName, orderCount);
}
```

**재주문 로직:**
- `reOrder == true`: 이미 주문한 상태에서 추가 주문
- 같은 커피 선택: 기존 수량에 추가 (`replace()`)
- 다른 커피 선택: 새로 추가 (`put()`)
- `reOrder == false`: 첫 주문, 그냥 추가

**문제점:**
- 현재 코드의 재주문 로직에 버그가 있을 수 있음
- `else` 블록에서 `break`가 있어서 첫 번째 다른 커피만 체크함

**개선 방안:**
```java
if(reOrder){
    if(orderList.containsKey(coffeeName)){
        // 같은 커피 재주문
        int addCount = orderList.get(coffeeName) + orderCount;
        orderList.replace(coffeeName, addCount);
    } else {
        // 새로운 커피 추가
        orderList.put(coffeeName, orderCount);
    }
} else {
    orderList.put(coffeeName, orderCount);
}
```

#### 2.4 addOrder() 메서드 - 추가 주문 확인

```java
private void addOrder() {
    reOrder = false;
    System.out.println("\n주문을 계속 하시겠습니까?");
    System.out.println("예(Y)/아니오(N)");
    String yesOrNo = sc.next();
    if(yesOrNo.equals("예") || yesOrNo.equalsIgnoreCase("y")){
        coffee.getMenu();
        reOrder = true;
        order();
    } else if(yesOrNo.equals("아니오") || yesOrNo.equalsIgnoreCase("n")){
        return;
    }
}
```

**해설:**
- **재귀 호출**: `order()` 메서드를 다시 호출하여 추가 주문 받기
- **reOrder 플래그**: 
  - `false`로 초기화 후
  - 추가 주문 시 `true`로 설정
- **equalsIgnoreCase()**: 대소문자 무시 비교
  - "Y", "y", "yes" 모두 인식

**동작 흐름:**
1. 첫 주문 완료 후 호출
2. 추가 주문 여부 확인
3. "예" 선택: 메뉴 다시 출력, `reOrder = true`, `order()` 재호출
4. "아니오" 선택: 메서드 종료

#### 2.5 totalOrder() 메서드 - 주문 내역 및 총액 계산

```java
private void totalOrder(Customer customer) {
    int s = 1;
    int totalMoney = 0;
    int coffeePrice = 0;
    DecimalFormat f = new DecimalFormat("###,000원");
    String name = customer.getOrderName()+"번 ";
    StringBuffer message = new StringBuffer();
    
    message.append("\n\n ")
        .append("+----------------------------------------------------+\n ")
        .append("|                                                    | \n ")
        .append("|             " + name + "고객님 의 주문 내역 입니다         | " + "\n");
    
    for(Map.Entry<String,Integer> order : customer.getCoffeeOrder().entrySet()){
        String coffeeName = order.getKey();
        int orderCount = order.getValue();
        int coffeeUnitPrice = coffee.menu.get(coffeeName);
        coffeePrice = coffeeUnitPrice * orderCount;
        totalMoney = totalMoney + coffeePrice;
        String pay = f.format(coffeePrice);
        message.append(String.format(" | [%d] %-20s : %2d잔  %7s |\n", 
            s, coffeeName, orderCount, pay));
        s++;
    }
    
    message.append(" |                                                    |\n ")
        .append("+----------------------------------------------------+ \n")
        .append(" ============ 총 결제 금액은 " + f.format(totalMoney) + "입니다 ========== \n");
    System.out.println(message);
    payment(totalMoney);
}
```

**해설:**

**1. 주문 내역 계산:**
```java
for(Map.Entry<String,Integer> order : customer.getCoffeeOrder().entrySet()){
    String coffeeName = order.getKey();           // 커피 이름
    int orderCount = order.getValue();            // 주문 수량
    int coffeeUnitPrice = coffee.menu.get(coffeeName);  // 단가
    coffeePrice = coffeeUnitPrice * orderCount;  // 항목별 금액
    totalMoney = totalMoney + coffeePrice;        // 총액 누적
}
```

**계산 과정:**
- `entry.getKey()`: 커피 이름 (예: "아메리카노")
- `entry.getValue()`: 주문 수량 (예: 2)
- `coffee.menu.get(coffeeName)`: 메뉴에서 가격 조회 (예: 2000)
- `coffeePrice = 2000 * 2 = 4000`: 항목별 금액
- `totalMoney += 4000`: 총액에 추가

**2. 포맷팅:**
```java
DecimalFormat f = new DecimalFormat("###,000원");
String pay = f.format(coffeePrice);
```
- `"###,000원"`: 천 단위 구분 기호 포함
- 4000 → "4,000원"
- 15000 → "15,000원"

**3. StringBuffer 사용:**
- 여러 줄의 문자열을 효율적으로 연결
- `append()`: 문자열 추가
- 마지막에 `toString()`으로 한 번에 출력

## 주요 개념 정리

### 1. 싱글톤 패턴 (Singleton Pattern)

**목적:** 객체를 하나만 생성하여 메모리 효율성과 데이터 일관성 보장

**구현 방법:**
1. private 생성자
2. static 인스턴스 변수
3. getInstance() 정적 메서드

**장점:**
- 메모리 효율
- 전역 접근
- 데이터 일관성

**단점:**
- 테스트 어려움
- 멀티스레드 환경에서 주의 필요

---

### 2. LinkedHashMap vs HashMap

| 특징 | HashMap | LinkedHashMap |
|------|---------|---------------|
| **순서 보장** | ❌ | ✅ |
| **속도** | 빠름 | 상대적으로 느림 |
| **용도** | 순서 불필요 | 순서 중요 |

**LinkedHashMap 사용 이유:**
- 메뉴 번호가 중요함 (1번, 2번, 3번...)
- 주문 순서가 중요함
- 출력 시 순서대로 표시 필요

---

### 3. DecimalFormat - 숫자 포맷팅

```java
DecimalFormat f = new DecimalFormat("0,000원");
String formatted = f.format(3000);  // "3,000원"
```

**패턴 설명:**
- `0`: 숫자 (없으면 0으로 채움)
- `,`: 천 단위 구분 기호
- `000`: 3자리 숫자
- `원`: 리터럴 문자열

**다른 패턴 예시:**
```java
new DecimalFormat("#,###원");     // 3000 → "3,000원"
new DecimalFormat("###,000원");   // 3000 → "3,000원"
new DecimalFormat("₩#,###");      // 3000 → "₩3,000"
```

---

### 4. StringBuffer vs StringBuilder

**StringBuffer:**
- **동기화 지원**: 멀티스레드 환경에서 안전
- **상대적으로 느림**: 동기화 오버헤드

**StringBuilder:**
- **동기화 없음**: 단일 스레드 환경에 적합
- **더 빠름**: 동기화 오버헤드 없음

**현재 코드:**
- 단일 스레드이므로 StringBuilder 사용 권장
- 하지만 StringBuffer도 문제없이 작동

---

### 5. Thread.sleep() - 지연 효과

```java
Thread t = new Thread();
t.sleep(2000);  // 2초 대기
```

**용도:**
- 사용자 경험 향상
- 실제 시스템 시뮬레이션
- 제조 시간 표현

**주의사항:**
- `InterruptedException` 발생 가능
- try-catch 필수
- 밀리초 단위 (1000 = 1초)

**더 나은 방법:**
```java
try {
    Thread.sleep(2000);
} catch (InterruptedException e) {
    Thread.currentThread().interrupt();
    e.printStackTrace();
}
```

## 코드 개선 제안

### 1. 재주문 로직 개선

**현재 코드의 문제:**
```java
if(reOrder){
    for(String coff : orderList.keySet()){
        if(coff.equals(coffeeName)){
            // ...
        } else {
            orderList.put(coffeeName, orderCount);
            break;  // 문제: 첫 번째 다른 커피만 체크하고 종료
        }
    }
}
```

**개선:**
```java
if(reOrder){
    if(orderList.containsKey(coffeeName)){
        // 같은 커피 재주문
        int addCount = orderList.get(coffeeName) + orderCount;
        orderList.replace(coffeeName, addCount);
    } else {
        // 새로운 커피 추가
        orderList.put(coffeeName, orderCount);
    }
} else {
    orderList.put(coffeeName, orderCount);
}
```

### 3. 입력 검증 강화

**현재:**
```java

```

**개선:**
```java
int choiceNum;
try {
    choiceNum = Integer.parseInt(choice.substring(0,1));
    if(choiceNum < 0 || choiceNum > coffee.coffeeList.size()){
        System.out.println("잘못된 번호입니다.");
        continue;
    }
} catch (NumberFormatException e) {
    System.out.println("숫자를 입력해주세요.");
    continue;
}
```
