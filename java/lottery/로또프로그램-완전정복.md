## 개요

이 로또 프로그램은 **1~45 범위의 숫자 중 6개를 선택**하는 현재 로또 시스템을 구현한 콘솔 기반 Java 애플리케이션입니다.

**주요 기능:**
- ✅ 회원가입 (미성년자 제한)
- ✅ 로또 번호 입력 (1~45 범위, 중복 불가)
- ✅ 랜덤 로또 번호 생성 (1~45 범위, 중복 불가)
- ✅ 당첨 결과 확인 (일치 개수에 따른 등급)
- ✅ 결제 비밀번호 확인

**로또 규칙:**
- 1~45 범위의 숫자 중 6개 선택
- 중복 불가
- 오름차순 정렬하여 표시
- 일치 개수에 따른 등급:
  - 6개 일치: 1등
  - 5개 일치: 2등
  - 4개 일치: 3등
  - 3개 일치: 4등
  - 2개 이하: 낙첨

#### 4-2. randomLotteryNum() 메서드

**로또 번호 생성 알고리즘:**

```java
public void randomLotteryNum() {
    ArrayList<Integer> numbers = new ArrayList<>();
    
    // 1. 1~45까지의 숫자 리스트 생성
    for(int i = 1; i <= 45; i++){
        numbers.add(i);
    }
    
    // 2. 리스트를 섞기
    Collections.shuffle(numbers);
    
    // 3. 앞에서 6개 선택
    for(int i = 0; i < 6; i++){
        randomNumbers[i] = numbers.get(i);
    }
    
    // 4. 오름차순 정렬
    for(int i = 0; i < 5; i++){
        for(int j = i + 1; j < 6; j++){
            if(randomNumbers[i] > randomNumbers[j]){
                int temp = randomNumbers[i];
                randomNumbers[i] = randomNumbers[j];
                randomNumbers[j] = temp;
            }
        }
    }
    
    // 5. 문자열로 변환
    randomNum = "";
    for(int i = 0; i < 6; i++){
        if(i > 0) randomNum += " ";
        randomNum += String.format("%2d", randomNumbers[i]);
    }
}
```

**알고리즘 설명:**

1. **1~45 숫자 리스트 생성**
   - `ArrayList`에 1부터 45까지 추가

2. **섞기 (Shuffle)**
   - `Collections.shuffle()`: 리스트를 무작위로 섞음
   - 중복 없이 랜덤하게 섞임

3. **6개 선택**
   - 섞인 리스트의 앞에서 6개 선택
   - 중복 없음이 보장됨

4. **정렬**
   - 버블 정렬로 오름차순 정렬
   - 출력 시 보기 좋게 정렬

5. **문자열 변환**
   - 배열을 문자열로 변환하여 저장

**왜 이 방법을 사용하나요?**
- 중복 없이 랜덤 선택이 보장됨
- `Math.random()`을 여러 번 호출하여 중복 체크하는 것보다 효율적
- 코드가 간결하고 이해하기 쉬움

### 6. DataPrinter.java

**역할:** 날짜/시간 출력 유틸리티

```java
package a0219.lottery;

import java.util.Calendar;

public class DataPrinter {
    public static void printDataTime(Calendar cal){
        int yy = cal.get(Calendar.YEAR);
        int mm = cal.get(Calendar.MONTH) + 1;  // MONTH는 0부터 시작
        int dd = cal.get(Calendar.DAY_OF_MONTH);
        int hh = cal.get(Calendar.HOUR_OF_DAY);
        int mi = cal.get(Calendar.MINUTE);
        int ss = cal.get(Calendar.SECOND);

        System.out.printf("설정된 일시: %d년 %02d월 %02d일 %02d:%02d:%02d\n", 
                          yy, mm, dd, hh, mi, ss);
    }
}
```

**설명:**
- `Calendar` 객체에서 날짜/시간 정보 추출
- `MONTH + 1`: Calendar의 MONTH는 0부터 시작하므로 1을 더함
- `%02d`: 두 자리 숫자로 포맷팅 (한 자리면 앞에 0 추가)

**사용 예시:**
```java
Calendar cal = Calendar.getInstance();
DataPrinter.printDataTime(cal);
// 출력: 설정된 일시: 2026년 01월 30일 14:30:05
```

## 핵심 개념

### 1. 싱글톤 패턴 (Singleton Pattern)

**목적:** 프로그램 전체에서 하나의 객체만 존재하도록 보장

**구현 방법:**
```java
private static Purchase p;  // 정적 변수

public static Purchase getInstance(){
    if(p == null){
        p = new Purchase();  // 첫 호출 시에만 생성
    }
    return p;  // 항상 같은 객체 반환
}

private Purchase(){}  // 외부에서 생성 불가
```

**장점:**
- 메모리 효율적 (객체 하나만 생성)
- 전역 상태 관리 용이
- 회원 정보, 구매 정보를 전역에서 공유

**사용 예시:**
```java
Purchase p1 = Purchase.getInstance();
Purchase p2 = Purchase.getInstance();
// p1과 p2는 같은 객체
```

### 2. Collections.shuffle()

**목적:** 리스트를 무작위로 섞기

**사용법:**
```java
ArrayList<Integer> numbers = new ArrayList<>();
// ... 숫자 추가
Collections.shuffle(numbers);  // 리스트 섞기
```

**장점:**
- 중복 없이 랜덤 선택 보장
- `Math.random()` 반복 호출보다 효율적
- 코드가 간결함

### 3. Calendar 클래스

**주요 메서드:**

| 메서드 | 설명 | 예시 |
|--------|------|------|
| `getInstance()` | 현재 날짜/시간으로 Calendar 객체 생성 | `Calendar cal = Calendar.getInstance();` |
| `get(Calendar.YEAR)` | 년도 가져오기 | `2026` |
| `get(Calendar.MONTH)` | 월 가져오기 (0~11) | `0` (1월) |
| `get(Calendar.DAY_OF_MONTH)` | 일 가져오기 | `30` |
| `set(Calendar.MONTH, value)` | 월 설정 (0~11) | `cal.set(Calendar.MONTH, 2)` (3월) |
| `getActualMaximum(Calendar.DAY_OF_MONTH)` | 해당 월의 최대 일수 | `31` (1월) |

**주의사항:**
- `MONTH`는 0부터 시작 (0=1월, 11=12월)
- 출력 시 `+1` 필요

### 5. String.format()

**목적:** 문자열을 특정 형식으로 포맷팅

### 6. 배열 정렬 (Bubble Sort)

**알고리즘:**
```java
for(int i = 0; i < 5; i++){
    for(int j = i + 1; j < 6; j++){
        if(numbers[i] > numbers[j]){
            // 교환
            int temp = numbers[i];
            numbers[i] = numbers[j];
            numbers[j] = temp;
        }
    }
}
```

**동작 과정:**
1. 첫 번째 요소와 나머지 요소들을 비교
2. 더 작은 값이 있으면 교환
3. 두 번째 요소와 나머지 요소들을 비교
4. 반복...

**예시:**
```
초기: [5, 2, 8, 1, 9, 3]
1회전: [2, 5, 1, 8, 3, 9]
2회전: [2, 1, 5, 3, 8, 9]
3회전: [1, 2, 3, 5, 8, 9]
```

```java
    for(int i = 0; i < 6; i++){
        String numStr = "";
        int num = 0;
        boolean isValid = false;
        
        // 유효한 번호를 입력할 때까지 반복
        while(!isValid){
            System.out.print((i+1) + "번째 번호 입력 : ");
            numStr = sc.next();
            
            try {
                num = Integer.parseInt(numStr);  // 문자열을 정수로 변환

                boolean isDuplicate = false;
                for(int j = 0; j < i; j++){
                    if(numbers[j] == num){
                        isDuplicate = true;
                        break;
                    }
                }
                
                if(isDuplicate){
                    System.out.println("[ERROR] 이미 입력한 번호입니다.");
                } else {
                    numbers[i] = num;  // 번호 저장
                    isValid = true;    // 유효한 입력으로 표시
                }

        if(i > 0) System.out.print(" ");
        System.out.print(String.format("%2d", numbers[i]));
    }
    System.out.println("] 입니다.");
```

```java
// 현재
for(int i = 0; i < 5; i++){

        }
```
