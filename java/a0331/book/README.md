# 도서 대여 시스템 (응용 버전)

## 프로젝트 개요

커피 주문 시스템의 패턴을 도서 대여 시스템에 응용한 프로젝트입니다.

## 파일 구조

```
a0331/book/
├── Book.java              # 싱글톤 패턴으로 도서 목록 관리
├── BookService.java       # 대여 서비스 로직
├── Member.java            # 회원 정보 관리
├── BookRentalImpl.java    # 메인 클래스
└── README.md             # 프로젝트 설명
```

## 주요 특징

1. **싱글톤 패턴**: Book 클래스가 싱글톤으로 구현됨
2. **LinkedHashMap**: 순서가 보장되는 도서 목록 및 대여 관리
3. **재대여 기능**: 같은 도서 재대여 시 기간 누적 (개선된 로직)
4. **결제 시스템**: 잔액 확인 및 결제 처리
5. **포맷팅**: DecimalFormat으로 가격 포맷팅
6. **지연 효과**: Thread.sleep()으로 도서 준비 시간 시뮬레이션

## 실행 방법

```bash
javac *.java
java BookRentalImpl
```

## 커피 시스템과의 차이점

| 항목 | 커피 시스템 | 도서 시스템 |
|------|------------|------------|
| **용어** | 주문, 잔 | 대여, 일 |
| **계산** | 가격 × 수량 | 가격 × 대여일수 |
| **초기 잔액** | 20000원 | 30000원 |
| **재주문 로직** | 버그 있음 | 개선됨 |
