# 문제 1. `Book` 클래스 (싱글톤)

### 요구사항

1. **싱글톤**
   - `private static Book instance`
   - `private Book() {}` — 외부에서 `new` 금지
   - `public static Book getInstance()` — 없으면 생성, 있으면 같은 객체 반환

2. **필드**
   - `ArrayList<String> bookList` — 도서 제목
   - `ArrayList<Integer> bookPrice` — 1일 대여 가격
   - `Map<String, Integer> menu` — 제목 → 가격 (`LinkedHashMap`)

3. **`getMenu()` 메서드**
   - 도서 6권 + 가격을 리스트에 넣고 `menu`에 `put`
   - 메뉴판 출력 (번호, 제목, 포맷된 가격)
   - `DecimalFormat` 사용 예: `"#,###원"` 또는 `"0,000원"`

### 힌트

```java
public static Book getInstance() {
    if (instance == null) {
        instance = new Book();
    }
    return instance;
}
```

```java
for (Entry<String, Integer> entry : menu.entrySet()) {
    System.out.printf("[%d] %s %s\n",
        s, entry.getKey(), f.format(entry.getValue()));
    s++;
}
```

### 체크

- [ ] `new Book()` 을 다른 클래스에서 호출하면 컴파일 오류
- [ ] `Book.getInstance() == Book.getInstance()` → `true`

# 문제 3. `BookService` 클래스

### 필드

| 필드 | 설명 |
|------|------|
| `boolean reRental` | 재대여 여부 (기본 `false`) |
| `int memberNum` | 회원 번호 (기본 `1`) |
| `Map<String, Integer> rentalList` | 이번 대여 목록 (`LinkedHashMap`) |
| `Book book` | `Book.getInstance()` |
| `Member member` | 현재 회원 |
| `Thread t` | 지연용 |
| `Scanner sc` | 입력 |

생성자에서 `rentalList = new LinkedHashMap<>();`

---

### 3-1. `start()`

1. 환영 메시지: `"어서오세요 더조은도서관입니다."`
2. `member = new Member(memberNum)`
3. `book.getMenu()`
4. `rental()` — 대여 받기
5. `totalRental(member)` — 내역 · 결제
6. `"기다려 주시면 대여하신 도서를 준비하겠습니다."` 출력 후 `t.sleep(2000)`
7. `end()` — 준비 완료 메시지

---

### 3-2. `rental()`

1. `"취소를 원하시면 0번을 눌러주세요"` 안내
2. 무한 루프에서 도서 **번호** 입력 (`0`이면 `System.exit(0)`)
3. `book.bookList.get(choiceNum - 1)` 로 도서명 구하기
4. **대여 일수** 입력
5. **재대여 처리**
   - `reRental == true` 이고 같은 책이 이미 있으면 → **일수 누적** (`replace`)
   - 없으면 → `put`
   - 첫 대여면 → `put`
6. `member.setBookRental(rentalList)`
7. `addRental()` 호출 후 루프 종료

### 재대여 로직 (중요)

```java
if (reRental) {
    if (rentalList.containsKey(bookName)) {
        int addDays = rentalList.get(bookName) + rentalDays;
        rentalList.replace(bookName, addDays);
    } else {
        rentalList.put(bookName, rentalDays);
    }
} else {
    rentalList.put(bookName, rentalDays);
}
```

> 커피 예제의 `for + else` 버그 대신 **`containsKey`** 를 쓰세요.

잘못된 입력은 `try-catch`로 `"잘못된 선택입니다"` 출력.

---

### 3-3. `addRental()`

1. `reRental = false` 로 초기화
2. `"대여를 계속 하시겠습니까?"` / `"예(Y)/아니오(N)"`
3. 예 / `y` / `Y` → `book.getMenu()`, `reRental = true`, `rental()` 다시 호출
4. 아니오 / `n` / `N` → `return`

---

### 3-4. `totalRental(Member member)`

각 도서에 대해:

```text
금액 = 1일 가격(book.menu) × 대여 일수
```

- 대여 내역 박스 출력 (번호, 제목, 일수, 금액)
- 총액 출력 후 `payment(totalMoney)` 호출

---

### 3-5. `payment(int totalMoney)`

1. `"결제를 도와 드리겠습니다 카드 넣어주세요"`
2. `payResult = member.getMoney() - totalMoney`
3. `"결제중입니다....."` + `t.sleep(2500)`
4. `payResult < 0` → 잔액 부족 메시지
5. 아니면 잔액 갱신, 결제 완료, `memberNum++`

---

### 3-6. `end()`

대여한 도서 목록을 다시 출력하며  
`"회원님 대여하신 도서 준비되었습니다"` 안내.
