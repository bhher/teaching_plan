# 자바 CRUD 연습 — 직원 관리 시스템 (문제)

`ArrayList`로 직원 정보를 **등록 · 조회 · 수정 · 삭제**하는 프로그램을 작성하세요.

입력은 모두 **`Scanner.nextLine()`** 을 사용합니다.  
(숫자도 `Integer.parseInt(scanner.nextLine())`)

## 1. Employee 클래스

### 필드 (private)

| 필드 | 타입 | 설명 |
|------|------|------|
| `id` | `String` | 사번 (예: E001) |
| `name` | `String` | 이름 |
| `dept` | `String` | 부서 |
| `salary` | `int` | 연봉 |

### 생성자

```java
public Employee(String id, String name, String dept, int salary)
```

### 메서드

- 모든 필드 Getter
- `name`, `dept`, `salary` Setter (`id`는 수정 불가)
- `toString()`  
  형식: `사번: E001 | 이름: 홍길동 | 부서: 개발팀 | 연봉: 3500만원`

## 2. EmployeeManager 클래스

### 필드

```java
private ArrayList<Employee> list = new ArrayList<>();
private Scanner sc = new Scanner(System.in);
```

### 생성자 — 더미 데이터 5명

프로그램 시작 시 아래 직원이 **미리 등록**되어 있도록 생성자에서 `list.add(...)` 하세요.

| 사번 | 이름 | 부서 | 연봉(만원) |
|------|------|------|------------|
| E001 | 홍길동 | 개발팀 | 3500 |
| E002 | 김영희 | 인사팀 | 3200 |
| E003 | 이철수 | 영업팀 | 3000 |
| E004 | 박민수 | 개발팀 | 3800 |
| E005 | 최지우 | 기획팀 | 3400 |

```java
public EmployeeManager() {
    list.add(new Employee("E001", "홍길동", "개발팀", 3500));
    list.add(new Employee("E002", "김영희", "인사팀", 3200));
    list.add(new Employee("E003", "이철수", "영업팀", 3000));
    list.add(new Employee("E004", "박민수", "개발팀", 3800));
    list.add(new Employee("E005", "최지우", "기획팀", 3400));
}
```

### 메뉴

```text
========== 직원 관리 시스템 ==========
1. 직원 등록 (C)
2. 전체 조회 (R)
3. 직원 수정 (U)
4. 직원 삭제 (D)
5. 사번으로 검색
0. 종료
선택>
```

### 기능 요구사항

#### 1) 직원 등록 (Create)

- 사번, 이름, 부서, 연봉 입력
- **사번 중복**이면 `"이미 존재하는 사번입니다."` 출력 후 등록하지 않음
- 성공 시 `"직원이 등록되었습니다."` 출력

#### 2) 전체 조회 (Read)

- 목록이 비어 있으면 `"등록된 직원이 없습니다."`
- 있으면 번호와 함께 모든 직원 `toString()` 출력

#### 3) 직원 수정 (Update)

- 사번 입력 → 해당 직원 찾기
- 없으면 `"해당 사번이 없습니다."`
- 있으면 이름, 부서, 연봉만 다시 입력받아 수정 (`id`는 유지)
- `"수정되었습니다."` 출력

#### 4) 직원 삭제 (Delete)

- 사번 입력 → 찾아 삭제
- 없으면 `"해당 사번이 없습니다."`
- 성공 시 `"삭제되었습니다."`

#### 5) 사번으로 검색

- 사번 입력 → 1명 출력 또는 `"해당 사번이 없습니다."`

### 도우미 메서드 (권장)

```java
private Employee findById(String id)
// 찾으면 Employee, 없으면 null
```

### 실행 흐름

- `run()` 메서드에서 메뉴 반복
- `0` 입력 시 `"프로그램을 종료합니다."` 후 종료
