## 기능 6. 부서로 검색

### 요구사항

1. `"검색할 부서: "` 출력 후 부서명 입력 (예: `개발팀`)
2. `list`를 돌면서 **부서가 일치**하는 직원만 출력
3. 한 명도 없으면 `"해당 부서 직원이 없습니다."`
4. 있으면 인원 수와 함께 출력  
   예: `"개발팀 직원 2명"`

### 힌트

```java
if (e.getDept().equals(dept)) {
    // 출력
}
```

부분 일치로 하려면 `contains` 를 써도 됩니다.  
(문제 기본은 **완전 일치** `equals`)

### 실행 예시

```text
선택> 6
검색할 부서: 개발팀
개발팀 직원 2명
사번: E001 | 이름: 홍길동 | 부서: 개발팀 | 연봉: 3500만원
사번: E004 | 이름: 박민수 | 부서: 개발팀 | 연봉: 3800만원
```

더미 기준: 개발팀 = 홍길동(3500), 박민수(3800)

## 기능 7. 연봉 평균

### 요구사항

1. 직원이 없으면 `"등록된 직원이 없습니다."` 후 return
2. 모든 직원의 `salary` 합계 ÷ 인원수 = **평균**
3. 평균은 **소수 첫째 자리**까지 출력 (`printf` 또는 계산)

출력 예:

```text
전체 직원 5명
연봉 합계: 16900만원
연봉 평균: 3380.0만원
```

### 더미 데이터 검산

```text
3500 + 3200 + 3000 + 3800 + 3400 = 16900
16900 ÷ 5 = 3380.0
```

### 힌트

```java
int sum = 0;
for (Employee e : list) {
    sum += e.getSalary();
}
double avg = (double) sum / list.size();
System.out.printf("연봉 평균: %.1f만원\n", avg);
```

> `sum / list.size()` 만 하면 **정수 나눗셈**이라 소수점이 사라집니다.  
> `(double) sum` 으로 실수 나눗셈 하세요.

## (선택) 도전 — 부서별 연봉 평균

메뉴 7을 고르면:

```text
1. 전체 평균
2. 부서별 평균
```

- 1 → 위와 동일  
- 2 → 부서 입력 후 **그 부서만** 합계·평균  
  예: 개발팀 → (3500+3800)/2 = **3650.0**
