# 커피 주문 시스템 실습 문제

## 문제 설명

HashMap을 사용하여 커피 주문 시스템을 구현하세요.

### 요구사항

1. **메뉴 관리**
   - 커피 이름과 가격을 HashMap에 저장
   - 메뉴: Americano(3000원), Latte(4000원), Mocha(4500원), Espresso(2500원)

2. **주문 기능**
   - 사용자가 커피 이름과 수량을 입력
   - 같은 커피를 여러 번 주문하면 수량이 누적됨
   - "exit" 입력 시 주문 종료

3. **입력 검증**
   - 메뉴에 없는 커피 이름 입력 시 오류 메시지 출력
   - 수량은 1 이상의 정수만 입력 가능
   - 숫자가 아닌 값 입력 시 오류 메시지 출력 후 재입력

4. **주문 내역 출력**
   - 주문한 커피별 수량과 금액 출력
   - 총 금액 계산 및 출력

### 실행 예시


## 학습 목표

1. **HashMap 사용법**
   - `put()`, `get()`, `containsKey()`, `getOrDefault()` 메서드 활용
   - `keySet()`, `entrySet()` 반복문 사용

2. **예외 처리**
   - `NumberFormatException` 처리
   - 입력 검증 로직 구현

3. **반복문 활용**
   - `while(true)` 무한 루프
   - `for-each` 반복문

4. **문자열 처리**
   - `equalsIgnoreCase()` 대소문자 무시 비교

## 구현 단계

### Step 1: 메뉴 HashMap 생성

```java
Map<String, Integer> menu = new HashMap<>();
menu.put("Americano", 3000);
menu.put("Latte", 4000);
menu.put("Mocha", 4500);
menu.put("Espresso", 2500);
```

### Step 2: 주문 HashMap 생성

```java
Map<String, Integer> order = new HashMap<>();
```

### Step 3: 메뉴 출력

```java
for(String coffee : menu.keySet()){
    System.out.println(coffee + " - " + menu.get(coffee));
}
```

### Step 4: 주문 입력 및 검증

- 커피 이름 입력
- "exit" 체크
- 메뉴 존재 여부 확인
- 수량 입력 및 검증

### Step 5: 주문 저장

```java
order.put(coffee, order.getOrDefault(coffee, 0) + quantity);
```

### Step 6: 주문 내역 출력

```java
for(Map.Entry<String, Integer> entry : order.entrySet()){
```
