# 자바 연산자 연습문제

`3장_연산자` 학습용 연습문제입니다.  
풀이는 [자바-연산자-연습문제-풀이.md](./자바-연산자-연습문제-풀이.md)를 참고하세요.

---

## 문제 1. 덧셈

두 정수를 저장하는 변수를 만들고 합을 출력하세요.

```java
int num1 = 10;
int num2 = 20;
```

---

## 문제 2. 사칙연산

두 변수의 덧셈, 뺄셈, 곱셈, 나눗셈을 출력하세요.

```java
int num1 = 30;
int num2 = 5;
```

---

## 문제 3. 몫과 나머지

17을 3으로 나눈 몫과 나머지를 출력하세요.

---

## 문제 4. 증감 연산자

증감 연산자를 사용하여 결과를 출력하세요.

```java
int a = 10;
```

---

## 문제 5. 복합 대입 연산자

복합 대입 연산자를 사용하세요.

```java
int score = 50;
```

다음을 순서대로 수행한 뒤 `score`를 출력하세요.

- `score`에 20을 더한다
- `score`에서 10을 뺀다
- `score`에 2를 곱한다

---

## 문제 6. 비교 연산자

다음 결과를 출력하세요.

```java
int a = 10;
int b = 20;
```

출력할 비교 결과:

- `a > b`
- `a < b`
- `a == b`
- `a != b`

---

## 문제 7. 논리 연산자

나이가 20살일 때 결과를 출력하세요.

```java
int age = 20;
```

조건: `age >= 19 && age <= 30`

---

## 문제 8. 짝수 판별

짝수인지 출력하세요.

```java
int num = 8;
```

---

## 문제 9. 홀수 판별

홀수인지 출력하세요.

```java
int num = 13;
```

---

## 문제 10. 평균 구하기

세 과목 평균을 출력하세요.

```java
int kor = 80;
int eng = 90;
int math = 100;
```

---

## 문제 11. 원의 넓이

반지름이 5인 원의 넓이를 출력하세요.

- 원주율: `3.14`
- 공식: `넓이 = 3.14 × 반지름 × 반지름`

---

## 문제 12. 시간 계산

3670초를 시간, 분, 초로 출력하세요.

---

## 문제 13. 총 금액 계산

가격과 수량을 이용하여 총 금액을 출력하세요.

```java
int price = 1200;
int count = 5;
```

---

## 문제 14. 할인 가격

20% 할인 금액과 최종 금액을 출력하세요.

```java
int price = 100000;
```
