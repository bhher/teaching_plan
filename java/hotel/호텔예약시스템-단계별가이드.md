## 📌 6단계: 메인 메뉴 구현

### 6-1. 기본 메뉴 구조

```java
public static void main(String[] args) {
    Scanner sc = new Scanner(System.in);
    ReservationManager manager = new ReservationManager();
    
    // 초기 호텔 추가
    manager.addHotel(new Hotel("그랜드 호텔", "서울", 150000, 50));
    
    while(true) {
        System.out.println("\n=== 호텔 예약 시스템 ===");
        System.out.println("1. 호텔 예약");
        System.out.println("2. 예약 조회");
        System.out.println("3. 예약 취소");
        System.out.println("0. 종료");
        System.out.print("선택: ");
        
        int choice = sc.nextInt();
        sc.nextLine();
        
        switch(choice) {
            case 1:
                manager.hotelReservation();
                break;
            case 2:
                manager.checkReservation();
                break;
            case 3:
                manager.cancelReservation();
                break;
            case 0:
                System.out.println("시스템을 종료합니다.");
                return;
            default:
                System.out.println("잘못된 선택입니다.");
        }
    }
}
```

## 💡 디버깅 팁

1. **인덱스 오류**: 방 번호는 1부터 시작하지만 ArrayList 인덱스는 0부터 시작
2. **리스트 삭제 오류**: 리스트를 순회하면서 삭제할 때는 뒤에서부터
3. **파일 경로**: Windows 경로는 `\\` 사용
4. **Scanner**: `nextInt()` 후 `nextLine()`으로 개행 문자 처리
