# 호텔 예약 시스템 실습 문제

## 📋 문제 개요

영화 예매 시스템을 참고하여 호텔 예약 시스템을 구현하세요. 사용자는 호텔을 예약하고, 운영자는 호텔을 관리할 수 있는 시스템입니다.

---

## 🎯 학습 목표

1. 클래스 설계 및 객체지향 프로그래밍 이해
2. ArrayList를 활용한 데이터 관리
3. 파일 입출력 (File I/O) 구현
4. 예외 처리 (Exception Handling)
5. 사용자 인터페이스 구현

---

## 📁 프로젝트 구조

```
hotel/
├── Hotel.java              (호텔 정보 클래스)
├── Room.java               (방 관리 클래스)
├── User.java               (사용자 클래스)
├── ReservationManager.java (예약 관리 클래스)
├── ReservationTicket.java  (티켓 출력 클래스)
└── HotelReservationMain.java (메인 프로그램)
```
