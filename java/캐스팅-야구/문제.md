# 야구 선수 캐스팅 문제 (업캐스팅 · 다운캐스팅)

**타자 · 투수 · 타율 · 방어율** 로 상속과 캐스팅을 연습합니다.

정답: [정답.md](./정답.md)

---

## 클래스 구조 (공통)

```text
Player (부모) — 선수
  ├── String name      // 이름
  ├── int number       // 등번호
  ├── void info()      // 기본 정보 출력
  └── void play()      // "선수가 경기에 나갑니다"

      ├── Batter (타자)
      │     double avg          // 타율 (예: 0.312)
      │     int hit             // 안타 수
      │     info() 오버라이딩
      │     play() 오버라이딩 → "타석에 들어섭니다"
      │     void swing()        // "스윙!" (타자만)
      │
      └── Pitcher (투수)
            double era          // 방어율 (예: 2.45)
            int strikeOut       // 탈삼진
            info() 오버라이딩
            play() 오버라이딩 → "마운드에 올라갑니다"
            void throwBall()    // "공을 던집니다!" (투수만)
```

# Part 1. 객관식 · 결과 예측

아래 코드를 기준으로 1~10번을 푸세요.

```java
class Player {
    String name;
    int number;

    Player(String name, int number) {
        this.name = name;
        this.number = number;
    }

    void info() {
        System.out.println(number + "번 " + name);
    }

    void play() {
        System.out.println("선수가 경기에 나갑니다");
    }
}

class Batter extends Player {
    double avg;  // 타율
    int hit;     // 안타

    Batter(String name, int number, double avg, int hit) {
        super(name, number);
        this.avg = avg;
        this.hit = hit;
    }

    @Override
    void info() {
        System.out.println(number + "번 타자 " + name
                + " | 타율: " + avg + " | 안타: " + hit);
    }

    @Override
    void play() {
        System.out.println("타석에 들어섭니다");
    }

    void swing() {
        System.out.println("스윙!");
    }
}

class Pitcher extends Player {
    double era;      // 방어율
    int strikeOut;   // 탈삼진

    Pitcher(String name, int number, double era, int strikeOut) {
        super(name, number);
        this.era = era;
        this.strikeOut = strikeOut;
    }

    @Override
    void info() {
        System.out.println(number + "번 투수 " + name
                + " | 방어율: " + era + " | 탈삼진: " + strikeOut);
    }

    @Override
    void play() {
        System.out.println("마운드에 올라갑니다");
    }

    void throwBall() {
        System.out.println("공을 던집니다!");
    }
}
```

# Part 2. 코드 작성

## 11번. 라인업 출력

`Player` 배열에 타자 2명, 투수 1명을 넣고  
반복문으로 모두 `info()` 를 호출하세요.

더미 예:

| 역할 | 이름 | 번호 | 기록 |
|------|------|------|------|
| 타자 | 이정후 | 51 | 타율 0.312, 안타 150 |
| 타자 | 김하성 | 7 | 타율 0.285, 안타 130 |
| 투수 | 원태인 | 18 | 방어율 2.45, 탈삼진 120 |

## 12번. 역할별 특기 발동

메서드 `specialAction(Player p)` 를 작성하세요.

- `Batter` 이면 → `swing()`  
- `Pitcher` 이면 → `throwBall()`  
- 그 외 → `"알 수 없는 선수"`

`instanceof` 로 검사한 뒤 다운캐스팅하세요.

---

## 13번. 타율 · 방어율 리포트

`Player[]` 를 받아:

1. 타자만 골라 **타율 합 / 타자 수 = 평균 타율** 출력  
2. 투수만 골라 **방어율 합 / 투수 수 = 평균 방어율** 출력  

(타자·투수가 0명이면 해당 항목은 `"없음"`)

힌트:

```java
if (p instanceof Batter) {
    Batter b = (Batter) p;
    // b.avg 사용
}
```

## 14번. 선발 투수 교체 (실전)

## 체크리스트

- [ ] `Player p = new Batter(...)` / `new Pitcher(...)` 업캐스팅
- [ ] `play()`, `info()` 오버라이딩 결과 이해
- [ ] 타자만의 `swing()`, 투수만의 `throwBall()` 은 다운캐스팅 후 호출
- [ ] 잘못된 캐스팅 → `ClassCastException`
- [ ] `instanceof` 로 타자/투수 구분

## 야구 용어 ↔ 자바

| 야구 | 자바 |
|------|------|
| 선수(Player) | 부모 클래스 |
| 타자 / 투수 | 자식 클래스 |
| 타율(avg) | Batter 전용 필드 |
| 방어율(era) | Pitcher 전용 필드 |
| 라인업(배열) | `Player[]` + 업캐스팅 |
| 역할에 맞는 플레이 | 오버라이딩 `play()` |
| 타격/투구 특기 | 다운캐스팅 후 전용 메서드 |
