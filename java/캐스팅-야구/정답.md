## Part 1. 객관식 · 결과 정답

| 문제 | 정답 | 해설 |
|------|------|------|
| 1 | ① | 자식(`Batter`) → 부모(`Player`) = **업캐스팅** |
| 2 | ② | 오버라이딩 → 실제 객체는 타자 → `타석에 들어섭니다` |
| 3 | ③ | `Player` 참조로는 투수 전용 `throwBall()` 호출 불가 |
| 4 | ② | `info()` 오버라이딩 → 투수 정보(방어율·탈삼진) 출력 |
| 5 | ① | 실제가 `Batter` → 다운캐스팅 성공 → `스윙!` |
| 6 | ③ | 실제는 `Pitcher`인데 `Batter`로 캐스팅 → `ClassCastException` |
| 7 | ① | `instanceof Batter` true → `avg` 출력 |
| 8 | ② | 배열 다형성: 타자·투수·타자 각각의 `play()` |
| 9 | ③ | 부모에 있는(또는 오버라이딩된) `play()` 만 바로 호출 가능 |
| 10 | `업캐스팅` / `다운캐스팅` / `instanceof` | (순서: 업캐스팅, 다운캐스팅, instanceof) |

> 10번 답안 예: **업캐스팅**, **다운캐스팅**, **instanceof**

### 11번. 라인업 출력

```java
public class LineupMain {
    public static void main(String[] args) {
        Player[] team = {
            new Batter("이정후", 51, 0.312, 150),
            new Batter("김하성", 7, 0.285, 130),
            new Pitcher("원태인", 18, 2.45, 120)
        };

        for (Player p : team) {
            p.info();  // 업캐스팅 + 오버라이딩
        }
    }
}
```

출력:

```text
51번 타자 이정후 | 타율: 0.312 | 안타: 150
7번 타자 김하성 | 타율: 0.285 | 안타: 130
18번 투수 원태인 | 방어율: 2.45 | 탈삼진: 120
```

### 12번. 역할별 특기 발동

```java
public static void specialAction(Player p) {
    if (p instanceof Batter) {
        Batter b = (Batter) p;
        b.swing();
    } else if (p instanceof Pitcher) {
        Pitcher pit = (Pitcher) p;
        pit.throwBall();
    } else {
        System.out.println("알 수 없는 선수");
    }
}

// 사용 예
public static void main(String[] args) {
    Player[] team = {
        new Batter("이정후", 51, 0.312, 150),
        new Pitcher("원태인", 18, 2.45, 120),
        new Batter("김하성", 7, 0.285, 130)
    };
    for (Player p : team) {
        specialAction(p);
    }
}
```

출력:

```text
스윙!
공을 던집니다!
스윙!
```

### 13번. 타율 · 방어율 리포트

```java
public static void report(Player[] team) {
    double sumAvg = 0;
    int batterCount = 0;
    double sumEra = 0;
    int pitcherCount = 0;

    for (Player p : team) {
        if (p instanceof Batter) {
            Batter b = (Batter) p;
            sumAvg += b.avg;
            batterCount++;
        } else if (p instanceof Pitcher) {
            Pitcher pit = (Pitcher) p;
            sumEra += pit.era;
            pitcherCount++;
        }
    }

    if (batterCount == 0) {
        System.out.println("평균 타율: 없음");
    } else {
        System.out.printf("평균 타율: %.3f (%d명)%n",
                sumAvg / batterCount, batterCount);
    }

    if (pitcherCount == 0) {
        System.out.println("평균 방어율: 없음");
    } else {
        System.out.printf("평균 방어율: %.2f (%d명)%n",
                sumEra / pitcherCount, pitcherCount);
    }
}
```

더미(이정후·김하성·원태인) 기준 예:

```text
평균 타율: 0.299 (2명)   // (0.312+0.285)/2
평균 방어율: 2.45 (1명)
```

## 전체 실행 예 (한 파일)

```java
public class BaseballCastingDemo {
    public static void main(String[] args) {
        Player[] team = {
            new Batter("이정후", 51, 0.312, 150),
            new Batter("김하성", 7, 0.285, 130),
            new Pitcher("원태인", 18, 2.45, 120)
        };

        System.out.println("=== 라인업 ===");
        for (Player p : team) {
            p.info();
        }

        System.out.println("\n=== 특기 ===");
        for (Player p : team) {
            specialAction(p);
        }

        System.out.println("\n=== 기록 리포트 ===");
        report(team);
    }

    // specialAction, report 는 위 12·13번과 동일
}
```

## 핵심 정리 (야구로 기억)

```text
Player p = new Batter(...);   // 업캐스팅 — "선수로 등록"
p.play();                     // 역할에 맞게 동작 (오버라이딩)

p.swing();                    // X — 타자 특기는 Player 티켓만으로는 불가

if (p instanceof Batter) {
    Batter b = (Batter) p;    // 다운캐스팅 — "타자 확인 후"
    System.out.println(b.avg); // 타율 조회
}
```

| 하고 싶은 일 | 필요한 것 |
|--------------|-----------|
| 타율 보기 | `Batter` 로 다운캐스팅 |
| 방어율 보기 | `Pitcher` 로 다운캐스팅 |
| 전원 play | `Player[]` + 업캐스팅만으로 OK |
| 투수를 타자로 강제 변환 | `ClassCastException` |
