# 영화 예매 시스템 (HashMap) - 연습문제

커피 주문 프로그램을 참고하여 **영화 예매 시스템**을 작성하세요.

---

## 요구사항

1. `HashMap<String, Integer>` 로 **영화 제목 → 티켓 가격** 을 저장합니다.
2. `HashMap<String, Integer>` 로 **주문(예매) 내역 → 매수** 를 저장합니다.
3. 메뉴를 출력하고, 영화 제목과 매수를 입력받습니다.
4. `종료` 입력 시 주문을 마칩니다.
5. 주문 내역과 **총 금액**, **평균 금액**을 출력합니다.

---

## 영화 메뉴 (더미 데이터)

| 영화 제목 | 가격 |
|-----------|------|
| 어벤져스 | 15000 |
| 기생충 | 12000 |
| 범죄도시 | 13000 |
| 인터스텔라 | 14000 |
| 타이타닉 | 12000 |
| 겨울왕국 | 11000 |
| 오펜하이머 | 15000 |

---

## 메뉴 출력 예시

```text
=== 영화 메뉴 ===
어벤져스: 15000원
기생충: 12000원
...
```

---

## 입력 규칙

- 영화 제목: `scanner.nextLine()`
- 매수: `scanner.nextInt()` + `scanner.nextLine()` (버퍼 비우기)
- 매수는 **1개 이상**
- 없는 영화는 `"해당 영화가 없습니다. 다시 입력해 주세요"`
- 같은 영화를 다시 주문하면 **매수 누적**

---

## 실행 예시

```text
=== 영화 메뉴 ===
어벤져스: 15000원
기생충: 12000원
...

주문할 영화를 입력하세요 (종료: '종료'): 기생충
매수를 입력하세요 : 2
기생충 2매가 예매되었습니다. (금액: 24000원)

주문할 영화를 입력하세요 (종료: '종료'): 어벤져스
매수를 입력하세요 : 1
어벤져스 1매가 예매되었습니다. (금액: 15000원)

주문할 영화를 입력하세요 (종료: '종료'): 종료

=== 예매 내역 ===
기생충 X 2 = 24000
어벤져스 X 1 = 15000

총 금액 : 39000원
평균 금액 : 13000.00원
```
