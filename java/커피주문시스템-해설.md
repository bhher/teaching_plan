# 커피 주문 시스템 코드 해설

## 전체 코드

```java
package a0326.coffee1;

import java.util.HashMap;
import java.util.Map;
import java.util.Scanner;

public class CoffeeOrder {
    public static void main(String[] args) {
        Map<String, Integer>menu = new HashMap<>();
        menu.put("Americano", 3000);
        menu.put("Latte", 4000);
        menu.put("Mocha", 4500);
        menu.put("Espresso", 2500);

        Map<String,Integer> order = new HashMap<>();
        Scanner sc = new Scanner(System.in);

        while (true) {
            System.out.println("\n메뉴");
            for(String coffee:menu.keySet()){
                System.out.println(coffee+" - "+menu.get(coffee));
            }

            System.out.println("주문할 커피 이름(종료:exit)");
            String coffee = sc.nextLine();

            if(coffee.equalsIgnoreCase("exit")){
                break;
            }
            if(!menu.containsKey(coffee)){
                System.out.println("해당 커피는 메뉴에 없습니다.");
                continue;
            }
            System.out.print("수량 : ");
            int quantity;
            while (true) {
                try {
                    quantity = Integer.parseInt(sc.nextLine());
                    if(quantity <= 0){
                        System.out.println("1이상의 숫자를 입력하세요");
                        continue;
                    }
                    break;
                } catch (NumberFormatException e) {
                    System.out.println("유효한 숫자를 입력하세요");
                }
            }
            order.put(coffee, order.getOrDefault(coffee, 0)+quantity);
            System.out.println(coffee+ " "+quantity+ "개 추가 되었습니다.");
        }
        sc.close();
        
        System.out.println("\n주문 내역");
        int total = 0;
        for(Map.Entry<String,Integer> entry : order.entrySet()){
            int price = menu.get(entry.getKey())*entry.getValue();
            System.out.println(entry.getKey()+ " X "+entry.getValue()+" = "+price+"원");
            total+=price;
        }
        System.out.println("총 금액 : "+total+"원");
    }
}
```

## 코드 상세 해설

### 1. HashMap 선언 및 초기화

```java
Map<String, Integer> menu = new HashMap<>();
menu.put("Americano", 3000);
menu.put("Latte", 4000);
menu.put("Mocha", 4500);
menu.put("Espresso", 2500);
```

**해설:**
- `Map<String, Integer>`: 키는 String(커피 이름), 값은 Integer(가격)
- `HashMap<>()`: HashMap 객체 생성
- `put(key, value)`: 키-값 쌍을 저장
- 메뉴 정보를 HashMap에 저장하여 빠른 검색 가능

**장점:**
- O(1) 시간 복잡도로 메뉴 검색 가능
- 키로 직접 가격 조회 가능

---

### 2. 주문 HashMap 생성

```java
Map<String, Integer> order = new HashMap<>();
```

**해설:**
- 주문 내역을 저장할 HashMap
- 키: 커피 이름, 값: 주문 수량
- 같은 커피를 여러 번 주문하면 수량이 누적됨

---

### 3. 메뉴 출력

```java
for(String coffee : menu.keySet()){
    System.out.println(coffee + " - " + menu.get(coffee));
}
```

**해설:**
- `keySet()`: HashMap의 모든 키를 Set으로 반환
- `menu.get(coffee)`: 키로 값을 조회
- 각 커피 이름과 가격을 출력

**다른 방법:**
```java
// entrySet() 사용
for(Map.Entry<String, Integer> entry : menu.entrySet()){
    System.out.println(entry.getKey() + " - " + entry.getValue() + "원");
}
```

**비교:**
- `keySet()`: 키만 필요할 때 사용 (값은 `get()`으로 조회)
- `entrySet()`: 키와 값 모두 필요할 때 사용 (더 효율적)

---

### 4. 커피 이름 입력 및 검증

```java
System.out.println("주문할 커피 이름(종료:exit)");
String coffee = sc.nextLine();

if(coffee.equalsIgnoreCase("exit")){
    break;
}
if(!menu.containsKey(coffee)){
    System.out.println("해당 커피는 메뉴에 없습니다.");
    continue;
}
```

**해설:**
- `sc.nextLine()`: 한 줄 전체를 문자열로 입력받음
- `equalsIgnoreCase("exit")`: 대소문자 무시하고 비교
  - "exit", "EXIT", "Exit" 모두 인식
- `containsKey(coffee)`: HashMap에 해당 키가 있는지 확인
- `continue`: 다음 반복으로 넘어감 (주문 건너뜀)

**주의사항:**
- `containsKey()`를 사용하여 메뉴 존재 여부 확인
- 없는 메뉴 입력 시 오류 메시지 출력 후 재입력

### 5. 수량 입력 및 예외 처리

```java
System.out.print("수량 : ");
int quantity;
while (true) {
    try {
        quantity = Integer.parseInt(sc.nextLine());
        if(quantity <= 0){
            System.out.println("1이상의 숫자를 입력하세요");
            continue;
        }
        break;
    } catch (NumberFormatException e) {
        System.out.println("유효한 숫자를 입력하세요");
    }
}
```

**해설:**
- `Integer.parseInt()`: 문자열을 정수로 변환
- `NumberFormatException`: 숫자가 아닌 값 입력 시 발생하는 예외
- `try-catch`: 예외 발생 시 처리
- `quantity <= 0`: 0 이하의 수량 체크
- `break`: 유효한 수량 입력 시 반복문 종료

**동작 흐름:**
1. 사용자가 수량 입력
2. `parseInt()`로 변환 시도
3. 성공: 수량이 1 이상인지 확인
4. 실패: 예외 발생 → 오류 메시지 출력 → 재입력
5. 유효한 수량 입력 시 `break`로 반복문 종료

### 6. 주문 저장 (핵심 로직)

```java
order.put(coffee, order.getOrDefault(coffee, 0) + quantity);
```

**해설:**
- `getOrDefault(key, defaultValue)`: 키가 있으면 값을 반환, 없으면 기본값 반환
- `order.getOrDefault(coffee, 0)`: 기존 주문 수량 가져오기 (없으면 0)
- `+ quantity`: 새로 주문한 수량 추가
- `put()`: 업데이트된 수량 저장

**예시:**
```java
// 첫 번째 주문: Americano 2개
order.getOrDefault("Americano", 0)  // 0 (없음)
0 + 2 = 2
order.put("Americano", 2)

// 두 번째 주문: Americano 3개
order.getOrDefault("Americano", 0)  // 2 (기존 수량)
2 + 3 = 5
order.put("Americano", 5)  // 수량 누적!
```

**다른 방법 (비효율적):**
```java
// containsKey 사용 (더 복잡함)
if(order.containsKey(coffee)){
    order.put(coffee, order.get(coffee) + quantity);
} else {
    order.put(coffee, quantity);
}
```

**getOrDefault의 장점:**
- 코드가 간결함
- null 체크 불필요
- 한 줄로 처리 가능

### 7. 주문 내역 출력

```java
System.out.println("\n주문 내역");
int total = 0;
for(Map.Entry<String, Integer> entry : order.entrySet()){
    int price = menu.get(entry.getKey()) * entry.getValue();
    System.out.println(entry.getKey() + " X " + entry.getValue() + " = " + price + "원");
    total += price;
}
System.out.println("총 금액 : " + total + "원");
```

**해설:**
- `entrySet()`: 키-값 쌍을 모두 가져옴
- `entry.getKey()`: 커피 이름
- `entry.getValue()`: 주문 수량
- `menu.get(entry.getKey())`: 메뉴에서 가격 조회
- `price = 가격 * 수량`: 각 항목의 금액 계산
- `total += price`: 총 금액 누적

**계산 과정:**
```
주문: Americano 5개, Latte 1개

1. Americano
   - 가격: menu.get("Americano") = 3000
   - 수량: entry.getValue() = 5
   - 금액: 3000 * 5 = 15000원
   - total = 15000

2. Latte
   - 가격: menu.get("Latte") = 4000
   - 수량: entry.getValue() = 1
   - 금액: 4000 * 1 = 4000원
   - total = 15000 + 4000 = 19000
```

## 핵심 개념 정리

### 1. HashMap 주요 메서드

| 메서드 | 설명 | 예시 |
|--------|------|------|
| `put(key, value)` | 키-값 쌍 저장 | `menu.put("Latte", 4000)` |
| `get(key)` | 키로 값 조회 | `menu.get("Latte")` → 4000 |
| `containsKey(key)` | 키 존재 여부 | `menu.containsKey("Latte")` → true |
| `getOrDefault(key, default)` | 키가 없으면 기본값 반환 | `order.getOrDefault("Latte", 0)` |
| `keySet()` | 모든 키 반환 | `menu.keySet()` → Set<String> |
| `entrySet()` | 모든 키-값 쌍 반환 | `menu.entrySet()` → Set<Entry> |

### 2. 반복문 방법 비교

**keySet() 사용:**
```java
for(String coffee : menu.keySet()){
    System.out.println(coffee + " - " + menu.get(coffee));
}
```
- 키만 순회
- 값을 가져오려면 `get()` 호출 필요

**entrySet() 사용:**
```java
for(Map.Entry<String, Integer> entry : menu.entrySet()){
    System.out.println(entry.getKey() + " - " + entry.getValue());
}
```
- 키-값 쌍을 직접 순회
- `get()` 호출 불필요 (더 효율적)

### 3. getOrDefault() 활용

**기본 사용법:**
```java
// 키가 없으면 기본값 반환
int value = map.getOrDefault("key", 0);
```

**누적 계산에 활용:**
```java
// 기존 값에 더하기
map.put(key, map.getOrDefault(key, 0) + 1);
```

**장점:**
- null 체크 불필요
- 코드 간결
- 안전한 기본값 처리

## 예외 처리 설명

### NumberFormatException

**발생 상황:**
- `Integer.parseInt("abc")` → 숫자가 아닌 문자열 변환 시도

**처리 방법:**
```java
try {
    quantity = Integer.parseInt(sc.nextLine());
    // 성공 시 처리
} catch (NumberFormatException e) {
    // 예외 발생 시 처리
    System.out.println("유효한 숫자를 입력하세요");
}
```

**주의사항:**
- `try-catch` 블록 내에서 변수 선언 시 스코프 문제 발생 가능
- 변수는 `try` 블록 밖에서 선언해야 함

## 개선 가능한 부분

### 1. 입력 검증 개선

```java
// 현재: 무한 반복
while (true) {
    // ...
}

// 개선: 최대 시도 횟수 제한
int maxAttempts = 3;
int attempts = 0;
while (attempts < maxAttempts) {
    // ...
    attempts++;
}
```

### 2. 메뉴 출력 개선

```java
// 현재: 단순 출력
for(String coffee : menu.keySet()){
    System.out.println(coffee + " - " + menu.get(coffee));
}

// 개선: 번호와 함께 출력
int num = 1;
for(String coffee : menu.keySet()){
    System.out.println(num++ + ". " + coffee + " - " + menu.get(coffee) + "원");
}
```

### 3. 주문 내역 포맷 개선

```java
// 현재: 단순 출력
System.out.println(entry.getKey() + " X " + entry.getValue() + " = " + price + "원");

// 개선: 정렬된 출력
System.out.printf("%-15s %3d개  %6d원\n", 
    entry.getKey(), entry.getValue(), price);
```
