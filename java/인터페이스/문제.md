# Part 2. 코드 결과 예측

다음 코드를 기준으로 7~12번을 푸세요.

```java
interface RemoteControl {
    int MAX_VOLUME = 100;  // 상수

    void turnOn();
    void turnOff();
    void setVolume(int volume);
}

class Television implements RemoteControl {
    private int volume;

    @Override
    public void turnOn() {
        System.out.println("TV를 켭니다");
    }

    @Override
    public void turnOff() {
        System.out.println("TV를 끕니다");
    }

    @Override
    public void setVolume(int volume) {
        if (volume > MAX_VOLUME) {
            this.volume = MAX_VOLUME;
        } else {
            this.volume = volume;
        }
        System.out.println("현재 볼륨: " + this.volume);
    }
}

class Audio implements RemoteControl {
    @Override
    public void turnOn() {
        System.out.println("Audio를 켭니다");
    }

    @Override
    public void turnOff() {
        System.out.println("Audio를 끕니다");
    }

    @Override
    public void setVolume(int volume) {
        System.out.println("Audio 볼륨: " + volume);
    }
}
```

# Part 3. 코드 작성

## 13번. 결제 인터페이스

```text
interface Payable
  └── void pay(int amount);

class CardPayment implements Payable
  └── "카드로 ○○원 결제"

class CashPayment implements Payable
  └── "현금으로 ○○원 결제"
```

`main`에서:

```java
Payable p1 = new CardPayment();
Payable p2 = new CashPayment();
p1.pay(10000);
p2.pay(5000);
```

예상 출력:

```text
카드로 10000원 결제
현금으로 5000원 결제
```

## 15번. 차량 — 인터페이스 + 클래스

차량 CRUD와 연결해 연습합니다.

```text
interface Driveable
  └── void drive();

class Sedan implements Driveable
  └── "세단이 주행합니다"

class Truck implements Driveable
  └── "트럭이 짐을 싣고 주행합니다"
```

1. `Driveable` 배열에 Sedan, Truck 담기  
2. 모두 `drive()` 호출  
3. `instanceof Truck` 이면 `"화물차입니다"` 추가 출력

## 16번. 다중 구현 — 스마트폰

```text
interface Camera { void takePhoto(); }
interface MusicPlayer { void playMusic(); }

class SmartPhone implements Camera, MusicPlayer
  └── takePhoto() → "사진을 찍습니다"
  └── playMusic() → "음악을 재생합니다"
```

`Camera c = new SmartPhone();` 로는 `takePhoto()` 만 호출하고,  
`MusicPlayer` 로 다시 담아 `playMusic()` 을 호출하는 코드를 작성하세요.  
(필요하면 다운캐스팅 또는 새 변수)

## 17번. 계산기 (default / static — 선택 심화)

Java 8+ :

```java
interface Calculator {
    int add(int a, int b);

    default void printAdd(int a, int b) {
        System.out.println(add(a, b));
    }

    static int multiply(int a, int b) {
        return a * b;
    }
}
```

`Calculator` 를 구현한 `SimpleCalc` 를 만들고  
`printAdd(3, 4)` 와 `Calculator.multiply(3, 4)` 를 호출하세요.

# 체크리스트

- [ ] `interface` / `implements` 구분
- [ ] 모든 추상 메서드 구현 + `@Override` + `public`
- [ ] 인터페이스 타입으로 변수·배열 사용
- [ ] 상수는 `인터페이스명.상수명`
- [ ] 다중 구현 `implements A, B`
- [ ] (선택) `default` / `static` 메서드

## 한눈에 보기

```text
interface Payable { void pay(int amount); }
        ▲
        │ implements
   ┌────┴────┐
CardPayment  CashPayment

Payable p = new CardPayment();  // 다형성
p.pay(10000);
```

| 비교 | 상속(`extends`) | 인터페이스(`implements`) |
|------|-----------------|--------------------------|
| 개수 | 부모 **하나** | **여러 개** 가능 |
| 관계 | ~이다 (IS-A) | ~할 수 있다 (CAN-DO) |
| 목적 | 공통 속성·동작 | 약속(메서드 목록) |
