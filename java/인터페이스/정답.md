## Part 1. 개념 정답

| 문제 | 정답 | 해설 |
|------|------|------|
| 1 | ③ | 추상 메서드는 구현 클래스에서 **전부** 구현해야 함. 인터페이스는 `new` 불가, 다중 구현 가능, 인스턴스 필드 불가(상수만) |
| 2 | ② | `implements` |
| 3 | ② | 올바른 인터페이스 선언. ①은 extends로 인터페이스 상속 아님, ③ 인스턴스 필드 불가, ④ new 불가 |
| 4 | `extends` / `implements` | 상속 / 구현 |
| 5 | ③ | 추상 메서드는 기본적으로 `public abstract` |
| 6 | ② | 다중 구현 |

## Part 3. 코드 작성 정답

### 13번. 결제 인터페이스

```java
interface Payable {
    void pay(int amount);
}

class CardPayment implements Payable {
    @Override
    public void pay(int amount) {
        System.out.println("카드로 " + amount + "원 결제");
    }
}

class CashPayment implements Payable {
    @Override
    public void pay(int amount) {
        System.out.println("현금으로 " + amount + "원 결제");
    }
}

public class PaymentMain {
    public static void main(String[] args) {
        Payable p1 = new CardPayment();
        Payable p2 = new CashPayment();
        p1.pay(10000);
        p2.pay(5000);
    }
}
```

출력:

```text
카드로 10000원 결제
현금으로 5000원 결제
```

### 14번. 도형 넓이

```java
interface Shape {
    double area();
}

class Circle implements Shape {
    double radius;

    Circle(double radius) {
        this.radius = radius;
    }

    @Override
    public double area() {
        return Math.PI * radius * radius;
    }
}

class Rectangle implements Shape {
    double width;
    double height;

    Rectangle(double width, double height) {
        this.width = width;
        this.height = height;
    }

    @Override
    public double area() {
        return width * height;
    }
}

public class ShapeMain {
    public static void main(String[] args) {
        Shape[] shapes = {
            new Circle(5),
            new Rectangle(4, 6)
        };
        for (Shape s : shapes) {
            System.out.printf("넓이: %.2f%n", s.area());
        }
    }
}
```

출력 예:

```text
넓이: 78.54
넓이: 24.00
```

### 15번. Driveable (차량)

```java
interface Driveable {
    void drive();
}

class Sedan implements Driveable {
    @Override
    public void drive() {
        System.out.println("세단이 주행합니다");
    }
}

class Truck implements Driveable {
    @Override
    public void drive() {
        System.out.println("트럭이 짐을 싣고 주행합니다");
    }
}

public class DriveMain {
    public static void main(String[] args) {
        Driveable[] cars = {
            new Sedan(),
            new Truck()
        };

        for (Driveable d : cars) {
            d.drive();
            if (d instanceof Truck) {
                System.out.println("화물차입니다");
            }
        }
    }
}
```

출력:

```text
세단이 주행합니다
트럭이 짐을 싣고 주행합니다
화물차입니다
```

### 16번. 스마트폰 다중 구현

```java
interface Camera {
    void takePhoto();
}

interface MusicPlayer {
    void playMusic();
}

class SmartPhone implements Camera, MusicPlayer {
    @Override
    public void takePhoto() {
        System.out.println("사진을 찍습니다");
    }

    @Override
    public void playMusic() {
        System.out.println("음악을 재생합니다");
    }
}

public class SmartPhoneMain {
    public static void main(String[] args) {
        Camera c = new SmartPhone();
        c.takePhoto();

        // 방법 1: 새 인터페이스 타입으로 담기
        MusicPlayer m = (MusicPlayer) c;  // 같은 객체
        m.playMusic();

        // 방법 2: SmartPhone 변수
        // SmartPhone phone = new SmartPhone();
        // phone.takePhoto();
        // phone.playMusic();
    }
}
```

출력:

```text
사진을 찍습니다
음악을 재생합니다
```

### 17번. default / static (심화)

```java
interface Calculator {
    int add(int a, int b);

    default void printAdd(int a, int b) {
        System.out.println(add(a, b));
    }

    static int multiply(int a, int b) {
        return a * b;
    }
}

class SimpleCalc implements Calculator {
    @Override
    public int add(int a, int b) {
        return a + b;
    }
}

public class CalcMain {
    public static void main(String[] args) {
        Calculator calc = new SimpleCalc();
        calc.printAdd(3, 4);  // 7

        int mul = Calculator.multiply(3, 4);
        System.out.println(mul);  // 12
    }
}
```

## 리모컨 전체 예제 (7~10번용)

```java
interface RemoteControl {
    int MAX_VOLUME = 100;

    void turnOn();
    void turnOff();
    void setVolume(int volume);
}

class Television implements RemoteControl {
    private int volume;

    @Override
    public void turnOn() {
        System.out.println("TV를 켭니다");
    }

    @Override
    public void turnOff() {
        System.out.println("TV를 끕니다");
    }

    @Override
    public void setVolume(int volume) {
        if (volume > MAX_VOLUME) {
            this.volume = MAX_VOLUME;
        } else {
            this.volume = volume;
        }
        System.out.println("현재 볼륨: " + this.volume);
    }
}

class Audio implements RemoteControl {
    @Override
    public void turnOn() {
        System.out.println("Audio를 켭니다");
    }

    @Override
    public void turnOff() {
        System.out.println("Audio를 끕니다");
    }

    @Override
    public void setVolume(int volume) {
        System.out.println("Audio 볼륨: " + volume);
    }
}

public class RemoteMain {
    public static void main(String[] args) {
        RemoteControl rc = new Television();
        rc.turnOn();
        rc.setVolume(150);  // 현재 볼륨: 100

        System.out.println("MAX = " + RemoteControl.MAX_VOLUME);

        RemoteControl[] devices = { new Television(), new Audio() };
        for (RemoteControl r : devices) {
            r.turnOn();
        }
    }
}
```

## 핵심 정리

```text
interface = 해야 할 일의 목록(계약)
class implements interface = 계약 이행

Payable p = new CardPayment();  // 인터페이스로 묶어서 다룸
```

| 키워드 | 용도 |
|--------|------|
| `interface` | 인터페이스 선언 |
| `implements` | 구현 |
| `extends` | 클래스 상속 **또는** 인터페이스끼리 상속 |

```text
추상 메서드 → 반드시 public으로 구현
상수 → 인터페이스명.상수명
여러 인터페이스 → implements A, B
```
