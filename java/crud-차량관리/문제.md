# 자바 CRUD 연습 — 차량 관리 시스템 (문제)

`ArrayList`로 차량 정보를 **등록 · 조회 · 수정 · 삭제**하는 프로그램을 작성하세요.

입력은 모두 **`Scanner.nextLine()`** 을 사용합니다.  
(숫자도 `Integer.parseInt(scanner.nextLine())`)

정답: [정답.md](./정답.md)

## 패키지

- `a0821.car` (수업 날짜에 맞게 변경 가능)

```text

```

## 1. Car 클래스

### 필드 (private)

| 필드 | 타입 | 설명 |
|------|------|------|
| `carNumber` | `String` | 차량번호 (예: 12가3456) |
| `model` | `String` | 차종 (예: 소나타) |
| `color` | `String` | 색상 |
| `year` | `int` | 연식 (예: 2022) |
| `price` | `int` | 가격(만원) |

### 생성자

```java
public Car(String carNumber, String model, String color, int year, int price)
```

### 메서드

- 모든 필드 Getter
- `model`, `color`, `year`, `price` Setter (`carNumber`는 수정 불가)
- `toString()`  
  형식: `번호: 12가3456 | 차종: 소나타 | 색상: 흰색 | 연식: 2022 | 가격: 2500만원`

## 2. CarManager 클래스

### 필드

```java
private ArrayList<Car> cars = new ArrayList<>();
private Scanner sc = new Scanner(System.in);
```

### 생성자 — 더미 데이터 5대

프로그램 시작 시 아래 차량이 **미리 등록**되어 있도록 생성자에서 `cars.add(...)` 하세요.

| 차량번호 | 차종 | 색상 | 연식 | 가격(만원) |
|----------|------|------|------|------------|
| 12가3456 | 소나타 | 흰색 | 2022 | 2500 |
| 34나7890 | 아반떼 | 검정 | 2021 | 1800 |
| 56다1234 | 그랜저 | 은색 | 2023 | 4200 |
| 78라5678 | 쏘렌토 | 파랑 | 2020 | 3100 |
| 90마9012 | 소나타 | 회색 | 2024 | 2800 |

```java
public CarManager() {
    cars.add(new Car("12가3456", "소나타", "흰색", 2022, 2500));
    cars.add(new Car("34나7890", "아반떼", "검정", 2021, 1800));
    cars.add(new Car("56다1234", "그랜저", "은색", 2023, 4200));
    cars.add(new Car("78라5678", "쏘렌토", "파랑", 2020, 3100));
    cars.add(new Car("90마9012", "소나타", "회색", 2024, 2800));
}
```

> 소나타가 2대 있어 **차종 부분 검색** 연습에 좋습니다.

### 메뉴

```text
========== 차량 관리 시스템 ==========
1. 차량 등록 (C)
2. 전체 조회 (R)
3. 차량 수정 (U)
4. 차량 삭제 (D)
5. 차량번호 검색
6. 차종으로 검색
0. 종료
선택>
```

### 기능 요구사항

#### 1) 차량 등록 (Create)

- 차량번호, 차종, 색상, 연식, 가격 입력
- **차량번호 중복**이면 `"이미 등록된 차량번호입니다."` 후 등록하지 않음
- 성공 시 `"차량이 등록되었습니다."`

#### 2) 전체 조회 (Read)

- 비어 있으면 `"등록된 차량이 없습니다."`
- 있으면 `[1]`, `[2]` … 형태로 전체 출력

#### 3) 차량 수정 (Update)

- 차량번호로 찾기
- 없으면 `"해당 차량이 없습니다."`
- 있으면 차종, 색상, 연식, 가격만 수정 (번호 유지)
- `"수정되었습니다."`

#### 4) 차량 삭제 (Delete)

- 차량번호로 삭제
- 없으면 `"해당 차량이 없습니다."`
- 성공 시 `"삭제되었습니다."`

#### 5) 차량번호 검색

- 정확히 일치하는 1대 출력

#### 6) 차종으로 검색

- 입력한 문자열이 **차종에 포함**되면 모두 출력  
  예: `"소나타"` → 소나타 관련 차량
- 없으면 `"검색 결과가 없습니다."`

### 도우미 메서드 (권장)

```java
private Car findByNumber(String carNumber)
```

### 실행 흐름

- `run()`에서 메뉴 반복
- `0` → `"프로그램을 종료합니다."` 후 종료
