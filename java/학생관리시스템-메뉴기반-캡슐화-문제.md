# 학생 관리 시스템 - 메뉴 기반 실습 문제 (캡슐화)

도서 관리 시스템을 학생 관리 시스템으로 변형하여 작성하세요.
`Student` 클래스의 필드는 `private`로 선언하고 Getter/Setter를 사용합니다.

---

## 1. Student 클래스

### 필드

```java
private String name; // 학생 이름
private int score;   // 학생 점수
```

### 생성자

```java
public Student(String name, int score)
```

### 메서드

- `getName()`, `getScore()` Getter 작성
- `setName()`, `setScore()` Setter 작성
- `toString()`을 재정의하여 학생 정보를 문자열로 반환

출력 형식:

```text
Student{name='홍길동', score=90}
```

---

## 2. StudentApp 클래스

학생 정보는 다음 ArrayList에 저장합니다.

```java
ArrayList<Student> list = new ArrayList<>();
```

### 더미 데이터

프로그램 시작 시 다음 학생 3명을 저장하세요.

```java
list.add(new Student("홍길동", 90));
list.add(new Student("김영희", 85));
list.add(new Student("이철수", 78));
```

### 메뉴

```text
------------------------
1. 학생 등록
2. 학생 검색
3. 학생 수정
4. 학생 삭제
5. 전체 출력
6. 종료
선택 >
```

### 메뉴 기능

1. **학생 등록**
   - 이름과 점수를 입력받아 학생을 등록합니다.
2. **학생 검색**
   - 이름으로 학생을 검색합니다.
3. **학생 수정**
   - 이름으로 학생을 찾아 점수를 수정합니다.
4. **학생 삭제**
   - 이름으로 학생을 찾아 삭제합니다.
5. **전체 출력**
   - 등록된 모든 학생을 출력합니다.
6. **종료**
   - 반복문을 종료하고 프로그램을 끝냅니다.

---

## 3. 필수 메서드

```java
static Student findStudent(ArrayList<Student> list, String name)

static boolean updateStudent(
        ArrayList<Student> list,
        String name,
        int newScore)

static boolean deleteStudent(
        ArrayList<Student> list,
        String name)
```

### 반환 규칙

- 검색 성공: 해당 `Student` 객체 반환
- 검색 실패: `null` 반환
- 수정·삭제 성공: `true` 반환
- 수정·삭제 실패: `false` 반환

---

## 4. 입력 및 예외 처리

- 모든 입력은 `sc.nextLine()`으로 받습니다.
- 메뉴와 점수는 `Integer.parseInt()`로 정수 변환합니다.
- 숫자가 아닌 값을 입력하면 안내 메시지를 출력합니다.
- 문자열 비교는 `==`가 아니라 `equals()`를 사용합니다.
- `private` 필드에 직접 접근하지 않고 Getter/Setter를 사용합니다.

```java
int menu = Integer.parseInt(sc.nextLine());
```
