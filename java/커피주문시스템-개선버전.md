# 커피 주문 시스템 - 개선 버전 (객체지향)

## 개선 사항

기존 코드를 객체지향적으로 개선하여 유지보수성과 확장성을 높였습니다.

---

## 개선된 클래스 구조

```
CoffeeOrderSystem (메인)
├── Menu (메뉴 관리)
├── Coffee (커피 정보)
└── OrderManager (주문 관리)
```

## 클래스별 코드

### 1. Coffee.java - 커피 정보 클래스

```java
package a0326.coffee1;

public class Coffee {
    private String name;
    private int price;
    
    public Coffee(String name, int price) {
        this.name = name;
        this.price = price;
    }
    
    public String getName() {
        return name;
    }
    
    public int getPrice() {
        return price;
    }
    
    @Override
    public String toString() {
        return name + " - " + price + "원";
    }
}
```

**설명:**
- 커피 정보를 캡슐화
- 생성자로 이름과 가격 초기화
- Getter 메서드로 정보 접근
- `toString()` 오버라이드로 출력 형식 정의

### 2. Menu.java - 메뉴 관리 클래스

```java
package a0326.coffee1;

import java.util.HashMap;
import java.util.Map;

public class Menu {
    private Map<String, Coffee> menuMap;
    
    public Menu() {
        menuMap = new HashMap<>();
        initializeMenu();
    }
    
    private void initializeMenu() {
        menuMap.put("Americano", new Coffee("Americano", 3000));
        menuMap.put("Latte", new Coffee("Latte", 4000));
        menuMap.put("Mocha", new Coffee("Mocha", 4500));
        menuMap.put("Espresso", new Coffee("Espresso", 2500));
    }
    
    public void displayMenu() {
        System.out.println("\n메뉴");
        for(Coffee coffee : menuMap.values()) {
            System.out.println(coffee);
        }
    }
    
    public boolean containsCoffee(String name) {
        return menuMap.containsKey(name);
    }
    
    public Coffee getCoffee(String name) {
        return menuMap.get(name);
    }
    
    public int getPrice(String name) {
        Coffee coffee = menuMap.get(name);
        return coffee != null ? coffee.getPrice() : 0;
    }
}
```

**설명:**
- 메뉴 초기화를 생성자에서 처리
- `displayMenu()`: 메뉴 출력 메서드
- `containsCoffee()`: 메뉴 존재 여부 확인
- `getCoffee()`, `getPrice()`: 커피 정보 조회

**장점:**
- 메뉴 관리 로직이 한 곳에 집중
- 메뉴 추가/수정이 쉬움
- 테스트하기 쉬움

### 3. OrderManager.java - 주문 관리 클래스

```java
package a0326.coffee1;

import java.util.HashMap;
import java.util.Map;

public class OrderManager {
    private Map<String, Integer> orders;
    private Menu menu;
    
    public OrderManager(Menu menu) {
        this.orders = new HashMap<>();
        this.menu = menu;
    }
    
    public void addOrder(String coffeeName, int quantity) {
        orders.put(coffeeName, orders.getOrDefault(coffeeName, 0) + quantity);
        System.out.println(coffeeName + " " + quantity + "개 추가 되었습니다.");
    }
    
    public void displayOrderSummary() {
        System.out.println("\n주문 내역");
        int total = 0;
        
        for(Map.Entry<String, Integer> entry : orders.entrySet()) {
            String coffeeName = entry.getKey();
            int quantity = entry.getValue();
            int price = menu.getPrice(coffeeName);
            int itemTotal = price * quantity;
            
            System.out.println(coffeeName + " X " + quantity + " = " + itemTotal + "원");
            total += itemTotal;
        }
        
        System.out.println("총 금액 : " + total + "원");
    }
    
    public boolean isEmpty() {
        return orders.isEmpty();
    }
}
```

**설명:**
- 주문 추가: `addOrder()` 메서드
- 주문 내역 출력: `displayOrderSummary()` 메서드
- Menu 객체를 주입받아 가격 조회

**장점:**
- 주문 관리 로직 분리
- 재사용 가능
- 테스트 용이

### 4. CoffeeOrderSystem.java - 메인 클래스

```java
package a0326.coffee1;

import java.util.Scanner;

public class CoffeeOrderSystem {
    public static void main(String[] args) {
        Menu menu = new Menu();
        OrderManager orderManager = new OrderManager(menu);
        Scanner sc = new Scanner(System.in);
        
        while (true) {
            menu.displayMenu();
            System.out.println("주문할 커피 이름(종료:exit)");
            String coffee = sc.nextLine();
            
            if(coffee.equalsIgnoreCase("exit")) {
                break;
            }
            
            if(!menu.containsCoffee(coffee)) {
                System.out.println("해당 커피는 메뉴에 없습니다.");
                continue;
            }
            
            int quantity = getValidQuantity(sc);
            orderManager.addOrder(coffee, quantity);
        }
        
        sc.close();
        
        if(!orderManager.isEmpty()) {
            orderManager.displayOrderSummary();
        } else {
            System.out.println("주문 내역이 없습니다.");
        }
    }
    
    private static int getValidQuantity(Scanner sc) {
        int quantity;
        while (true) {
            System.out.print("수량 : ");
            try {
                quantity = Integer.parseInt(sc.nextLine());
                if(quantity <= 0) {
                    System.out.println("1이상의 숫자를 입력하세요");
                    continue;
                }
                break;
            } catch (NumberFormatException e) {
                System.out.println("유효한 숫자를 입력하세요");
            }
        }
        return quantity;
    }
}
```

**설명:**
- 메인 로직만 담당
- 입력 검증을 별도 메서드로 분리
- 각 클래스의 메서드 호출로 기능 수행

**장점:**
- 코드 가독성 향상
- 역할 분리 명확
- 유지보수 용이

## 개선 버전의 장점

### 1. 객체지향 설계 원칙 적용

- **단일 책임 원칙 (SRP)**: 각 클래스가 하나의 책임만 가짐
- **캡슐화**: 데이터와 메서드를 클래스로 묶음
- **의존성 주입**: OrderManager가 Menu를 주입받음

### 2. 확장성

**메뉴 추가가 쉬움:**
```java
// Menu.java의 initializeMenu()만 수정
menuMap.put("Cappuccino", new Coffee("Cappuccino", 5000));
```

**기능 추가가 쉬움:**
```java
// OrderManager에 메서드 추가
public void removeOrder(String coffeeName, int quantity) {
    // 주문 취소 기능
}
```

### 3. 테스트 용이성

```java
// 단위 테스트 예시
Menu menu = new Menu();
assertTrue(menu.containsCoffee("Latte"));
assertEquals(4000, menu.getPrice("Latte"));
```

### 4. 재사용성

- Menu 클래스를 다른 시스템에서도 사용 가능
- OrderManager를 다른 주문 시스템에 적용 가능

## 추가 개선 사항

### 1. 할인 기능 추가

```java
public class OrderManager {
    public int calculateTotal() {
        int total = 0;
        for(Map.Entry<String, Integer> entry : orders.entrySet()) {
            total += menu.getPrice(entry.getKey()) * entry.getValue();
        }
        return total;
    }
    
    public int calculateDiscount() {
        int total = calculateTotal();
        if(total >= 20000) {
            return (int)(total * 0.15);  // 15% 할인
        } else if(total >= 10000) {
            return (int)(total * 0.10);  // 10% 할인
        }
        return 0;
    }
    
    public int getFinalTotal() {
        return calculateTotal() - calculateDiscount();
    }
}
```

### 2. 주문 취소 기능

```java
public void cancelOrder(String coffeeName, int quantity) {
    if(!orders.containsKey(coffeeName)) {
        System.out.println("주문 내역에 없는 커피입니다.");
        return;
    }
    
    int currentQuantity = orders.get(coffeeName);
    if(quantity >= currentQuantity) {
        orders.remove(coffeeName);
        System.out.println(coffeeName + " 주문이 모두 취소되었습니다.");
    } else {
        orders.put(coffeeName, currentQuantity - quantity);
        System.out.println(coffeeName + " " + quantity + "개 취소되었습니다.");
    }
}
```

### 3. 파일 저장/로드 기능

```java
import java.io.*;
import java.util.*;

public class Menu {
    public void saveToFile(String filename) throws IOException {
        try (PrintWriter writer = new PrintWriter(new FileWriter(filename))) {
            for(Coffee coffee : menuMap.values()) {
                writer.println(coffee.getName() + "," + coffee.getPrice());
            }
        }
    }
    
    public void loadFromFile(String filename) throws IOException {
        try (BufferedReader reader = new BufferedReader(new FileReader(filename))) {
            String line;
            while((line = reader.readLine()) != null) {
                String[] parts = line.split(",");
                menuMap.put(parts[0], new Coffee(parts[0], Integer.parseInt(parts[1])));
            }
        }
    }
}
```

## 비교: 기본 버전 vs 개선 버전

| 항목 | 기본 버전 | 개선 버전 |
|------|----------|-----------|
| **코드 구조** | 단일 클래스 | 여러 클래스로 분리 |
| **유지보수** | 어려움 | 쉬움 |
| **확장성** | 낮음 | 높음 |
| **테스트** | 어려움 | 쉬움 |
| **재사용성** | 낮음 | 높음 |
| **가독성** | 보통 | 좋음 |
