## 프로그램 개요

이 프로그램은 학생 정보(이름, 나이, 학번)를 입력받아 **삽입 정렬(Insertion Sort)** 알고리즘을 사용하여 **이름을 알파벳 순으로 정렬**하는 프로그램입니다.

**주요 기능:**
- 학생 정보 입력 (이름, 나이, 학번)
- 삽입 정렬을 이용한 이름 순 정렬
- 정렬된 결과 출력

## 클래스별 상세 설명

### 1. Student 클래스

**역할:** 학생 정보를 저장하는 데이터 클래스

#### 필드 (Fields)

```java
private String name;      // 학생 이름
private int age;          // 학생 나이
private int studentId;    // 학생 학번
```

- 모든 필드는 `private`로 캡슐화되어 있습니다.
- 외부에서 직접 접근할 수 없고, getter/setter를 통해서만 접근 가능합니다.

#### 생성자 (Constructor)

```java
public Student(String name, int age, int studentId) {
    this.name = name;
    this.age = age;
    this.studentId = studentId;
}
```

- 학생 객체를 생성할 때 이름, 나이, 학번을 초기화합니다.
- `this` 키워드를 사용하여 인스턴스 변수와 매개변수를 구분합니다.

#### Getter/Setter 메서드

```java
public String getName() {
    return name;
}

public void setName(String name) {
    this.name = name;
}

// age, studentId에 대해서도 동일한 패턴
```

- **Getter**: 필드 값을 읽어오는 메서드
- **Setter**: 필드 값을 설정하는 메서드
- 캡슐화 원칙에 따라 필드에 직접 접근하지 않고 메서드를 통해 접근합니다.

#### toString() 메서드

```java
@Override
public String toString() {
    return "Student [ name = "+name+", age = "+age+", studentId = "+studentId+"]";
}
```

- 객체를 문자열로 표현하는 메서드입니다.
- `@Override` 어노테이션으로 부모 클래스(Object)의 `toString()` 메서드를 재정의합니다.
- 출력 시 객체의 정보를 보기 좋게 표시합니다.

**출력 형식:** `Student [ name = 홍길동, age = 20, studentId = 2024001]`

### 2. Main1 클래스

**역할:** 프로그램의 진입점과 주요 로직을 담당하는 클래스

#### main 메서드

**전체 흐름:**

```java
public static void main(String[] args) {
    // 1단계: 학생 수 입력
    Scanner sc = new Scanner(System.in);
    System.out.print("학생 수 입력 :");
    int n = sc.nextInt();
    sc.nextLine();  // 개행 문자 소비

    // 2단계: 학생 배열 생성
    Student[] students = new Student[n];
    
    // 3단계: 학생 정보 입력
    for (int i = 0; i < n; i++) {
        System.out.print("학생 이름: ");
        String name = sc.nextLine();
        System.out.print("학생 나이: ");
        int age = sc.nextInt();
        System.out.print("학생 학번: ");
        int studentId = sc.nextInt();
        sc.nextLine(); // 개행 문자 소비

        students[i] = new Student(name, age, studentId);
    }

    // 4단계: 삽입 정렬 수행
    InsertionSort(students);

    // 5단계: 정렬된 결과 출력
    System.out.println("정렬된 학생 목록:");
    for (Student student : students) {
        System.out.println(student);
    }

    sc.close(); // Scanner 닫기
}
```

#### 단계별 상세 설명

**1단계: 학생 수 입력**
```java
int n = sc.nextInt();
sc.nextLine();  // 개행 문자 소비
```
- `nextInt()`로 정수를 읽은 후, 버퍼에 남아있는 개행 문자(`\n`)를 제거합니다.
- 다음 `nextLine()` 호출 시 문제가 발생하지 않도록 합니다.

**2단계: 학생 배열 생성**
```java
Student[] students = new Student[n];
```
- 입력받은 학생 수만큼 Student 객체를 저장할 배열을 생성합니다.
- 배열의 각 요소는 `null`로 초기화됩니다.

**3단계: 학생 정보 입력**
```java
for (int i = 0; i < n; i++) {
    String name = sc.nextLine();
    int age = sc.nextInt();
    int studentId = sc.nextInt();
    sc.nextLine(); // 개행 문자 소비
    
    students[i] = new Student(name, age, studentId);
}
```

**주의사항:**
- `nextInt()` 후에는 반드시 `nextLine()`을 호출하여 개행 문자를 소비해야 합니다.
- 그렇지 않으면 다음 입력에서 문제가 발생할 수 있습니다.

**입력 순서:**
1. 이름 (문자열) → `nextLine()`
2. 나이 (정수) → `nextInt()`
3. 학번 (정수) → `nextInt()`
4. 개행 문자 소비 → `nextLine()`

**4단계: 정렬된 결과 출력**
```java
for (Student student : students) {
    System.out.println(student);
}
```
- 향상된 for문(Enhanced For Loop)을 사용합니다.
- `System.out.println(student)`는 자동으로 `student.toString()`을 호출합니다.

## 삽입 정렬 알고리즘

### 알고리즘 개요

**삽입 정렬(Insertion Sort)**은 배열의 각 요소를 이미 정렬된 부분에 적절한 위치에 삽입하는 방식으로 정렬하는 알고리즘입니다.

**특징:**
- 구현이 간단하고 이해하기 쉬움
- 작은 데이터셋에 효율적
- 안정 정렬(Stable Sort)
- 시간 복잡도: O(n²) (최악의 경우), O(n) (이미 정렬된 경우)

### 알고리즘 동작 원리

```java
private static void InsertionSort(Student[] students) {
    int n = students.length;
    
    // i는 현재 정렬할 요소의 인덱스 (1부터 시작)
    for(int i = 1; i < n; i++){
        Student currentStudent = students[i];  // 현재 정렬할 학생
        int j = i-1;  // 이미 정렬된 부분의 마지막 인덱스
        
        // 알파벳순으로 비교하여 적절한 위치 찾기
        while (j >= 0 && students[j].getName().compareTo(currentStudent.getName()) > 0) {
            students[j+1] = students[j];  // 오른쪽으로 한 칸 이동
            j--;  // 왼쪽으로 이동
        }
        
        students[j+1] = currentStudent;  // 적절한 위치에 삽입
    }
}
```

### 단계별 동작 과정

**예시:** `["Charlie", "Alice", "Bob"]` 배열을 정렬하는 과정

**초기 상태:**
```
인덱스:  0        1       2
배열:  [Charlie, Alice,  Bob]
```

**1단계: i=1 (Alice 정렬)**
```
currentStudent = Alice
j = 0

비교: Charlie.compareTo(Alice) > 0  → true
      "Charlie" > "Alice" (알파벳 순서상 C가 A보다 뒤)

이동: students[1] = students[0]  → [Charlie, Charlie, Bob]
      j = -1

삽입: students[0] = Alice  → [Alice, Charlie, Bob]
```

**2단계: i=2 (Bob 정렬)**
```
currentStudent = Bob
j = 1

비교: Charlie.compareTo(Bob) > 0  → true
      "Charlie" > "Bob" (C가 B보다 뒤)

이동: students[2] = students[1]  → [Alice, Charlie, Charlie]
      j = 0

비교: Alice.compareTo(Bob) > 0  → false
      "Alice" < "Bob" (A가 B보다 앞)

삽입: students[1] = Bob  → [Alice, Bob, Charlie]
```

**최종 결과:**
```
인덱스:  0      1      2
배열:  [Alice, Bob, Charlie]
```

### compareTo() 메서드 이해

```java
students[j].getName().compareTo(currentStudent.getName()) > 0
```

**String.compareTo() 메서드:**
- 두 문자열을 사전식(알파벳) 순서로 비교합니다.
- 반환값:
  - **음수**: 호출한 문자열이 매개변수보다 앞에 옴 (작음)
  - **0**: 두 문자열이 같음
  - **양수**: 호출한 문자열이 매개변수보다 뒤에 옴 (큼)

**예시:**
```java
"Alice".compareTo("Bob")   → 음수 (Alice가 앞)
"Bob".compareTo("Alice")   → 양수 (Bob이 뒤)
"Alice".compareTo("Alice") → 0 (같음)
```

**조건식 해석:**
```java
students[j].getName().compareTo(currentStudent.getName()) > 0
```
- `students[j]`의 이름이 `currentStudent`의 이름보다 **뒤에 있으면** (알파벳 순서상 크면)
- `true`를 반환하여 요소를 오른쪽으로 이동시킵니다.

## 핵심 개념 정리

### 1. 삽입 정렬 (Insertion Sort)

**정의:**
- 배열의 각 요소를 이미 정렬된 부분에 적절한 위치에 삽입하는 정렬 알고리즘

**특징:**
- **시간 복잡도:**
  - 최선: O(n) - 이미 정렬된 경우
  - 평균: O(n²)
  - 최악: O(n²) - 역순으로 정렬된 경우
- **공간 복잡도:** O(1) - 추가 메모리 사용 없음
- **안정 정렬:** 같은 값의 요소들의 상대적 순서 유지

**적용 시나리오:**
- 작은 데이터셋 (n < 50)
- 거의 정렬된 데이터
- 실시간 데이터 스트림

### 2. String.compareTo() 메서드

**용도:** 두 문자열을 사전식 순서로 비교

**반환값:**
- 음수: 호출한 문자열이 매개변수보다 앞
- 0: 두 문자열이 같음
- 양수: 호출한 문자열이 매개변수보다 뒤

**예시:**
```java
"Apple".compareTo("Banana")  → 음수
"Banana".compareTo("Apple")  → 양수
"Apple".compareTo("Apple")   → 0
```

**주의사항:**
- 대소문자를 구분합니다 (`"A" < "a"`)
- 한글도 유니코드 순서로 비교됩니다

### 3. Scanner의 nextInt()와 nextLine() 혼용

**문제점:**
```java
int n = sc.nextInt();      // 정수 입력 후 Enter 키 입력
String name = sc.nextLine(); // Enter 키가 버퍼에 남아있어 빈 문자열 읽음
```

**해결책:**
```java
int n = sc.nextInt();
sc.nextLine();  // 개행 문자 소비
String name = sc.nextLine();  // 정상적으로 입력 받음
```

**이유:**
- `nextInt()`는 정수만 읽고 개행 문자(`\n`)는 버퍼에 남김
- `nextLine()`은 개행 문자까지 읽어서 제거해야 함

### 4. 향상된 for문 (Enhanced For Loop)

**기본 for문:**
```java
for (int i = 0; i < students.length; i++) {
    System.out.println(students[i]);
}
```

**향상된 for문:**
```java
for (Student student : students) {
    System.out.println(student);
}
```

**장점:**
- 코드가 간결함
- 인덱스 관리 불필요
- 배열의 모든 요소를 순회할 때 유용

**단점:**
- 인덱스가 필요한 경우 사용 불가
- 배열의 요소를 수정할 때는 기본 for문이 더 적합

### 5. toString() 메서드

**역할:** 객체를 문자열로 표현

**자동 호출:**
```java
Student s = new Student("Alice", 20, 2024001);
System.out.println(s);  // 자동으로 s.toString() 호출
```

**재정의 이유:**
- 기본 `toString()`은 `클래스명@해시코드` 형식으로 출력
- 의미 있는 정보를 출력하기 위해 재정의 필요

## 개선 가능한 부분

### 1. 대소문자 구분 없이 정렬

**현재 코드:**
```java
students[j].getName().compareTo(currentStudent.getName()) > 0
```

**개선 코드:**
```java
students[j].getName().compareToIgnoreCase(currentStudent.getName()) > 0
```

**효과:** "Alice"와 "alice"를 같은 것으로 취급하여 정렬

### 2. 정렬 기준 선택 기능 추가

**개선 예시:**
```java
// 이름으로 정렬
InsertionSort(students, "name");

// 나이로 정렬
InsertionSort(students, "age");

// 학번으로 정렬
InsertionSort(students, "studentId");
```

### 3. 오름차순/내림차순 선택

**개선 예시:**
```java
InsertionSort(students, "name", true);   // 오름차순
InsertionSort(students, "name", false);  // 내림차순
```

### 4. 입력 검증 추가

**개선 예시:**
```java
System.out.print("학생 나이: ");
int age = sc.nextInt();
if (age < 0 || age > 150) {
    System.out.println("올바른 나이를 입력하세요!");
    i--;  // 다시 입력받기
    continue;
}
```

### 5. 예외 처리 추가

**개선 예시:**
```java
try {
    int n = sc.nextInt();
    if (n <= 0) {
        throw new IllegalArgumentException("학생 수는 양수여야 합니다.");
    }
} catch (InputMismatchException e) {
    System.out.println("숫자를 입력해주세요!");
    sc.nextLine();  // 잘못된 입력 제거
}
```

### 6. 메서드명 네이밍 컨벤션

**현재:**
```java
private static void InsertionSort(Student[] students)
```

**개선:**
```java
private static void insertionSort(Student[] students)
```

**이유:** Java 네이밍 컨벤션에 따르면 메서드명은 소문자로 시작해야 합니다.
