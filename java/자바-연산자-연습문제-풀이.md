## 문제 1. 덧셈

### 풀이

```java
public class Main {

    public static void main(String[] args) {

        int num1 = 10;
        int num2 = 20;

        System.out.println(num1 + num2);

    }

}
```

### 출력

```
30
```

## 문제 2. 사칙연산

### 풀이

```java
public class Main {

    public static void main(String[] args) {

        int num1 = 30;
        int num2 = 5;

        System.out.println(num1 + num2);
        System.out.println(num1 - num2);
        System.out.println(num1 * num2);
        System.out.println(num1 / num2);

    }

}
```

### 출력

```
35
25
150
6
```

## 문제 12. 시간 계산

### 풀이

```java
public class Main {

    public static void main(String[] args) {

        int second = 3670;

        int hour = second / 3600;
        int minute = (second % 3600) / 60;
        int sec = second % 60;

        System.out.println(hour + "시간");
        System.out.println(minute + "분");
        System.out.println(sec + "초");

    }

}
```

### 출력

```
1시간
1분
10초
```

## 문제 14. 할인 가격

### 풀이

```java
public class Main {

    public static void main(String[] args) {

        int price = 100000;

        int discount = price * 20 / 100;

        int result = price - discount;

        System.out.println("할인 금액 : " + discount);
        System.out.println("최종 금액 : " + result);

    }

}
```

### 출력

```
할인 금액 : 20000
최종 금액 : 80000
```
