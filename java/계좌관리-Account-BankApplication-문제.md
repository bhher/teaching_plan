# 20. 계좌 관리 프로그램 (Account / BankApplication)

키보드로부터 계좌 정보를 입력받아 계좌를 관리하는 프로그램입니다.

- 계좌는 **`Account` 객체**로 생성됩니다.
- `BankApplication`에서 길이 **100**인 **`Account[]` 배열**로 관리합니다.
- 실행 결과를 보고 `Account`와 `BankApplication` 클래스를 작성하세요.
- 키보드 입력은 **`Scanner`의 `nextLine()`** 메소드를 사용합니다.

---

## 메뉴

```text
----------------------------------------------------------
1.계좌생성 | 2.계좌목록 | 3.예금 | 4.출금 | 5.종료
----------------------------------------------------------
선택>
```

## 클래스 설계 힌트

### Account 클래스

| 필드 | 타입 | 설명 |
|------|------|------|
| `ano` | `String` | 계좌번호 |
| `owner` | `String` | 계좌주 |
| `balance` | `int` | 잔액 |

- 생성자, Getter / Setter 작성

### BankApplication 클래스

```java
private static Account[] accountArray = new Account[100];
private static Scanner scanner = new Scanner(System.in);
```

| 메서드 | 역할 |
|--------|------|
| `main` | 메뉴 반복 |
| `createAccount()` | 계좌 생성 |
| `accountList()` | 계좌 목록 |
| `deposit()` | 예금 |
| `withdraw()` | 출금 |
| `findAccount(String ano)` | 계좌번호로 계좌 찾기 |

### 잔액 변화 확인

| 계좌 | 초기 | 예금/출금 | 최종 |
|------|------|-----------|------|
| 111-111 홍길동 | 10000 | +5000 | **15000** |
| 111-222 강자바 | 20000 | -3000 | **17000** |

---

## 입력 주의

- 모든 입력은 `scanner.nextLine()` 사용
- 숫자(메뉴, 금액)는 `Integer.parseInt(scanner.nextLine())`로 변환

```java
int money = Integer.parseInt(scanner.nextLine());
```
