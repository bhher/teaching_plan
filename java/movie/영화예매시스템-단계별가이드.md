## 💡 디버깅 팁

1. **인덱스 오류**: 좌석 번호는 1부터 시작하지만 ArrayList 인덱스는 0부터 시작
2. **리스트 삭제 오류**: 리스트를 순회하면서 삭제할 때는 뒤에서부터
3. **파일 경로**: Windows 경로는 `\\` 사용
4. **Scanner**: `nextInt()` 후 `nextLine()`으로 개행 문자 처리
5. **정적 변수**: `reservationCounter`는 모든 User 객체가 공유
