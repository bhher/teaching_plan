# 영화 예매 시스템 실습 문제

## 📋 문제 개요

영화 예매 시스템을 단계별로 구현하여 객체지향 프로그래밍과 Java의 핵심 개념을 학습합니다.

---

## 🎯 학습 목표

1. 클래스 설계 및 객체지향 프로그래밍 이해
2. ArrayList를 활용한 데이터 관리
3. 파일 입출력 (File I/O) 구현
4. 예외 처리 (Exception Handling)
5. 객체 간 관계 이해 (Composition, Aggregation, Dependency)
