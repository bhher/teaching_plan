## 1. 한눈에 보기

| 종류 | 대표 클래스 | 순서 | 중복 | 접근 |
|------|-------------|------|------|------|
| **List** | `ArrayList` | O | O | 인덱스 `get(i)` |
| **Set** | `HashSet` | X (Hash) | X | 포함 여부 `contains` |
| **Map** | `HashMap` | X (Hash) | 키 중복 X | 키로 `get(key)` |

```text
배열: 크기 고정, int[] 등
컬렉션: 크기 가변, 객체만 저장 (제네릭)

ArrayList<String> list = new ArrayList<>();
```

### 언제 무엇을?

| 하고 싶은 일 | 선택 |
|--------------|------|
| 목록, 순서, CRUD | `ArrayList` |
| 중복 제거, 회원 ID 집합 | `HashSet` |
| 학번→점수, 상품코드→재고 | `HashMap` |
| 입력 순서 유지 Set | `LinkedHashSet` |
| 자동 정렬 | `TreeSet` / `TreeMap` |

## 2. List — 설명 + 예제

### 설명

- **순서 있음**, **중복 가능**, **인덱스**로 꺼냄
- `ArrayList`: 조회 빠름 → 수업·실무에서 가장 많이 사용

### 핵심 메서드

```java
list.add("사과");           // 추가
list.add(0, "딸기");        // 인덱스에 삽입
list.get(0);                // 꺼내기
list.set(0, "수박");        // 수정
list.remove(0);             // 인덱스로 삭제
list.remove("사과");        // 값으로 삭제
list.size();
list.contains("사과");
list.indexOf("사과");
```

### 미니 예제 (콘솔)

```text
[딸기, 사과, 바나나]
0번: 딸기
포함? true
```

→ `ListExample.java`

## 3. Set — 설명 + 예제

### 설명

- **중복 저장 안 됨** (같은 값 `add` 해도 한 번만)
- `HashSet`: 순서 보장 안 함
- `LinkedHashSet`: 넣은 순서 유지

### 핵심 메서드

```java
set.add("사과");
set.add("사과");      // 무시됨, size 그대로
set.contains("사과");
set.remove("사과");
```

### 미니 예제

```text
원본 리스트: [A, B, A, C, B]
중복 제거: [A, B, C]  (HashSet — 순서 달라질 수 있음)
```

→ `SetExample.java`

## 4. Map — 설명 + 예제

### 설명

- **키 → 값** 한 쌍
- 키는 중복 불가, 값 중복 가능
- `put` / `get` / `containsKey` / `keySet` / `entrySet`

### 핵심 메서드

```java
map.put("홍길동", 90);
map.get("홍길동");              // 90
map.getOrDefault("이순신", 0); // 없으면 0
map.containsKey("홍길동");
map.remove("홍길동");

for (String key : map.keySet()) { ... }
for (Map.Entry<String, Integer> e : map.entrySet()) {
    e.getKey(); e.getValue();
}
```

### 미니 예제 — 단어 개수

```text
사과: 3번
바나나: 2번
```

→ `MapExample.java`

## 5. 실전 예제 — 학원 수강 · 좌석 관리

한 프로그램에서 **List + Set + Map** 을 같이 씁니다.

| 컬렉션 | 용도 |
|--------|------|
| `ArrayList<String> courses` | 개설 강좌 목록 (순서) |
| `HashMap<String, Integer> seats` | 강좌명 → 남은 좌석 |
| `HashSet<String> enrolled` | 수강 신청한 **학생ID** (중복 신청 방지) |
| `HashMap<String, String> whoTook` | 학생ID → 수강한 강좌 |

### 시나리오

1. 강좌 3개 등록 + 좌석 수 설정  
2. 학생 수강 신청 (좌석 감소, ID 중복이면 거절)  
3. 전체 강좌·잔여 좌석 출력  
4. 수강생 명단 출력  

→ `CollectionPractice.java`

## 6. List vs Set vs Map 한 줄

```text
List  = 줄 서서 번호 붙인 명단
Set   = 중복 입장 금지 명찰
Map   = 사물함 (열쇠=키, 내용=값)
```

```java
// List — 점수 나열
ArrayList<Integer> scores = new ArrayList<>();

// Set — 출석한 학번 (중복 X)
HashSet<String> attend = new HashSet<>();

// Map — 학번으로 점수 찾기
HashMap<String, Integer> scoreMap = new HashMap<>();
```

## 7. 자주 하는 실수

| 실수 | 고치기 |
|------|--------|
| `list.get(list.size())` | 인덱스는 `0 ~ size()-1` |
| Map을 for-each로 값만 돌리기 | `keySet()` 또는 `entrySet()` |
| Set에 순서 기대 | `LinkedHashSet` 사용 |
| `map.get(없는키)` → null | `containsKey` 또는 `getOrDefault` |
| 기본형 `ArrayList<int>` | `ArrayList<Integer>` (래퍼) |
