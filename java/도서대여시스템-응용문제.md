# 도서 대여 시스템 실습 문제 (응용)

## 문제 설명

커피 주문 시스템을 참고하여 도서 대여 시스템을 구현하세요.

### 요구사항

1. **싱글톤 패턴 사용**
   - Book 클래스를 싱글톤 패턴으로 구현
   - 도서 목록을 한 곳에서 관리

2. **도서 메뉴 관리**
   - 도서 제목과 대여 가격을 LinkedHashMap에 저장
   - 메뉴 출력 시 번호와 함께 표시
   - DecimalFormat으로 가격 포맷팅

3. **대여 기능**
   - 사용자가 도서 번호와 대여 기간 입력
   - 같은 도서를 여러 번 대여하면 기간 누적
   - 재대여 기능 구현

4. **대여 내역 및 결제**
   - 대여한 도서 목록과 총 금액 출력
   - 잔액 확인 및 결제 처리
   - Thread.sleep()으로 대여 처리 시간 시뮬레이션

5. **완료 메시지**
   - 대여 완료 후 안내 메시지 출력

## 구현 단계

### Step 1: Book.java (싱글톤 패턴)

**요구사항:**
- 싱글톤 패턴으로 구현
- LinkedHashMap으로 도서 목록 관리
- DecimalFormat으로 가격 포맷팅
- 메뉴 출력 메서드 구현

### Step 2: Member.java (회원 정보)

**요구사항:**
- 회원 번호
- 잔액 (초기값 30000원)
- 대여 내역 (Map)

### Step 3: BookService.java (대여 서비스)

**요구사항:**
- 대여 받기
- 재대여 기능
- 대여 내역 출력
- 결제 처리
- 완료 메시지

### Step 4: BookRentalImpl.java (메인 클래스)

**요구사항:**
- 프로그램 진입점
- BookService 시작

## 추가 도전 문제

### 문제 1: 연체료 계산

- 대여 기간이 7일을 넘으면 연체료 부과
- 연체료: 1일당 500원
- 총 금액에 연체료 포함

### 문제 2: 할인 기능

- 총 대여 금액이 10000원 이상이면 10% 할인
- 총 대여 금액이 20000원 이상이면 15% 할인

### 문제 3: 대여 취소 기능

- 대여 내역을 보여주고 취소할 도서 선택
- 대여 기간을 입력받아 해당 기간만큼 차감

### 문제 4: 도서 검색 기능

- 도서명으로 검색
- 검색 결과에서 바로 대여 가능
